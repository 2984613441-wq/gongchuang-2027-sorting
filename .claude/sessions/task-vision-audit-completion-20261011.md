## 关键发现

### 发现1：形状识别根本不存在

**证据**：`stage1_color_v6_send.py:409` 原文 
```python
shape, bin_id = COLOR_TO_MATERIAL[color]  # 查色表查出来的
```

**影响**：省赛"同色同形同盒"规则 → 纯颜色识别必然失分

**解决方案**：ToF深度融合（已设计+测试完成，待实测）

### 发现2：正四面体不在YOLO 7类中

**证据**：
- `视觉/TRAINING.md:25-31` — 7类无`regular_tetrahedron`
- `省赛规则.txt:139-141` — 示例含正四面体

**影响**：若省赛出现正四面体 → 识别为`unknown` → 0分

**解决方案**：补采200+张 → 重训8类模型（3.5天）

### 发现3：三组"俯视相同"歧义

| 歧义组 | YOLO能力 | ToF方案 | 状态 |
