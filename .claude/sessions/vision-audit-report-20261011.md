#### P0-1：正四面体不在YOLO类别中

**风险**：赛规示例显示"正四面体"，但现有模型只有7类（不含它）

**证据**：
- `视觉/TRAINING.md:25-31` — 7类列表无`regular_tetrahedron`
- `视觉/models/labels_yolo5s_geom7c.txt` — 7行类名
- `docs/references/赛题原文-提取文本/省赛规则.txt:139-141` — 示例含正四面体

**影响**：省赛若出现正四面体 → 识别为`unknown` → 分错盒 → 0分

**缓解方案**：
1. **补采数据**：正四面体至少200张（6面×多角度）
2. **重训模型**：7类→8类，重新导出`.onnx`
3. **验证测试**：`test_yolo_eight_classes.py`
4. **更新labels**：`labels_yolo5s_geom8c.txt`

**时间**：数据采集2天 + 训练1天 + 验证0.5天 = 3.5天

**负责人建议**：AI工程师（优先级最高）

#### P0-3：置信度阈值不一致

**风险**：两处配置不同 → 生产行为不明确

**证据**：
- `视觉/src/sorting_vision/config.py:15` — `CONFIDENCE_THRESHOLD = 0.50`
- `视觉/examples/vision_loop_template.py:31` — `if conf < 0.35: continue`

**影响**：0.35-0.50之间的检测 → 行为不确定 → 可能误检或漏检

**缓解方案**：
1. **统一阈值**：全局使用`config.CONFIDENCE_THRESHOLD`
2. **删除硬编码**：`vision_loop_template.py` 改为读配置
3. **测试验证**：`test_confidence_threshold.py`

**时间**：0.5天

**负责人建议**：代码质量工程师
