# 模板索引

所有协作文档必须使用以下统一模板。L1 可简化，L2+ 必须完整填写。

| 模板 | 文件 | 适用等级 | 填写时机 |
|------|------|---------|---------|
| 任务书 | [task-template.md](task-template.md) | L1-L4 | 任务开始前 |
| 交接记录 | [handoff-template.md](handoff-template.md) | L2-L4 | 任务完成/转交时 |
| 审核记录 | [review-template.md](review-template.md) | L2-L4 | 产出进入主分支前 |
| 经验条目 | [experience-template.md](experience-template.md) | L2-L4 | 任务完成后 24h 内 |

## 文件命名规范

```
任务书：   .claude/tasks/TASK-YYYYMMDD-NNN.md
交接记录： .claude/tasks/TASK-YYYYMMDD-NNN-handoff.md
审核记录： .claude/reviews/REVIEW-YYYYMMDD-NNN.md
经验条目： .claude/experiences/EXP-YYYYMMDD-NNN.md
```
