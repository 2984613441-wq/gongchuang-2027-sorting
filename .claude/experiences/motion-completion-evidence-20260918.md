# 运动完成排查：已验证经验（非实机根因）

- 情境：2026-09-18 主机审查“动作结束但零完成帧、5～10.6 秒 FAULT”，交付摘要按 500 Hz 推算约 11.3 秒。
- 行动：实际编译 Board ISR、Axis、Plan、App、Gateway 和诊断代码，仅替换 HAL；逐腿累加真实 Profile ARR，分别运行正常与单变量故障注入，并执行 Keil rebuild。
- 结果：当前顺序规划恒速预算 16.88 秒，真实曲线理想预算 6.42508 秒，主机轮询 6.428 秒两帧各一次；Keil 0 error / 0 warning。现场 SSH 超时，未做实机操作，未定案现场根因。
- 适用规则：预算要沿调用链追到底层真实曲线；诊断 DONE 走独立回调，不能自动证明生产 completion latch 被消费；时间相符的故障注入只能证明候选相容，不能证明现场因果。
- 证据与边界：`docs/reports/运动完成上报-根因-2026-09-18.md` 及同目录 `motion-completion-20260918/` 原始输出。主机 HAL 不含硬件中断延迟、UART 实际成功与机械反馈；这些结果不可表述为实机通过。
