# TASK-20260818-001：X/Y 与 PB10 舵机受控组合动作

> 等级：L4（多执行器调度，后续涉及实机上电）  
> 当前阶段：代码方案与主机侧验证；不授权接线、上电、烧录或实体运动  
> 任务边界：当前对话仅负责 STM32 主控；视觉仍由独立对话负责

## 原始需求

用户要求按既定协作流程，由 Codex 实现 X、Y 与“Z轴”同步测试代码，并给出引脚和后续指令。此处“Z轴”按当前已验证机构解释为 PB10 数字舵机夹爪，而不是 PE5/TIM9_CH1 的旧 Z 步进通道。

## 表面问题与真正问题

- 表面问题：增加一条命令，让 X、Y 步进与 PB10 舵机一起动作。
- 真正问题：在不破坏既有单轴测试和安全互锁的前提下，增加一个一次授权、固定时长、遇故障立即全部停止的组合状态机，并明确它只能做到软件顺序启动的“近同时”，不能宣称硬件定时器严格同步。

## 目标状态

1. 新增独立组合状态机和诊断命令；既有 `MOTION`、`MOVE`、`SERVO`、`STOP ALL` 行为保持不变。
2. 固定语义：`OPEN=1000 us`、`CLOSE=1900 us`；不允许组合命令携带任意 PWM 数值。
3. X/Y 方向只能选择 `DIR0` 或 `DIR1`；运行最长 2 秒。
4. 组合授权有效 10 秒且一次性消费；九路输入中任一路导致 `ACTIVE != 0`、串口异常、显式停止或内部启动失败时，均停止 X/Y STEP、禁用驱动并停止 PB10 PWM。
5. 与现有单轴步进/舵机测试双向互斥，不自动重试。

## 事实、推断与未知

### 已确认事实

- X：STEP PC6/TIM8_CH1，DIR PA7，ENABLE PA5（低有效）。
- Y：STEP PB6/TIM4_CH1，DIR PC7，ENABLE PD7（低有效）。
- 舵机：PWM PB10/TIM2_CH3，50 Hz。
- 用户实测舵机 `1000 us` 为合适最大开口，`1900 us` 为闭合。
- 当前固件已有一次性授权、2 秒停止、安全输入中止和 `STOP ALL` 基础能力；组合动作采用更严格条件，直接要求完整九路 `ACTIVE == 0`。

### 推断

- “三轴同步”解释为在同一次命令中启动 X、Y 与 PB10 舵机。由于三路外设通过软件依次调用，验收口径为“同一轮询周期内近同时启动”，不是相位对齐或同一计数器边沿启动。

### 未知

- X/Y 的真实机械 DIR0/DIR1 方向与组合动作应采用的最终方向。
- 多执行器同时启动时的电源压降、峰值电流、机械干涉和真实启动时间差。
- 驱动板外部 ENABLE/STEP 默认电阻和 SLEEP/RESET 失效安全是否已落实。

## 关键约束与风险

- 当前存在两个独立 P0 缺口：所有非隔离控制信号必须可靠共地；MCU 复位/烧录高阻窗口还需驱动侧 ENABLE 默认禁能、STEP 默认不活动。两者未实测关闭前，禁止多执行器同时上电。
- 本轮不得改变 GPIO/定时器映射，不得声称主机测试等于串口、波形或实体动作通过。
- `STOP ALL` 不是物理急停；实机测试必须另行明确授权并保留可直接切断执行器动力的手段。

## 节点能力建议与决策边界

- 主代理：独立审查差异、运行严格主机测试、检查 Keil 工程接入和构建证据。
- 用户：决定真实 X/Y 方向、确认 P0 硬件门禁、授权后续烧录和实体同步试验。

## 预期接口

```text
GROUP ARM
GROUP START XDIR0 YDIR0 OPEN
GROUP START XDIR0 YDIR0 CLOSE
GROUP STOP
```

方向组合应覆盖 XDIR0/1 与 YDIR0/1。命令必须完整精确匹配。

## 最小验证行动

1. 严格主机编译：`-std=c11 -Wall -Wextra -Werror -pedantic`。
2. 单元测试覆盖：授权成功/过期/一次性消费、四种方向组合、OPEN/CLOSE、1999/2000 ms 边界、安全输入中止、已有 STEP/SERVO 忙时拒绝、组合运行时反向拒绝单轴命令、启动部分失败后的全停、`GROUP STOP`、`STOP ALL`、串口超长/溢出全停。
3. 回归现有全部主机测试。
4. Keil 工程必须只接入一次新增源文件并构建到 `0 Error(s), 0 Warning(s)`；若本机无法构建，应明确记录未验证。
5. 实体测试不属于本轮验收；需 P0 关闭和用户单独授权后执行。
