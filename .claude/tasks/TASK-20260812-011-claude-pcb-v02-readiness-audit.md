## 4. 已确认事实与不得越过的边界

- 主控是正点原子探索者 STM32F407ZGT6 开发板，自制 PCB 是可拆卸载板/接口板，不重复集成 MCU、晶振、下载器或板载 USB 串口。
- X/Y 电机型号为 `17HS4401`：NEMA17、1.8°、1.7 A/相、40 N·cm；供应商完整电气/机械资料、实物线序及实际负载仍待补齐。
- 夹爪型号为 `DS3120MG`，采用 PWM 开合，旋转默认关闭；精确 PWM 范围、堵转电流、夹持行程和断电状态仍需对应实物资料及台架确认。
- A4988 只是 X/Y 的候选、默认 DNP 模块位。芯片或通用模块宣传值不能替代具体模块版本、采样电阻、限流、热设计及实物测试证据。
- 用户已裁决方案 A：`J_DRV_X_CTRL`、`J_DRV_Y_CTRL` 默认 DNP，提供 `STEP/DIR/ENABLE/GND_LOGIC` 及可选反馈；对应 A4988 与板外驱动器必须二选一，不得同时连接或共同驱动同一电机。
- Z 轴只预留通用 `STEP/DIR/ENABLE` 及可选反馈。具体执行器、驱动器、动力、制动和断电防坠仍未知且全部位于载板外。
- 整机只有一套内部电源；逻辑与危险动力分路。载板不集成主电源入口/保护、高电流 DC/DC、舵机功率分配、急停接触器/继电器、补光功率开关或 Z 轴功率驱动器。
- 急停使用独立硬件，只切危险动力正极，不切公共参考地；逻辑保持供电以诊断。解除急停不得自动恢复危险动力或旧任务。
- `ESTOP_FB` 只读状态，不替代急停主回路。
- `BARRIER_READY` 不能因为发送了 PWM 就成立。当前只预留 `J_BARRIER_READY_IN` / `J_AUX_IN_n`，最终传感器或经验证时序判据仍未确定。
- MCU 排针/GPIO、A4988 实物针序/封装、具体电源/保护/连接器参数、铜厚线宽、挡板舵机、限位和多个机械参数仍不得写死。

若其他文档与以上事实冲突，应报告冲突，而不是自行选择一个版本静默覆盖。

## 6. 全面 PCB 工程审核清单

### 6.1 接口和网络

- 对 X/Y/Z 的 `STEP`、`DIR`、`ENABLE`、反馈、电机和动力网络逐项检查，确认不跨轴误并网。
- 检查 `J_DRV_X_CTRL` / `J_DRV_Y_CTRL` 与 A4988 候选插座是否只共享经过评审的低能量控制源，且文档明确物理装配/供能互斥。
- 检查板外驱动器的动力输入、电机输出、保护和可能的隔离是否明确留在载板外。
- 检查 `J_ESTOP_FB`、`J_BARRIER_READY_IN`、限位/原点、启动、人工复位、舵机、夹爪、补光、通信及测试接口的信号方向、参考地和未知项是否自洽。
- 检查是否存在同名标签导致逻辑电源、舵机动力、A4988 危险动力、补光电源或不同轴网络误并的风险。

### 6.2 失电、上电和安全状态

- 检查 `ENABLE`、`RESET`、`SLEEP`、PWM 和外接驱动接口在 MCU 未上电、复位、连接器未装或外部模块单独供电时的默认状态是否被正确标为待资料/待审查，而非未经证据给定。
- 检查反向供电、地参考漂移和从信号脚寄生供电风险是否进入后续门禁。
- 检查急停边界是否始终是“独立硬件切危险动力正极、公共参考地连续、逻辑保电、释放不自动恢复”。
- 检查 Z 轴断电防坠尚未确定时，文档是否阻止动力回路或原理图冻结。

### 6.3 电源、信号完整性和保护

- 检查载板是否越权集成本应板外的高能量功能。
- 检查去耦、储能、ESD/TVS、串阻、RC、上拉/下拉、电平转换和隔离是否保持“器件位/待参数”，并要求以最终接口资料、计算和波形为依据。
- 检查动力回流、逻辑回流、传感参考、屏蔽/机壳连接的文字是否互相矛盾，是否错误建议随意分割地平面。
- 检查高能量网络是否禁止使用可随意触及的普通测试焊盘。
- 检查是否把 GPIO、电压、保险、端子额定、线宽、铜厚、过孔数量或器件封装写成无来源定值。

### 6.4 KiCad 与制造准备

- 检查 `00` 至 `09` 页或主方案对应分页是否完整覆盖：层级、MCU 载板、逻辑电源/输入保护、X/Y 候选驱动、板外驱动、舵机/夹爪/补光、安全输入、通信/测试、连接器台账。
- 检查 Explorer 开发板连接符号/封装、安装孔、板边禁布、USB/SWD 可达性是否明确要求官方资料和 1:1 实物核对。
- 检查 A4988 候选模块封装是否要求按实际模块尺寸、针序、方向、调流位置、散热器和插拔空间核对。
- 检查连接器台账是否要求对端、方向、针序、防呆、线束、额定、失电态和版本字段。
- 检查 ERC、网络审查、封装 1:1、机械协同、间距/爬电、制造规则、BOM/装配字段、丝印和测试计划是否作为后续门禁存在。

总体审核不得只写一个笼统的“通过”。必须分别给出：

| 门槛 | 可选裁决 | 含义 |

## 8. 发现项分级

- **P0**：可能直接破坏急停、安全边界、产生共驱/误动作/危险供电，或把未验证设计误判为可投板。
- **P1**：会导致原理图关键网络、针序、模块互斥、供电/参考或关键接口错误，阻止进入下一门槛。
- **P2**：跨文档不一致、状态标签错误、门禁遗漏、可维护性或可验证性不足，但当前不直接形成危险动作。

每个发现必须包含：编号、等级、文件与行号、事实依据、具体风险、最小修正建议、影响的 G1-G4 门槛、建议分类（接受/拒绝/待供应商或机械输入）。没有证据不要创建问题；没有问题时明确写“未发现”。
