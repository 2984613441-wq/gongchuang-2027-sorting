## 3. 求是检查

- **事实**：X/Y 电机为 `17HS4401`；A4988 仍是候选/DNP；X/Y 板外驱动接口默认 DNP，并与对应 A4988 二选一。
- **事实**：载板仅向板外驱动器提供低能量控制/可选反馈；板外驱动器动力、电机输出和保护均在载板外。
- **事实**：急停独立硬件仅切危险动力正极，不切公共参考地；逻辑继续供电；释放后不自动恢复动力或旧任务。
- **未知**：MCU 排针/GPIO、A4988 实物针序和封装、电源/保护/连接器参数、铜厚线宽、Z 轴驱动与防坠、挡板就绪判据仍未冻结。
- **限制**：设计文件当前未被 Git 跟踪，普通 `git diff` 不能证明其内容变更；因此另以关键词矩阵、旧措辞反查、UTF-8 检查和文件定位作为本次静态证据。
- **弱独立护栏追加发现**：基线旧文曾把 DS3120MG 候选 PWM 范围写成确定值，并写入缺少模块级证据的 A4988 通用能力/替代型号；任务阻塞表也仍把已确认的电机与夹爪写成型号未知。已分别改为“供应商候选资料待实物验证”“按具体模块资料/计算/台架门禁”和“仅完整资料/实测仍阻塞”。

## 4. 验证结果

- `git diff --check`：退出码 0。
- 旧措辞反查：`DRV3_EXTERNAL`、仅 `STEP/DIR` 的第三路目标/拓扑/BOM/自检措辞均为 0 个命中。
- 关键项存在：`J_DRV_X_CTRL`、`J_DRV_Y_CTRL`、`EXTERNAL_DRIVER_CTRL`、`STEP/DIR/ENABLE`、`CANDIDATE - DNP UNTIL REQUIRED` 均可在基线定位。
- 编码：`modular-pcb-design.md` 为有效 UTF-8。
- 未新增具体电压、保险、端子、铜厚、线宽、GPIO 或未验证封装参数；已确认器件额定参数保留来源，候选模块能力和控制范围不作为冻结值。
