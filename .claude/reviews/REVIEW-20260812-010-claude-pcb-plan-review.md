## 1. 总体裁决

**裁决：有条件通过。**

本方案可以进入 KiCad 候选原理图草图阶段，但必须在原理图冻结前完成以下条件：

1. **P1-01 必须裁决**：X/Y 的 A4988 失败替代控制路径（见第 2 节）。
2. **P2 项应对账后合并**：文档内部不一致项在下一版方案修订中统一。

方案准确继承了已确认执行器型号（17HS4401、DS3120MG）和安全/接口边界；A4988 保持候选/DNP；未知参数正确标记。未发现 P0 级安全冲突或事实错误。

## 3. 事实、推断、建议与未知

| 分类 | 内容 |
|------|------|
| **事实** | X/Y 为 `17HS4401`（NEMA17、1.8°、1.7A/相、40N·cm）；夹爪为 `DS3120MG`（数字舵机、PWM 开合）；A4988 为候选 DNP；单一内置电源；急停仅切危险动力正极且不切公共参考地。以上与全部基线文档一致。 |
| **事实** | 方案正确避免了所有"禁止推断"项：未虚构 GPIO、排针号、A4988 针序、电源电压、保险值、端子额定值、铜厚或线宽。 |
| **推断** | 方案在 P1-01 解决后足以作为 KiCad 候选原理图的接口输入，但不能作为投板输入。 |
| **建议** | 除 P1-01 裁决外，建议在下一版方案修订时合并 P2-01/P2-02/P2-03 的对账修改。 |
| **未知** | Z 轴执行器、挡板舵机型号、限位参数、各支路峰值、端子、线束、GPIO、铜厚、线宽、保护器件和 A4988 实物适配——方案均已正确标记为未知。 |
