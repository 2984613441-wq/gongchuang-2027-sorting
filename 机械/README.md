# 机械子系统

> **当前阶段为纯输入角色**。不负责代码编写，仅向电控子系统提供接口参数。

## 当前职责边界

本子系统在当前阶段：

- ✅ 提供机械结构信息（布局、尺寸、机构构成）
- ✅ 向电控组提供执行器和传感器电气参数
- ✅ 确认重力轴断电自然状态及防坠方案
- ✅ 确认相机/补光安装空间、电控安装空间

**不负责**：
- ❌ 不编写控制代码
- ❌ 不负责电机驱动、通信、传感器信号处理
- ❌ 不负责视觉算法或模型训练

## 电控等待的接口输入

以下参数必须由机械组提供，电控组才能进入详细设计：

| 优先级 | 参数 | 用途 |
|--------|------|------|
| 1 | X/Y/机械手电机型号 + 电气参数 | 驱动器选型、运动参数 |
| 1 | 挡板舵机型号 + PWM 范围 + 电流 | 舵机供电 + 控制接口 |
| 1 | 限位/原点数量、类型、位置、电平 | STM32 引脚分配、回零逻辑 |
| 1 | 夹爪执行器类型 + 电气接口 | 控制接口 + 供电 |
| 1 | 重力轴断电自然状态 + 防坠方案 | 急停回路设计 |
| 2 | 补光灯直径、安装空间、遮挡关系 | 补光灯选型 |
| 2 | 相机安装视野 | 视觉参数标定 |
| 2 | 电控、电池安装空间 | 布局与布线 |
