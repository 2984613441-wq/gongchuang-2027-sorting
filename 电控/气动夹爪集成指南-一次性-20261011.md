## ⚠️ 注意事项

### 1. TIM2已启动（确认）
气动夹爪使用TIM2_CH4，与现有舵机（TIM2_CH3）共享定时器。

确认 `main.c` 中已调用：
```c
MX_TIM2_Init();  // 在main()函数中
```

### 2. 硬件连接（必须）
```
STM32 PB11 → 气动阀信号线
STM32 GND  → 气动阀GND
5V电源     → 气动阀VCC（独立供电，不从GPIO取电）
```

### 3. 脉宽范围（待标定）
初始值：
- 张开：1000us
- 闭合：2000us

实际值需现场测试后调整（修改 `ec_pneumatic_gripper.c` 中的宏定义）。
