# 电控子系统

> 本系统是当前阶段唯一负责代码编写的子系统。

## 职责（方案 B）

- 树莓派 4B：任务队列管理、名称/图片映射、显示界面、集中日志
- STM32F407：单件运动控制、回零、限位、急停、15 秒监控、补光控制
- 三设备通信协议实现（统一二进制帧）
- 状态机实现（上电→自检→回零→待机→自动运行→完成）
- 安全回路与故障分级处理

## 明确不承担

| 不承担项 | 原因 |
|---------|------|
| 视觉模型训练、数据集标注 | 由视觉子系统负责 |
| 机械结构设计、零件选型、CAD 出图 | 由机械子系统负责 |
| 电机/舵机/夹爪/滑台/储物盒本体采购 | 机械本体不纳入电控采购责任 |
| 机械执行器的电气参数测定 | 由机械组提供，电控只据此选型驱动器和供电 |

## 机械接口输入（等待机械组提供）

电控需要以下参数才能进入详细设计，但**不负责产生这些参数**：

- X/Y/机械手电机型号、额定电压/电流、峰值电流、传动方式、行程、速度、负载
- 4 个挡板舵机型号、工作电压、单个与同时动作峰值电流、PWM 范围、极限位置
- 夹爪执行器类型、电气参数、是否确需末端旋转
- 限位/原点数量、常开/常闭类型、安装位置、电平
- 重力轴断电自然状态及防坠方案
- 相机与补光安装视野、电控与电池安装空间
