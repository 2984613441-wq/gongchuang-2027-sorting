# 电控子系统

> 本系统是当前阶段唯一负责代码编写的子系统。

## 职责（方案 B）

- 树莓派 4B：任务队列管理、名称/图片映射、显示界面、集中日志
- STM32F407：单件运动控制、回零、限位、急停、15 秒监控、补光控制
- 三设备通信协议实现（统一二进制帧）
- 状态机实现（上电→自检→回零→待机→自动运行→完成）
- 安全回路与故障分级处理

## 明确不承担

| 不承担项 | 原因 |
|---------|------|
| 视觉模型训练、数据集标注 | 由视觉子系统负责 |
| 机械结构设计、零件选型、CAD 出图 | 由机械子系统负责 |
| 电机/舵机/夹爪/滑台/储物盒本体采购 | 机械本体不纳入电控采购责任 |
| 机械执行器的电气参数测定 | 由机械组提供，电控只据此选型驱动器和供电 |

## 机械接口输入（型号已确认，电气参数待机械组补齐）

已确认型号（来源：[要求汇总](资料/要求汇总.md) 2026-08-24 + 用户 2026-08-26 补充）：

| 机构 | 已确认 | 仍待机械组提供 |
|---|---|---|
| X/Y 滑台 | X、Y 各 1 台 **17HS4401** 步进电机（NEMA17，1.8°，1.7A/相，40N·cm 保持扭矩）；行程 27cm | 传动方式、速度、负载、安装尺寸 |
| Z 轴（升降+夹爪联动） | **DS3120MG** 舵机（**单舵机联动**实现升降+夹爪；原 17HS4401 步进方案废弃） | 联动结构、完整行程、夹持可靠性、断电状态验证 |
| 四周挡板 | **MG996R** 舵机 ×4（4 路独立 PWM，可同阶段同时动作） | 极限位置 |

电控只据此选型驱动器和供电，**不负责产生这些参数**；执行器本体采购不纳入电控采购责任。

> - 精确电气参数（电压范围、PWM 脉宽/频率、堵转电流、夹持行程）由电控自行查数据手册，不列为待提供项。
> - X/Y 不设独立限位开关；供电安装空间不纳入电控接口输入。
> - A4988 驱动 17HS4401 的 1.7A 台架验证是电控自己的选型验证。
