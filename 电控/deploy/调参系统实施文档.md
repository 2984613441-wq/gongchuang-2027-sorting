## 🎯 核心功能

### 1. 配置文件结构（7个章节）

```ini
[Vision]         # MaixCAM视觉参数
[Motion]         # STM32运动参数
[Timeout]        # 超时保护
[Safety]         # 安全参数（只读）
[Calibration]    # 标定记录
[Network]        # 网络配置
```

**特点**：
- 每个参数都有注释说明
- 标注`[PLACEHOLDER]`等待实测标定
- 只读参数防止误修改

---

### 2. 参数同步脚本

**功能**：
- 读取`sorting_config.ini`
- 通过UART同步到STM32（运动参数）
- 通过TCP同步到MaixCAM（视觉参数）
- 支持`--vision`/`--motion`选择性同步

**使用**：
```bash
python3 sync_params.py              # 全部同步
python3 sync_params.py --vision     # 只同步视觉
python3 sync_params.py --motion     # 只同步运动
```

---

### 3. STM32固件处理器

**协议**：
```
帧格式：[0xA5] [0x20] [len=10] [payload] [checksum]

Payload（10字节，big-endian）：
  x_speed_multiplier(2B, 千分比)  # 1000 = 1.0
  y_speed_multiplier(2B)
  accel_factor(2B)
  max_speed_limit(4B, Hz)

响应：
  ACK:  [0xA5] [0x21] [0x00] [checksum]
  NACK: [0xA5] [0x22] [error_code] [checksum]
```

**安全机制**：
- 只在IDLE状态接受更新
- 参数范围校验（0.5-2.0）
- 不持久化到EEPROM（防止误配置）

---

### 4. MaixCAM热更新

**协议**：
```json
{
  "type": "UPDATE_PARAMS",
  "conf_th": 0.5,
  "iou_th": 0.45
}
```

**响应**：`b'OK'` 或 `b'ERROR'`

**实现**：
- `ParamManager`类管理参数
- 非阻塞接收（0.001秒超时）
- 不阻塞检测循环

## ⚠️ 已知限制

### 1. 参数不持久化

**现象**：断电后恢复默认值

**原因**：为了防止现场误配置，参数故意不写入EEPROM

**解决**：
- 赛前调好配置文件，每次开机运行`sync_params.py`
- 如需持久化，在STM32端手动调用`eeprom_write_config()`

---

### 2. STM32只在IDLE接受更新

**现象**：运动过程中无法更新参数

**原因**：安全设计，防止运动中修改参数导致异常

**解决**：等待当前任务完成，或按急停后复位

---

### 3. MaixCAM重启丢失参数

**现象**：MaixCAM重启后conf_th恢复到0.3

**原因**：main.py初始化时使用硬编码的`CONF_TH`

**解决方案A**（临时）：每次MaixCAM重启后重新运行`sync_params.py`

**解决方案B**（永久）：修改`main.py`从配置文件读取初始值：
```python
import configparser
config = configparser.ConfigParser()
config.read('/home/pi/sorting_config.ini')  # 通过NFS挂载或网络读取
CONF_TH = config.getfloat('Vision', 'confidence_threshold')
```

### 2. 参数调整策略

**优先级排序**：
1. **视觉参数** > 运动参数（漏检比速度慢更致命）
2. **confidence_threshold** > iou_threshold
3. **speed_multiplier** > acceleration_factor

**保守原则**：
- 第一次比赛：使用默认值（confidence=0.3, speed=1.0）
- 第二次比赛：根据第一次结果微调（±0.1, ±0.2）

### 3. 现场调试流程
