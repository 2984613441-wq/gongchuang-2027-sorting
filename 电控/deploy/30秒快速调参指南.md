# 30秒快速调参操作指南

## 🎯 目标
在赛前30秒调试时间内，通过SSH快速修改参数并同步到设备。

---

## ⚡ 30秒操作流程（实战版）

### 准备（赛前完成）
1. 笔记本已连接树莓派WiFi热点
2. SSH已配置免密登录（`ssh-copy-id pi@raspberrypi.local`）
3. `sync_params.py`已添加执行权限（`chmod +x ~/sync_params.py`）

### 正式操作（30秒内）

```bash
# Step 1：SSH登录（5秒）
ssh pi@raspberrypi.local

# Step 2：编辑配置文件（15秒）
nano ~/sorting_config.ini

# 修改以下关键参数（根据现场情况）：
#   [Vision]
#   confidence_threshold = 0.5    # 物料清晰度好→提高到0.5-0.6
#                                 # 物料模糊/污损→降低到0.3-0.4
#
#   [Motion]
#   x_speed_multiplier = 1.2      # 时间紧张→提高到1.2-1.5
#   y_speed_multiplier = 1.2      # 运动稳定→保持1.0

# Ctrl+O 保存，Ctrl+X 退出

# Step 3：同步参数（8秒）
python3 ~/sync_params.py

# Step 4：验证（2秒）
# 观察终端输出：
#   ✅ STM32参数同步成功
#   ✅ MaixCAM参数同步成功
#   ✅ 所有参数同步完成！

# 完成！退出SSH
exit
```

## 📊 参数调整策略

### 场景1：漏检（物料没被识别）

**症状**：托盘里有物料，但MaixCAM没检测出来

**解决**：
```ini
[Vision]
confidence_threshold = 0.3  # 从0.5降到0.3
```

**原理**：降低置信度阈值，允许更低质量的检测结果通过。

---

### 场景2：误检（空气也被识别为物料）

**症状**：托盘空了，但还在抓取"幽灵物料"

**解决**：
```ini
[Vision]
confidence_threshold = 0.6  # 从0.3提高到0.6
```

**原理**：提高置信度阈值，只允许高质量检测结果通过。

---

### 场景3：运动太慢（超时15秒）

**症状**：单件任务超过13秒，触发赛规红线

**解决**：
```ini
[Motion]
x_speed_multiplier = 1.5  # 从1.0提高到1.5
y_speed_multiplier = 1.5
```

**警告**：
- 不要超过2.0（可能丢步）
- 如果电机抖动/噪音大，降回1.2-1.3
- 优先标定`EC_AXIS_MOVE_FREQUENCY_HZ`，再考虑提速

---

### 场景4：运动抖动/丢步

**症状**：电机噪音大、终点位置不准

**解决**：
```ini
[Motion]
x_speed_multiplier = 0.8  # 从1.0降到0.8
acceleration_factor = 0.7  # 从1.0降到0.7
```

**原理**：降低速度和加速度，减少机械冲击。

## ⚠️ 故障排查

### 问题1：`❌ STM32拒绝：当前不在IDLE状态`

**原因**：STM32正在执行任务

**解决**：
1. 等待当前任务完成
2. 按一次急停（进入故障锁定）
3. 重新上电复位
4. 再次运行`sync_params.py`

---

### 问题2：`❌ MaixCAM无响应（可能需要重启）`

**原因**：MaixCAM代码版本太旧，不支持热更新

**临时解决**：
1. SSH到MaixCAM：`ssh root@172.20.10.2`
2. 手动编辑：`nano /root/maixcam_app/main.py`
3. 修改`CONF_TH`和`IOU_TH`常量
4. 重启MaixCAM：`reboot`

**永久解决**：
更新MaixCAM代码到最新版本（包含`ParamManager`）

---

### 问题3：`❌ 无法打开串口 /dev/ttyUSB0`

**原因**：串口设备名错误

**解决**：
```bash
# 查看实际串口设备
ls /dev/tty*

# 可能是 /dev/ttyAMA0 或 /dev/ttyUSB1
# 修改配置文件
nano ~/sorting_config.ini
# [Network]
# stm32_port = /dev/ttyAMA0  # 改为实际设备名
```

## 🎓 最佳实践

1. **小步迭代**：每次只改1-2个参数，立即测试
2. **记录数值**：用手机拍照记录每次修改
3. **快速回退**：不行立即恢复上一版
4. **优先视觉**：漏检/误检比速度更致命
5. **保守提速**：speed_multiplier不超过1.3
