# 注意：
#   * Pillow 版本下限按**实测能跑的版本**写，不要写高：树莓派上装的是系统包
#     python3-pil 8.1.2（apt 装的），而 display_hdmi.py 已经为 8.x 做了兼容
#     （Image.Resampling 是 Pillow 9.1 才有的，代码用 getattr 兜底；
#      ImageOps.fit 自 Pillow 2.7 起就有）。原先写 >=9.0.0 会让 pip 去升级
#     Pillow —— 在 Pi 上大概率要现场编译，白等半小时还可能失败，且升完并没有
#     任何新能力被用到。
#   * pyserial 同理：树莓派上是 **3.5b0**（beta），按 PEP 440 它 **小于** 3.5，
#     所以 `>=3.5` 会判定不满足并试图重装。下限写 3.4 即可 —— 本工程只用
#     serial.Serial 的基础读写，3.4 起就没有 API 差异。
#   * 视觉侧（MaixCAM）线格式未冻结，本清单不含任何视觉专用依赖。
