## 测试目标
- 确定Z轴舵机安全脉宽范围（升降+夹爪联动）
- 验证夹持可靠性、断电状态
- 冻结脉宽参数

## ⚠️ 已知信息（实测，2026-09-18 更新）
- **单舵机联动**：一个 LDX-335MG（PB10 = TIM2_CH3）同时决定升降与夹爪开合，一个自由度
  （`ec_axis_driver.h:122-124`）。
- **方向语义（修正模板旧描述）**：**脉宽越大 → 越闭合、越下压；脉宽越小 → 越张开、越抬起**。
  即：**张开=抬起（Z_UP）、闭合=下压（Z_DOWN）**（`ec_axis_driver.h:80-81`）。
  ⚠️ 模板旧描述「1000us=张开/下降」把升降方向写反了，以此为准。
- **断电状态**：保持最后状态（数字舵机自锁）。
- **单调、无死区**：P1000→P1900 递增扫描，开度随脉宽单调变化，无跳变死区。

## 1. 张开侧脉宽扫描（越小越开）

| 测试脉宽(us) | 观察结果 | 通过/失败 |
|------------|---------|----------|
| 900  | 比 P950/P1000 更开；**无堵转异响**；释放干脆 | ☑ 通过 |
| 950  | 比 P1000 更开，无堵转 | ☑ 通过 |
| 1000 | 可用，但非最大开度 | ☑ 通过 |
| 1100 | 旧值，实际未开到底 | ☑ 通过（已弃用为开度端） |
| <900（850/800） | **未测**（待测：小步下探，勿一次跳远，越过机械端点会持续堵转烧舵机） | ☐ 待测 |

**完全张开脉宽**：**900 us（最低已验证值，非机械端点）**
理由：P900 无堵转异响说明仍有行程余量；900 是"已验证可用的最低值"，不是机械端点
（`ec_axis_driver.h:74-77`）。

## 最终参数确定（与现行代码一致）

现行代码（`ec_axis_driver.h:59-61,80-81`）：
```c
#define EC_AXIS_GRIPPER_OPEN_US UINT16_C(900)    // 实测张开（抬起）
#define EC_AXIS_GRIPPER_CLOSE_US UINT16_C(1900)  // 实测闭合（下压）
#define EC_AXIS_GRIPPER_SETTLE_MS UINT32_C(200)  // ⚠️ 占位，待测
#define EC_AXIS_Z_UP_US   EC_AXIS_GRIPPER_OPEN_US   // 900  张开+抬起
#define EC_AXIS_Z_DOWN_US EC_AXIS_GRIPPER_CLOSE_US   // 1900 闭合+下压
```

冻结结论：
- OPEN/Z_UP = **900 us**，CLOSE/Z_DOWN = **1900 us**（已实测冻结）
- SETTLE_MS = 200 ms（**待测**，见上）
