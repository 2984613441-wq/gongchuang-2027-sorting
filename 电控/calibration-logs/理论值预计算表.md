## 📐 计算公式

```
STEPS_PER_MM = (200步/圈 × 微步数) / 传动参数
```

## 🧮 手算步骤（机械组提供参数后）

### 场景1: 同步带（最常见）

**机械组提供**：
- 微步数：______ (填：1/2/4/8/16)
- 带轮齿数：______ 齿
- 节距：______ mm (常见：2mm GT2)

**计算**：
```
步进电机每圈步数 = 200 × 微步数 = 200 × ______ = ______ 步/圈

带轮每圈行程 = 齿数 × 节距 = ______ × ______ = ______ mm/圈

STEPS_PER_MM = ______ / ______ = ______ steps/mm
```

**示例**（16微步，20齿，2mm节距）：
```
200 × 16 = 3200 步/圈
20 × 2 = 40 mm/圈
3200 / 40 = 80 steps/mm ✓
```

### 场景3: 齿条

**机械组提供**：
- 微步数：______
- 模数：______
- 齿轮齿数：______

**计算**：
```
步进电机每圈步数 = 200 × ______ = ______ 步/圈

齿轮每圈行程 = π × 模数 × 齿数 = 3.14 × ______ × ______ = ______ mm/圈

STEPS_PER_MM = ______ / ______ = ______ steps/mm
```

**示例**（16微步，模数1，20齿）：
```
200 × 16 = 3200 步/圈
3.14 × 1 × 20 = 62.8 mm/圈
3200 / 62.8 ≈ 51 steps/mm ✓
```
