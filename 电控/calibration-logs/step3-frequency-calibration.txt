## 1. 传动比（STEPS_PER_MM）

### 机械参数
- 步进电机：1.8°/步 = 200 步/圈
- A4988 微步：16 微步
- 传动：同步带 GT2，20 齿，齿距 2mm → 每圈行程 20×2 = 40mm

### 理论计算
STEPS_PER_MM = (200 × 16) / 40mm = **80 steps/mm**

### 实测验证（正方形闭合法）
方法：`工具/pi_square.py 100`（走 100mm 正方形），实机四条边准确、**正方形闭合** ⇒ 无丢步。
- 结论：**80 steps/mm 成立**（100mm 尺度四边准确、首尾闭合）✅
- 误差：四边闭合无累积偏差 ⇒ 传动比与实测一致

☑ 误差 < 5%，采用 80 steps/mm

> 注：`ec_board_stm32.c:196` 注释里写的是 `pi_square.py 50`（50mm 正方形）；
> 本次 V8/派工书实测口径为 100mm。两种边长都用同一闭合判定法；以本次 100mm 记录为准。

## 2. 最大步频测试（渐进提升）

测试条件：
- 巡航频率现为 **5000 Hz**（实参，`ec_board_stm32.c:200`）
- 验证方法：走正方形闭合 + 到位后手推无偏移 = 无丢步

### 现行生效参数（实读 `ec_board_stm32.c:200`）
```c
ec_step_profile_plan(profile, steps,
                     200U,    /* start_hz = 200 Hz */
                     5000U,   /* cruise_hz = 5000 Hz */
                     200U,    /* end_hz = 200 Hz */
                     10000U,  /* accel_hz_per_s = 10000 Hz/s */
                     10000U); /* decel_hz_per_s = 10000 Hz/s */
```
参数顺序见 `stm32_logic/include/ec_step_profile.h:59-62`。

- 巡航频率：**5000 Hz**（= 62.5 mm/s）
- 加减速率：**10000 Hz/s**（🔴 实读值；派工书/任务 C2 写的是 5000，文件已漂移，待对齐）
- start/end：200 Hz

> ⚠️ 注意：真正生效的是**本行的 cruise 实参 5000**；`EC_AXIS_MOVE_FREQUENCY_HZ = 500`
> （`ec_axis_driver.h:38`）**只在规划失败兜底的 `period==0` 分支用，改它不提速**
> （`ec_board_stm32.c:191-192,203-206`）。

### 巡航门槛与线速度（2026-09-19 补，依据 15 秒预算分析 §1.1/§2）

- **线速度**：巡航 5000 Hz ÷ 80 步/mm = **62.5 mm/s**。
- **进入完整巡航的腿长门槛 = 2 × 加速段步数**：
  `accel_steps = (cruise² − start²)/(2·a) = (5000²−200²)/(2×10000) = 1248 步`
  （`ec_step_profile.c:76-77`）→ 门槛 = **2496 步**（=31.2mm）。
  🔴 旧文档里的 **7192 / 4992 已作废**（预算报告附录 B）。
- **本程序 6 条运动腿全部 ≥ 2496 步**（最短腿 3768 步），即全部跑满 5000Hz 巡航平台，无三角曲线腿。
- **单轮行进总量**：**37200 步 = 465.0 mm**（19:24 那轮，预算报告 §2 合计）。

### 舵机脉宽与停留（2026-09-19 补，来源见交接 §5）

- 夹爪脉宽：**开 = 900 µs / 闭 = 1900 µs**（`ec_axis_driver.h:59-60`）。
- 取料点停留 `EC_AXIS_PICK_DWELL_MS`：当前 **2000 ms**（`ec_axis_driver.h:138`）；
  **计划**压到 **200 ms**（与 SETTLE 同量级）——🔴 截至本记录**尚未改固件，仍为 2000 ms**，
  改后单轮可省约 1.8s（预算报告 §5.2）。注意不许改成 0（`step_is_valid()` 判非法步）、
  不许删该步（会变 9 步、拆掉 10 步 host 测试）。

### 步进频率渐进表
| 步频(Hz) | 结果 | 通过/失败 |
|---------|------|----------|
| 500~4000 逐档 | **未逐档实测**（待测） | ☐ 待测 |
| 5000 | 100mm 正方形四边准确、闭合 ⇒ 无丢步（V8） | ☑ 通过 |
| >5000 | 未测（待测） | ☐ 待测 |

### 结论
- 最高**已验证**不丢步步频：**5000 Hz**（100mm 尺度，无丢步）
- **最高安全步频：待测**（500~4000 逐档未做；温升未测）
- 安全步频 = 最高步频×0.8：**待测**（无逐档上限，不计算）

> **测量方法（待现场执行）**：
> 1. 在无超程风险的行程内，逐档把 cruise 从 500 提到 4000（每档改 `:200` 实参重烧/台架）；
> 2. 每档走一次 100mm 正方形，看是否闭合、四边是否各 100mm；
> 3. 手摸电机外壳测温升（目标 <70°C）；
> 4. 第一个出现丢步/异响/超温的档位上一档即为上限，×0.8 得安全步频。
> 🔴 因 X/Y 无限位，超程即堵转并带挂主控（`ec_axis_driver.c:9-11`），务必在行程内小步提频。
