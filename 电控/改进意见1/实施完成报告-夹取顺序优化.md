## 🎯 核心功能

### 1. 三阶段时间分段策略

```
阶段1（0-7s）：快速收割期
  → 策略：高置信度 + 近距离
  → 目标：快速完成3-4件
  → 实现：_phase1_select()

阶段2（7-12s）：稳定填充期
  → 策略：TSP路径优化 + 只选SAFE物块
  → 目标：高效完成4-5件
  → 实现：_phase2_select() + greedy_tsp()

阶段3（12-15s）：保守收尾期
  → 策略：confidence>0.9 且 time<1.5s
  → 目标：避免15秒判罚
  → 实现：_phase3_select() + should_abort()
```

### 2. 风险分级系统

```python
RiskLevel枚举：
- SAFE: confidence>0.85 且 success_rate>0.8
- MEDIUM: confidence>0.7
- RISKY: 其他情况

贝叶斯更新：
- 成功：success_rate = 0.9 * current + 0.1
- 失败：success_rate = 0.7 * current
```

### 3. TSP路径优化

```python
greedy_tsp(): 贪心最近邻算法
  → 时间复杂度：O(n²)
  → 近似比：~1.5x最优解

two_opt_improve(): 2-opt局部搜索（可选）
  → 在贪心基础上进一步优化
  → 适用于阶段2稳定期
```

## 🔌 集成接口

### 使用示例

```python
from electrical_control.scheduler import PhasedScheduler, SchedulerBridge

# 1. 创建调度器
scheduler = PhasedScheduler(time_limit_s=15.0)
bridge = SchedulerBridge(scheduler)

# 2. 处理视觉批次
bridge.process_batch(batch_targets)

# 3. 获取下一个任务
while not bridge.should_abort_round():
    task = bridge.get_next_task()
    if task is None:
        break
    
    # 执行任务...
    success = execute_pick_task(task)
    
    # 更新调度器
    bridge.mark_task_completed(task.target_seq, success)

# 4. 查看统计
stats = bridge.get_scheduler_stats()
print(f"完成：{stats['completed']}/{stats['total']}")
```
