## 🚀 快速开始

### 1. 导入模块

```python
from electrical_control.scheduler import (
    PhasedScheduler,
    SchedulerBridge,
)
```

### 2. 初始化调度器

```python
# 创建调度器（默认15秒时间限制）
scheduler = PhasedScheduler(time_limit_s=15.0)

# 创建桥接层（连接视觉和调度器）
bridge = SchedulerBridge(scheduler)
```

### 3. 处理视觉批次

```python
# 当收到视觉批次时
def on_batch_received(batch_targets):
    # 初始化调度器
    bridge.process_batch(batch_targets)
    
    # 开始调度循环
    dispatch_next_target()
```

### 4. 调度循环

```python
def dispatch_next_target():
    # 检查是否应该提前终止
    if bridge.should_abort_round():
        print("[调度] 剩余时间不足，提前终止避免15秒判罚")
        finish_round()
        return
    
    # 获取下一个目标
    task = bridge.get_next_task()
    
    if task is None:
        print("[调度] 无可用目标，本轮结束")
        finish_round()
        return
    
    # 发送任务到STM32
    send_to_stm32(task)
```

### 5. 处理结果反馈

```python
def on_item_result(result):
    target_seq = result['target_seq']
    success = result['success']
    
    # 更新调度器（贝叶斯学习）
    bridge.mark_task_completed(target_seq, success)
    
    # 调度下一个
    dispatch_next_target()
```

## 🎯 三阶段说明

### 阶段1：快速收割（0-7秒）
- **策略**：抓最近的高置信度物块
- **目标**：快速完成3-4件
- **特点**：不考虑路径优化，只求快

### 阶段2：稳定填充（7-12秒）
- **策略**：TSP路径规划 + 只选SAFE物块
- **目标**：高效完成4-5件
- **特点**：最大化吞吐量

### 阶段3：保守收尾（12-15秒）
- **策略**：只选超高置信度且快速的物块
- **目标**：避免触发15秒判罚
- **特点**：宁可不抓，也不冒险

## ⚙️ 参数调优

### 运动参数（需实测标定）

```python
# 在 risk_classifier.py 中修改
_MOTION_SPEED_MM_PER_S = 50.0    # 实际运动速度（mm/s）
_PICK_ACTION_TIME_S = 2.0        # 夹取动作时间（秒）
```

**标定方法**：
1. 测量10次XY平面100mm移动时间，取平均
2. 测量10次完整夹取动作时间，取平均

### 阶段时间阈值

```python
# 在 phased_scheduler.py 中修改
PHASE1_END = 7.0     # 阶段1持续时间（秒）
PHASE2_END = 12.0    # 阶段2结束时间（秒）
ABORT_MARGIN_S = 3.0 # 安全边界（秒）
```

**调优策略**：
- 速度快 → 延长阶段1（7→9秒）
- 速度慢 → 缩短阶段1（7→5秒），增加安全边界（3→4秒）

### 风险阈值

```python
# 在 risk_classifier.py 中修改
_SAFE_CONFIDENCE_THRESHOLD = 0.85        # 降低→更多SAFE物块
```

## ❓ 常见问题

### Q1: 为什么阶段3返回None？
**A**: 这是正常的保守策略。阶段3只选超高置信度且快速的物块，如果没有符合条件的，会主动停止避免15秒判罚。

### Q2: 如何提高完成数量？
**A**: 
1. 提高视觉置信度（调优YOLO模型）
2. 标定准确的运动速度参数
3. 适当降低风险阈值（但会增加失败率）

### Q3: 贝叶斯更新多久生效？
**A**: 每次pick后立即更新，但需要2-3轮比赛数据才能显著改善分类准确性。建议赛前用训练数据预热。

### Q4: TSP优化效果如何？
**A**: 贪心TSP能比随机顺序减少15-25%路径长度，2-opt可进一步优化5-10%。阶段2自动启用。

### Q5: 如何禁用某个阶段？
**A**: 修改阶段时间阈值即可：
```python
# 禁用阶段2（直接从阶段1跳到阶段3）
PHASE1_END = 7.0
PHASE2_END = 7.0  # 设置为与PHASE1_END相同
```
