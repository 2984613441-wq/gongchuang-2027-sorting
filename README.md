## 5. 本机 Python 环境（最容易卡住的地方）

本机 `python` 指向一个**没有 pip 的 venv**，`pip`/`python -m pip`/`python xxx.py` 都会失败。
**必须用 `py -3`**（系统 Python 3.14.5）：

```powershell
py -3 -m pip install -r 工具\requirements.txt    # 装依赖（PyQt5）
py -3 工具\monitor_gui.py                        # MaixCAM 监控（9001）
py -3 工具\monitor_gui_v2.py                     # 全链路监控（9002）
py -3 工具\check_clock_tree.py                   # ★ 固件时钟树自检（改 PSC 后必跑）
py -3 工具\audit_workspace_clutter.py            # ★ 工作区重复/过期体检
```
⚠️ **已知缺口**：本机缺 `cv2` ⇒ `视觉/tests/test_stage1_color_v6_pose.py` 的 25 条 cv2 用例会**整组 skip（假绿）**。

## 6. 铁律（每条都付过学费）

1. **事实与推断分开标注**；每个断言带 `文件:行号` 或原始输出。
2. **数值以设备实读为准**——仓库副本长期与 Pi 不同步（台账 `E-43`）。
3. **不要把主机侧测试说成实机通过**。
4. **未经用户对该具体动作的确认，不改文件 / 不烧录 / 不起链 / 不发运动命令。**
5. `STEP_RESULT=1` **只证明"脉冲发完了"，不证明"到位了"**（开环步进）。
6. **每次运动先公告**：`起点 + Δ = 终点`，X 和 Y 都要核。
7. **上电即原点**：先把滑台推到负向最里角，**再**上电；顺序错 = 顶死堵转。
8. 改任何脚本入口前**先 grep 全部调用方**。
