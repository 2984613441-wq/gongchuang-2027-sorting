## 五、加权排序测评结论（摘要）

详见 `docs/reports/测评-加权排序可行性-20261102.md`（300 帧离线仿真，脚本 `工具/eval_weighted_order.py`）

| 指标 | 结果 |
|---|---|
| 权重 ±0.1 时首位变化率 / Kendall τ | **4.38 % / 0.952**（稳）|
| 默认权重下难件首位率 | **10.33 %** → 加护栏后 **0 %** |
| 总行程（6 件均值）| 1158.9 mm（旧口径 1116.0，**+4.3 %**；贪心 975.6）|
| X 方向来回横跳 | **0.00 %** |
| front 权重置 0 后顺序一致性 | **τ = −0.055** ⇒ **front 主导，`open_side` 装错则全乱** |

结论：**GO（有条件）** —— 需先实机确认 `[Tray] open_side` 与相机前端轴，再台架空跑 A/B 对比。
