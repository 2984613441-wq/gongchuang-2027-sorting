# 夹取顺序：加权评分模型（2026-11-02）

> 用户口径（2026-11-02）：「主摄像头前端的最先夹取；最先夹取里面又有一个顺序是置信度高的先，
> 也就是正方体这种好夹的；把**路线、物料夹取、前端**这三个都考虑进去，给予权重」。

---

## 一、模型

对每个可派件算 **4 个分项（0..1，越大越优先）**，再按权重加权求和：

```
total = w_front × front + w_pick × pick + w_route × route + w_iso × isolation
```

| 分项 | 含义 | 计算 | 默认权重 |
|---|---|---|---|
| **front** | 前端（主相机画面里靠外/靠无壁边的那一排）| `1 − 归一化(到无壁边的距离)` | **0.70** |
| **pick** | 物料夹取（好夹 + 置信度高）| `0.75×(1 − 难度层/2) + 0.25×(置信度/100)` | 0.15 |
| **route** | 路线（空爪行程；有上次落点时加上到落点的距离）| `1 − 归一化(平均单腿距离)` | 0.10 |
| **isolation** | 隔离度（周围件越少越安全）| `1 − min(邻居数,3)/3` | 0.05 |

**停稳是更高一级条件**：`SettleTracker` 明确判定「还在动」的件**永远排最后**，
之后才比权重分（用户要求「停稳才抓」）。

**同分可复现**：`(−total, 行扫描键)` 定序，同一帧重复调用结果一致。

### 默认权重为什么是 0.70/0.15/0.10/0.05

按用户「前端最先」的表述，前端必须能压过「好夹」的差异。实算例子（demo 配置，托盘 y_max 为无壁边）：

| 件 | front | pick | route | 加权总分 |
|---|---|---|---|---|
| 靠前圆锥（y=60，难夹）| 0.9906 | 0.225 | 0.3064 | **0.8078** |
| 靠里正方体（y=0，好夹）| 0.7643 | 0.975 | 0.4867 | 0.7800 |

⇒ 靠前的先抓；**当两件 front 接近时**（同一排），`pick` 项会把正方体这类好夹的顶到前面 ——
正好对应用户说的「最先夹取里面再按置信度高/好夹的先」。

## 二、怎么用（默认关闭）

`pick_strategy.ini`：

```ini
[Strategy]
order_mode = weighted        # 【待实测】切换到加权评分（缺省 legacy = 不排序）
weight_front = 0.70          # 【待实测】前端
weight_pick = 0.15           # 【待实测】夹取（难度+置信度）
weight_route = 0.10          # 【待实测】路线
weight_isolation = 0.05      # 【待实测】隔离度
```

或命令行：`run_chain.py --pick-strategy order --order-mode weighted`

**权重约束**：四项均 ≥ 0，总和必须 > 0；非法值 ⇒ `ConfigError`（fail-closed）。

**回退**：`order_mode = legacy`（或 `group` 回到旧口径），一行配置即可，无需改代码。

---

## 三、调参建议（现场怎么定权重）

1. **先只调 `weight_front`**：0.70 是「前端压过好夹」；若发现“老是先抓靠里的件”，调高到 0.8。
2. **`weight_pick` 的作用只在“同一排/相距不远”时体现**（因为 front 是全局面板）。
   若希望更难件更靠后，调高到 0.25~0.3，同时把 `weight_front` 降到 0.6。
3. **`weight_route` 调大会变成“就近原则”**（回到旧行为），建议 0.05~0.15。
4. **`weight_isolation`** 用于避免碰倒邻件，通常 0.05 足够；托盘很挤时可加到 0.15。
5. 每次只改一个权重，跑一轮对比日志里的 `排序输出（策略序）`。

---

## 四、与其它排序模式的关系

| `order_mode` | 口径 | 适用 |
|---|---|---|
| `legacy`（缺省）| 不排序（原顺序）| 现状，回归对比用 |
| `group` | 分组 → 待定 → 难度 → 行扫描 | 省赛旧口径（分类集中）|
| `difficulty` | 待定 → 难度 → 行扫描 | 只想要「先易后难」|
| `open_edge` | 离无壁边最近（硬规则）| 只有前端因素 |
| `five_key` | 停稳→待定→难度→隔离度→落点距离（字典序）| 硬规则版「先易后难」|
| **`weighted`** | **前端/夹取/路线/隔离度加权** | **本次新增，最贴近用户口径** |

## 六、已知限制

1. `front` 用「到无壁边距离」近似「主相机画面靠前」，**相机装位/倾斜变化后需重标** `[Tray] open_side`
2. `pick` 里的置信度取的是**副相机/主相机送来的整数 conf**（0..100），不是 YOLO 原始概率
3. `route` 只用「空爪 + 到上次落点」两段，没算转盘换挡时间与 Z 轴升降
4. 权重与阈值均标【待实测】，需要现场跑几轮看日志再定
