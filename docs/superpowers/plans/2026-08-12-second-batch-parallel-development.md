# 第二批电控代码并行实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不接线、不烧录、不猜写硬件与未冻结协议参数的前提下，完成跨层集成验证、STM32 C纯逻辑骨架和树莓派显示调度骨架。

**Architecture:** 三条泳道使用独立目录并行推进。集成泳道先证明协议消息经上下文验证后才能进入状态机；STM32泳道只迁移可验证的CRC32和纯逻辑安全规则；树莓派泳道只实现离线任务、显示模型与渲染确认。任一关键节点掉电或重启后均锁定旧轮次，禁止自动续跑。

**Tech Stack:** Python `unittest`、主机侧C测试工具链（存在性先检查）、Markdown治理记录；不使用真实STM32、UART、GPIO、电机或显示硬件。
