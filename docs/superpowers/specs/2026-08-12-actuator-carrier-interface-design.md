# 智能分拣装置执行器与载板接口设计

> 状态：V1.0，用户已确认的方案基线；用于 GPIO/定时器分配和嘉立创 EDA 原理图设计，不构成投板、采购、接线或上电授权。  
> 日期：2026-08-12  
> 适用范围：正点原子探索者 STM32F407ZGT6 开发板载板/接口板。

## 1. 目标与验收方式

本设计把已经确认的机械执行机构转换为明确的电控通道、连接器和安全边界。达到以下条件后，才允许把候选原理图升级为可布局版本：

1. 每个执行机构都有唯一、可追踪的功能网络名和板外接口。
2. 四个挡板使用四路独立 PWM，并能在同一控制周期同步更新。
3. X、Y、Z 三个步进轴均有独立 `STEP/DIR/ENABLE`；Z 轴使用板外驱动器。
4. 三指夹爪由 `DS3120MG` 控制开合；腕部旋转仅预留接口，默认不装、不启用。
5. 急停通过板外硬件切断危险动力，载板只读取反馈。
6. GPIO/定时器分配经过探索者官方原理图、扩展排针和板载资源冲突核对。
7. 原理图通过 ERC 和逐网检查；板框与布局必须等待用户给出机械尺寸。

## 2. 已确认机构

| 机构 | 数量 | 执行器/状态 | 控制方式 | 载板处理 |
|---|---:|---|---|---|
| X 轴滑台 | 1 | `17HS4401` 步进电机 | `STEP_X/DIR_X/ENABLE_X` | A4988 候选模块位；同时保留默认 DNP 的板外驱动接口，二者互斥 |
| Y 轴滑台 | 1 | `17HS4401` 步进电机 | `STEP_Y/DIR_Y/ENABLE_Y` | 与 X 轴相同，但网络完全独立 |
| Z 轴机械手升降 | 1 | 步进电机，具体型号由机械组选定 | `STEP_Z/DIR_Z/ENABLE_Z` | 仅连接板外驱动器，不在载板集成功率级 |
| 四周挡板 | 4 | 四个舵机 | `BARRIER_PWM_1..4` | 四路独立输出，软件同步下发，允许分别校准方向和角度 |
| 三指自定心夹爪 | 1 | `DS3120MG` 数字舵机 | `GRIP_PWM` | 负责三指同步开合，舵机动力由板外模块提供 |
| 腕部旋转 | 0，预留 1 | 当前比赛版本不安装 | `WRIST_PWM` | 预留连接器和 MCU 资源，默认 DNP、固件禁用 |
| 六个储物盒 | 6 | 固定机械部件 | 无 | 不设置电机、驱动器、限位或控制接口 |

比赛只要求将物体抓起并投入对应储物盒，不要求投放后的姿态。因此当前版本选择三指自定心夹爪，避免把腕部旋转加入比赛主链。三指方案仍需用赛事物料的最大/最小尺寸、球体、圆柱、立方体、长方体和薄/细长物体完成实物抓取验证；验证不通过时才启用预留的腕部旋转通道。

## 3. 控制架构

```text
探索者 STM32F407
├─ X 轴：STEP_X / DIR_X / ENABLE_X
├─ Y 轴：STEP_Y / DIR_Y / ENABLE_Y
├─ Z 轴：STEP_Z / DIR_Z / ENABLE_Z
├─ 挡板：BARRIER_PWM_1..4（独立输出、同步更新）
├─ 三指夹爪：GRIP_PWM
├─ 腕部预留：WRIST_PWM（默认禁用）
├─ 六路通用限位：X_HOME/X_END/Y_HOME/Y_END/Z_UP/Z_DOWN
├─ 急停反馈：ESTOP_FB
├─ 启动与人工复位：START_SIG / MANUAL_RESET_SIG
└─ 通信、补光、驱动反馈和调试接口
```

四路挡板 PWM 不得在 PCB 上直接并联。软件在同一次状态转换中装载四个目标脉宽，并通过同一更新事件或受控的临界区使其同步生效。这样既保留同步动作，又允许逐路修正安装方向、机械零位和行程差异。

## 4. 连接器与网络

### 4.1 步进轴

| 位号建议 | 信号 | 说明 |
|---|---|---|
| `U_DRV_X_SOCKET` | A4988 X 轴完整功能网络 | 候选、默认 DNP，实物针序和热能力验证后才能装配 |
| `U_DRV_Y_SOCKET` | A4988 Y 轴完整功能网络 | 与 X 同构但禁止跨轴共网 |
| `J_DRV_X_CTRL` | `STEP_X/DIR_X/ENABLE_X/GND_LOGIC`，可选反馈 | 板外驱动备用，默认 DNP；与 X 轴 A4988 互斥 |
| `J_DRV_Y_CTRL` | `STEP_Y/DIR_Y/ENABLE_Y/GND_LOGIC`，可选反馈 | 板外驱动备用，默认 DNP；与 Y 轴 A4988 互斥 |
| `J_DRV_Z_CTRL` | `STEP_Z/DIR_Z/ENABLE_Z/GND_LOGIC`，可选 `FAULT/READY` 和逻辑参考 | Z 驱动器完全板外，功率与电机相线不经过此连接器 |
| `J_X_MOTOR`、`J_Y_MOTOR` | 两相四线电机输出 | 仅在对应 A4988 装配方案中使用；线序必须实测 |

`ENABLE_X/Y/Z` 必须有经过审查的上电禁止默认态。驱动器未就绪、MCU 复位、急停有效或故障锁定时，不得仅依靠软件初始化后才关闭输出。

### 4.2 舵机

| 位号建议 | 信号 | 装配状态 |
|---|---|---|
| `J_BARRIER_CTRL_1..4` | 每路 `PWM/GND_LOGIC`，可选逻辑参考 | 四路全部安装 |
| `J_GRIPPER_CTRL` | `GRIP_PWM/GND_LOGIC`，可选逻辑参考 | 安装 |
| `J_WRIST_CTRL` | `WRIST_PWM/GND_LOGIC`，可选逻辑参考 | 默认 DNP |

载板不承载舵机动力电流。四个挡板、夹爪以及未来可能安装的腕部舵机由急停边界内的板外高电流舵机供电/配电模块供电；PWM 参考地的连接、隔离和电平兼容性按最终模块资料核对。

### 4.3 限位与操作输入

原理图先保留六个可复用限位输入：

- `X_HOME`、`X_END`
- `Y_HOME`、`Y_END`
- `Z_UP`、`Z_DOWN`

每个接口保留 `V_SENSOR/LIMIT_SIG/GND_SENSOR` 三个功能位置，以及上拉、串联限流、RC 滤波和瞬态保护器件位。当前优先采用常闭机械开关，使断线更容易被识别；若机械组最终选择光电、NPN 或 PNP 传感器，则按其电压和输出形式调整调理电路，不直接接入不兼容的 STM32 GPIO。

`START_SIG` 和 `MANUAL_RESET_SIG` 分开。人工复位不直接复位 MCU，也不能在急停释放后自动恢复旧任务或危险动力。

## 5. 急停与供电边界

急停按钮采用至少两组常闭触点的蘑菇头：

1. 第一组控制板外继电器/接触器，物理切断 X/Y/Z 驱动器和全部舵机的危险动力正极。
2. 第二组形成 `ESTOP_FB`，供 STM32 只读监测。
3. 公共参考地不得作为急停切断对象。
4. STM32、树莓派、MaixCAM 和显示保持逻辑供电，以便显示故障和保存日志。
5. 急停释放后必须人工复位并重新自检、回零，禁止自动续跑。

单电池按功能分路：逻辑/计算支路、舵机支路、X/Y/Z 驱动支路和补光支路。各 DC/DC、保险、继电器/接触器和导线的额定值只根据最终电池电压及连续/峰值负载计算，不在缺少数据时填经验值。

Z 轴是重力轴。机械组负责确定断电自锁、常闭制动、配重或其他防坠结构；该方案经机械与台架验证前，急停危险动力回路不得冻结为最终版本。

## 6. GPIO 与定时器分配规则

精确分配由下一阶段完成，必须输出“功能网络 → STM32 外设/GPIO → 探索者排针 → 板载冲突 → 嘉立创 EDA 网名”五列表。分配遵守以下规则：

1. 先核对正点原子探索者 STM32F407ZGT6 官方原理图、引脚表和扩展口，不要求用户重复提供公开资料。
2. 保持 TF 卡、SWD/ST-Link、板载 USB 串口以及实际需要的开发板接口可访问，避免占用其固定复用引脚。
3. 三路步进脉冲优先使用可验证的硬件定时器输出比较/PWM资源；若采用统一高频调度定时器加 GPIO 生成脉冲，必须给出最大步频、抖动和三轴协调的计算与台架验证方法。
4. 四路挡板 PWM 必须独立；夹爪 PWM 独立；腕部 PWM 预留。所有舵机通道使用一致的帧周期策略，但保留逐路脉宽校准。
5. 六路限位优先使用具备外部中断能力且不会冲突的 GPIO；安全逻辑不能只依赖中断，周期采样仍需校验有效状态。
6. 上电期间所有 `ENABLE`、PWM 和补光输出必须处于不会引发运动的默认态。

## 7. 嘉立创 EDA 布局边界

用户负责提供：板框尺寸、排母实际间距和方向、安装孔位置、连接器朝向及维护空间。收到这些数据前可以完成原理图、网络表和候选封装核对，但不得冻结 PCB 布局。

探索者开发板通过排母可拆卸安装。TF 卡、SWD、USB、复位键以及需要操作的跳帽/按键必须留出插拔和维护空间。动力端子、传感器端子和调试端子分区布置；步进电机相线及舵机动力线远离限位、UART 和其他低能量输入。

## 8. 阶段门槛

### G1：允许完成原理图草图

- 已采用本文件的通道数量和网络命名。
- 已核对探索者官方资料并形成 GPIO/定时器映射表。
- 未知参数保持为设计输入，不伪造器件定值或针序。

### G2：允许冻结原理图

- A4988 实物针序、封装、采样电阻和限流关系完成核对。
- Z 轴电机与外接驱动器型号确定。
- 挡板舵机、限位类型和接口电平确定。
- DS3120MG 精确供电、PWM 和堵转电流资料完成实物验证。
- 急停反馈电气形式、默认态和隔离方式确定。
- ERC 与逐网审查无未解释错误。

### G3：允许 PCB 布局

- 用户提供并确认板框、排母、安装孔和连接器朝向。
- 所有封装完成数据手册、实物和 1:1 打印核对。
- 电流、铜厚、温升、线宽、过孔和连接器额定完成计算。

### G4：允许投板

- DRC、Gerber/钻孔/BOM/坐标文件检查通过。
- 急停及 Z 轴防坠完成独立安全审查。
- A4988 适配、舵机同时动作、掉压、干扰和温升台架测试通过。
- 用户对具体生产文件明确授权。

## 9. 最小验证清单

- 原理图中恰有三路独立 `STEP/DIR/ENABLE`。
- 原理图中恰有四路独立挡板 PWM、一路夹爪 PWM和一路默认 DNP 的腕部 PWM。
- 六个储物盒没有任何电控网络。
- X/Y A4988 与对应板外驱动器存在明确的二选一装配规则。
- 舵机动力不经过载板，急停主回路不经过 MCU 或载板逻辑。
- `ESTOP_FB` 失线、急停按下和 MCU 复位均导向禁止运动状态。
- TF 卡、SWD 和正式通信接口不存在 GPIO/复用冲突。
- 三指夹爪通过规定物料集合的抓取测试后，才能正式取消腕部旋转装配。
