## 2. 🔴 铁律（违反的交付一律作废）

```
1. Python 命令必须用 py -3（本机 python 指向一个坏 venv）
2. 必须带 PYTHONPATH，否则 26 个 collection error：
      $env:PYTHONIOENCODING='utf-8'; $env:PYTHONUTF8='1'
      $env:PYTHONPATH=(Resolve-Path '电控\src').Path
      cd 电控 ; py -3 -m pytest tests -q -p no:cacheprovider
3. 只改你自己名下的文件；要改别人的，先在交付里写「我需要改 X，请批准」
4. 改文件前先看 LastWriteTime —— 可能有别的 AI 正在改同一个文件
5. 不确定就写下来问，不要猜
6. 「完成」不算完成：必须给「改了哪个文件第几行 + 跑了什么命令 + 命令的原始输出」
7. 交付必须写清「我没验证什么」
8. ⚠️ 禁止用 CubeMX 重新生成代码（.ioc 落后于源码，会覆盖 168MHz 等已改项）
```

**绝对禁止（L4，需用户书面批准）**：
- 删/覆盖模型权重
- 改机械图纸
- **改 I/O 引脚映射**（除非电控交接文档里明确指定）
- **改协议字节布局**（除非视觉交接文档里明确指定）
- 任何上电 / 烧录 / 接线 / 让电机转动
- 把构建产物留在仓库里
- 用 CubeMX 重新生成 STM32 代码
