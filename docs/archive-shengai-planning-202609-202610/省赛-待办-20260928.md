### ★ 由此得到的四条硬结论

**① 判分维度 = 颜色 + 形状（两条）。"信息"不在评分条款里。**
`:262-266` 通篇只按"颜色和形状"判；`:139-141` 现场流程也只写"形状相同且颜色相同"。
⇒ 与你 2026-09-28 的口径（"只有颜色和形状都相同才可同盒"）**完全一致**。

**② "信息"（污渍/缺陷/文字/二维码）出现在两处，但两处性质不同：**
- `:19-20` = **识别能力要求**（"应能识别颜色、形状、文字、图像、二维码等"）
- `:52-55` = **货物外观描述 + 通用同盒条款**（"形状、颜色以及信息完全一致"）
- ⚠️ **`:52-55` 与 `:139-141`/`:262-266` 字面冲突**：前者要求三要素一致，后者只按两要素判分与评分。
  **这是赛规自身的矛盾，不是我们的文档问题 —— 建议现场向裁判确认一句。**

**③ 🔴 所以"纯颜色法失效"的真正原因不是二维码，而是「形状必须识别」。**
- 校赛：一色一件 ⇒ 颜色唯一确定货格 ⇒ `stage1_color_v6_send.py` **根本不测形状**（纯 HSV 阈值分色）
- 省赛：种类 ≥6、24 件 ⇒ **必然出现"同色不同形"或"同形不同色"**，而判分要求"颜色+形状都相同才可同盒" ⇒ **形状必须测**
- ⇒ **视觉的最小充分目标 = 颜色 + 形状（几何体类别）**；二维码/文字/污渍属"合规能力 + 风险对冲"，**不是拿分依据**

**④ 🔴 新风险：显示示例里出现「正四面体」，而我们的 7 类里没有这一类。**

| 事实 | 证据 |
|---|---|
| 我们模型是 7 类几何体：`cube / cuboid / cylinder / hexagonal_prism / pentagonal_prism / square_pyramid / triangular_prism` | `视觉/models/labels_yolo5s_geom7c.txt`、`training/data.yaml:6-14` |
| 赛规显示示例第 2 条 = **"正四面体"** | `省赛规则.txt:154` |
| 台账记录：用户 2026-09-15 曾裁决"**赛题的「正四面体」= 我们的「四棱锥」(`square_pyramid`, class_id=5)**"，词表不补类；**但当时留了分歧**——几何上正四面体（4 个全等三角形面）≠ 四棱锥（方形底 + 4 三角形面），并给出"低成本验证：看实物底面" | `docs/冲突与决策台账-2026-09-10.md` §0（`:74`）、`docs/reports/2026-08-26-vision-review.md:71` |
