## ⚡ 供电系统

### 主电源（4S 14.8V电池）
```
电池XT60+
    ↓
保险丝 15A
    ↓
船型开关
    ↓
分支：
    ├─→ PD42S1 X轴 (V+)
    ├─→ PD42S1 Y轴 (V+)
    ├─→ 降压模块① 输入
    └─→ 降压模块② 输入

电池XT60- → 总地
```

### 降压模块① → 5V/5A
| 输入 | 输出 | 供给 |
|------|------|------|
| 14.8V | 5.0V | 树莓派 (Pin2) |
| GND | GND | STM32 (5V) |
| — | — | ToF (VDD) |

**⚠️ 调节**：万用表测输出，调到5.0V ±0.1V

### 降压模块② → 6V/5A
| 输入 | 输出 | 供给 |
|------|------|------|
| 14.8V | 6.0V | 电磁阀 (VCC) |
| GND | GND | 微雪板 (VIN) |

## ✅ 接线检查清单（按顺序）

### 第一步：断电状态检查
- [ ] 船型开关在**断开**位置
- [ ] 电池已连接保险丝
- [ ] 降压模块①②已接好输入

### 第二步：PD42S1驱动器（断电）
- [ ] X轴：STEP=PC6, DIR=PA7, EN=PA5, COM=3.3V
- [ ] X轴：V+=电池+, GND=电池-
- [ ] X轴：T/A/H=红+绿, R/B/L=蓝+黄
- [ ] X轴：细分拨码=**16**
- [ ] Y轴：STEP=PB6, DIR=PC7, EN=PD7, COM=3.3V
- [ ] Y轴：V+=电池+, GND=电池-
- [ ] Y轴：T/A/H=红+绿, R/B/L=蓝+黄
- [ ] Y轴：细分拨码=**16**

### 第三步：控制器供电（断电）
- [ ] 树莓派：5V/GND ← 降压①（或充电宝）
- [ ] STM32：5V/GND ← 降压①

### 第四步：通讯线（断电）
- [ ] STM32 PA2/PA3 ↔ 树莓派 GPIO14/GPIO15
- [ ] ToF: VDD/RX/TX/GND ↔ 5V/PC10/PC11/GND
- [ ] 电磁阀：控制线→PB11, VCC→6V, GND→总地

### 第五步：上电前最后检查
- [ ] 所有接线已紧固
- [ ] 无裸露金属
- [ ] 正负极无反接
- [ ] GND全部共地
- [ ] 万用表测降压①=5.0V, 降压②=6.0V
- [ ] 船型开关仍在**断开**位置

### 第六步：上电测试
- [ ] 打开船型开关
- [ ] 树莓派红绿灯亮
- [ ] STM32指示灯亮
- [ ] PD42S1指示灯亮（2个）
- [ ] 无异常发热/异味/火花

---

## ⚠️ 重要提醒

1. **COM必须接3.3V**（PD42S1共阳接法，2个驱动器各1根）
2. **电磁阀接PB11**（不是PB10）
3. **细分=16**（2个驱动器都要设）
4. **EN极性待测试**（上电后若电机不动，可能需要改固件）
5. **所有GND共地**
6. **V+/GND用粗线**（14AWG或更粗）
