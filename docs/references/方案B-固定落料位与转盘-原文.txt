可能原因
排查依据
旧坐标未清除
移走物料，检查是否明确返回“无目标”，而非继续使用上一帧坐标。

同时记录采图帧号和推理完成状态；心跳正常不代表图像正常。
供电或物理连接问题
检查故障是否集中在舵机动作、电机启动时；核对供电、共地、接口与通信参数。
推荐协议：新请求、新图像、一次执行
① 树莓派准备处理下一件时生成request_id；视觉端应使用新采集图像响应，返回同一请求编号。无目标、推
理失败也应返回明确状态。
② 只接受当前请求的有效结果。重复、过期、已完成任务和重启前会话的数据均拒绝。未经时钟同步时，不直
接相减两块板子的时间戳，可用请求编号及树莓派本地超时管理。
③ 运动命令使用独立cmd_id；控制器重复收到相同编号时只回复状态，不重复执行。ACK表示收到命令，
DONE表示动作完成，不能混用。
④ 串口采用完整分帧与校验；一次读取未必对应一个完整数据包。Sipeed文档提供了帧头、帧尾或长度、校验
的说明。[4]
建议数据字段：request_id、frame_id、status、target_id、shape、color、info、x、y、confidence、bin_id。
坐标必须说明属于像素还是机械毫米坐标，不能混用。
失联与异常处理
监测最近成功采图和推理时间，而不只看通信心跳。超时后禁止启动新抓取；对已锁定目标且正在进行的搬运
，按预设状态暂停或收尾，不简单断电导致物料掉落。抓空、货格未到位或落料异常时，不虚增成功数量。
若树莓派直接用普通Python循环产生步进脉冲，应评估把脉冲、限位和动作完成反馈交给运动控制器或单片机。推理、显示和
运动调度应避免相互阻塞。

落料口的几何位置
上层矩形平面的角落不一定处在下方圆盘上方。固定落料口需避开中心轴、外壁和径向隔板，校核物料最大姿
态下的水平包络以及下落偏移。
r = sqrt[(Xd - Xc)² + (Yd - Yc)²]
Ri + a + c ≤ r ≤ Ro - a - c
C(Xc,Yc)为转轴中心，P(Xd,Yd)为落料中心；Ri、Ro为可用内外半径，a为物料水平包络圆半径，c为定位与下落偏移余量。该式
只校核内外壁，还应单独校核两侧隔板。
校核项目
具体要求
物料离盘高度
固定落料位减少了逐盒放置的变化，但XY本身不产生抬升。若夹爪闭合已有托举作用，验证底
面净空；否则补充必要抬升。
底板动作空间
向下翻开的底板不能碰货格隔板或已存物料。先停转盘再开底板，确认关到位后才允许转盘运
动。
货格定位
设置零位和可靠的位置依据，不能只用电机通电时间选格。六格等分时名义角间隔60°，偏角与
方向实测。
连续装料
分别测试货格内已有1、2、3件时再落料；检查卡口、跨格、外露以及转盘加减速导致的物料
移动。

坐标体系与标定方法
将上层一个固定落料点与下方六个选格角度分开管理。
参数
定义及用途
图像坐标 (u,v)
图像左上角为原点，u向右、v向下，单位像素。
托盘坐标 (XT,YT,ZT)
选定水平托盘参考平面的一个角为原点，X向右、Y向远端、Z向上，单位mm。
机械坐标与工具偏移
机械原点由回零确定；补偿滑块参考点至实际夹持中心的偏移。若夹爪旋转，偏移可
能随角度变化。
抓取点、落料点、退出点
抓取点每件更新；落料点(Xd,Yd)和退出点(Xs,Ys)分别标定。
转盘角度 θk
θk = θ0 + s × (k - 1) × 60°。仅适用于六格等分，k为1-6，s为实测正反方向。
