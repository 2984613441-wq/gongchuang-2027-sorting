**日期**：2026-10-11

## 一、树莓派接线

### 1. 树莓派 ↔ STM32通讯

| 树莓派引脚 | 接到 | STM32引脚 | 说明 |
|-----------|------|----------|------|
| **GPIO14 (Pin8, TX)** | → | **PA3 (RX)** | 树莓派→STM32 |
| **GPIO15 (Pin10, RX)** | ← | **PA2 (TX)** | STM32→树莓派 |
| **Pin6 (GND)** | ─ | **GND** | 共地 |

**⚠️ 注意**：
- Pin编号是物理位置（40针排针）
- GPIO编号是逻辑引脚
- Pin8 = GPIO14 = TXD
- Pin10 = GPIO15 = RXD

### 2. 树莓派供电

| 树莓派引脚 | 接到 | 说明 |
|-----------|------|------|
| **Pin2 (5V)** | 降压模块① 5V输出 | 主供电（或充电宝） |
| **Pin6 (GND)** | 总地 | 地 |

**⚠️ 当前状态**：用充电宝临时供电

## 二、ToF测距（TinyF）

### 接线

| TinyF端子 | 接到 | 说明 |
|----------|------|------|
| **VDD (5V)** | 降压模块① 5V输出 | 供电 |
| **RX** | STM32 **PC10** (UART4_TX) | STM32发送 |
| **TX** | STM32 **PC11** (UART4_RX) | STM32接收 |
| **GND** | 总地 | 地 |

**⚠️ 注意**：
- ToF的RX接STM32的TX（PC10）
- ToF的TX接STM32的RX（PC11）
- 交叉连接，不要接反

### 通讯协议

TinyF使用简单协议（115200 8N1）：
```
帧格式：0xAA 0x55 <距离高字节> <距离低字节> <校验>
距离单位：mm
测量范围：0~8000mm
```

**当前状态**：
- ✅ STM32已添加UART4初始化
- ⚠️ 缺少TinyF帧解析代码（后续添加）

## 三、转盘舵机（微雪总线舵机）

### 方案

根据DeepSeek调查报告，当前方案是：
- **方案C**：3个固定落点 × 转盘2位（A侧/B侧）
- 转盘由微雪总线舵机控制
- 通过串口（USB转TTL）控制

### 接线

#### 微雪板供电

| 微雪板端子 | 接到 | 说明 |
|-----------|------|------|
| **VIN (6V)** | 降压模块② 6V输出 | 供电 |
| **GND** | 总地 | 地 |

#### 微雪板 ↔ 树莓派通讯

| 微雪板端子 | 接到 | 树莓派引脚 | 说明 |
|-----------|------|-----------|------|
| **TXD** | → | **GPIO15 (Pin10, RX)** | 微雪→树莓派 |
| **RXD** | ← | **GPIO14 (Pin8, TX)** | 树莓派→微雪 |
| **GND** | ─ | **Pin6 (GND)** | 共地 |

**⚠️ 冲突问题**：
- 树莓派GPIO14/GPIO15已经给STM32用了
- **方案1（推荐）**：用USB转TTL连微雪板
- **方案2**：改用其他GPIO（需改代码）

### 方案1：USB转TTL（推荐）

```
USB转TTL模块
    ↓ USB
树莓派USB口
```

微雪板接USB转TTL：
| 微雪板 | USB转TTL |
|-------|---------|
| TXD | RX |
| RXD | TX |
| GND | GND |

树莓派侧设备：`/dev/ttyUSB0`

**优点**：
- 不占用GPIO
- 简单可靠
- 当前配置已经是这个方案（`sorting_config.ini` 里写的是 `/dev/ttyUSB0`）

**缺点**：
- 需要USB转TTL模块
- 占用一个USB口

### 转盘舵机参数（已配置）

根据 `sorting_config.ini`：

```ini
[Turntable]
center_us = 1500          # 中位脉宽
us_per_90deg = 655        # 每90°对应脉宽变化

# 计算结果（2026-09-22确认）
A侧 = 1500 - 655 = 845 µs
B侧 = 1500 + 655 = 2155 µs

settle_s = 1.0            # 稳定时间
index_side = none         # 索引开关（未启用）
```

**盒子映射**（`sorting_config.ini [BoxMap]`）：
```
盒子1,2,3 → A侧（845 µs）
盒子4,5,6 → B侧（2155 µs）
```

## 四、完整接线图

```
【供电系统】
14.8V电池+
    ├─→ PD42S1 X轴 (V+)
    ├─→ PD42S1 Y轴 (V+)
    ├─→ 降压模块① 输入
    └─→ 降压模块② 输入

降压模块① 5V输出
    ├─→ 树莓派 Pin2
    ├─→ STM32 5V
    └─→ ToF VDD

降压模块② 6V输出
    ├─→ 电磁阀 VCC
    └─→ 微雪板 VIN

总地（所有GND共地）


【控制信号】
树莓派 GPIO14/15
    ↓ UART
STM32 PA2/PA3
    ↓ 解析协议
    ├─→ PD42S1 X/Y轴（PC6,PA7,PA5 / PB6,PC7,PD7）
    ├─→ 电磁阀（PB11）
    └─→ ToF（PC10/PC11）

树莓派 USB口
    ↓ USB转TTL
微雪板 (/dev/ttyUSB0)
    ↓ feetech协议
转盘舵机
```
