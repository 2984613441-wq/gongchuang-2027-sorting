### 改动2：ToF接UART4（PC10/PC11）

**新增引脚**：
| 功能 | 引脚 | 原来用途 |
|------|------|---------|
| UART4 TX | PC10 | 空闲 ✅ |
| UART4 RX | PC11 | 空闲 ✅ |

**需要修改的文件**：

**1. Core/Src/main.c（CubeMX生成部分）**
```c
// 在 MX_GPIO_Init() 或 CubeMX 里配置：
// PC10 = UART4_TX (AF8)
// PC11 = UART4_RX (AF8)

UART_HandleTypeDef huart4;

void MX_UART4_Init(void) {
    huart4.Instance = UART4;
    huart4.Init.BaudRate = 115200;
    huart4.Init.WordLength = UART_WORDLENGTH_8B;
    huart4.Init.StopBits = UART_STOPBITS_1;
    huart4.Init.Parity = UART_PARITY_NONE;
    huart4.Init.Mode = UART_MODE_TX_RX;
    HAL_UART_Init(&huart4);
}
```

**2. App/Src/ec_tof.c（新建文件）**
```c
#include "ec_tof.h"
#include "stm32f4xx_hal.h"

extern UART_HandleTypeDef huart4;

void tof_init(void) {
    // 已在 MX_UART4_Init() 初始化
}

uint16_t tof_measure(void) {
    uint8_t rx_buf[5];
    // TinyF 帧格式：0xAA 0x55 <距离高> <距离低> <校验>
    if (HAL_UART_Receive(&huart4, rx_buf, 5, 100) != HAL_OK) {
        return 0xFFFF;  // 超时
    }
    
    // 校验
    uint8_t checksum = rx_buf[0] ^ rx_buf[1] ^ rx_buf[2] ^ rx_buf[3];
    if (checksum != rx_buf[4]) {
        return 0xFFFF;  // 校验失败
    }
    
    // 距离（mm）
    uint16_t distance = (rx_buf[2] << 8) | rx_buf[3];
    return distance;
}
```

**3. App/Inc/ec_tof.h（新建文件）**
```c
#ifndef EC_TOF_H
#define EC_TOF_H

#include <stdint.h>

void tof_init(void);
uint16_t tof_measure(void);  // 返回距离（mm），失败返回0xFFFF

#endif
```

### 改动3：Z轴气动夹爪（PB10改GPIO）

**原来**：PB10 = TIM2_CH3 PWM（舵机脉宽控制）

**改成**：PB10 = GPIO输出（电磁阀控制）

**需要修改的文件**：

**1. Core/Src/main.c（CubeMX部分）**
```c
// 在 CubeMX 里：
// PB10 从 TIM2_CH3 改成 GPIO_Output
// 或者代码里手动配置：

GPIO_InitTypeDef GPIO_InitStruct = {0};
GPIO_InitStruct.Pin = GPIO_PIN_10;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
GPIO_InitStruct.Pull = GPIO_NOPULL;
GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
HAL_GPIO_Init(GPIOB, &GPIO_InitStruct);
```

**2. App/Src/ec_pneumatic_gripper.c（已有文件，检查是否需要修改）**
```c
// 检查这个文件是否已经实现了气动夹爪控制
// 如果没有，添加：

void gripper_open(void) {
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_10, GPIO_PIN_RESET);  // 低电平 = 松开
}

void gripper_close(void) {
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_10, GPIO_PIN_SET);    // 高电平 = 夹紧
}
```

**3. 删除舵机相关代码**
- 检查 `ec_motion_plan.c` 里是否有 `EC_AXIS_STEP_Z_SERVO`
- 如果有，改成调用 `gripper_open()` / `gripper_close()`

### 改动4：STS3215转盘（树莓派控制，STM32不改）

**无需修改STM32代码**

原因：STS3215通过微雪板USB连接树莓派，STM32不参与控制

**树莓派侧**（另一个仓库）：
```python
from feetech import STS3215

servo = STS3215(port='/dev/ttyUSB0', baudrate=1000000)
servo.set_position(servo_id=1, angle=120)
```
