# 电控与视觉优化方案汇总（夹爪改气动后）

> **前提**：夹爪改成气动（机械组负责），我们只管电控和视觉优化。
> **日期**：2026-10-10
> **来源**：从交接总纲、省赛硬件升级文档、历次讨论中提取

---

## 一、电控优化（7项）

### 1.1 主频提升：16MHz → 168MHz

**现状**：`system_stm32f4xx.c:119` 已改 `PLL_M=8`，7 个 TIM PSC 已改，`check_clock_tree.py` PASS，**但还没编译、没烧录**。

**效果**：STM32 运行速度提升 10.5 倍 ⇒ 串口处理、运动规划、堵转检测响应更快。

**实施**：编译 → 烧录 → 测试（用示波器测 PWM 频率确认是否真的跑在 168MHz）。

---

### 1.2 XY 轴闭环：A4988 → PD42S1

**现状**：A4988 开环，丢步了系统不知道，校赛因此越程堵转 3 次。

**方案**：换正点原子 ATK-PD42S1（光耦隔离版，¥72.4 × 2）
- 板载 16384 线磁编码器
- 堵转保护（可设堵转电流）
- 无限位回零（省掉限位开关）
- 细分设 16 ⇒ 3200 脉冲/圈，**80 步/mm 不变**
- 脉冲电平 0~5V 共阳，**STM32 3.3V 直连**

**电控改动**（L4）：
1. **引脚重分配**：现有 PA0/PA1/PA2/PA3 被 A4988 占，PD42S1 用新引脚（如 PE0~PE7）
2. **接线**：STEP / DIR / EN / COM（3.3V）接 STM32，A+ A- B- B+ 接电机
3. **供电**：12~32V 直接从 4S 14.8V 电池取

**效果**：XY 轴不再丢步；堵转立即停止；省掉限位开关。

---

### 1.3 转盘：270° 舵机 → STS3215（360° 编码舵机）

**现状**：现在这个 270° 舵机到不了 180° 那格。

**方案**：换飞特 STS3215（¥105）
- 360° 绝对角度位置模式
- 自带磁编码器（0.088° 分辨率）⇒ **不需要光电开关做零点**
- 19.5 kg·cm @ 7.4V，转盘负载轻，富余量大
- 堵转速度 52 RPM = 312°/秒 ⇒ 转 60° 约 0.19 秒

**电控改动**（推荐不触发 L4）：
1. STS3215 接**微雪总线板**（¥24，USB-C + UART）
2. 微雪板 USB-C 接**树莓派**（不接 STM32）
3. 转盘逻辑全在树莓派 `turntable.py`，固件不动 ⇒ **不触发 L4**
4. 供电：6V（从舵机专用降压模块调到 6V 再进微雪板）

**效果**：转盘 360° 可控；不需要光电开关；堵转保护。

---

### 1.4 Z 轴夹爪：单舵机 PWM → 气动电磁阀

**现状**：DS3120MG 单舵机联动，脉宽 1000us 张开、1900us 闭合（`ec_motion_plan.c:147-151`）。

**方案**（待机械组出图）：
- 气动夹爪 = **电磁阀** + 气缸 + 气泵（或气罐）
- 电磁阀控制：STM32 的一个 **GPIO 输出**（高电平吸合、低电平释放）
- 不再需要 PWM（TIM2_CH3 PB10 可以释放出来）

**电控改动**（L4）：
1. 删掉 `ec_motion_plan.c:147-151` 的舵机脉宽代码
2. 改成电磁阀控制：
   ```c
   void gripper_open(void) {
       HAL_GPIO_WritePin(GPIOB, GPIO_PIN_10, GPIO_PIN_RESET);  // 低电平释放
   }
   void gripper_close(void) {
       HAL_GPIO_WritePin(GPIOB, GPIO_PIN_10, GPIO_PIN_SET);    // 高电平吸合
   }
   ```
3. 回退 `ec_board_stm32.c:243` 和 `stm32f4xx_hal_msp.c:484` 的 PB10 总线切换代码（改完气动后这段代码就没用了）

**效果**：抓力更大（气动 > 舵机）；抓尖顶件更稳；代码更简单（GPIO 翻转 vs PWM 脉宽）。

---

### 1.5 固定落点 + 转盘转格

**现状**：`ec_app.c:238-242` 有 6 个 XY 坐标占位符。

**方案**：6 个盒固定位置（只有 1 个落点），抓完一件不动 XY、只转盘让下一格过来。

**电控改动**（等实物装好后测量）：
1. 手动示教：摇杆移到那 1 个落点正上方，记录 `current_x / current_y`
2. 写死到 `ec_app.c`：
   ```c
   static const int16_t drop_position_x = xxx;  // 固定落点 X
   static const int16_t drop_position_y = yyy;  // 固定落点 Y
   ```
3. 改 `handle_item_task()` 里的 `target_x / target_y`：
   ```c
   target_x = drop_position_x;  // 恒定
   target_y = drop_position_y;  // 恒定
   ```
4. 转盘脉宽映射表（等 STS3215 到货后测 6 个角度对应的脉宽）

**效果**：XY 轴只在"取件区 ↔ 落点"之间移动，路径固定 ⇒ 速度更快、更稳定。

---

### 1.6 供电架构：单电池 + 双降压

**现状**：校赛那块小电池撑 1 小时就掉到 11.3V，一掉压步进就丢步。

**方案**：
```
4S 14.8V 电池（XT60 口，≥6000mAh）
    │
    ├─ 15A 保险丝 + 船型开关
    │
    ├─→ PD42S1 驱动器 ×2（X/Y 轴，直接 14.8V）
    │
    ├─→ 降压模块 ① → 5V ≥5A
    │       ├─→ 树莓派 4B
    │       ├─→ STM32F407ZGT6
    │       └─→ 白光补光灯
    │
    └─→ 降压模块 ② → 6V ≥5A
            ├─→ 微雪总线板 → STS3215 转盘舵机
            └─→ 气动电磁阀（若需要）
```

**电控改动**：无（只是接线）。

**效果**：电池容量大 6 倍（1000mAh → 6000mAh）；电压不掉（14.8V 末段仍 >12V）；舵机独立供电（交接总纲要求）。

---

### 1.7 生产工程配置：关调试宏

**现状**：`uvprojx:337` 的 `EC_DIAGNOSTIC_BUILD / EC_MOTION_TEST_BUILD / EC_SERVO_TEST_BUILD=1` 仍开着 ⇒ 赛时串口噪声会被拼成命令让机器自己动。

**方案**：改 `=0`。

**电控改动**：编译前改一次，以后都用生产配置。

**效果**：赛时不会因为串口噪声自己乱动。

## 二、视觉优化（5项）

### 2.1 形状识别：纯颜色查表 → 模型 + HSV + ToF

**现状**：没有形状识别，只有颜色查表（`stage1_color_v6_send.py`）⇒ **省赛判分要求"颜色 + 形状"都对**。

**方案（路线 C）**：
1. **形状**：YOLO 模型（MaixCAM 跑 `.mud`）
2. **颜色**：HSV 像素统计（`stage1_color_v6_send.py` 的现有逻辑）
3. **深度**：TinyF 测 2~3 个点（中心 + 偏 10mm 两侧），区分"俯视长得一样"的三组
4. **特征点**：只做"置信度加权辅助"，不做硬筛选（`final = 0.3·特征 + 0.7·模型`）

**视觉改动**（L4）：
1. 标注 600~1260 张（Roboflow）
2. 训练 YOLO → MaixHub 转 `.mud`
3. MaixCAM 加载 `.mud` 跑推理
4. 发给树莓派：`(形状, 颜色, is_flat_top, is_peaked, d_center)`

**效果**：能识别 6 类形状；能区分"圆柱 vs 圆锥"、"正方体 vs 四棱锥"、"三棱柱 vs 正四面体"。

---

### 2.2 ToF 深度：单点 + 多点测量

**现状**：没有深度信息。

**方案**：TinyF 测距模块（¥43.8）
- 装在 Z 轴/夹爪头上
- 抓之前移到件正上方 80~100mm 高度
- 测 3 个点：中心 + 偏 10mm 两侧
- 判断逻辑：
  ```python
  is_flat_top = (abs(d_center - d_right) < 5 && abs(d_center - d_left) < 5)
  is_peaked = (d_center < d_right - 5 && d_center < d_left - 5)
  ```

**视觉改动**（L4）：
1. TinyF VDD/RX/TX/GND 接 STM32 某个 UART（如 UART4 PC10/PC11）
2. 固件封装 `uint16_t tinyf_measure(void)`，返回距离（mm）
3. Z 轴移到件正上方，调用 3 次，XY 偏移 ±10mm
4. 发给树莓派：`is_flat_top / is_peaked`

**效果**：区分"平顶 vs 尖顶" ⇒ 解决"圆柱 vs 圆锥"、"正方体 vs 四棱锥"。

---

### 2.3 补光灯：自然光 → 白光补光

**现状**：HSV 阈值在自然光下标的，光照变化时阈值不稳。

**方案**：白光补光灯（5V、6000~6500K、环形，¥30）
- 装到相机旁
- 5V 从降压模块取

**视觉改动**：
1. 补光灯装好后，重新用 6 类件拍 20 张（每类件在不同位置/堆叠状态）
2. 用 `cv2.inRange()` 重新标 HSV 下限/上限
3. 写回 `stage1_color_v6_send.py`

**效果**：HSV 阈值稳定，不受自然光照变化影响。

---

### 2.4 协议改动：MaixCAM 报颜色+形状、树莓派查表

**现状**：MaixCAM → 树莓派的 `BATCH_TARGETS` 帧，第 1 字节是**盒号**（1~6） ⇒ **6 类件现场才知道放哪个盒，改规则就得重刷 MaixCAM**。

**方案**：第 1 字节从"盒号"改成 **高 4 位颜色 + 低 4 位形状**
- 帧长不变 7 字节
- 树莓派新增配置节 `(颜色, 形状) → 盒号`
- **6 类件现场才知道** ⇒ 改一个 ini 就行，**不用重刷 MaixCAM**

**视觉改动**（L4）：
1. `vision_ingest.py:52`（现在把 ID 字节当盒号）
2. MaixCAM 发送端 `encode_target`（现在只接受 1..6）
3. `interface-contract.md` 升版
4. 端到端测试

**效果**：现场分配盒号只需改树莓派 ini，不用重刷 MaixCAM（约省 10 分钟）。

---

### 2.5 Week1 验证实验：确认两个关键假设

**目标**：
1. **几何特征准确率**：确认"特征点辅助"是否有用
2. **数据量对比**：确认 600 还是 1260 张够

**视觉改动**（10-23~10-26，4 天）：
1. 用现有物料（6 类件各 10 个）测几何特征（面积/周长/凸包/矩）识别准确率
2. 若 **<70%**，则不用特征辅助，只用模型 + HSV 颜色
3. 标注 300/600/1260 张三组，训练 3 个模型，测 mAP@0.5
4. 画曲线：数据量 vs mAP，找拐点
5. 若 600 张已达 mAP >0.85 且 1260 张只提升 <5%，则只标 600 张

**效果**：避免浪费时间在无用的特征工程上；避免过度标注。

## 三、汇总与优先级

| # | 项 | 类别 | 改动量 | 效果 | 优先级 |
|---|---|---|---|---|---|
| 1 | 主频 168MHz | 电控 | 小（已改，只差烧录） | 全局提速 10.5 倍 | **P0** |
| 2 | XY 闭环（PD42S1） | 电控 | 中（引脚重分配） | 解决丢步 | **P0** |
| 3 | 形状识别（模型 + HSV） | 视觉 | 大（标注 + 训练） | 省赛判分要求 | **P0** |
| 4 | Z 轴气动夹爪 | 电控 | 小（GPIO 替换 PWM） | 抓力更大、抓尖顶件 | **P1** |
| 5 | 转盘 STS3215 | 电控 | 小（接树莓派不触发 L4） | 360° 可控、不需光电开关 | **P1** |
| 6 | ToF 深度（TinyF） | 视觉 | 中（接 UART + 算法） | 区分平顶/尖顶 | **P1** |
| 7 | 补光灯 + 重标 HSV | 视觉 | 小（装灯 + 重标） | HSV 阈值稳定 | **P2** |
| 8 | 固定落点 + 转盘转格 | 电控 | 小（写死坐标） | XY 路径固定、更快 | **P2** |
| 9 | 供电架构（4S 电池） | 电控 | 小（只是接线） | 电池容量大 6 倍 | **P2** |
| 10 | 协议改动（颜色+形状） | 视觉 | 中（跨子系统 L4） | 现场分配盒号不用重刷 | **P2** |
| 11 | 生产工程配置 | 电控 | 极小（改 3 个宏） | 赛时不会乱动 | **P3** |
| 12 | Week1 实验 | 视觉 | 中（4 天实验） | 避免浪费时间 | **P1** |

**P0**：必须做，否则省赛无法参赛（形状识别）或风险极高（丢步）。
**P1**：强烈推荐，效果明显。
**P2**：有改进，但不紧急。
**P3**：保险项。
