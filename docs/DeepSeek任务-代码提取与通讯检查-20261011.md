## 三、任务2：检查三端通讯协议

### 2.1 STM32 → 树莓派（USART2）

**从run_chain.py中查找**：
```bash
grep -n "serial\|UART\|115200\|/dev/serial0" run_chain.py | head -30
```

**关键信息**：
- 波特率：应为115200
- 串口设备：`/dev/serial0` → ttyS0
- 数据格式：8N1
- 协议格式：查找帧头、帧尾、校验

**示例协议**（需确认）：
```
STM32 → 树莓派：
- 确认指令：ACK/NACK
- 状态上报：位置、限位、错误

树莓派 → STM32：
- 运动指令：G <box_id> <x> <y>
- 夹爪指令：GRIP_OPEN / GRIP_CLOSE
- 查询指令：?
```

### 2.2 MaixCAM → 树莓派（TCP 8765）

**从run_chain.py中查找**：
```bash
grep -n "8765\|socket\|TCP\|recv\|send" run_chain.py | head -30
```

**关键信息**：
- 监听端口：8765
- 协议格式：查找数据包结构
- 识别数据：box_id, x, y（像素坐标）

**示例协议**（需确认）：
```
MaixCAM → 树莓派：
每目标约7字节：
<box_id><x_high><x_low><y_high><y_low><conf><checksum>
```

### 2.3 STM32 ↔ ToF（UART4，新增）

**已知配置**：
- 引脚：PC10 (TX) / PC11 (RX)
- 波特率：115200
- TinyF协议：0xAA 0x55 <距离高> <距离低> <校验>

**需要确认**：
- 距离单位：mm
- 更新频率：Hz
- 集成到哪个模块
