## 3.2 高度视差补偿：机制完整但被关闭

`pixel_to_device.py` 实现「仿射 → 顶面坐标 → 视差补偿 → 底面坐标」，
`scale = camera_height / (camera_height - object_height)`，配置项 `[ObjectHeights]`。

**但当前 6 个全填 `0.0`（2026-09-18 粗标期间有意关闭）。**

**量化影响**（`camera_height = 262 mm`）：

| 情形 | 离光轴 50mm 处误差 | 87.5mm（近角落）处误差 |
|---|---|---|
| 不补偿，物块实高 30mm | **6.5 mm** | **11.3 mm** |
| 填 30 实 25 | 0.4 mm | **2.1 mm** |

**⇒ 量一下物块高度填进 `[ObjectHeights]`，误差可从 11mm 降到 2mm。**
**⇒ 比"动态按尺寸补偿"（需改协议加 bbox 宽高，L4）划算 10 倍。**

## 3.3 Z 轴现状：当前**没有真正的 Z 轴**

`ec_axis_driver.h:44` 原文：「单舵机联动：一个舵机同时决定"升降"与"夹爪开合"」，
`EC_AXIS_Z_DOWN_US == EC_AXIS_GRIPPER_CLOSE_US`。

**⇒ 现在的"Z"是 LDX-335MG 通过连杆同时实现升降+开合，一个自由度。**
**⇒ 真 Z 轴硬件未到；到了之后需新增 PWM 通道并拆分运动计划（不做白做）。**

## 3.4 现行生产视觉是「颜色查表」，不是「识别形状」

`视觉/src/maixcam_deploy/stage1_color_v6_send.py:249-251`：
```python
COLOR_TO_MATERIAL = {
    "cyan": ("cube", 1), "green": ("cube", 2),
    "red": ("triangular_prism", 3), "blue": ("triangular_prism", 4),
    "black": ("cylinder", 5), "orange": ("cylinder", 6),
}
```

**⇒ 这是校赛"颜色唯一确定货物"的做法；新赛规"5色×6形状解耦"下 100% 失效。**
