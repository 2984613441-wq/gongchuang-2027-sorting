## 七、供电

### 主电源
```
4S电池+ → 保险丝 → 船型开关 → 分4路:
    ├─ PD42S1 X轴 (14.8V)
    ├─ PD42S1 Y轴 (14.8V)
    ├─ 降压① 输入 (14.8V)
    └─ 降压② 输入 (14.8V)

4S电池- → 总地
```

### 降压模块①（调到5V）
- 输入：14.8V
- 输出：树莓派 + STM32 + TinyF

### 降压模块②（调到6V）
- 输入：14.8V
- 输出：微雪板 + 电磁阀
