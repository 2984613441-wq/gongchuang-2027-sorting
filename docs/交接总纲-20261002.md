## 6. 已经改了什么 / 什么还没烧

### 6.1 🔴 固件主频：**16 MHz → 168 MHz（代码已改，❌ 还没烧录）**

**改了什么**（共 2 个文件 / 18 行）：

| 文件 | 改动 |
|---|---|
| `Core/Src/main.c` → `SystemClock_Config()` | `HSI 16MHz + PLL_NONE` → **`HSE 25MHz + PLL = 168MHz`**；`APB1=DIV4`（42MHz）、`APB2=DIV2`（84MHz）；`FLASH_LATENCY_0 → 5` |
| `Core/Src/main.c` → **7 个定时器 Prescaler** | TIM2/3 `15→83`、**TIM4 `159→839`**、**TIM8 `159→1679`**、TIM9 `159→839`、TIM10/11 `15→167` |
| `Core/Src/system_stm32f4xx.c` | `SystemCoreClock 16000000 → 168000000` |

**为什么**：① 项目**自己的设计文档**就按 168MHz 时钟树核算（`docs/design/stm32f407-pin-timer-allocation.md:90`）；② 运动规划代码的设计假设就是 168MHz（`ec_step_profile.h:66-67` 原文"sqrt is ~1 us on a 168 MHz M4"）—— 16MHz 下同一开方要 **10.5µs**，占 100µs 预算的 10%，**且每拍在步进中断里都算**。

**自检**：新增 `工具/check_clock_tree.py`，**已通过（exit 0）**：
```
HSE 25MHz → PLL 25/336/2 → SYSCLK 168MHz；HCLK 168 / PCLK1 42 / PCLK2 84
TIM2/3 = 50.00 Hz ✅   TIM4/8/9 计数钟 = 100,000 Hz ✅（= EC_STEP_TIMER_HZ）
TIM10/11 = 50.00 Hz ✅   SystemCoreClock = 168,000,000 ✅
```

**回退**：`Core/Src/main.c.bak-before-20260928-168mhz`、`Core/Src/system_stm32f4xx.c.bak-before-20260928-168mhz`（连同 7 个 PSC 一起回退）。

**⚠️ 关键提醒**：**F407 绝不能调用 `HAL_PWREx_EnableOverDrive()`**（`stm32f407xx.h` 无 `PWR_CR_ODEN`；HAL 该函数注释写明只适用 F42x/F43x/F446/F469/F479）—— 误调用会等一个永不置位的标志 ⇒ **板子不启动**。

**⚠️ 本次刻意没改巡航频率** ⇒ **烧完后动作速度应该和现在几乎一样**。所以"改对了没有"可以靠"**现象没变化**"来验证 —— 这是一步**零功能变化**的改动。
**真正的提速是下一步**：巡航 `5000 → 6250 Hz`（整除档，ARR=15）。

| **④ 深度** | **ToF** —— 解开 §7.2-7 的三组歧义 + 自动量件高 + 判断"两件黏在一起" |

### 10.2 夹爪（三个方案，等 §8-2 定）

| 方案 | 好处 | 坏处 |
|---|---|---|
| **① 从上往下罩住式**（三/四指从上面罩下去再收拢） | **不用挤缝，贴得再紧也能抓** ⭐推荐 | 要重做爪子 |

### 10.3 转盘

| 项 | 设计 |
|---|---|
| 执行器 | **360° 位置型**舵机（脉宽 = 绝对角度） |
| 分格 | **6 格各自定位**；位置型有绝对反馈 ⇒ 光电开关降级为校验件 |
| 落点 | **1 个固定落点** + 转盘把目标格转过来 |
| 驱动 | 仍 **Pi GPIO18**（不动协议、不动固件） |
| 作废 | `[TurntableSides]`/`[TurntablePositions]` 2 位置语义、`[DropPoints]` 孪生约束、`工具/pi_set_droppoint3.py` |
| 新增 | 6 格脉宽表；换格策略；**每次转格时间要计入 15 秒窗** |

### 10.4 运动链（顺序很重要）

```
① 闭环：TMC2209 StallGuard 堵转检测 + 无传感器回零      ⚠️ L4
② 提主频 168 MHz（含 7 个定时器 PSC）                  ← 已完成，待烧录
③ 24V + Vref 重标定（Rs 必须实测）
④ 提巡航 5000 → 6250 Hz（整除档，ARR=15）
⑤ 提加速率 10000 → 20000 Hz/s
⑥ 热浸 + 15 秒窗对账
```
**为什么这个顺序**：提主频**只改时序、可一键回退**（改回 HSI 即恢复），不引入机械/热/电流风险；升 24V 同时引入**电压、电流、发热、电源跌落、限流设定** 5 类物理风险。**两者都必须排在"闭环"之后**（24V 和 168MHz 都会把系统推到"更容易丢步"的工况，而现在对丢步**零可观测性**）。

**并行项**：**同向逼近**（先走到目标 −3mm 再正向走 3mm）把回程差从"随机误差"变成"固定常量"。

### 10.5 供电

| 项 | 要求 |
|---|---|
| 电池 | **12V / ≥10Ah**（整机峰值约 60~80W ⇒ 12V 侧 5~7A） |
| 舵机 | **独立 5~6V ≥5A 支路**，**与主板共地** |
| Pi 入口 | 加 **1000µF + 0.1µF**；验收 `vcgencmd get_throttled` 低两位 = 0 |
