## 一、关键差异

### 朋友的代码（`f407测试气泵/Core/Src/main.c`）

```c
/* Air pump: TIM2_CH4 = PB11, 50 Hz (PSC=720-1, ARR=2000-1).
   100% duty (max suction) = 2000, 0% = 0. */
#define PUMP_DUTY_MAX   2000U
#define PUMP_ON_MS      3000U
#define PUMP_OFF_MS     3000U

/* 主循环 */
while (1) {
    /* max suction for 3 seconds */
    __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_4, PUMP_DUTY_MAX);
    HAL_Delay(PUMP_ON_MS);

    /* release for 3 seconds */
    __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_4, 0);
    HAL_Delay(PUMP_OFF_MS);
}
```

**定时器配置**：
- PSC = 720-1 = 719
- ARR = 2000-1 = 1999
- 频率 = 72MHz / 720 / 2000 = **50 Hz** ✅
- 占空比 = CCR / ARR
  - 最大 = 2000 / 2000 = **100%**
  - 最小 = 0 / 2000 = **0%**

## 二、问题分析

### 🔴 问题1：TIM2配置可能不匹配

**朋友的代码**：
- PSC = 719, ARR = 1999
- 72MHz时钟 → 50Hz
- CCR范围：0~2000

**我们的代码**：
- PSC = 83, ARR = 19999（注释说的）
- 168MHz时钟 → 应该是50Hz，但需要验证实际配置
- CCR单位假设是1µs，但可能不对

### 🔴 问题2：脉宽值范围不对

**朋友的代码**（气泵，开关控制）：
- 最大吸附 = 2000 (100%占空比)
- 释放 = 0 (0%占空比)

**我们的代码**（误用舵机脉宽）：
- 张开 = 1500µs
- 闭合 = 2500µs
- 这是**舵机的脉宽范围**，不是气泵的占空比

### 🔴 问题3：控制逻辑不对

**气动电磁阀（开关阀）**：
- 只有两个状态：开 / 关
- 应该用占空比 0% 或 100%
- 不需要中间值

**舵机（位置控制）**：
- 脉宽 1000~2000µs 控制角度
- 有中间值

**我们的代码混淆了这两种设备**

```c
#define PNEUMATIC_DUTY_OFF     0U      /* 释放：0%占空比 */
#define PNEUMATIC_DUTY_ON      2000U   /* 吸附：100%占空比 */

{
    __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_4, PNEUMATIC_DUTY_OFF);

{
    __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_4, PNEUMATIC_DUTY_ON);
}
```

**但前提是**：TIM2的PSC和ARR必须配置正确。

- 改成朋友的控制方式
- 占空比 0% = 释放
- 占空比 100% = 吸附
