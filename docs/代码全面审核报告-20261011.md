## 一、协议实现对照

### 1.1 外层帧格式（26字节）

**STM32实现**（`ec_protocol.h` + `ec_protocol.c`）：
```c
// 帧头：0xA5 0x5A
#define EC_PROTO_HEADER_0 0xA5
#define EC_PROTO_HEADER_1 0x5A
#define EC_PROTO_VERSION 0x01

// 帧结构（12字节头 + payload + 2字节CRC）
// 0-1:   0xA5 0x5A
// 2:     version (0x01)
// 3:     sender (device_id)
// 4:     receiver (device_id)
// 5-6:   task_id (BE u16)
// 7-8:   frame_seq (BE u16)
// 9:     command (u8)
// 10-11: data_len (BE u16)
// 12+:   payload
// 末2B:  CRC16-MODBUS
```

**树莓派实现**（`_pi-extract/protocol/outer_frame.py`）：
```python
HEADER_0 = 0xA5
HEADER_1 = 0x5A
VERSION = 0x01
HEADER_LEN = 12
CRC_LEN = 2
FRAME_OVERHEAD = 14

# CRC-16/MODBUS
def _crc16_modbus(data: bytes) -> int:
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 1:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return crc
```

**✅ 结论**：完全一致

### 1.2 CRC16-MODBUS实现对照

**STM32**（`ec_protocol.c:7-25`）：
```c
uint16_t ec_crc16_modbus(const uint8_t *data, size_t length)
{
    uint16_t crc = 0xFFFF;
    for (index = 0; index < length; ++index) {
        crc ^= (uint16_t)data[index];
        for (bit = 0; bit < 8; ++bit) {
            if ((crc & 0x0001) != 0) {
                crc = (crc >> 1) ^ 0xA001;
            } else {
                crc = crc >> 1;
            }
        }
    }
    return crc;
}
```

**树莓派**（同上）

**测试向量**（双方共享）：
```
"123456789" → 0x4B37
```

**✅ 结论**：算法完全一致

### 1.3 ITEM_TASK payload（12字节）

**STM32**（`ec_protocol.h:150-184`）：
```c
#define EC_PROTO_ITEM_TASK_PAYLOAD_LEN 12U
#define EC_PROTO_ITEM_TASK_X_LIMIT 1450  // ±145.0mm
#define EC_PROTO_ITEM_TASK_ANGLE_NONE 0xFF

typedef struct {
    uint8_t target_seq;      // offset 0
    uint8_t class_id;        // offset 1
    uint8_t image_id;        // offset 2  (必须 == class_id)
    int16_t x_mm10;          // offset 3-4  (落料点X, BE, 有符号)
    int16_t y_mm10;          // offset 5-6  (落料点Y, BE, 有符号)
    uint8_t grip_angle;      // offset 7    (必须 0xFF)
    int16_t pick_x_mm10;     // offset 8-9  (抓取点X, BE, 有符号, 新增)
    int16_t pick_y_mm10;     // offset 10-11 (抓取点Y, BE, 有符号, 新增)
} ec_proto_item_task_t;
```

**树莓派**（`_pi-extract/protocol/item_context.py:17-70`）：
```python
@dataclass(frozen=True)
class ItemTaskPayload:
    target_seq: int           # 1..255
    class_id: int             # 0..255
    image_id: int             # 必须 == class_id
    x_position: int           # 落料点X, 单位0.1mm, |v|≤1450
    y_position: int           # 落料点Y, 单位0.1mm, |v|≤1450
    grip_angle: int           # 必须 0xFF
    pick_x_position: int      # 抓取点X, 单位0.1mm, |v|≤1450, 不能None
    pick_y_position: int      # 抓取点Y, 单位0.1mm, |v|≤1450, 不能None

# 编码（line 124-152）
def encode_item_task(item: ItemTaskPayload) -> bytes:
    if item.pick_x_position is None or item.pick_y_position is None:
        raise PayloadError("grasp point missing")  # 硬约束
    return (
        bytes((item.target_seq, item.class_id, item.image_id))
        + x.to_bytes(2, "big", signed=True)
        + y.to_bytes(2, "big", signed=True)
        + bytes((item.grip_angle,))
        + pick_x.to_bytes(2, "big", signed=True)
        + pick_y.to_bytes(2, "big", signed=True)
    )
```

**✅ 结论**：
- 字段顺序一致
- 单位一致（0.1mm）
- 约束一致（image_id==class_id, grip_angle==0xFF, 抓取点必须有值）
- 坐标范围一致（|v|≤1450）

### 1.5 MaixCAM→树莓派协议（TCP 8765）

**格式**（`_pi-extract/vision_ingest.py`）：
```
裸数据，无外层帧，无CRC

结构：
target_count(1字节) + task_id(2字节BE) + [每个target 7字节]

每个target：
  [0]    id字节 = box_id (1..6)  ← 校赛模式，不是class_id
  [1]    confidence (0..100)
  [2-3]  X中心像素 (BE u16)
  [4-5]  Y中心像素 (BE u16)
  [6]    angle (必须0xFF)
```

**⚠️ 关键约束**（`vision_ingest.py`）：
```python
BATCH_ID_BYTE_IS_BOX_ID = True  # 校赛模式
# 如果False，整个链路停摆（box_id=None → 全部拒识）
```

**✅ 结论**：
- MaixCAM→树莓派是裸数据，不是外层帧
- id字节当前承载box_id，不是class_id
- 如果要用形状模式，必须先补class_id→box_id映射

## 二、数据流完整性检查

### 2.1 端到端数据流

```
MaixCAM (172.20.10.9 或 .2，当前离线)
    ↓ TCP客户端 → 树莓派:8765
    裸3+7N字节：count(1) + task_id(2) + [id+conf+X+Y+angle](7)*N
    id字节 = box_id (1..6)

树莓派 (172.20.10.8)
    ↓ vision_ingest.parse_batch_targets()
    提取：box_id, confidence, x_pixel, y_pixel
    ↓ pixel_to_device (仿射 + 视差补偿)
    抓取点：pick_x_mm10, pick_y_mm10 (单位0.1mm)
    落料点：查[DropPoints]配置 → x_mm10, y_mm10
    ↓ 封装ITEM_TASK (12字节)
    target_seq + class_id + image_id + x + y + 0xFF + pick_x + pick_y
    ↓ 外层帧 (26字节)
    0xA5 0x5A + 版本/设备/task_id/seq + 0x21 + len=12 + payload + CRC16

STM32 (USART2 PA2/PA3 @ 115200 8N1)
    ↓ 解析外层帧
    ec_proto_decode() → 验证CRC → 提取payload
    ↓ 解析ITEM_TASK
    ec_proto_decode_item_task() → 验证约束
    ↓ 运动规划
    抓取点 → 落料点 → 气动夹爪
    ↓ 回复
    ACK/NACK → MOTION_DONE → ITEM_RESULT
```

**✅ 结论**：数据流完整，每一步都有对应实现
