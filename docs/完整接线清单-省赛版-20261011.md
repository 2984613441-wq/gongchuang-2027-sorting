# 完整接线清单 - 省赛版

**更新时间**：2026-10-11  
**硬件版本**：气动夹爪 + PD42S1闭环 + STS3215转盘 + TinyF测距  
**供电方案**：4S 14.8V 电池 + 双降压模块

## 🔌 供电架构总览

```
4S 14.8V 电池（XT60 口，≥6000mAh）
    │
    ├─ 15A 保险丝
    │
    ├─ 船型开关（主开关）
    │
    ├─→ PD42S1 驱动器 ×2（X/Y 轴，直接 14.8V）
    │
    ├─→ 降压模块 ① → 5V ≥5A
    │       ├─→ 树莓派 4B（5V/3A）
    │       ├─→ STM32F407ZGT6（5V/0.5A）
    │       └─→ 白光补光灯（5V/0.3A）
    │
    └─→ 降压模块 ② → 6V ≥5A
            ├─→ 微雪总线板 → STS3215 转盘舵机（6V/2A）
            └─→ Z 轴电磁阀（6V，若是6V电磁阀）
```

```python
servo.set_position(servo_id=1, angle=120)  # 转到120°
```

## 六、常见问题排查

### PD42S1不工作

**症状**：电机不转、无力矩、指示灯异常

**排查**：
1. 检查12~32V供电电压（万用表测）
2. 检查STEP/DIR/EN信号是否到达（示波器）
3. 检查COM是否接3.3V（共阳必须接）
4. 检查细分拨码开关是否设为16
5. 检查电机接线是否正确（A+A-B+B-）

---

### ToF无数据

**症状**：UART4无输出、数据全0

**排查**：
1. 检查VDD是否5V（万用表测）
2. 检查RX/TX是否接反
3. 检查UART4波特率是否115200
4. 用逻辑分析仪看TX线是否有数据

---

### STS3215不响应

**症状**：Python指令发出，舵机不动

**排查**：
1. 检查微雪板VIN电压（6V）
2. 检查树莓派是否识别到`/dev/ttyUSB0`
3. 检查舵机ID是否正确（默认1）
4. 检查舵机D/V/G接线是否松动
5. 用飞特调试软件测试舵机

---

### 电磁阀不动作

**症状**：PB10有电平变化，但电磁阀无声音

**排查**：
1. 检查VCC是否6V（或12V）
2. 检查控制线是否接PB10
3. 用万用表测PB10输出电压（高3.3V/低0V）
4. 电磁阀是否损坏（直接接6V测试）

## 七、接线规范

### 线材要求

- **电源主干（4S电池 → 驱动器）**：14AWG（2.5mm²），耐压30V
- **降压模块输出（5V/6V）**：18AWG（1.0mm²）
- **信号线（STM32 GPIO）**：杜邦线（24AWG）
- **气管**：外径6mm，内径4mm，透明PU管

### 颜色规范

- **红色**：正极（5V/6V/12V）
- **黑色**：GND（地）
- **黄色**：信号线（STEP/DIR/EN）
- **蓝色**：通讯线（TX/RX）

### 标签

每根线贴标签：
- 电源线：`5V OUT` / `6V OUT` / `14.8V IN`
- 信号线：`X_STEP` / `Y_DIR` / `ToF_TX`
- 通讯线：`UART3_TX` / `UART4_RX`
