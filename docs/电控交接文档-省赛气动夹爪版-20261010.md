## 三、电控改动详解（7 项）

### 3.1 引脚重分配（E2，L4）

**现状**：
- PA0/PA1：X 轴 A4988 STEP/DIR
- PA2/PA3：Y 轴 A4988 STEP/DIR
- PA9/PA10：USART1
- PD8/PD9：USART3 调试口
- PB10：TIM2_CH3 Z 轴舵机 PWM（还有运行时切换 USART3 的代码）

**方案 A**（推荐）：
- **PD42S1 #1（X轴）**：PE0 / PE1 / PE2 / PE3（STEP / DIR / EN / COM）
- **PD42S1 #2（Y轴）**：PE4 / PE5 / PE6 / PE7
- **TinyF 测距**：UART4 PC10/PC11（或 UART5 PC12/PD2）
- **Z 轴电磁阀**：PB10 改成 GPIO 输出（不再是 PWM）

**实施步骤**：
1. 读 `电控/diankongv1.0.ioc`，确认 PE0~PE7 是否空闲
2. 若空闲，在 `ec_board_stm32.h` 定义新宏：
   ```c
   // PD42S1 X 轴
   #define STEPPER_X_STEP_PIN       GPIO_PIN_0
   #define STEPPER_X_STEP_PORT      GPIOE
   #define STEPPER_X_DIR_PIN        GPIO_PIN_1
   #define STEPPER_X_DIR_PORT       GPIOE
   #define STEPPER_X_EN_PIN         GPIO_PIN_2
   #define STEPPER_X_EN_PORT        GPIOE
   
   // PD42S1 Y 轴
   #define STEPPER_Y_STEP_PIN       GPIO_PIN_4
   #define STEPPER_Y_STEP_PORT      GPIOE
   #define STEPPER_Y_DIR_PIN        GPIO_PIN_5
   #define STEPPER_Y_DIR_PORT       GPIOE
   #define STEPPER_Y_EN_PIN         GPIO_PIN_6
   #define STEPPER_Y_EN_PORT        GPIOE
   ```
3. 在 `ec_stepper.c` 用新宏替换所有 `HAL_GPIO_WritePin(GPIOA, GPIO_PIN_0, ...)` 等
4. 在 `stm32f4xx_hal_msp.c` 或 `ec_board_stm32.c` 的 `HAL_GPIO_Init()` 里初始化 PE0~PE7 为输出、推挽、高速
5. **不要动 `.ioc`**（它是 16MHz 的，重新生成会覆盖 168MHz）

**接线**：
| PD42S1 端子 | 接 STM32 | 说明 |
|---|---|---|
| STEP | PE0（X）/ PE4（Y） | 脉冲信号 |
| DIR | PE1（X）/ PE5（Y） | 方向信号 |
| EN | PE2（X）/ PE6（Y） | 使能信号（低电平使能） |
| COM | 3.3V | 共阳，接 STM32 的 3.3V 输出 |
| A+ A- B- B+ | 电机 | 四线接带编码器的 42 电机 |
| 12~32V | 4S 14.8V 电池 | 功率电源 |
| GND | 电池 GND | 功率地 |

### 3.3 转盘 STS3215（E4，不触发固件 L4）

**现状**：270° 舵机到不了 180° 那格。

**方案**：STS3215 接微雪板，微雪板 USB-C 接**树莓派**，转盘逻辑全在树莓派 `turntable.py`。

**固件改动**：**无**（不接 STM32，不触发 L4）。

**树莓派改动**（另一份文档）：
1. 安装飞特 SDK（Python）
2. 在 `turntable.py` 里封装：
   ```python
   def turntable_move_to_slot(slot_id):  # slot_id = 0~5
       angle = slot_id * 60  # 0°/60°/120°/180°/240°/300°
       servo.move_to_position(angle)
   ```
3. 测 6 个角度对应的脉宽，写成映射表

**接线**：
| 微雪板端子 | 接哪里 | 说明 |
|---|---|---|
| USB-C | 树莓派 USB | 通讯 |
| 电源输入（9~12.6V 标称） | **6V**（从舵机降压模块） | ⚠️ 先确认板内是否降压，透传则接 6V；降压则接 12V 也可 |
| D/V/G（舵机口） | STS3215 | 单线半双工总线 |

### 3.4 Z 轴气动夹爪（E3，L4）

**现状**：DS3120MG 单舵机 PWM（PB10 TIM2_CH3），脉宽 1000us 张开、1900us 闭合。

**方案**：气动夹爪 = 电磁阀 + 气缸，STM32 的 **GPIO 输出**控制电磁阀（高电平吸合、低电平释放）。

**固件改动**：
1. 删掉 `ec_motion_plan.c:147-151` 的舵机脉宽代码：
   ```c
   // 删掉这段
   // set_servo_pulse_width(SERVO_Z, 1000);  // 张开
   // set_servo_pulse_width(SERVO_Z, 1900);  // 闭合
   ```
2. 改成 GPIO 控制：
   ```c
   // 在 ec_motion_plan.c 或 ec_board_stm32.c 里加
   void gripper_open(void) {
       HAL_GPIO_WritePin(GPIOB, GPIO_PIN_10, GPIO_PIN_RESET);  // 低电平释放
   }
   
   void gripper_close(void) {
       HAL_GPIO_WritePin(GPIOB, GPIO_PIN_10, GPIO_PIN_SET);    // 高电平吸合
   }
   ```
3. 在 `handle_item_task()` 里调用：
   ```c
   // 原来是 set_servo_pulse_width(SERVO_Z, 1000);
   gripper_open();
   
   // 原来是 set_servo_pulse_width(SERVO_Z, 1900);
   gripper_close();
   ```
4. 删掉 `ec_board_stm32.c:243` 和 `stm32f4xx_hal_msp.c:484` 的 PB10 总线切换代码（PWM ↔ USART3 的运行时切换，改气动后不需要了）
5. 在 `HAL_GPIO_Init()` 里把 PB10 初始化为 GPIO 输出、推挽、低电平

**接线**：
| 电磁阀端子 | 接哪里 | 说明 |
|---|---|---|
| 控制线 | PB10 | STM32 GPIO 输出 |
| VCC | 6V（舵机降压模块） | 电磁阀供电（若是 12V 电磁阀则接 12V） |
| GND | 电池 GND | 地 |
| 气路 | 气缸 | 气管连接（机械组负责） |

### 3.5 固定落点 + 转盘转格（E5，等实物装好后测量）

**现状**：`ec_app.c:238-242` 有 6 个 XY 坐标占位符。

**方案**：6 个盒固定位置（只有 1 个落点），抓完一件不动 XY、只转盘让下一格过来。

**固件改动**：
1. 手动示教：摇杆移到那 1 个落点正上方，记录 `current_x / current_y`
2. 写死到 `ec_app.c`：
   ```c
   // 删掉原来的 6 对坐标
   // 改成 1 个固定落点
   static const int16_t drop_position_x = 1234;  // 实测值
   static const int16_t drop_position_y = 5678;  // 实测值
   ```
3. 改 `handle_item_task()` 里的 `target_x / target_y`：
   ```c
   // 原来是 target_x = drop_positions[task.class_id][0];
   target_x = drop_position_x;  // 恒定
   target_y = drop_position_y;  // 恒定
   ```
4. 转盘脉宽映射表（若 STS3215 接 STM32 ⇒ 固件里写数组；若接树莓派 ⇒ 在 `turntable.py` 里查表，固件不动）

### 3.6 供电架构（E6，只是接线）

**现状**：校赛小电池撑 1 小时就掉到 11.3V，一掉压步进就丢步。

**方案**：
```
4S 14.8V 电池（XT60 口，≥6000mAh）
    │
    ├─ 15A 保险丝
    │
    ├─ 船型开关（主开关）
    │
    ├─→ PD42S1 驱动器 ×2（X/Y 轴，直接 14.8V）
    │
    ├─→ 降压模块 ① → 5V ≥5A
    │       ├─→ 树莓派 4B（5V/3A）
    │       ├─→ STM32F407ZGT6（5V/0.5A）
    │       └─→ 白光补光灯（5V/0.3A）
    │
    └─→ 降压模块 ② → 6V ≥5A
            ├─→ 微雪总线板 → STS3215 转盘舵机（6V/2A）
            └─→ Z 轴电磁阀（若 6V 电磁阀）
```

**固件改动**：无（只是接线）。

**接线要点**：
1. 4S 电池 XT60 公头 → 保险丝 → 船型开关 → 主回路
2. 主回路分 3 路：PD42S1 ×2（14.8V）、降压模块 ① 输入、降压模块 ② 输入
3. 降压模块 ① 调到 5V，带树莓派 + STM32 + 补光灯
4. 降压模块 ② 调到 6V，带微雪板 + 电磁阀
5. 所有地接在一起（共地）

## 八、关键注意事项

### 8.1 禁止用 CubeMX 重新生成代码

**原因**：`.ioc` 文件落后于源码（16MHz / 旧 PSC / USART3 引脚），重新生成会覆盖以下已改项：
- `system_stm32f4xx.c:119` `PLL_M=8`（168MHz）
- 7 个 TIM PSC
- USART3 引脚（如有改动）
