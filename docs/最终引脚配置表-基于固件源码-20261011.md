**源码依据**：
- `ec_pneumatic_gripper.c:4` 定义 `PNEUMATIC_GRIPPER_PIN GPIO_PIN_11`

- `main.c:130` 调用 `ec_pneumatic_gripper_init()`

## 📊 引脚冲突/风险汇总

### ✅ 无冲突（可以直接用）
- PC6/PA7/PA5（X轴）
- PB6/PC7/PD7（Y轴）
- PC10/PC11（ToF）
- PB11（电磁阀）

### ⚠️ 需要测试确认
1. **PD42S1 EN极性**：
   - 固件按低有效写（`GPIO_PIN_RESET`=使能）
   - 文档说PD42S1是高有效
   - **冲突** → 上电后测试，若反了需改固件

2. **PB10/PB11 TIM2共享**：
   - PB10=TIM2_CH3（舊舵机，已废弃但代码还在）
   - PB11=TIM2_CH4（新气动）
   - 两者共用一个定时器，可能互相干扰
   - 需要测试气动动作时PB10是否有异常输出

### 🔴 需要代码改动
1. **UART4初始化**（ToF）：
   - 当前固件没有UART4
   - 需要新增初始化代码
   - 需要配置PC10/PC11为AF8

2. **PB10舵机代码清理**（可选）：
   - `ec_board_stm32.c` 里还有PB10切换逻辑
   - 如果不再用舵机，可以删除

## 🔧 接线清单（按这个接）

### PD42S1 X轴驱动器
```
STEP → STM32 PC6
DIR  → STM32 PA7
EN   → STM32 PA5
COM  → STM32 3.3V  ⚠️ 新增
12~32V → 电池+ (14.8V)
GND → 电池-

```

### PD42S1 Y轴驱动器
```
STEP → STM32 PB6
DIR  → STM32 PC7
EN   → STM32 PD7
COM  → STM32 3.3V  ⚠️ 新增
12~32V → 电池+ (14.8V)
GND → 电池-
A+/A-/B+/B- → Y轴电机
细分拨码 = 16

```
VDD (5V) → 降压① 5V输出
RX → STM32 PC10

GND → 总地
```

```
