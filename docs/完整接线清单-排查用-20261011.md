## 🔌 一、供电系统

### 主电源（4S 14.8V电池）
```
电池XT60+ (14.8V)
    ↓
保险丝 (15A)
    ↓
船型开关（主开关）
    ↓
分支4路：
    ├─→ PD42S1 #1 (X轴) 12~32V输入
    ├─→ PD42S1 #2 (Y轴) 12~32V输入  
    ├─→ 降压模块① 输入
    └─→ 降压模块② 输入

电池XT60- → 总地（所有GND接在一起）
```

### 降压模块① → 5V/5A
| 输入 | 输出 | 供给设备 |
|------|------|---------|
| 14.8V | 5V | 树莓派4B (Pin2/Pin4) |
| GND | GND | STM32F407 (5V) |
| — | — | TinyF ToF (VDD) |
| — | — | 白光补光灯（未来） |

**调节**：万用表测VOUT，调到5.0V ±0.1V

### 降压模块② → 6V/5A
| 输入 | 输出 | 供给设备 |
|------|------|---------|
| 14.8V | 6V | 微雪总线板 VIN |
| GND | GND | 电磁阀 VCC |

**调节**：万用表测VOUT，调到6.0V ±0.1V

## 🔧 常见问题排查

### PD42S1不工作
**症状**：电机不转、无力矩、指示灯异常

**检查**：
1. 万用表测12~32V供电（应为14.8V）
2. 示波器测STEP信号（应有脉冲）
3. 万用表测COM电压（应为3.3V）
4. 检查细分拨码开关（应为16）
5. 检查电机接线（A+A-B+B-）

### ToF无数据
**症状**：UART4无输出、数据全0

**检查**：
1. 万用表测VDD（应为5V）
2. 检查RX/TX是否接反
3. 检查UART4波特率（应为115200）
4. 逻辑分析仪看TX线数据

### STS3215不响应
**症状**：Python指令发出，舵机不动

**检查**：
1. 万用表测微雪板VIN（应为6V）
2. 树莓派 `ls /dev/ttyUSB*`（应有ttyUSB0）
3. 检查舵机ID（应为1）
4. 检查D/V/G接线是否松动

### 电磁阀不动作
**症状**：PB10有电平变化，但电磁阀无声音

**检查**：
1. 万用表测VCC（应为6V）
2. 万用表测PB10输出（高3.3V/低0V）
3. 电磁阀直接接6V测试
