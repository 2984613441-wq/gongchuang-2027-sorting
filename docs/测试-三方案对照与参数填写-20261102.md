## 一、三套方案（预设 ini 已生成）

| 代号 | 名称 | `order_mode` | `skip_shapes` | 说明 |
|---|---|---|---|---|
| **A** | 原来的 | `group` | `0`（全抓）| 旧口径：分组 → 待定 → 难度 → 行扫描 |
| **B** | 权重的 | `weighted` | `0`（全抓）| 前端 0.70 / 夹取 0.15 / 路线 0.10 / 隔离度 0.05 + 难件不得排首位护栏 |
| **C** | 放弃的 | `weighted` | `3,5`（弃圆柱+圆锥）| B 的基础上**完全不抓**圆柱/圆锥 |

### 切换命令（Pi 上）

```bash

python3 run_chain.py --pick-strategy order \
  --pick-strategy-config /home/pi/电控/deploy/presets/pick_strategy.planA_legacy.ini

# B：权重的
python3 run_chain.py --pick-strategy order \
  --pick-strategy-config /home/pi/电控/deploy/presets/pick_strategy.planB_weighted.ini

# C：放弃的（圆柱+圆锥）
```

## 四、怎么从三套里选（决策规则）

```
1) 若任一套出现「掉件」⇒ 该套作废（赛规：掉件=本轮结束）
2) 在无掉件的套里，比「两轮最好得分」
3) 得分相同 ⇒ 比总用时（短者优）
4) C 若因随机物料出现「全是圆柱/圆锥 ⇒ 0 分」⇒ 建议启用保底
   （TODO：skip_min_pickable，尚未实现）
5) 若三套差别 < 5 分 ⇒ 选 A（最简单、行为最可预测）
```
