## 三、这些引脚能不能继续用？

### 问题1：A4988 vs PD42S1 引脚兼容吗？

**A4988 接口**：
- STEP：脉冲输入（上升沿触发）
- DIR：方向输入（高/低电平）
- EN：使能输入（低电平有效）

**PD42S1 接口**：
- STEP：脉冲输入（上升沿触发）✅ 兼容
- DIR：方向输入（高/低电平）✅ 兼容
- EN：使能输入（低电平有效）✅ 兼容
- COM：共阳参考（接3.3V）⚠️ A4988没有这个

**结论**：信号逻辑兼容，但需要加 COM 接 3.3V

---

### 问题2：原有引脚能直接用吗？

**可以继续用**（不换引脚）：

| 原引脚 | 新用途 | 是否兼容 | 备注 |
|--------|--------|---------|------|
| PC6 (TIM8_CH1) | PD42S1 X轴 STEP | ✅ 是 | 脉冲兼容 |
| PA7 (GPIO) | PD42S1 X轴 DIR | ✅ 是 | 电平兼容 |
| PA5 (GPIO) | PD42S1 X轴 EN | ✅ 是 | 低电平有效 |
| PB6 (TIM4_CH1) | PD42S1 Y轴 STEP | ✅ 是 | 脉冲兼容 |
| PC7 (GPIO) | PD42S1 Y轴 DIR | ✅ 是 | 电平兼容 |
| PD7 (GPIO) | PD42S1 Y轴 EN | ✅ 是 | 低电平有效 |

**额外需要**：
- 找2个空闲引脚接 X/Y 的 COM → 3.3V
- 或者直接硬件短接 COM 到 3.3V（不通过STM32）

---

### 问题3：为什么之前说要换 PE0~PE7？

**原因分析**：

我之前看到交接文档里说"PA0/PA1用于X轴，PA2/PA3用于Y轴"，以为这是当前配置。

但实际代码显示：
- **PA0/PA1/PA2/PA3** 根本没在用（可能是早期版本）
- **实际在用**：PC6/PA7/PA5（X轴） + PB6/PC7/PD7（Y轴）

所以之前的PE0~PE7方案是**不必要的**。

## 四、推荐方案（不换引脚）

### 方案A：保留原有引脚 ✅ 推荐

**优点**：
- 代码改动最小（只改细分参数）
- 硬件接线最小（只换驱动器）
- 不用改 .ioc 文件

**需要做的**：
1. 拔掉 A4988，换上 PD42S1
2. 接线保持原样：
   - X轴：STEP=PC6, DIR=PA7, EN=PA5
   - Y轴：STEP=PB6, DIR=PC7, EN=PD7
3. **新增**：PD42S1 的 COM 接 3.3V（2个驱动器各接一个）
4. 代码改动：
   ```c
   // 在 ec_board.h 或 config.h
   #define PD42S1_SUBDIVISION 16  // 细分设为16
   #define STEPS_PER_REV 3200     // 1圈3200步（原来1600步）
   ```

**硬件接线**：
| PD42S1端子 | 接STM32 | 原A4988 |
|-----------|---------|---------|
| STEP | PC6 | 相同 ✅ |
| DIR | PA7 | 相同 ✅ |
| EN | PA5 | 相同 ✅ |
| COM | 3.3V | **新增** ⚠️ |

---

### 方案B：换成 PE0~PE7 ❌ 不推荐

**缺点**：
- 需要改很多代码
- 需要改 .ioc（可能覆盖已改代码）
- PE0~PE7 不支持定时器输出（要改成GPIO软件脉冲）

**唯一优势**：
- 引脚集中在 PE 组，接线可能更整齐

---

## 五、COM 引脚怎么接？

### 选项1：硬件直接短接（推荐）

**做法**：
- PD42S1 驱动器的 COM 端子，用杜邦线直接接到 STM32 的 3.3V 引脚
- 不占用额外GPIO

**优点**：代码不用改

---

### 选项2：用GPIO输出3.3V

**做法**：
- 找2个空闲GPIO（如 PE0/PE4）
- 配置为输出，初始化时写高电平
- PD42S1 的 COM 接这2个GPIO

**缺点**：占用2个GPIO

---

## 六、代码需要改的地方（方案A）

### 1. 细分参数（必改）

**文件**：`App/Inc/ec_board.h` 或 `ec_config.h`

```c
// 原来 A4988 细分=16，1圈=1600步
// 现在 PD42S1 细分=16，1圈=3200步

// 如果代码里写死了 1600，要改成 3200
// 或者改 steps_per_mm 的计算
```

**检查位置**：
```bash
grep -r "1600\|steps_per" App/Src/ --include="*.c"
```

---

### 2. 使能极性（可能不用改）

PD42S1 和 A4988 的 EN 都是**低电平有效**，应该不用改。

**验证**：
```c
// ec_board_stm32.c 里应该有：
HAL_GPIO_WritePin(ENABLE_X_GPIO_Port, ENABLE_X_Pin, GPIO_PIN_RESET);  // 使能
HAL_GPIO_WritePin(ENABLE_X_GPIO_Port, ENABLE_X_Pin, GPIO_PIN_SET);    // 禁用
```

如果是这样，不用改。

---

### 3. 脉冲频率（可能不用改）

PD42S1 最高支持 200kHz 脉冲，A4988 一般 50kHz。

代码里用的是 100kHz 时钟，应该没问题。
