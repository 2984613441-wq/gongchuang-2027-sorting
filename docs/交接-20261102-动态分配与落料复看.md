## 二、这一周做完的四条线

### 1) 固件：Z 轴独立舵机 + 落料槽门（未编译烧录）

- 引脚：Z = **PB0/TIM3_CH3**、夹爪 = **PB10/TIM2_CH3**、槽门 = **PE5/TIM9_CH1**
- 新增 `ec_z_servo.c/h`、`EC_AXIS_STEP_SLOT` 步类型、`ec_motion_plan_build_v2()`（**15 步**）
- 调试命令新增 `ZPOS us|UP|DOWN|MID|?`、`SLOT us|OPEN|CLOSE|MID|?`
- 方案与实测表：`docs/改造-Z轴双舵机与落料槽舵机-方案-20261101.md` §八
- **状态**：代码在仓库，**没编译过、没烧录、Z/夹爪脉宽仍是占位值（1500）**

### 2) 协议：`class_id` 冻结为 `code(1..30)`（草案，未生效）

- `code = (shape-1)*5 + color`；shape 1..6、color 1..5
- `BATCH_TARGETS` **仍 7 字节**，id 字节 = code；`code=0` ⇒ 判不出，只拒识该件
- `ITEM_TASK` **仍 12 字节**，`class_id = code`
- 逐件运动参数（Z 取/放、夹爪）走**固件按 shape 查表**，不上 wire
- 开关：发送端 `--id-mode shape|code`（默认 shape=现状）；接收端 `BATCH_ID_BYTE_MODE=box_id|code`（默认 box_id=现状）
- **实现期发现并已修**：转盘预置原来把 `payload.class_id` 当货格号，code 模式会转错角度 ⇒ 改为先 `code→box_id`

### 3) 夹取策略：五键排序（默认关闭）

- 新模块 `pick_strategy/orderer.py`：**停稳 → 待定 → 难度 → 隔离度 → 落点距离 → seq**
- `chain_adapter` 增加 `order_mode`（`legacy/group/difficulty/open_edge/five_key`，通过配置 `[Strategy] order_mode` 或 `--order-mode` 选择，缺省 `legacy`）
- `socket_vision_source` 增加 `current_position_provider`：TSP 锚点用「上一次落料点」，`--anchor fixed` 可回退
- 参数全部带【待实测】标签；停稳判据含**超时降级**

### 4) 动态分配 + 落料位复看（默认全关）

- `rpi/slot_allocator.py`：`code→box_id` 动态分配（同 code 复用、同侧优先、满格不猜、按 round_id 持久化、`correct()` 纠正）
- `rpi/place_eye.py`：`[PlaceEye]` 配置（缺节=禁用）+ 抓帧 + ROI 采样 + HSV 众数
- `rpi/color_judge.py`：cv2 HSV → 五色，阈值全【待实测】
- `rpi/place_verifier.py`：`verify_place()`（code 级）/`verify_place_color()`（颜色级）→ MATCH/MISMATCH/UNKNOWN
- `rpi/place_verify_runtime.py`：`off/observe/correct` 三档 + 统计 + 台账纠正
- `run_chain`：`--slot-mode static|dynamic`（默认 static）、`--verify-place off|observe|correct`（默认 off）、`--slot-journal`、`--place-eye-config`
- 文档：`docs/落料位复看-PlaceEye-标定与回退-20261101.md`

## 三、回退开关一览（出问题先按这个关）

| 症状 | 开关 |
|---|---|
| 排序顺序不对/链变慢 | `--order-mode legacy` 或 `--pick-strategy off` |
| 转盘转到错格 | `--slot-mode static`（并确认 `--pick-strategy off`） |
| 复看拖慢/误判 | `--verify-place off` |
| 落料点锚点可疑 | `--anchor fixed` |
| 协议新语义出问题 | 发送端 `--id-mode shape` + 接收端 `BATCH_ID_BYTE_MODE=box_id` |
| 五键排序参数不对 | `[Strategy] order_mode = legacy` |
