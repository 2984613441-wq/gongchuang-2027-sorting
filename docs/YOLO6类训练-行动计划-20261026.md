### 阶段4：模型转换（P0，预计1-2小时）

#### 任务4.1：转换流程
```bash
# 在WSL里执行（有MaixCAM工具链）
cd _deploy_maixcam

# 1. 导出ONNX
python export_onnx.py --weights ../best.pt --imgsz 448

# 2. 切输出节点（关键！）
python extract_model.py \
  --input yolo11n_6c_448.onnx \
  --output yolo11n_6c_448_clean.onnx \
  --output-names "/model.23/dfl/conv/Conv_output_0" \
                 "/model.23/Sigmoid_output_0"

# 3. 简化
onnxsim yolo11n_6c_448_clean.onnx yolo11n_6c_448_sim.onnx

# 4. 转MLIR
model_transform.py \
  --model_name yolo11n_6c \
  --model_def yolo11n_6c_448_sim.onnx \
  --input_shapes [[1,3,448,448]] \
  --mean 0,0,0 --scale 0.00392156862745098,0.00392156862745098,0.00392156862745098 \
  --pixel_format rgb \
  --mlir yolo11n_6c.mlir

# 5. 量化校准（需要校准图集）
run_calibration.py yolo11n_6c.mlir \
  --dataset calibration_imgs/ \
  --input_num 100 \
  -o yolo11n_6c_cali_table

# 6. 生成cvimodel
model_deploy.py \
  --mlir yolo11n_6c.mlir \
  --processor cv181x \
  --quantize INT8 \
  --calibration_table yolo11n_6c_cali_table \
  --model yolo11n_6c_int8_cv181x.cvimodel
```

## 三、风险与应对

### 风险1：圆锥数据不足
- **应对**：数据增强（旋转/翻转/亮度/噪声）
- **fallback**：几何特征辅助（顶部尖锐度检测）

### 风险2：圆柱/圆锥混淆
- **应对**：
  - 增加侧视训练数据（如果能拍）
  - 标注时注意底面边缘特征
  - 考虑双目/深度辅助

### 风险3：模型转换失败
- **应对**：
  - 严格按已验证流程
  - 保留中间所有文件
  - 回退到7类模型改造

### 风险4：白托盘域偏移无法解决
- **应对**：
  - 优先用白托盘数据训练
  - 考虑迁移学习（fine-tune）
  - 最坏情况：现场重新采集+快速训练
