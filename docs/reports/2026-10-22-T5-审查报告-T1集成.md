### 2.1 急停缺口（安全性，Level 3）

**问题**：`ec_safety_port_stop_all()` 只停 PB10（夹爪舵机），**未停 PE5（落料舵机）**。

**证据**：
```c
// 电控/firmware/stm32f407_m144z/App/Src/ec_board_stm32.c (未改动部分)
void ec_safety_port_stop_all(void)
{

    ec_step_port_stop_all();
```

```c
void ec_safety_port_stop_all(void)

    ec_step_port_stop_all();

}
```

### 2.2 上电语义风险（安全性，Level 2）

**问题**：`ec_drop_servo_init()` 立即输出 1500µs。**"发中位命令" ≠ "舵机物理静止"**。

**代码**：
```c
// ec_drop_servo.c:8-19
bool ec_drop_servo_init(void)
{
    ready = false;
    current_us = EC_DROP_SERVO_MID_US;
    if (!ec_board_drop_servo_set_us(EC_DROP_SERVO_MID_US)) {  // ← 立即输出
        current_us = 0U;
        return false;
    }
    ready = true;
    return true;
}
```

**风险场景**：
1. 如果该型号舵机的"中位 1500µs" ≠ 机械安全位
2. 或者舵机上电前摇臂不在中位
3. 上电瞬间舵机会**快速转到 1500µs 对应角度** → 可能撞到机构

**验证方法**（用户操作）：
1. 首次上电**必须脱开机构或手扶**
2. 观察舵机是否动作
3. 如果动作，量舵机上电前摇臂角度 vs 1500µs 角度的差值
4. 如果差值 > 10°，考虑改为"init 不立即输出，首次调用 set_us 才输出"

**是否阻塞**：⚠️ **不阻塞代码合并，但必须记录为"首上电注意事项"**

### 8.1 fail-closed 语义 ✅

**设计原则**：任何错误（未 init / 越界 / 板级失败）都拒绝操作，不改状态。

**验证**：
```c
// ec_drop_servo.c:21-32
bool ec_drop_servo_set_us(uint16_t pulse_us)
{
    if (!ready || pulse_us < EC_DROP_SERVO_MIN_US ||
        pulse_us > EC_DROP_SERVO_MAX_US) {
        return false;                         // ← 前置检查，越界直接拒绝
    }
    if (!ec_board_drop_servo_set_us(pulse_us)) {
        return false;                         // ← 板级失败也拒绝

    current_us = pulse_us;                    // ← 只有成功才更新状态
    return true;
}
```

## 十、TIM9 PSC 错误修正（Lead 承认）

**原错误**（我在任务书里写的）：
```c
htim9.Init.Prescaler = 83;      // 84MHz/84 = 1MHz
```

**真相**：
- TIM9 在 **APB2**（不是 APB1）
- 时钟 = **168MHz**（不是 84MHz）
- 正确 PSC = **167**（不是 83）

**Lead 修正后**：
```c
// main.c:565
htim9.Init.Prescaler = 167;     /* TIM9/APB2: 168MHz/168 = 1MHz, 1us tick */
htim9.Init.Period = 19999;      /* 1MHz/20000 = 50Hz (20ms period) */
```

**附带发现**：原 PSC=839 在 168MHz 下实际是 **200kHz**（不是注释说的 100kHz），因为 TIM9 一直没用过，从没暴露。

✅ **错误已修正，我承认原任务书里的 PSC=83 是错的。**
