### 问题1：默认 2/3 多数票对「两类互相误判」几乎无过滤

**证据**：交替 12 帧（class_id=2,3,2,3...）实测 accepted=10。窗口 [2,3,2] 票数 2:2 → 判 2 通过（2 票达 quorum=2）；窗口 [3,2,3] 票数 2:1 → 判 3 通过。

**修复**：
- 新增 `class_vote_mode: str = "unanimous"`（"majority" | "unanimous"），**默认 unanimous**
- **unanimous**：窗口满（len=frames）且窗口内 class_id 全一致才采纳
- **majority**：保持原 quorum 逻辑（向后兼容）
- 非法 mode 抛 ValueError

**验证**（探针1）：
```
交替10帧 unanimous → accepted=0（预期=0），rejected=9 ✅
```

### 问题2：默认 frames=3、max_wait=6 且历史封顶 3 ⇒ len(hist)>=6 恒假，timeout 永远 0

**证据**：第1轮判据 `len(hist) >= max_wait` 恒假（hist 最多 3 条）。

**修复**：
- 超时改按「目标年龄」计：新增 `_vote_seen: dict[key, int]` 记录**从该 key 首次出现算起的已见帧数**
- 判据：`_vote_seen[key] >= max_wait` 且未采纳 ⇒ timeout + WARNING（每 key 只警告一次）
- 超时后丢弃该 key 的历史与计数

**验证**（探针2）：
```
默认参数持续摇摆8帧（class_id=2,3,4,2,3,4,2,3）：
第6帧 timeout=1（seen=6 >= max_wait=6），key 被删除 ✅
```

### 问题3：跨轮历史不清空

**证据**：第1轮未在 `set_permitted(True)` 时清空历史，实测新一轮混入上一轮类别。

**修复**：
- `set_permitted(True)` 时清空 `_vote_history`、`_vote_seen`、`_vote_absent`、`_vote_timeout_warned`
- 每帧淘汰连续 `frames*2` 帧未再出现的 key（防内存增长）

**验证**（探针3）：
```

```

## 一、问题与证据（第1轮，未变）

主相机 6 类模型（`_runs/main_6c_v2/weights/best.pt`，输入 448，YOLO11n）在**五棱柱 / 正方体 / 长方体**三类上互相误判。验证集（94 张 / 270 实例）结果：

| 类别 | Precision | Recall | mAP50 |
|---|---|---|---|
| cube 正方体 | 1.000 | **0.914** | 0.983 |
| cuboid 长方体 | 0.942 | 0.948 | **0.955** |
| cylinder 圆柱 | 0.896 | 1.000 | 0.993 |
| **pentagonal_prism 五棱柱** | **0.891** | 0.951 | 0.962 |
| cone 圆锥 | 0.994 | 0.932 | 0.984 |
| tetrahedron 四面体 | 1.000 | 0.975 | 0.995 |

归一化混淆矩阵（`runs/detect/_runs/val_main_v2/cls_report/confusion_matrix_normalized.png`）显示：
- cuboid 的预测里 **5% 判成 cube、5% 判成 penta、2% 判成 cone**
- penta 的预测里 **5% 判成 cube、5% 判成 cuboid**
- cube 的预测里 1% 判成 cuboid
- 另有 **25%/29%/17%**（cube/cuboid/penta）的预测落在 background（误检）

**根因**：俯视投影下这三类都是多边形，cube vs cuboid 只差长宽比，penta 的第五条边在小件/模糊/过曝时看不出；且训练集类别不均衡（cuboid 411 / penta 241 / cube 201 实例）。

## 二、实现内容

### A. 推理端「多帧类别投票」（Pi 侧，`socket_vision_source.py`）

**位置**：`电控/src/electrical_control/rpi/socket_vision_source.py`

**功能**：
- 对同一目标维护最近 N 帧的 `(class_id, conf, 像素坐标)` 历史
- 🔴 **第2轮**：默认 **unanimous 模式**（窗口满且全一致才采纳），解决交替误判问题
- 🔴 **第2轮**：超时按**目标年龄**计（`_vote_seen[key]` 每帧自增），不再依赖 `len(hist)`
- 🔴 **第2轮**：**位置栅格键** `(grid_x, grid_y)` 统一关联目标，不再用 `target_seq`
- 🔴 **第2轮**：换轮时自动清空历史（`set_permitted(True)`）

**新增构造参数**（全部有默认值）：
```python
class_vote_enabled: bool = False              # 默认关闭（保持现状）
class_vote_frames: int = 3                    # 历史窗口大小（默认 3 帧）
class_vote_quorum: int = 2                    # majority 模式的最少票数（默认 2/3）
class_vote_max_wait_frames: int = 6           # 超时上限（默认 6 帧）
# 🔴 第2轮新增：
class_vote_mode: str = "unanimous"            # "majority" | "unanimous"（默认 unanimous）
class_vote_grid_px: int = 80                  # 位置栅格大小（像素，默认 80）
class_vote_match_radius_px: int = 80          # 位置匹配半径（像素，默认 80）
```

**开关方式**：
- **关闭**（默认）：`class_vote_enabled=False` 或不传该参数 → 行为与第1轮改动前逐字节等价
- **开启**：在 `SocketVisionSource` 构造时传 `class_vote_enabled=True`
  - 推荐默认参数（unanimous + frames=3）：对交替误判有效
  - 宽松模式：`class_vote_mode="majority", class_vote_quorum=2`（向后兼容第1轮）

**统计接口**：
```python
src.vote_stats()  # → {"accepted": int, "rejected_no_quorum": int, "timeout": int}
```

**新增方法**：
- `vote_stats() -> dict[str, int]`：返回统计 `{"accepted": ..., "rejected_no_quorum": ..., "timeout": ...}`

**行为保证**：
- 关闭投票时输出必须与改动前逐字节等价
- 不破坏现有行为：`_resolve_box_ids`、`_filter_skipped`、`_visibility_signature`、`_expand`、首件稳定门、α 补尾语义都保持
- 统计信息可通过 `vote_stats()` 查询，在派件日志里可打印

### B. 设备端「分类别置信度阈值」（MaixCAM 侧，`yolo_v11_send.py`）

**位置**：`_pi_tools/maixcam_scripts/yolo_v11_send.py`

**功能**：
- 新增 `--min-conf-by-class "2:0.55,3:0.55"`（格式 `class_id(0-based):threshold`，逗号分隔）
- 不写的类用 `--conf`（默认 0.40）
- 未达阈值的检测**不加入 BATCH_TARGETS**；若整帧全被过滤，仍按现有逻辑发空批（保持链路心跳）
- 新增可选 `--unknown-as-code0`：开启 `--id-mode code` 时，若某件置信度介于 `--conf` 与分类阈值之间，可选择发 `code=0`（判不出）而不是丢掉——**默认关闭**（保持现状）

**新增参数**：
```bash
--min-conf-by-class "class_id:threshold,class_id:threshold"
    # 例："2:0.55,3:0.55" 对 cylinder(class_id=2) 和 penta(class_id=3) 用 0.55
    # 其他类用 --conf 0.40

--unknown-as-code0
    # --id-mode code 时，低置信件发 code=0（判不出）而不是丢掉
    # 默认关闭
```

**打印统计**（每帧 + 结束时）：
```
目标统计：sent=150 dropped_low_conf=12 dropped_class=8
```
