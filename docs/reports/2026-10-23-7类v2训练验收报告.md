## 四、混淆矩阵发现（`confusion_matrix_normalized.png`）

对角线（按真实类归一）：cube 0.41 / cuboid 0.27 / cylinder **0.83** / hex 0.32 / pent 0.23 / tri 0.40 / **pyr 0.74**

主要混淆：
1. **cube ↔ cuboid ↔ pentagonal_prism** 三者互串（cube 有 0.24 被判成 cuboid、0.16 判成 pentagonal）
2. **hexagonal_prism ↔ pentagonal_prism** 互串（0.29 / 0.32）—— 5 边 vs 6 边，448 分辨率下确实难分
3. **triangular_prism 召回偏低**（0.40），部分被判成 hex/pent
4. background 很干净（漏检少）

**改进方向**（按性价比）：
- 棱柱类（hex/pent/tri）**补样本 + 补角**：现在 5/6/3 边棱柱各只有 142~183 框
- 考虑输入提到 **640×384** 或 **512**（需重新转 cvimodel，NPU 算力要复核）
- cube/cuboid 加"长宽比"难例样本

## 七、环境坑（本轮新增，务必记）

| 坑 | 现象 | 解决 |
|---|---|---|
| **沙箱禁命名管道** | Ultralytics 扫标签缓存用 `ThreadPool` → `SimpleQueue→Pipe` → `PermissionError [WinError 5]`，训练起不来 | `_turntable-edit/train_7c_sandbox_safe.py`：**导入 ultralytics 之前**把 `multiprocessing.pool.ThreadPool` 换成串行替身（等价，仅慢几秒） |
| **PowerShell 管道截断** | `python ... \| Select-Object -First N` 会关管道 → 进程 exit 1（训练被掐死） | 一律 `*> logfile` 重定向，别用截断管道 |
| **cv2.imread 读不了中文路径** | 返回 None / 报 can't open | 用 `PIL` 读入后转 numpy，再交给 cv2 |
| WSL 在本沙箱不可用 | `wsl ...` → `Wsl/E_ACCESSDENIED` | cvimodel 转换由用户在本机 WSL 执行 |
