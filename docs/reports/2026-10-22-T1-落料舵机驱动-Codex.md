## TIM9 参数核算

派工单给出的 PSC=83 使用了 APB1 的 84 MHz 假设，但 STM32F407 的 TIM9 位于 APB2。当前工程配置为 PCLK2=84 MHz、APB2 定时器时钟=168 MHz，因此 PSC=167 得到 1 MHz 计数时钟；ARR=19999 得到 50 Hz、20 ms 周期。这里按当前 MCU 总线映射和时钟配置修正了任务书数值。

```diff
- htim9.Init.Prescaler = 839;
- htim9.Init.Period = 9999;
+ htim9.Init.Prescaler = 167;  /* TIM9/APB2: 168MHz/168 = 1MHz, 1us tick */
+ htim9.Init.Period = 19999;   /* 1MHz/20000 = 50Hz (20ms period) */
```

## 命令规格

- `DROP OPEN`：调用 `ec_drop_servo_open()`，当前占位脉宽 1500 us。
- `DROP CLOSE`：调用 `ec_drop_servo_close()`，当前占位脉宽 1500 us。
- `DROP MID`：调用 `ec_drop_servo_mid()`，脉宽 1500 us。
- `DROP POS <us>`：解析为 `uint16_t` 后调用 `ec_drop_servo_set_us()`；函数接受 500~2500 us，越界返回 false 且不改输出。
- `DROP?`：读取 `ec_drop_servo_current_us()` 与目标值；当前驱动没有独立的目标/当前异步状态，返回值即最后成功下发的脉宽。

## 未决与边界

- 舵机型号、方向、行程及三个脉宽的物理意义未知；所有动作脉宽仍是占位值，必须待现场实测，不能据此做实机动作判断。
- 上电初始化会将 1500 us 写入 CCR 并启动 PWM。它只发中位命令，不代表未知型号的舵机物理上必然静止；此行为仍需脱开机构或采取机械防护后验证。
- `ec_drop_servo_stop()` 已提供，但本轮没有把它接入现有 `STOP ALL` / 安全停止路径，因为任务书限制为在板级文件新增函数，未授权修改现有停止函数。当前急停是否能停止该通道为 **未验证/未集成**。
