## 2. 参考代码实际内容

### 电控侧（Arduino）

- 串口 9600，逐字符接收 ASCII，以 `o` 结尾触发一帧。
- 帧结构：`rubbish_quality` + 多组 3 位数值；最后一组为校验值。
- 返回：`1` 开始、`2` 完成、`0` 校验失败。
- 控制对象：X/Y 步进、夹爪/平台/挡板舵机、四路挡板、超声测距、推杆。
- 大量舵机角度、步数、坐标和超声阈值为硬编码。

### 视觉侧（YOLOv5）

- 类别：`['else waste', 'hazardous', 'kitchen', 'recyclable']`，界面映射为
  其他/有害/厨余/可回收。
- 串口脚本：`mydetsectpro2.py` / `mydetsectpro3.py` 用 `COM5`，
  `mydetsectmatepro.py` 用 `COM6`，均 9600。
- 发送内容：识别类别首字母、bbox 四角数值（补零到 3 位）、平均值校验，
  以 `o` 结尾；按电控返回的 `1/2/0` 决定下一步。
- 存在多个历史“副本”脚本，主入口不唯一。

## 3. 可吸收 / 不可吸收的判断

### 暂不照搬

- **bbox → 步数换算**：参考视觉把像素坐标直接换算成 X/Y 步数。我们的 XY
  每毫米步数、像素→机械坐标变换都未标定，照搬等于猜参数，故不实施。
- **字符串补零 + 平均值校验**：该机制可靠性弱于现有 JSONL 严格校验 +
  连续帧稳定 + 故障锁存，不采用。
- **失败后自动重发运动**：参考代码收到 `0` 会重发；我们的桥接层按指令清单
  规则禁止自动重发运动命令，保留人工处理。

### 已确认可参考

- 类别维度可参考：其他 / 有害 / 厨余 / 可回收，与四路挡板/四类分拣对应。
- 视觉输出应携带目标中心信息；待坐标标定冻结后，可在 JSONL 契约扩展
  bbox/中心坐标，并由上层把类别 + 坐标映射成 `MOVE STEPS`。
- 串口必须显式配置，不能沿用参考的硬编码 `COM5/COM6`。
