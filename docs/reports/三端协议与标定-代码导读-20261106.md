## 2. 三端协议总览

### 2.1 链路与物理参数

| 链路 | 载体 | 参数 | 代码位置 |
|---|---|---|---|
| **MaixCAM → 树莓派** | **TCP 8765**（现场）；文档另写 UART 115200 8N1 | `BATCH_TARGETS`，3+7N 字节 | 发送：`_pi_tools/maixcam_scripts/yolo_v11_send.py`<br>解析：`电控/src/electrical_control/rpi/vision_ingest.py:102` |
| **树莓派 → STM32** | UART **USART2 PA2 TX / PA3 RX**，115200 8N1 | 统一外层帧 + `ITEM_TASK` 12B | 编码：`protocol/outer_frame.py:102`、`protocol/item_context.py:115`<br>发送：`rpi/outbound.py`、`rpi/serial_link.py` |
| STM32 → 树莓派 | 同一条 UART | `ACK/NACK`(2B)、`ITEM_RESULT`(3B)、`MOTION_DONE`、`STATUS` | 解码：`protocol/ack_nack.py`、`protocol/frames.py:32` |
| 树莓派 → 屏 | Micro-HDMI（写 `/dev/fb0`）| `DISPLAY_DATA`；`DISPLAY_ACK` 6B | `rpi/display_hdmi.py`、`protocol/frames.py:43` |
| PC（调试）| TCP 8765 / HTTP 8766 / 8080 | 三路窗口取图与监听 | `_pi_tools/three_way_view.py` |

### 2.2 统一外层帧（**已冻结**，改动属 L4）

`protocol/outer_frame.py:25-31, 102-127`

```
偏移  长度  字段        值/说明
0     1    header0     0xA5
1     1    header1     0x5A
2     1    version     0x01（不变；只有不兼容变更才动）
3     1    sender      Device：1=MaixCAM 2=Pi 3=STM32
4     1    receiver    同上
5     2    task_id     大端
7     2    frame_seq   大端
9     1    command     命令字（见 2.3）
10    2    data_len    大端（载荷长度，不含头/CRC）
12    N    payload
12+N  2    CRC16       **CRC-16/MODBUS**（poly 0x8005 反射式 = 0xA001，init 0xFFFF，无最终异或）
                       黄金串：b"123456789" → 0x4B37（outer_frame.py:62-78）
```

### 2.3 命令字（`protocol/types.py`）

| 值 | 命令 | 方向 | 载荷 |
|---|---|---|---|
| 0x01/0x02 | HEARTBEAT / HEARTBEAT_ACK | Pi↔STM32 | — |
| 0x03/0x04 | DEVICE_READY / ERROR | — | — |
| 0x05/0x06 | **ACK / NACK** | STM32→Pi | **2B**：reason_code + target_seq（`ack_nack.py:31-46`）|
| 0x10 | **BATCH_TARGETS** | MaixCAM→Pi | 3 + 7N（见 2.4）|
| 0x11/0x12 | TARGET_REACQUIRE_REQ/RSP | — | — |
| 0x13 | DIAG_SCAN | — | — |
| 0x20 | BARRIER_READY | STM32→Pi | 注意：调参命令字 0x20 曾撞号（历史遗留，见台账 E-10）|
| 0x21 | **ITEM_TASK** | Pi→STM32 | **12B**（见 2.5）|
| 0x22 | MOTION_DONE | STM32→Pi | — |
| 0x23 | **ITEM_RESULT** | STM32→Pi | **3B**：target_seq, result_code, basis（`frames.py:32-40`）|
| 0x24/0x25 | DISPLAY_DATA / **DISPLAY_ACK** | Pi↔STM32 | DISPLAY_ACK **6B**：target_seq, render_result, crc32(4)（`frames.py:43-68`）|
| 0x26 | ESTOP | — | — |

### 2.4 `BATCH_TARGETS`（MaixCAM → Pi）

解析权威：`rpi/vision_ingest.py:102`（常量 `_BATCH_TARGET_BYTES = 7`、`_BATCH_ANGLE_NONE = 0xFF`）

```
偏移 长度 字段          说明
0    1    target_count  本帧目标数
1    2    task_id       大端
3    7×N  每个目标：
        +0  class_id    shape_id(1..6) 或 code(1..30)，取决于 --id-mode；0=判不出
        +1  confidence  0..100
        +2  X           大端（像素）
        +4  Y           大端（像素）
        +6  angle       必须 0xFF（夹爪不旋转）
```

- 发送端：`_pi_tools/maixcam_scripts/yolo_v11_send.py`（仓库版支持 `--id-mode code`、HSV 判色、`--snap-port 8766`、`--min-conf-by-class`）
- **code 语义**（V1.0 草案）：`code=(shape-1)*5+color+1`，`vision_ingest.py:76 code_to_shape_color()`

### 2.5 `ITEM_TASK`（Pi → STM32，**12 字节**）

编码：`protocol/item_context.py:115-153`；解码/校验：`:156-189`；长度常量 `_ITEM_TASK_PAYLOAD_LEN = 12`（`:104`）

```
偏移 长度 字段                      说明
0    1    target_seq                1..255
1    1    class_id                  image_id 必须 == class_id（冻结 1:1）
2    1    image_id
3    2    x_position                落料点 X，有符号，**0.1mm**，|v|≤1450
5    2    y_position                落料点 Y，同上
7    1    grip_angle                必须 0xFF
8    2    pick_x_position           抓取点 X，有符号 0.1mm（V0.9 新增）
10   2    pick_y_position           抓取点 Y
```

**fail-closed 规则**（`item_context.py:131-145`）：
- 抓取点 `None` → **拒绝序列化**（不允许默认 0，否则会"抓装置中心"E-18）
- `grip_angle != 0xFF` → 拒绝
- `image_id != class_id` → 拒绝
- 坐标超 ±1450 → 拒绝

### 2.6 时序/护栏（写在 Pi 侧，不是协议字段）

| 机制 | 值/位置 | 说明 |
|---|---|---|
| 陈旧帧护栏 | `max_batch_age_s=2.5`（`socket_vision_source`）| 帧超 2.5s 直接丢 |
| 首件稳定门 | `first_dispatch_settle_frames`（默认 0；现场用 3）| 前 3 帧签名不变才派第一件 |
| 一帧一件 | `next_if_permitted()` 消费整帧 | 防排队坐标过期 |
| 多帧类别投票 | `class_vote_*`（默认**关**，第 2 轮已改为 unanimous 默认）| 见 §6 |

## 3. 标定在链路里的位置（公式 + 文件）

> 标定的目标：把 MaixCAM 报的**像素**换成 STM32 要的**0.1mm 装置坐标**，并叠加工具偏移。

### 3.1 换算链（`rpi/pixel_to_device.py`）

```
① 像素域检查（整帧有效区）
② 仿射： (u,v) → 顶面装置坐标 (x_top, y_top)   [CameraCalibration] 6 参数
     x_mm = a11*u + a12*v + tx
     y_mm = a21*u + a22*v + ty
③ 视差补偿： (x_top,y_top) → 底面 (x_bot,y_bot)
     scale = H / (H - h)        H=[CameraCalibration] 相机高度，h=[ObjectHeights] 件高
     bottom = nadir + (top - nadir) * scale
     nadir = affine(图像中心)   ← 光轴落点
④ 工作区检查 [WorkspaceLimits]（fail-closed：超出 → None）
⑤ mm → 0.1mm（协议单位）
⑥ 叠加 [ToolOffset]（`build_grasp_point` 在 run_chain 里，**不属于相机标定**）
```

代码：`pixel_to_device.py:180`（`PixelToDeviceConverter`）、`:348`（转换主函数）；`run_chain.py` `build_grasp_point` 负责 ⑥。

### 3.2 ⚠️ 关键陷阱：**有两份 calibration_config.ini**

| 路径 | 谁在用 | 现状 |
|---|---|---|
| `/home/pi/电控/calibration_config.ini` | **链与 `p_look2.py` 实际读这份**（`p_look2.py:14 _CFG=...`）| p_look2 现场打印 `ToolOffset=(-120.5, -43.5)` |
| `/home/pi/calibration_config.ini` | 采集快照里的副本（可能是历史/备份）| 快照里 `ToolOffset=(-75.0, -25.0)` |
| `电控/calibration_config.ini`（仓库）| 仅供离线/测试 | **过期占位值**，别拿它当真值 |

> 标定回写前先确认**链读的是哪份**：`run_chain.py --calibration-config` 缺省走环境变量 `CALIBRATION_CONFIG`，否则用默认路径。**写错文件 = 静默失效**（`is_calibrated=False` 后整链退回固定抓取点，现场表现是"完全不抓"）。

### 3.3 配置文件节

| 节 | 键 | 说明 |
|---|---|---|
| `[CameraCalibration]` | `a11 a12 a21 a22 tx ty`（+`camera_height`/`frame_w/h` 等）| 6 参数仿射 |
| `[ObjectHeights]` | 按 class 或全局件高 h（mm）| 视差补偿用；**不能填 0** |
| `[ToolOffset]` | `x_mm y_mm` | 夹爪/工具偏移（机械真值）|
| `[WorkspaceLimits]` | `x_min x_max y_min y_max` | 与固件 `ec_motion_plan.h` 的可达域对齐（-95/90, -97.5/92.5）|

## 4. 标定工具矩阵（选哪个、怎么用）

| 工具 | 输入 | 输出 | 适用/判据 |
|---|---|---|---|
| **`工具/calib_photo.py`** | **一张照片**（含夹爪尖端在机器 (0,0) + 一把尺子），鼠标点 3 下 | 比例 + 原点 + X 方向 ⇒ 仿射 | 快速粗标（± 数 mm）；适合现场快速起链 |
| **`工具/calib_affine.py`** | `标定点.txt`，每行 `u v x y`（≥3 点，越多越好）| 6 参数最小二乘 + 残差 | 常规标定；给出残差判断可用性 |
| **`工具/fit_affine_conformal.py`** | 3 个**精确**点（夹爪开到滑台坐标→件塞爪心→记号→退开→读像素）| 共形 4 参（`a,b,tx,ty`）+ 真检验残差 | 4 未知/6 方程，2 自由度检验；精度最好之一 |
| **`工具/calib_joint.py`** ⭐ | `points.csv`：`u,v,h_mm,px_mm,py_mm` | 共形参数（含视差反解，迭代收敛）+ RMS | **推荐**：联合标定，直接给"像素→滑台记账 PICK"；判据 **RMS ≤2.0mm、单点 ≤4.0mm、任取 4 点 ≤3.0mm** |
| `工具/pi_set_calib.py` | `键名 新值 [备注]` | 安全回写 ini（**无 BOM UTF-8**，保留注释）| 回写必须用它，别手改（有过 BOM 事故）|
| `工具/pi_calib_truth.py` | 在 Pi 上运行 | 打印光轴、帧尺寸、件高表、工作区，并用已知像素**回放**验证 | 回写后**必跑**：确认链真的读到了新值 |
| `工具/pi_probe_calib.py` | 在 Pi 上运行 | 抬爪→走到件上方→保持 20s 供目视 | 视觉+机械联合验证 |
| `docs/落料位复看-PlaceEye-标定与回退-20261101.md` | — | 落料位 ROI 标定与回退 | 启用复看前读 |

### 4.2 标定常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| 链完全不抓 | `is_calibrated=False`（参数全 0 / 文件写次了 / BOM）| 用 `pi_calib_truth.py` 看加载结果；确认改的是链读的那份 ini |
| 偏 9mm 左右 | `ToolOffset` 有两处真相（硬编码/ini）| 只从 ini 读（历史坑，见 `p_look2.py:12-17`）|
| 边角偏大、中心准 | 视差补偿没开/件高填 0 | 填 `[ObjectHeights]`，用 `calib_joint.py` 联合解 |
| 符号反（X 或 Y 镜像）| Y 轴方向未实测 | 用九宫格验证；必要时在仿射里调 a12/a21 符号 |
