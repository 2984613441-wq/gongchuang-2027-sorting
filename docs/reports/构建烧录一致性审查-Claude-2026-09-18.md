### 1.1 核心发现

#### 路径 A2：宏定义在源码与工程配置两处重复定义

**触发条件**：
- 工程配置（uvprojx:337）定义宏 `EC_DIAGNOSTIC_BUILD=1`
- 源码（如 `ec_app.c:19-20`）又有 `#ifndef EC_DIAGNOSTIC_BUILD / #define EC_DIAGNOSTIC_BUILD 0`
- 不同编译器版本或配置下，宏优先级可能不同

**证据**：
```
MDK-ARM/diankongv1.0.uvprojx:337
  <Define>USE_HAL_DRIVER,STM32F407xx,EC_DIAGNOSTIC_BUILD=1,EC_MOTION_TEST_BUILD=1,EC_SERVO_TEST_BUILD=1,EC_GROUP_TEST_BUILD=0,EC_BARRIER_TEST_BUILD=0,EC_APP_PROGRESS_SOURCE_ENABLED=0</Define>

App/Src/ec_app.c:19-20
  #ifndef EC_DIAGNOSTIC_BUILD
  #define EC_DIAGNOSTIC_BUILD 0
  #endif
```

**后果**：
- 理论上工程配置优先（命令行 `-D` 传入），但若编译器行为异常或配置被覆盖，源码默认值生效
- **实际生效值**：工程配置 `=1`（因为 `#ifndef` 检查失败，不会重定义）
- 但存在歧义：其他 AI/开发者可能误读源码认为 `=0`

**判定方法**：
```c
// 在 ec_app.c 中添加编译时断言（临时验证用）
#if EC_DIAGNOSTIC_BUILD != 1
#error "DIAGNOSTIC mismatch: expected 1"
#endif
```

**防护建议**：
1. **删除源码中的 `#ifndef` 默认值定义**，只在工程配置中定义
2. 或在源码中添加 `#ifdef EC_DIAGNOSTIC_BUILD / #error "Must define via project" / #endif`

### 7.1 build_id.h 生成脚本（Windows batch）

保存为 `MDK-ARM/generate_build_id.bat`：

```batch
@echo off
REM Generate build_id.h with timestamp and git hash

set OUTPUT_FILE=..\Core\Inc\build_id.h

REM Get Unix timestamp (Windows 需要 PowerShell)
for /f %%i in ('powershell -Command "[int][double]::Parse((Get-Date -UFormat %%s))"') do set TIMESTAMP=%%i

REM Get git short hash (4 bytes = 8 hex chars)
for /f %%i in ('git rev-parse --short^=8 HEAD 2^>nul') do set HASH=%%i
if "%HASH%"=="" set HASH=00000000

REM Write header file
echo // Auto-generated by generate_build_id.bat > %OUTPUT_FILE%
echo // DO NOT EDIT >> %OUTPUT_FILE%
echo. >> %OUTPUT_FILE%
echo #ifndef BUILD_ID_H >> %OUTPUT_FILE%
echo #define BUILD_ID_H >> %OUTPUT_FILE%
echo. >> %OUTPUT_FILE%
echo #define BUILD_TIMESTAMP  0x%TIMESTAMP%UL >> %OUTPUT_FILE%
echo #define BUILD_HASH       0x%HASH%UL >> %OUTPUT_FILE%
echo. >> %OUTPUT_FILE%
echo #endif >> %OUTPUT_FILE%

echo Generated %OUTPUT_FILE% with timestamp=%TIMESTAMP% hash=%HASH%
```

### 7.4 树莓派侧解析代码（Python）

```python
import struct
import datetime

def parse_status_frame(status_bytes):
    """解析 STATUS 帧中的构建信息"""
    diagnostic_build = status_bytes[10]
    progress_enabled = status_bytes[11]
    
    # 解析时间戳（大端序 uint32）
    timestamp = struct.unpack('>I', bytes(status_bytes[12:16]))[0]
    build_time = datetime.datetime.fromtimestamp(timestamp)
    
    # 解析哈希（大端序 uint16）
    hash_short = struct.unpack('>H', bytes(status_bytes[16:18]))[0]
    
    print(f"固件构建信息:")
    print(f"  DIAGNOSTIC_BUILD: {diagnostic_build}")
    print(f"  PROGRESS_ENABLED: {progress_enabled}")
    print(f"  构建时间: {build_time.strftime('%Y-%m-%d %H:%M:%S')}")
    print(f"  源码哈希: {hash_short:04x}")
    
    return {
        'diagnostic': diagnostic_build,
        'progress': progress_enabled,
        'build_time': build_time,
        'hash': hash_short
    }
```
