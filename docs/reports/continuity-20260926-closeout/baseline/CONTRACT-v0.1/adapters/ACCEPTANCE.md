# 五节点 Provider Adapter 接线与验收矩阵（草案）

## 定位与边界

每个 Provider Adapter 只负责把该节点接到同一个文件交接协议：定位共享项目、启动或接续时读取入口、交出当前工作时写入记录、记录读写证据。它不复制项目事实，不代表其他节点发言，也不把内部帝国治理角色当作跨 AI 节点。五个节点是否能运行对应钩子须逐一实测；此文是接线目标，不表示已部署。

## 目录及分发约定

项目层唯一权威文件由主协议定义。每个节点持有自己的 `nodes/<provider>/ADAPTER.md` 和 `nodes/<provider>/receipts/`，只记本节点运行限制及读写回执，不保存决定和参数的独立副本。共享目录可用时，所有节点以相同项目 ID 和规范化相对路径访问。不同机器、云端会话、Web AI 无法直接访问本地文件时，使用由用户或外部进程搬运的交接包；记录原始路径、导出时间、文件哈希与导入时间，不声称已直接读取共享目录。接收节点只依据实际传入内容反馈缺件，不假称同步成功。

## Adapter 最小契约

1. 入口：识别 `project_id`、当前 `task_id`、协议版本、共享目录或交接包来源。缺失则标为 `BLOCKED_MISSING_INPUT`，不得编造上下文。
2. 恢复：先读 `STATE` 中的共同理解、纠正记录、边界、确认和待确认事项，再读决定、开放项、参数、证据和最新交接；逐项报告读到的文件路径、版本/哈希、时间。上下文压缩后的恢复按同一流程，不能只依赖模型的对话摘要。
3. 执行：将事实、推断、提案、已确认决定分开；涉及参数按原文保留单位、值、范围、来源及生效版本。决策权限遵循共同规则；跨节点建议仍需显式提交用户裁决。
4. 写出：在交接、压缩前、会话结束前写快照；如果平台无法在压缩前自动触发，则将“压缩前交接”标为 `MANUAL_REQUIRED`，由用户主动触发，不能报告为自动化。
5. 回执：记录读取的输入集合、发现的缺件与冲突、当前共同理解摘要、修改文件清单、未验证状态、下一节点待办。只可宣称本节点实际执行的工作。
6. 并发：同一任务同一权威状态文件仅一个写入者；其他节点写自己的候选回应，用户或指定合并者检查冲突后合并。文件写入采用临时文件和原子替换，保留历史事件。

## 节点验收矩阵

| 节点 | 入口及调用方式 | 读取/写入验证 | 压缩或新对话恢复验证 | 现阶段应填状态 |
| --- | --- | --- | --- | --- |
| Claude Code | 本地会话钩子或项目入口指令；具体 hook 名、输出 schema 按安装版本核对 | 在真实机器用一次完整交接包读写，并核对回执和落盘内容 | 实际触发新会话与压缩，再核对共同理解、修正、未定稿项、精确参数 | `UNVERIFIED`，不得由历史局部 Skill 测试推断完成 |
| Codex CLI/Desktop | 项目 `AGENTS.md` 或可用的启动入口；是否共享配置及读取时机分别验证 | 用同一项目 ID 验证 CLI 与 Desktop，各自输出读写回执 | 分别开启新会话并模拟压缩恢复 | `UNVERIFIED`；第三方 API 路由正常不等于 Adapter 生效 |
| DeepSeek Harness | 独立节点入口指令和文件交接；不预设内部 subagent 承载协作 | 候选回应独立写入该节点输出，主状态由合并者接收 | 重开上下文后按交接包逐项回放 | `UNVERIFIED` |
| Zcode | 待查本地/远端文件访问能力；优先使用入口指令加搬运包 | 若无共享文件系统，以输入包哈希和输出包回执核验 | 重新开聊时重新导入并逐项回读 | `UNVERIFIED` |
| Grok | 待查本地/远端文件访问能力；优先使用入口指令加搬运包 | 若无共享文件系统，以输入包哈希和输出包回执核验 | 重新开聊时重新导入并逐项回读 | `UNVERIFIED` |

## 最小端到端验收

准备同一项目的五类信息：①用户纠正过的问题定义；②已确认但未正式写入规范的共识；③明确未定稿的方案；④带单位和范围的精确参数；⑤一条尚有分歧的节点建议。每节点分别从新会话读取，输出带输入哈希的恢复回执；要求能够准确复述五类状态且不将建议写成决定。再让一个节点写候选、另一个节点读取并指出分歧，由用户或指定合并者裁决并更新主状态。最后真实触发一次上下文压缩或重开，核查恢复回执与状态文件一致。任一关键项丢失或被改写则该节点判 `FAIL`；无法运行实际压缩测验则判 `PARTIAL`，不能判 `PASS`。

## 本草案的证据边界

当前没有该五节点环境的直接访问和实测日志；验收矩阵所有节点均为 `UNVERIFIED`。文中“钩子”和入口是候选接法，必须按各安装版本核对。需要节点端真实读写、压缩、重启证据后才能升级状态。
