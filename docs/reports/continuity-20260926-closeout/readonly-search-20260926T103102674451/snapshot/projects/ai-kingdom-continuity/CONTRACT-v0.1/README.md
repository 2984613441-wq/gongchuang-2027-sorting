这是分发和验证用的首版契约，不表示任何节点已经安装。先发 `00-SEND-TO-ALL-AI.md`，再发本包；各节点需按真实环境确定 Active Root，不能直接把此包写成第二套权威规则。

读取顺序：节点入口 → 项目 `INDEX.md` → `SHARED-UNDERSTANDING.md` → `STATE.md` → 最新 handoff → handoff 的 must_read → 本节点 Adapter。必须留恢复回执，精确记录实际读取的文件版本、缺失项及共同理解。

关键记录一有变化即增量写入，不能仅依赖临近上下文压缩时的一次总结。共享项目事实只有一个权威位置；各节点只独立写自己的回复。任何跨节点采纳、合并和重大规则变化经用户裁决。

`core/` 是契约；`projects/_template/` 是新项目模板；`nodes/` 是节点提示词；`adapters/ACCEPTANCE.md` 是验收矩阵。实际部署路径必须由每个节点核实并记录。
