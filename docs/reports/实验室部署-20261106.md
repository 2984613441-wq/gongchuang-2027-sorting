### 2.2 副相机（DF200 on Pi）——**部署形态与主相机完全不同**

**关键事实（本次现场核实）**：

1. 副相机是 **USB 摄像头接在树莓派**上（`lsusb`: `2993:0858 icSpring icspring camera`，节点 `/dev/video0`）
2. Pi 上的脚本**只做采集与推流**，**没有任何推理代码**：
   - `pi_cam2_stream.py`：MJPEG 流 `http://<pi>:8080/`、单帧 `/snap`、存图 `/save`
   - `pi_cam2_capture.py`：采集会话
   - 全盘 grep `cv2.dnn|readNet|onnxruntime|tflite|ncnn` → **0 命中**
3. `/home/pi/yolo11n_6c_cam2.onnx`（10 MB）是**死文件**（没有代码加载它）
4. Pi 环境：Raspberry Pi 4B / 4 核 / 1.8 GB 内存 / Python 3.9.2 / 有 numpy+cv2，**无 onnxruntime**
5. 因此 **副相机模型实际在 PC 上跑**（三路窗口 `_pi_tools/three_way_view.py --model ...`）
   —— 这就是"主副相机部署不一样"的原因：**主相机要转 cvimodel 放 MaixCAM；副相机是 ONNX 放 PC，Pi 只当取流服务器**

| Pi 推流服务 | ✅ 已在 Pi 上后台启动：`python3 pi_cam2_stream.py --port 8080 --dev 0`（日志 `/tmp/cam2_stream.log`）|
| PC 取图 | ✅ `http://172.20.10.8:8080/snap` 返回 200 / 33 KB JPEG |
| 新模型 | ✅ `_deploy_maixcam/yolo11n_6c_cam2_v2_20261105.onnx`（448/opset13，56 张复核集训练）|
