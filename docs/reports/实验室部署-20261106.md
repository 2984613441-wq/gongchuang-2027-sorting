## 七、补光灯：两路独立控制（2026-11-06 现场）

**用户反馈「只开了一个补光灯」** → 查固件确认是**两条独立 WS2812 灯带**，必须分别开：

| 通道 | 命令 | 引脚 | 说明 |
|---|---|---|---|
| CH0 | `LIGHT ON/OFF`、`LIGHT LV 0-255`、`LIGHT RGB r g b`、`LIGHT?` | `LIGHT_EN` | 原有补光灯（16 颗）|
| CH1 | `LIGHT2 ON/OFF`、`LIGHT2 LV 0-255`、`LIGHT2 RGB r g b`、`LIGHT2?` | **PE3 / LIGHT2_EN** | 2026-10-30 新增，独立数据线（不级联）|

代码位置：`电控/firmware/stm32f407_m144z/App/Src/ec_diag.c:395-464`、`ec_light_ws2812.c`、`main.h:71-72`。

### 现场执行结果（软件层确认两路都开）

```bash
python3 /home/pi/pi_light.py "LIGHT LV 255"   # OK LIGHT LV
python3 /home/pi/pi_light.py "LIGHT2 LV 255"  # OK LIGHT2 LV
python3 /home/pi/pi_light.py "LIGHT ON"       # OK LIGHT ON
python3 /home/pi/pi_light.py "LIGHT2 ON"      # OK LIGHT2 ON
python3 /home/pi/pi_light.py "LIGHT?"         # OK LIGHT LV=255 LED=16
python3 /home/pi/pi_light.py "LIGHT2?"        # OK LIGHT2 LV=255 LED=16
```

⇒ **固件/命令层两路都是 LV=255 已点亮**。若实际只有一根亮，属**硬件接线**问题，排查顺序：

1. 第二根灯带 **DIN 是否接在 PE3**（不是第一根的公共数据线）
2. 第二根 **5V/GND 是否独立供电**（16 颗 × 0.3 W ≈ 1 A/根，两根约 2 A）
3. **PE3 复用冲突**：`Core/Src/main.c:844-847` 注释说 PE3 原为 `DIR_Z`，2026-10-30 才并入 `LIGHT2_EN`
   —— 若 Z 轴方向线仍接 PE3，会与灯带数据打架
4. 3.3 V 数据电平驱动 5 V WS2812 余量不足（尤其线长/无电平转换时可能不亮）
