## 二、实现要点

### 1) 判定（纯函数，`judge_frame`）

```
差分：|frame - baseline| 在 ROI 内 > pixel_diff 的像素占比 ≥ diff_threshold ⇒ OCCUPIED，否则 CLEAR
兜底：基准帧不可用/尺寸不符 ⇒ ROI 内高饱和像素占比 ≥ 0.25 ⇒ OCCUPIED，否则 UNKNOWN
```
* 只判"有/无"，不细分类（符合用户口径）；
* ROI 越界、图像维度非法 ⇒ `BarrierCheckError`；
* 基准帧尺寸与当前分辨率不符 ⇒ 记 `baseline_error` 并退兜底（**不静默当"没有"**）。

### 2) 巡检器（`BarrierChecker`）

* `frame_provider()` 抛错/返回 None ⇒ **UNKNOWN**（不猜"没有"）；
* 每次巡检留 evidence（改变像素数/占比/兜底依据），便于日志复盘；
* `mode=off` 时不允许构造（防止"以为开着"）。

### 3) `run_chain` 三档与动作

| 档位 | OCCUPIED | UNKNOWN |
|---|---|---|
| `off`（默认） | 不执行 | 不执行 |
| `observe` | 记日志 + 台账（STAGE），不拦截 | 记日志，按 `on_unknown` 提示，不拦截 |
| `stop` | 记 FAULT + **停链** | `on_unknown=stop` ⇒ 记 FAULT + 停链；否则继续 |

* 巡检点是**发 ITEM_TASK 之前**（即"去落料点之前"，L80）；
* 取图地址来自 `[BarrierCheck] snapshot_url`（主相机 `:8766/snap` 或副相机 `:8080/snap`，M3 定相机，D8）；
* 配置解析容忍 Windows BOM（`utf-8-sig`），避免"第一行带 BOM 导致读不到段"。

### 4) D7 动作映射（供上层使用，骨架已提供但未接）

```python
occupied_action(has_code=True)  -> "treat_as_item"   # 能判 code：当正常件抓进对应格
occupied_action(has_code=False) -> "claw_stop"       # 判不出：夹爪停住
unknown_action(config)          -> "continue" | "stop"
```
