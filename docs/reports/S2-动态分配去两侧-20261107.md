## 二、S2 改动

### 1) `电控/src/electrical_control/rpi/slot_allocator.py`

* 分配规则改为两条（原来三条）：**同 code 复用** → **空格取编号最小（1→6）**。
* 删除 `prev_side/same_side` 分支；`_side_of_box` 不再参与决策。
* 构造参数 `side_of_box` 保留（兼容旧调用），**非空即 WARNING**：
  `side_of_box 已废弃（2026-11-07 S2：选格固定 1→6），本次忽略`。
* `journal` 里的 `last_box` 字段保留（旧台账可继续读），但不再用于选格。

### 2) `电控/deploy/run_chain.py`

| 改动 | 说明 |
|---|---|
| 动态分配装配上移 | 从 `else:`（真实模式）移到 `if demo:` **之前**：demo 冒烟也能验证映射；demo 不写 journal（不污染 `/home/pi/slot_alloc.log`）|
| 新增 `--demo-items N` | `--fake-link` 演示件数（默认 2，保持原行为）；`6` 用于验证六格/六件 |
