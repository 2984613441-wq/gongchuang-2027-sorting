## 二、实测证据（我自己跑的探针，不是读代码猜的）

### 2.1 默认参数下「超时保护」不可达

`class_vote_frames=3`、`class_vote_max_wait_frames=6`，而历史窗口被封顶在 3：

```python
hist.append(...); if len(hist) > self._vote_frames: hist.pop(0)   # 最长 3
...
elif len(hist) >= self._vote_max_wait:                            # 3 >= 6 永不成立
```

实测（12 帧、类别在两类之间来回切）：

```
stats {'accepted': 10, 'rejected_no_quorum': 2, 'timeout': 0}   ← timeout 永远 0
```

⇒ 提交信息里"超时保护：max_wait 帧未达标 → 按不可用处理 + WARNING"**在默认参数下不会发生**。

### 2.2 更关键：默认 2/3 多数票，对「两类互相误判」几乎没有过滤作用

同样的 12 帧「2/3 交替」，窗口 `[2,3,2]` 的票数是 `2:2, 3:1` ⇒ **判定 class_id=2 通过**。
而我们这次要治的正是 **cube↔cuboid↔penta 的互相误判**（典型就是两类交替）。
⇒ `quorum=2/3` 只能过滤"偶发单帧噪声"，**过滤不了持续的两类摇摆**。

实测：交替 12 帧里 `accepted: 10`——绝大部分帧都被采纳了。

### 2.3 跨轮历史不清空（状态残留）

`_vote_history` 以 `("seq", target_seq)` 为键，**从不清理**；而每轮 `target_seq` 都从 1 重新开始。
实测（同一个 source 实例，先喂 class=2 两帧，再模拟新一轮喂 class=5 两帧）：

```
第一轮后 hist {('seq', 1): [(2,…), (2,…)]}
新一轮后 hist {('seq', 1): [(2,…), (5,…), (5,…)]}   ← 上一轮的 2 还在里面
stats {'accepted': 3, …}                              ← 已经按混合历史判过 3 次
```

⇒ 若同一进程跑多轮（或调试时复用 source），**新一轮最初几帧会被上一轮的类别污染**。

### 2.4 「位置匹配」分支是死代码

- 生产链里 `vision_ingest` 一定给 `target_seq` 赋非 0 值 ⇒ `if target.target_seq and target.target_seq != 0` 恒真 ⇒ `("pos", grid)` 分支**永不执行**。
- 注释写 `POS_MATCH_THRESHOLD_PX = 40  # 40 像素约 40mm`（混单位，像素/毫米不是一回事）。
- 测试 `test_vote_falls_back_to_position_when_seq_missing` 用 `target_seq=0` 构造，所以"通过"，但那是**生产不会出现的输入**。

### 2.5 统计语义

`vote_stats()["accepted"]` = "投票达标次数"，**不是派件次数**；稳定门（`_visibility_signature`）里也会调用投票，
所以会出现"accepted 涨了但本帧没派件"。不是 bug，但字段名容易误读，建议改名 `vote_passed` 或注释写清。

## 四、建议修复（A 的 4 点，改动都不大）

1. **默认改成"全一致"**：`class_vote_quorum` 默认 = `class_vote_frames`（3/3），或新增 `class_vote_mode = majority|unanimous` 默认 `unanimous`；
   理由：2/3 对两类摇摆无效（§2.2 实测）。
2. **超时改成按"目标年龄"计**：为每个 target_key 记 `first_seen_frame` / `seen_frames`，与 `max_wait` 比较（不要用被截断的 `len(hist)`）。
3. **加历史清理**：`set_permitted(True)`（新一轮开始）时 `_vote_history.clear()`；并每帧淘汰"最近 K 帧没再出现"的键（防内存增长）。
4. **位置匹配分支**：要么删掉（生产用不到，减少死代码），要么保留但改成"生产确实可能 seq 变化"的注释 + 单位改对（像素阈值 vs mm 换算写清）。
5. （可选）`vote_stats` 字段改名 `vote_passed`，或在 docstring 写明"这是投票通过次数，不是派件次数"。

**修复后验收**（我复核时会跑）：

```powershell

```

并新增 3 个必测用例：
- 两类交替 N 帧 → **不得**采纳（unanimous 模式下）
- 默认 `max_wait` 下，类别持续摇摆 → 必须触发 `timeout` 计数
- `set_permitted(True)` 后历史被清空（跨轮不污染）
