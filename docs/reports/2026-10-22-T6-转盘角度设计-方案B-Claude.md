## 一、方案B 核心机制（已实现）

### 1.1 工作原理

**固定落料点 + 转盘旋转选格**：

```
滑台 → 移动到固定落料点（X=+90.0mm, Y=+88.5mm）
          ↓
     落料舵机打开
          ↓
     物块靠重力落入转盘
          ↓
     转盘旋转，让目标货格对准落料口
```

**与方案A的区别**：

| 项 | 方案A（六固定盒） | 方案B（转盘） |
|---|---|---|
| 滑台落点 | **6 个不同坐标** | **1 个固定坐标** |
| 选格机制 | 滑台移动到不同位置 | 转盘旋转不同角度 |
| 配置段 | `[DropPoints]`（6 行） | `[TurntableAngles]`（1 落点 + 6 角度） |
| 时间开销 | 每件都要滑台大行程移动 | 滑台只移动一次，转盘并行转动 |

### 1.2 代码实现现状（`drop_strategy.py`）

✅ **已完整实现**，无需修改代码：

```python
class TurntableStrategy(DropStrategy):
    """方案B：转盘选格，box_id → 转盘角度（落料点固定，转盘对准货格）。"""
    
    def get_drop_point(self, box_id: int) -> tuple[int, int] | None:
        """所有货格用同一落料点"""
        return self._drop_point  # 固定坐标
    
    def get_angle(self, box_id: int) -> float | None:
        """查转盘角度（度）"""
        return self._angles.get(box_id)
```

**配置驱动切换**（`load_strategy_from_cfg`）：

```python
if cfg.has_section("TurntableAngles"):
    # 方案B：读 turntable_drop_point + 6 个角度
    return TurntableStrategy(drop_point, angle_table)
elif cfg.has_section("TurntablePositions"):
    # 方案C（已弃用）
else:
    # 方案A（当前）
    return FixedBoxStrategy(drop_points)
```

## 三、设计方案（两种可能）

### 方案 3.1：等分 6 格（最简单，推荐先试）

**假设**：
- 转盘机械上是 6 等分（每格 60°）
- 6 格排列成圆周，围绕中心对称
- 货格 1 零位对应舵机中位（1500µs = 0°）

**角度表**（270° 量程，等分 6 格）：

```ini
[TurntableAngles]
# 固定落料点（滑台记账坐标，单位 mm）
# 🔴 待现场标定：当前值是实测行程极限，可能需要微调
turntable_drop_point = 90.0, 88.5

# 6 个货格角度（度，0° = 舵机中位 1500µs，顺时针为正）
# 🔴 以下是"等分 6 格"示例，实际需要现场标定确认
1 = 0.0      # 中位（1500µs）
2 = 60.0     # 顺时针 60°（≈1992µs）
3 = 120.0    # 顺时针 120°（≈2369µs，接近上限）
4 = -60.0    # 逆时针 60°（≈1008µs）
5 = -120.0   # 逆时针 120°（≈631µs，接近下限）
6 = 180.0    # ❌ 超出 270° 量程！需要改用方案 3.2
```

**⚠️ 问题**：货格 6 若取 180°，脉宽 = 1500 + 180×(655/90) ≈ **2810µs**，**超出 2500µs 上限**！

**解决**：**不能完整覆盖 6 格等分圆周**，必须改用围绕中心对称布局（方案 3.2）。

---

### 方案 3.2：围绕中心对称布局（270° 约束下的最优解）

**原理**：
- 6 格分布在 270° 弧内（不覆盖完整圆周）
- 每格间隔 45°（270° / 6 = 45°）
- 围绕中心对称：`[-112.5°, -67.5°, -22.5°, +22.5°, +67.5°, +112.5°]`

**脉宽范围**：
```
最小：1500 + (-112.5) × (655/90) ≈ 1500 - 819 = 681 µs  ✅ > 500µs
最大：1500 + (+112.5) × (655/90) ≈ 1500 + 819 = 2319 µs ✅ < 2500µs
```

**配置示例**：

```ini
[TurntableAngles]
# 固定落料点（滑台记账坐标，单位 mm）
# 🔴 待现场标定：当前值是 2026-10-22 实测行程极限（X+14800步/Y+14880步）
turntable_drop_point = 90.0, 88.5

# 6 个货格角度（度，围绕中心对称，间隔 45°）
# 基准：0° = 舵机中位（1500µs），顺时针为正
# 🔴 以下角度假设货格在转盘上是对称分布，需要现场标定确认实际编号
1 = -112.5   # 脉宽 ≈ 681µs
2 = -67.5    # 脉宽 ≈ 1008µs
3 = -22.5    # 脉宽 ≈ 1336µs
4 = 22.5     # 脉宽 ≈ 1664µs
5 = 67.5     # 脉宽 ≈ 1992µs
6 = 112.5    # 脉宽 ≈ 2319µs
```

**优点**：
- ✅ 脉宽全部在 500~2500µs 范围内
- ✅ 围绕中心对称，机械上最稳定
- ✅ 与 `turntable.py` 自检完全一致（见第 516-520 行）

**缺点**：
- ⚠️ 假设货格在转盘上是对称分布
- ⚠️ 货格编号（1~6）与角度对应需要现场确认

**步骤 2：确认转盘零位（货格 1 基准）**

```bash

# 或通过转盘后端：
echo "1500" > /home/pi/pw.txt

# 目视确认：
# - 转盘停在哪个位置
# - 哪个货格对准落料口
# - 记录该货格编号作为"货格 1"
```

**步骤 3：试探每个货格的角度**

```bash
# 假设货格 1 已在 0°，试探货格 2
# 若货格等分 60°：
echo "1992" > /home/pi/pw.txt  # 1500 + 60×(655/90) ≈ 1992µs

# 目视确认转盘是否转到货格 2
# 若未对齐，微调角度：

# 重复试探，直到货格 2 对准落料口

# 记录实际脉宽，反推角度：
# angle = (pulse_us - 1500) / (655/90)
```

**步骤 4：填入配置**


**脉宽越界校验**（`turntable.py:108-118`）：

```python
def pulse_for_angle(self, angle_deg: float) -> int:
    pulse = int(round(self.zero_pulse_us + self.angle_sign * angle_deg * self.us_per_degree))
    if not (PULSE_MIN_US <= pulse <= PULSE_MAX_US):
        raise TurntableUncalibrated(
            f"角度 {angle_deg:.1f}° → 脉宽 {pulse}µs 超出 [500, 2500]"
        )
    return pulse
```
