### 📏 Step 5：PWM 频率验证（10 分钟）

```bash
# 工具：示波器 或 频率计
# 测量点：舵机 PWM 输出（PB10）

# 判据
✅ 频率 = 50 Hz（周期 20ms）
✅ 脉宽在 625~1900 µs 范围内

# 如果是 262.5 Hz 或 525 Hz
→ TIM2 的 PSC 没改到（应该是 83）
→ 检查 main.c:TIM2_Init() 中的 Prescaler 值
```

**快速算法**：
- 168 MHz → APB1 42 MHz → APB1 timer 84 MHz
- TIM2: `84MHz / (83+1) / (19999+1) = 50 Hz` ✅

### ⚙️ Step 10：A4988 Vref 标定（30 分钟）⭐

#### 10.1 测量 Rs（感流电阻）

```bash
# 工具：万用表（电阻档）
# 测量点：A4988 板子上的 Rs 电阻（SMD，很小）

# 常见值
- 0.05Ω（501 标注）
- 0.068Ω（R068 标注）
- 0.1Ω（R100 标注）

# 判据
✅ 读数稳定（±5%）
✅ 记录 Rs = _____ Ω（填空）
```

#### 10.2 计算 Vref 目标值

```bash
# 公式：Vref = 8 × Rs × I_trip
# 目标电流：I_trip = 1.7A（每相）

# 示例
Rs = 0.05Ω  → Vref = 8 × 0.05 × 1.7 = 0.68V
Rs = 0.068Ω → Vref = 8 × 0.068 × 1.7 = 0.925V
Rs = 0.1Ω   → Vref = 8 × 0.1 × 1.7 = 1.36V
```

#### 10.3 调整 Vref（电位器）

```bash
# 工具：小螺丝刀 + 万用表（电压档）
# 测量点：Vref 测试点（A4988 板上标注）

# 操作
1. 板子上电（但电机不动）
2. 万用表黑表笔接 GND，红表笔接 Vref
3. 缓慢旋转电位器（顺时针 = 增大）
4. 调到目标值（如 0.68V）

# 判据
✅ Vref = 目标值 ± 0.05V
✅ X 轴和 Y 轴都调好
```

#### 10.4 验证（温度 + 扭矩）

```bash
# 1. 温度测试
pi_square.py 50  # 跑 5 次
用温度枪测量：
- 驱动板温度 ≤ 60°C ✅
- 电机温度 ≤ 50°C ✅

# 2. 扭矩测试
手抓住轴，感受阻力：
- 能抓住但需要用力 ✅（正常）
- 轻松抓住 → Vref 太低 → 增大
- 抓不住 → Vref 可能过高 → 检查温度

# 如果温度 >70°C
→ Vref 过高
→ 降低 0.1V 重测
```

## ⚠️ 紧急回退流程

### 场景 1：不启动（无 PONG）

```bash
1. 【立刻】断电
2. Keil → Flash → Download（烧回 backup-before-168mhz-YYYYMMDD.hex）
3. 上电，确认能收到 PONG
4. ✅ 回退成功，硬件无损
5. 带回分析（可能是 HSE 配置问题）
```

### 场景 2：丢步（pi_square 不闭合）

```bash
# 不是固件问题，是 Vref / 电源问题
1. 降低 Vref（如 0.68V → 0.6V）
2. 重测 pi_square
3. 仍不闭合 → 可能是电源不足
4. 记录现象，带回分析
```

### 场景 3：PWM 频率错误（不是 50Hz）

```bash
# PSC 没改到
1. 检查 main.c 中 TIM2 的 Prescaler
2. 应该是 83（不是 15）
3. 重新编译烧录
```
