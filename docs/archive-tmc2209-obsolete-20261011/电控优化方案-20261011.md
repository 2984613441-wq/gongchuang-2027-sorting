## 3. Phase 1：闭环基础设施（Week 1-2）—— ⚠️ L4 需批准

### 3.1 目标

**解决"丢步无人知道"** —— 当前开环步进，丢步后坐标基准永久失准且无告警。

### 3.2 方案：TMC2209 替换 A4988

| 项 | A4988 | TMC2209 |
|---|---|---|
| **接口** | STEP/DIR/EN | ✅ **完全一样（直接插上）** |
| **堵转检测** | ❌无 | ✅ StallGuard（实时） |
| **丢步检测** | ❌无 | ✅ 通过堵转间接检测 |
| **无传感器回零** | ❌无 | ✅ 支持 |
| **串口** | ❌无 | UART（可选，调参/诊断） |
| **价格** | 便宜 | ✅ **也很便宜** |
| **驱动电流** | 最大 2A | 最大 2.8A（峰值） |

### 3.3 硬件改动

| 项 | 操作 |
|---|---|
| **STEP/DIR/EN** | ✅ 不动（引脚完全一样） |
| **UART** | ✅ 用空的 **PA9/PA10**（USART1）|
| **Vref** | 重新标定（TMC2209 公式不同） |

### 3.4 固件改动（估算）

| 文件 | 改动 | 难度 |
|---|---|---|
| `ec_tmc2209.c/.h` | **新增**：UART 初始化、寄存器读写、StallGuard 查询 | 中 |
| `ec_board_stm32.c` | 堵转检测集成到 `ec_step_port_*` | 低 |
| `ec_app.c` | 堵转事件上报（新增 `STALL_DETECTED` 响应字） | 低 |
| `main.c` | USART1 初始化（PA9/PA10） | 低 |

### 3.5 验证矩阵

| 场景 | 判据 |
|---|---|
| **正常运动** | 无误报，运动顺畅 |
| **人为堵转**（手抓住滑台） | ≤200ms 内检测到 + 上报 `STALL_DETECTED` |
| **丢步复现**（负载过大） | 能检测到（通过 StallGuard 阈值调优） |
| **无传感器回零** | 轴撞到机械端点后回退 5mm = HOME |

### 3.6 风险与缓解

| 风险 | 缓解 |
|---|---|
| TMC2209 参数调优复杂 | 先用默认参数跑通，再优化 |
| StallGuard 阈值误报 | 保留 A4988 作为回退方案 |
| 串口冲突（USART1 已被占用？） | ✅ 已确认 PA9/PA10 空闲 |

## 4. Phase 2：性能提升（Week 3-4）

### 4.1 提速三步走（**顺序很重要**）

```
① 168 MHz 已完成（Phase 0 烧录）
    ↓
② 巡航 5000 → 6250 Hz（+25%）
    ↓
③ 加速率 10000 → 20000 Hz/s（+100%）
```

**为什么这个顺序**：168 MHz 只改时序，可一键回退；6250 Hz 引入机械/热/电流风险；20000 Hz/s 把系统推到更容易丢步的工况。**两者都必须排在"闭环"之后**（Phase 1），否则丢步零可观测性。

### 4.2 巡航提速：5000 → 6250 Hz

| 项 | 值 |
|---|---|
| **目标频率** | 6250 Hz = 78.1 mm/s（+25%） |
| **ARR 档位** | ARR = 15（整除档，100kHz / 16 = 6250） |
| **改动位置** | `ec_board_stm32.c:201` 第 4 个实参 `5000U → 6250U` |
| **单行改动** | 是（1 个数字） |
| **验证** | `pi_square.py 50`：四边各 50mm，首尾闭合 |
| **预期收益** | 单件 13s → **10.4s**（节省 2.6s） |

### 4.3 加速率提升：10000 → 20000 Hz/s

| 项 | 值 |
|---|---|
| **目标加速率** | 20000 Hz/s |
| **改动位置** | `ec_board_stm32.c:201` 第 5、6 个实参 `10000U → 20000U`（两处） |
| **单行改动** | 是（2 个数字） |
| **验证** | 短距离往返（5mm × 20 次）：听声音、看是否抖动 |
| **预期收益** | 加减速段缩短 ⇒ 单件再省 **0.5~1s** |

### 4.4 总收益

| 阶段 | 单件耗时 | 15 秒窗余量 |
|---|---|---|
| **现状** | 13.0s | 1.2 ~ 1.8s |
| Phase 2 完成 | **9.9s** | **4.2 ~ 4.8s** ⭐ |
| **节省** | **3.1s** | **+2.4s** |

## 5. Phase 3：精度优化（Week 5-6）

### 5.1 同向逼近（回程差修正）

**原理**：回程差来自机械间隙（6~15mm/件）。每次换向时：
1. 先走到目标 **−3mm**
2. 正向走 **3mm** 到达目标

⇒ **把"随机误差"变成"固定常量"**，消除累积失准。

### 5.2 改动位置

| 文件 | 改动 |
|---|---|
| `ec_motion_plan.c` | 新增 `approach_with_backlash_comp()` |
| `ec_board_stm32.c` | 包装到 `ec_step_port_move_to()` |

### 5.3 验证

| 场景 | 判据 |
|---|---|
| 单轴往返 20 次（−50 ↔ +50） | 终点偏移 ≤1mm |
| 九宫格抓取（9 个点） | 每点重复定位精度 ≤2mm |
