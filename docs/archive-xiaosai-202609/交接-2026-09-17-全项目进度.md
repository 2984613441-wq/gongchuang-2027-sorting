## 0. 项目是什么

设计并实现一套**智能物料分拣装置**：摄像头识别托盘里的货物 → 判断该进哪个货格 →
机械臂抓取并投放 → 屏幕显示本次分拣信息。

**硬件构成**

| 部件 | 型号/说明 |
|---|---|
| 视觉 | MaixCAM Pro（SG2002，1TOPS），俯视托盘，TCP 8765 发检测结果 |
| 主控（上层） | 树莓派 4B（`172.20.10.8`，Raspberry Pi OS bullseye，**Python 3.9.2**） |
| 主控（下层） | STM32F407（Keil MDK，ARMCC V5） |
| 执行 | XY 双轴步进（17HS4401 ×2 + A4988）+ 1 个舵机（Z 升降/夹爪） |
| 显示 | 7 寸 HDMI 屏，1024×600 |
| 通信 | 树莓派 ↔ STM32：USART2（PA2/PA3）115200 8N1 |

**冻结参数（不要改）**：行程 165mm = 全程 → 机械可达 ±82.5mm（825 × 0.1mm），
协议域 ±1450（0.1mm）；steps_per_mm = 80；原点 = 装置中心；`CONF_TH = 0.5`。
