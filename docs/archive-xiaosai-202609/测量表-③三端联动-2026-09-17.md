# 测量表 ③ · 三端联动（树莓派 ↔ MaixCAM ↔ STM32）（2026-09-17）

> **这张表只做一件事**：把三端的地址、协议、连通性、以及**摄像头装在哪**全部固定下来。
> 链路是两段，**中间是树莓派**：
> `MaixCAM --TCP 8765--> 树莓派 --UART2 115200--> STM32`

---

## 0. 三端地址（已核实）

| 端 | 标识 | 地址 / 端口 | 依据 |
|---|---|---|---|
| **MaixCAM** | `EC_DEVICE_MAIXCAM = 0x01` | **client**，主动连树莓派 | `ec_protocol.h` |
| **树莓派** | `EC_DEVICE_PI = 0x02` | **`172.20.10.8`**，监听 **TCP 8765** | 实机确认（HTTP 日志 + `main.py:39-40`） |
| **STM32** | `EC_DEVICE_STM32 = 0x03` | **USART2 = PA2(TX)/PA3(RX)，115200 8N1** | `stm32f4xx_hal_msp.c:451-459` |

**MaixCAM 侧环境变量**（`视觉/src/maixcam_deploy/main.py:36-43`）：

| 变量 | 默认值 | 作用 |
|---|---|---|
| `GATEWAY_HOST` | `172.20.10.8` | 树莓派地址（**与实机一致 ✓**） |
| `GATEWAY_PORT` | `8765` | 目标端口 |
| `TASK_ID` | `0` | 本轮任务号 |
| `ENABLE_NETWORK` | `1` | **设 `0` 可离线单独测视觉**（树莓派不在线时用） |
| `ENABLE_MONITOR` | 见 `main.py:61` | 9001 只读监控，**比赛时建议关** |

| S5 | `enable_uart=1` 是否在 config.txt 里 | ✅ 已在（实测 config.txt 倒数第二行） |

### 2.2 验证方法

```bash
# 只读监听（默认一个字节都不发），看 STM32 会不会主动吐帧
py -3 工具/link_check_stm32.py --port COM<x> -t 15
```
> ⚠️ 已知：`DEVICE_READY(0x03)` 固件里**没有任何发送路径**，别等它；
> `BARRIER_READY(0x20)` 只在进 `WAIT_TASK` 那一刻发一次，错过就没有。

### 2.3 命令字（权威）

| 命令字 | 名称 | 方向 |
|---|---|---|
| `0x20` | BARRIER_READY | STM32 → Pi |
| `0x21` | ITEM_TASK | Pi → STM32 |
| `0x22` | MOTION_DONE | STM32 → Pi |
| `0x23` | ITEM_RESULT | STM32 → Pi |
| `0x25` | DISPLAY_ACK | Pi → STM32 |

**ITEM_TASK 载荷 = 12 字节**（`EC_PROTO_ITEM_TASK_PAYLOAD_LEN 12U`）：
`target_seq(1) + class_id(1) + image_id(1) + x_mm10(2) + y_mm10(2) + grip_angle(1) + pick_x(2) + pick_y(2)`
（末两个是 2026-09-16 新加的，原来只有 8 字节）

## 5. 三端联动的启动顺序（建议）

| 序 | 动作 | 为什么 |
|---|---|---|
| 1 | 先给树莓派上电，确认 `172.20.10.8` 可达 | 它是中间节点 |
| 2 | 树莓派上跑 `link_listen_8765.py` 监听 | 确认段 1 通 |
| 3 | MaixCAM 上电，确认连上 8765 | 段 1 通 |
| 4 | 单独验视觉（`ENABLE_NETWORK=0`） | 排除网络因素 |
| 5 | STM32 上电，`link_check_stm32.py` 监听 | 段 2 通 |
| 6 | 三者全开，跑一轮 | 端到端 |

> 🔴 **但注意**：树莓派主链 `run_chain.py` **现在跑不起来**
> （`electrical_control` 因 Python 3.9 与 `slots=True` 不兼容，import 即 `TypeError`）。
> 所以第 6 步之前**必须先修 Python 3.9 兼容性**。详见 `docs/交接-2026-09-17-全项目进度.md` §4-A。
