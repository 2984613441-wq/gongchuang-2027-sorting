### 关键：ec_motion_test_on_counted_done() 的调用时机

[ec_step_test.c:222-229](vscode-webview://1cr3jtkavdrshksecklc8b60t6iscm166b1d5h7d1vq7l0h8fb7k/index.html?id=2eea0a87-d732-4bef-9ba1-3ded12bde1dc&parentId=1&origin=4a2294cc-7fad-4dfb-9a73-6f73947920a7&swVersion=6&extensionId=Anthropic.claude-code&platform=electron&vscode-resource-base-authority=vscode-resource.vscode-cdn.net&parentOrigin=vscode-file://vscode-app&session=9e148565-4b52-4a29-a528-54e6716e10fc)：

if ((mode == EC_STEP_TEST_MOTION_COUNTED) \|\|

**该函数在** ec_step_test.c **内部没有调用点** → 必定是**外部模块（很可能是 ISR）** 回调。

从命名 on_counted_done 与 :16-19 的注释推断：

> \"active_axis/started_at_ms/counted_steps/mode/counted_result are shared between **the ISR** (ec_motion_test_on_counted_done / stop_active_test) and the main-loop poll: must be volatile.\"

→ **该函数由步进端口的 ISR 在「软件计数归零」时调用。**

### 结论：STEP_RESULT=1 能否作为「物理完成」的证据？

**❌ 不能作为充分证据。理由：**

1.  **该值只表示「软件脉冲计数器减到 0，且 ISR 回调已执行」**，是**开环信号**。

2.  如果定时器 PWM 通道根本没有真正输出脉冲（引脚配置错误、CCR=0、定时器未使能等），ISR 仍会按预期频率递减计数器并触发回调。

3.  从用户观测 **「STEP_REMAIN=0 + STEP_RESULT=1 + 物理零位移」** 三者并存，正是这种「软件认为完成、硬件无输出」的典型症状。

**验证方法**：

- **示波器/逻辑分析仪** 接在候选 STEP 引脚（[排查文档 §A.1](vscode-webview://1cr3jtkavdrshksecklc8b60t6iscm166b1d5h7d1vq7l0h8fb7k/index.html?id=2eea0a87-d732-4bef-9ba1-3ded12bde1dc&parentId=1&origin=4a2294cc-7fad-4dfb-9a73-6f73947920a7&swVersion=6&extensionId=Anthropic.claude-code&platform=electron&vscode-resource-base-authority=vscode-resource.vscode-cdn.net&parentOrigin=vscode-file://vscode-app&session=9e148565-4b52-4a29-a528-54e6716e10fc) 推测 PB0/PB1）上，重发命令，看是否有 400 个脉冲。

- 若有脉冲但电机不动 → 驱动器电源/ENABLE/接线问题（排查文档 §C 步骤 1/2/4/6）。

- 若无脉冲 → 固件输出配置问题（见下节 ②）。

### 优先排查顺序（基于成本与现象匹配度）

1.  **A1/A2/A4（硬件层）** → 万用表，零风险，**最符合「板子报完成但不动」现象**

2.  **A3 + B1（引脚层）** → 示波器/LED，需实机运动但安全（400 步=5mm）

3.  **E2（软件映射错误）** → 读 ec_board_stm32.c，纯代码审查

4.  **C2/C3/C5（配置层）** → 读端口层实现

5.  **D1/D3（运行时异常）** → 加日志或断点（需重新烧录）

### 立即可操作的验证（无需改代码/烧录）

**方法 1：示波器/逻辑分析仪验证（决定性）**

- 接在 **PB0**（候选 STEP_X）上

- 重发 MOTION ARM + MOVE X DIR0 STEPS 400 HZ 500

- **预期**：应看到约 400 个脉冲（按更正块实际是梯形曲线 200→2000→200 Hz，时长 0.49558 秒）

- **若无脉冲** → 固件输出配置问题（B/C/E 类）

- **若有脉冲但电机不动** → 硬件问题（A 类）

**方法 2：万用表三项快速排除（零风险）**

1.  量驱动器 VMOT 与 GND：应为驱动器额定电压（24V/48V）

2.  量 PA5(ENABLE_X) 对 GND：使能时应为 LOW（A4988 低有效）

3.  量 MCU GND 与驱动器 GND：应导通（电阻 \<1Ω）

**若以上全合格但仍无脉冲** → 必定是固件配置问题，需读 ec_board_stm32.c 定位。

## 梯队清单（已代入你们冻结引脚：X=STEP/PC6、DIR/PA7、EN/PA5；Y=STEP/PB6、DIR/PC7、EN/PD7；EN 低有效）

**T0 万用表 10 秒级（高概率×低成本，先做）**

1.  **EN 未生效**（A4988 低有效；悬空/线断/接错） ① EN 为高或悬空时输出级全关断、线圈零电流，固件照常报完成。当前工作树固件在发脉冲前会拉低 EN（ec_axis_driver.c:228），所以若驱动板 EN 仍为高，问题在线缆/接错/共地，或台上固件版本不同。 ② 运动命令期间分别量 MCU 的 EN 脚与驱动板 EN 脚（参考各自 GND）。 ③ 两处均 ≤0.8V；MCU 低而板高 → 线断/虚焊/接错；两处都高 → 固件未使能（版本/命令路由）。

2.  **VMOT 缺失或 \<8V** ① 功率级无供电（或低于 8V 超规格）→ 全桥不斩波、零电流。典型翻车：主控板由 USB/调试器供电一切正常，VMOT 独立电源没开/保险断/急停回路断开。 ② 量驱动板 VMOT 对 GND，顺带查电源开关、保险、急停、端子。 ③ 8--35V（典型 12/24V）且运动不掉压；0V=没供上，5V=超规格。

3.  **限流电位器归零（Vref≈0）** ① Vref=0 → 峰值电流=0，驱动器\"在运行\"但线圈无电流（新模块出厂常归零/过低）。 ② 驱动上电，量 VREF 脚（电位器中心抽头）对 GND。 ③ I=Vref/(8·Rs)；Rs=0.1Ω 时 1A↔0.8V，17HS4401 按 1.7A → ≈1.36V（Rs 以你模块实际为准）；≈0V 即命中。

4.  **MCU 与驱动器不共地** ① 两套地参考不一致 → STEP/EN 电平相对驱动逻辑阈值乱飘，信号无效。 ② 万用表直流档量 MCU GND 与驱动 GND；测信号一律以驱动板 GND 为参考。 ③ \<0.3V；\>1V 即异常。

**T1 示波器/复测级**

1.  **STEP 未到达驱动板**（断线/虚焊/接错/排针接触） ① 定时器在 MCU 内跑满、固件报完成，但 STEP 沿断在物理链路（此时保持力矩应正常）。 ② 示波器先测 MCU STEP 脚，再测驱动板 STEP 脚。 ③ MCU 脚 500Hz 方波串（高≈1ms）、数量=80×mm；驱动板脚同形；板脚平线 → 线缆；**MCU 脚本身无脉冲 → 固件层**（GPIO AF 配置/台上固件版本），交固件侧。

2.  **STEP 脉宽过窄/频率超限** ① A4988 要求 STEP 高、低各 ≥1µs：脉宽过窄沿被忽略（完全不动），频率过高丢步失步（通常有声）。 ② 示波器量高/低脉宽与频率；DIR 变化到 STEP 沿 ≥200ns。 ③ 高、低各 ≥1µs。**当前树固件 500Hz/50%（高≈1ms）远大于下限，此原因概率极低**，仅当台上版本不同或改过频率时重点复查。

3.  **nSLEEP/nRESET 被拉低或悬空** ① nSLEEP 低 → 全桥休眠零输出；nRESET 低 → 逻辑复位不工作。模块一般默认上拉，裸片/个别模块需自查。 ② 量两脚对 GND。 ③ ≥2V；≈0V 命中。

4.  **动力电源带载跌落** ① 空载量着够，一斩波被拉垮到 \<8V（欠压），驱动反复关断 → 不动或抖动。 ② 万用表/示波器挂 VMOT，发命令同时观察。 ③ 运动期间始终 ≥8V；塌陷 → 电源功率不足/线太细/端子接触电阻大/大电解电容缺失。

5.  **过流/过热保护锁死（OCP/TSD）** ① 相线短路/错接触发内部 OCP，或持续大电流过热触发 TSD，输出级关断 → 无力矩无声（多数模块无 FAULT 灯，只能靠测量）。 ② 摸芯片温度；串电流表量 VMOT 电流；断电重上电复测同一命令。 ③ 正常斩波：芯片温热、电流数百 mA\~A 级；锁死：电流≈0。重上电恢复但一运动又锁 → 先查电机短路（相间/对壳）。

**T2 拆除/替换级（低概率但覆盖）**

1.  **相线接错/线圈断路** ① 两相交叉错接或某一线圈断路 → 合成磁场失效/力矩极弱：双断完全不动、单断微抖或不动。 ② 断电拔线，电阻档量 1A-1B、2A-2B，再量相间、对机壳。 ③ 同相 1--10Ω 且两相对称（差\<10%）；相间/对壳 OL；断路 → OL。

2.  **微步跳线 MS1/MS2/MS3** ① 只改步距与电流形状，不改变\"是否转动\"------几乎不可能是完全不动的原因（排除项）。你们固定 1/16（三脚全高）。 ② 量 MS1-3 电平对照真值表。 ③ 与目标细分一致即可；不一致只会位移量错误。

3.  **驱动器/模块损坏** ① 输出级烧毁或模块故障，无斩波无电流。 ② 前 11 项全过后换一块已知好模块（同供电/同信号）对比。 ③ 好板命令时有斩波电流/电机转动；坏板没有。换板前先核对接线与限流，避免再烧。

**排除项（看着像、不会导致\"完全不动\"）**：STEP 与 DIR 接反（仍会动，只是方向怪异）；串口/波特率（固件都回完成了）；机械卡死（有电流时会堵转啸叫，本现象无声，但盘轴确认最稳）；微步细分。
