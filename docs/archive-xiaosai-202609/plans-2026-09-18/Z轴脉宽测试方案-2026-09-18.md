## 3. 台架命令（已烧录的固件支持）

```
SERVO ARM              ← 给 10 秒窗口
SERVO PB10 Pxxxx       ← 发脉宽；发完只跑 2 秒自动停
SERVO STOP             ← 主动停
```

**白名单只有 7 档**：`1000 / 1100 / 1200 / 1300 / 1500 / 1700 / 1900`
（**没有 1400 / 1600** → 做不了 100µs 细步进，最小步进是 200µs）

**安全联锁**：`EC_INPUT_ESTOP_FB` 被拉低时**拒绝启动**。

**每一档的做法**：重新 `SERVO ARM` → 发值 → 观察 **2 秒** → **记录 → 等它自己停** → 再发下一档。

### 🔴 第 1 题怎么答（**边测边答**）

看 **1100** 和 **1900** 这两档：

```
1100 时：夹爪是【张开】还是【闭合】？  爪子在【上面】还是【下面】？
1900 时：同上

→ 若 1900 = 闭合 + 上升   → 固件现在的时序【是对的】，收工
→ 若 1900 = 闭合 + 下降   → 固件时序【反了】，必须把 EC_AXIS_Z_UP_US / Z_DOWN_US 对调
```

### 🔴 第 3 题怎么测（**最关键的那个数**）

```
① 先手动把爪子摆到能夹住 40mm 正方体的位置
② 把爪子夹住方块（发"闭合"那一档）
③ 量【货物底面离地】高度 =  A ______ mm
④ 再量【托盘上沿最高点离地】=  B ______ mm

判定：A > B → 货物能过托盘上沿 → 没问题
      A ≤ B → 差 (B − A) mm → 需要开托盘缺口（明天演示方案）或改机械
```

## 5. ⛔ 禁止（任一条违反立即停止）

| 禁止 | 原因 |
|---|---|
| **首发 1000 或 1900** | `1100→1900` 约等于一次甩 72°，会夹手 / 打坏连杆 |
| **连发 / 扫频 / 宏 / 两值连发** | 台架设计上不允许 |
| **在 1100 ↔ 1900 之间来回甩** | 同第一条 |
| **憋死还继续** | 嗡鸣 / 电流 >2.0A / 外壳 >60°C / 齿响抖动 → **先断动力电**（LDX-335MG 是数字舵机，**堵转不会自松**） |
| **带电拔插舵机线** | 会打坏驱动 |
| **用生产 `ITEM_TASK` / `DEMO` / `GROUP` / `BARRIER` 命令测** | 会带动整条链 |
