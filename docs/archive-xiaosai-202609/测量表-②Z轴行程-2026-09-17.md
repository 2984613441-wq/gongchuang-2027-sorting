## 5. ⚠️ 安全红线（逐条读）

| 项 | 说明 |
|---|---|
| **断电手动量** | §1 全程断电。舵机推不动就停手，别硬掰 |
| **上电前四道闸门** | ① 型号已确认 LDX-335MG ② 万用表通断确认信号线在 **PB10** ③ 独立 5–6V ≥3A 且**与 STM32 共地**、禁止从 STM32 取动力电 ④ **急停能真正切断舵机动力**（量 5–6V → 0V） |
| **先拆舵盘空载** | 测方向必须**空载**，否则可能带飞机构 / 撞碎 / 夹手 |
| **X/Y 动力电断开** | 拔 A4988 的 VMOT 或电机线，防止误动 |
| **手不离急停** | 软件 `SERVO STOP` 只停 PWM，**不切动力电** |
| **禁止** | 连发、扫频、宏、两值连发、GROUP/BARRIER/MOTION/DEMO/生产 ITEM_TASK |
| **憋死立即断电** | 嗡鸣 / 电流 >2.0A / 外壳 >60°C / 齿响抖动 → 先断动力电 |
| **L4** | 上电属 L4，**只能用户本人操作**，需逐项授权 |
