# 相机安装方案 — 2026-09-16

> 议题：相机**放中间（正俯视）**还是**放边上（偏置+斜视）**？
> **结论：放中间，光轴对准托盘中心，倾角 0°，不斜视。**
> 本文只做决策，不改任何现有文件；依据不足处一律标 **推断** 或 **未定/需实测**。

## 0. 三条决定（可直接执行）

- **决定 1**｜相机固定在**装置中心正上方**，光轴垂直向下（θ=0°），对准托盘中心。依据：§1 对比表；视差恒为 0（§2）。
- **决定 2**｜倾角**只在"中心正上方装不下相机"时才开**，上限 **15°**，并接受分层标定代价。依据：§2 表 —— 30° 时 40mm 物料视差 23.1mm ≈ 物料自身 58%。
- **决定 3**｜**拍照时机 = 夹爪停在停放位**，停放位不得在光轴正下方。依据：`docs/design/抓取时序-2026-09-15.md:89,96-98`。

## 1. 中间 vs 边上

| 维度 | 中间（正俯视 θ=0°） | 边上（偏置 + 斜视 θ>0） |
|---|---|---|
| 40mm 高物体视差 | **0 mm** | 10.7 / 14.6 / 23.1 / 40.0 mm（15/20/30/45°） |
| 平面映射 | **1 张单应** | **每高度层 1 张单应** |
| 遮挡（≥12 件挤在 160×160 托盘内） | 只有夹爪/龙门，可用停放位规避 | **高件挡矮件**，随机摆放必发生 |
| 标定工作量 | 1 组九点 | 每高度 1 组九点 |
| 训练分布 | **与现有模型一致**（mAP50 0.865，`视觉/training/README-视觉资产来源-2026-09-15.md:82`） | 视角变 = 分布漂移，**需重训**（词表零余量，`docs/冲突与决策台账-2026-09-10.md:488`） |
| 机械包络 | 相机要占 XY 龙门**上方**的高度 | 相机可贴侧壁，省高度 |
| "问题六"（三棱锥/三棱柱投影同） | 分不开 | **可能**分开，但需 ≥30° 才明显 —— 与视差冲突 |
| 对托盘位置的要求 | (0,0) | "放边角" |

**推荐：中间 + 0°。** 三条理由：

1. **偏差 = 零分**。放错盒不得分（`docs/references/赛题原文-提取文本/省赛规则.txt:262-266`）；形状错还会让屏幕货物名称错 →"出现任何错误不得分"（`同:271`）。0° 下单应覆盖全域，斜视每加 1° 都是链条上一个新的未标定偏移源。
2. **"夹爪挡镜头"不是相机位置的锅**。遮挡源是"夹爪要进到托盘上方"，**斜视同样挡**；解法已定 = 拍照时夹爪停停放位（`抓取时序:66`），与倾角无关。
3. **斜视要重训，而现在不能重训**。现行数据集 638 图（`视觉/training/README-视觉资产来源-2026-09-15.md:61`），且 `cuboid` 已排除、active 只剩 6 类 = 赛题下限（`台账:488`）。改视角 = mAP50 0.865 作废。

> ⚠️ **诚实的例外**：若机械上中心正上方装不下相机（龙门占位/线缆干涉），只能偏置+斜视 —— 按 §2 取最小可行倾角，代价一并接受。**"放边上"常是空间所迫，不是光学更优。** 机械组先回答：中心正上方有没有净空？

## 2. 倾角量化：视差表

公式 **横向视差 ≈ h·tanθ**，物料 h ≤ 40mm（`省赛规则.txt:53`）。像素列按 **视场 ≈200mm 见方 / 448px → 2.24 px/mm**（推断；视场收到 176mm 则 ×1.14）。

| θ | tanθ | 视差 @h=40mm | 占托盘 160mm | 像素 | 占物料自身(40mm) | 纵向分辨率损失 1/cosθ |
|---|---|---|---|---|---|---|
| **0°** | 0.000 | **0.0 mm** | 0 % | 0 px | 0 % | 1.00 |
| 15° | 0.268 | **10.7 mm** | 6.7 % | 24 px | 27 % | 1.04 |
| 20° | 0.364 | **14.6 mm** | 9.1 % | 33 px | 37 % | 1.06 |
| 30° | 0.577 | **23.1 mm** | 14.4 % | 52 px | 58 % | 1.15 |
| 45° | 1.000 | **40.0 mm** | 25.0 % | 90 px | **100 %** | 1.41 |

**判据（推断阈值）**：视差应 ≤ 物料尺寸的 1/4（≤10mm）→ **θ ≤ 15°**。45° 时偏移等于一整个物料；30° 时相当于多半个物料，夹爪闭到位时物料已在爪口边缘。
**由包络反推可达倾角**：包络 ≤350×350×450mm（`省赛规则.txt:40-41`）→ 相机水平偏心 L ≤ 约 175mm；若相机距托盘平面 d=300mm，则 θ ≤ atan(175/300) ≈ **30°**（推断）。**"选倾角"等价于"选偏心量"**（tanθ = L/d）。

> ⚠️ **0° 消除了倾斜视差，但没有消除透视视差**。相机在托盘中心正上方 d 处，离光轴 x 的物体顶面(h) 被单应映射到 x·d/(d−h)，误差 ≈ **x·h/(d−h)**：d=400 / h=40 / x=80mm → ≈ **8.9mm**（推断，d 需实测）。它与倾斜无关，必须靠 §5 的标定面或解析修正消化。

## 3. 斜视能不能解决"三棱锥 vs 三棱柱投影相同"（问题六）

**判断：理论上能，但不是当前问题的解法，先别为它改机构。**

1. 🔴 **词表里可能根本没有"三棱锥"**。7 类是 `cube/cuboid/cylinder/hexagonal_prism/pentagonal_prism/square_pyramid/triangular_prism`（`视觉/training/README-视觉资产来源-2026-09-15.md:45`）；`square_pyramid` 是**四棱锥**。台账已把"正四面体"映射到它并**留了分歧声明**（正四面体 4 个全等三角形面 ≠ 四棱锥方形底，`台账:74`）。→ **若实物是正四面体，模型没有这一类，斜视 0 收益。**
2. 斜视要产生**可分的顶面透视**需要足够大的倾角，而那就是 §2 里被否决的那些值 —— 两者方向相反，这是本议题的核心张力。
3. 现行模型训自**某一固定视角**的 638 图（`README-视觉资产:61`），视角一变即分布漂移。

**低成本验证实验（不动机械、不重训，约 1.5h）**

- **第 0 步（0 成本，先做）**：**目视实物底面**。正方形底 = 四棱锥（有类）；三角形底 = 正四面体（**无类**）。做法见 `台账:74`。**这步不通过，下面不用拍。**
- **第 1 步（需授权：涉相机上电，红线见 `docs/prompts/协作-2026-09-15/00-总览与交接规则.md:61-64`）**：器材 = 现有 MaixCAM + 量角器支架 + 两类实物 ≥2 件；**3 倾角 {0°,15°,30°} × 2 位置（中心 / 对角 (±50,±50)）× 10 张 = 60 张**，另加 **15 张两类并排同框**（每角度 5 张）测遮挡与 NMS 合并，**共 75 张**；每 3~4 张换一次朝向；安装高度 d 与最终一致（d 未定则先固定并记录）。
- **判据（全满足才算"斜视有效"）**：① 可分性 —— 30° 组两类互误 ≤ 2/20；② 不劣化 —— 0° 组正确率 ≥ 现有基线（先做 0° 当对照）；③ 不合并 —— 并排同框 NMS 后两类**各出一个框**；④ 阈值 —— conf ≥ 0.5（`docs/参数冻结表-2026-09-15.md:15`）的帧占比 ≥ 80%。
- **产出**：`视觉/training/camera-tilt-probe-<日期>/`，图名 `{角度}_{位置}_{类}_{序号}.jpg`，结果写 `RESULT.md`。**本方案不预判结果。**

## 4. 与方案 A / B 的关系：可分开定，但有两条硬耦合

不必等机构选型就能定相机方案 —— 因为**机构选型也被同一组冻结参数锁定了**。

| 耦合 | 内容 | 依据 |
|---|---|---|
| **硬耦合 1** | **光轴必须对准托盘中心**；托盘在哪，相机就对准哪 | `抓取时序:62`（相机固定、不随 XY 移动） |
| **硬耦合 2** | **托盘中心最多偏离原点约 22mm** | 可达 ±82.5mm（`docs/参数冻结表-2026-09-15.md:13`）+ 物料 ≤40mm（`省赛规则.txt:53`）→ 物料中心最远 80−20=60mm；60+22.5>82.5 即超界。**推断，需实机复核** |

- **方案 A（六盒）**：托盘居中 (0,0) 与 `参数冻结表:22` 一致 ✓ → **相机对准装置中心、0°**。
- **方案 B（转盘）**：用户方案是"**托盘放到边边角角**"（`docs/design/方案B-转盘选格-2026-09-15.md:13`），但与 ±82.5mm 可达域**直接冲突**（托盘挪 50mm → 远侧物料中心到 110mm ≫ 82.5mm）→ **"挪托盘腾视野"这个前提不成立**。若坚持转盘，只能"托盘仍居中 + 转盘放别处"，此时**相机结论与方案 A 完全相同**。

## 5. 标定：九点够不够？要不要按高度分层？

**九点（3×3）够用**（它拟合的就是单应），但必须满足三个前提：

| # | 前提 | 不满足会怎样 |
|---|---|---|
| 1 | 标定点覆盖**托盘全域含四角** | 边缘外插误差放大 |
| 2 | **标定平面高度 = 判决平面高度** | 引入 §2 的 `x·h/(d−h)` 误差（d=400mm 时边缘 ≈9mm） |
| 3 | 标定点用**夹爪实测坐标**，不是目视 | 标出来的是"目视坐标"，系统性偏 |

**要不要分层？** 按成本排序三选一：

| 处置 | 做法 | 校赛 | 省赛换物料 |
|---|---|---|---|
| **① 抬标定面** ⭐ | 九点标定板垫到**物料高度 h**（= 用实物标定） | ✅ **即现行裁决**（`抓取时序:197-222`） | ✅ 首选 |
| **② 解析修正** | `x_true = x_meas·(d−h)/d`，一行代码 | ✅ 可选（需实测 d） | ✅ 首选 |
| **③ 分层标定** | h = 0/20/40mm 各做一组九点 | ❌ 不必 | ⚠️ 仅当 ①② 都做不到 |

> **为什么 0° 下不必分层**：①② 都能把误差吃到 0，分层要多标 2 组、多 2 个出错点。**这也是 §2"倾斜代价"的量化说法**：θ>0 时误差方向随 θ 方位角变化，标定从"1 个标量修正"恶化成"每高度 1 张 3×3 单应"，①② 失效，只剩 ③。

**加做**：13 点（九点+四角）成本几乎为零，建议做，用于复核。**验收判据**：托盘内任取 4 点残差 ≤ **3mm**（推断阈值）—— ⚠️ 该阈值取决于**夹爪张开尺寸/最小夹持厚度**，两者至今空白（`参数冻结表:163`），**测出来后才能定死**。
