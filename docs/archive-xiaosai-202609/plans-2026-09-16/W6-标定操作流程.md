## 0️⃣ 前提条件检查

- [ ] 相机已安装（装置中心正上方，0° 倾角，光轴垂直向下）
- [ ] MaixCAM 能正常运行（可通过 TCP 9001 端口接收检测结果）
- [ ] 树莓派与 MaixCAM 网络连通
- [ ] STM32 固件已烧录（能响应 ITEM_TASK 命令）
- [ ] 准备工具：卷尺/游标卡尺（精度 ±0.5mm）、记录表格、A4 纸

## 1️⃣ 测量相机高度

### 操作步骤

1. 用卷尺测量 **相机镜头中心** 到 **托盘台面** 的垂直距离
2. 记录测量值（单位 mm，精度 ±5mm 可接受）
3. 填入 `电控/calibration_config.ini` 的 `camera_height` 字段

### 示例

```
测量值：398mm
→ 填入配置：camera_height = 398.0
```

---

## 2️⃣ 测量物体高度

### 操作步骤

1. 用游标卡尺测量每类物体的高度（从底面到顶面）
2. 记录每个 class_id 对应的高度（单位 mm）
3. 填入 `电控/calibration_config.ini` 的 `[ObjectHeights]` 节

### 示例

```
class_id 1（螺母）：高度 34.8mm
class_id 2（螺栓）：高度 19.5mm
class_id 3（垫片）：高度 11.2mm
...

→ 填入配置：
[ObjectHeights]
1 = 34.8
2 = 19.5
3 = 11.2
```

## 3️⃣ 九点标定（推荐方案：靶标法）

### 器材清单

| 器材 | 用途 | 备注 |
|------|------|------|
| A4 纸 | 打印标定靶标 | 黑白棋盘格（7×7 格子，每格 20mm） |
| 卷尺 | 测量靶标实际尺寸 | 打印可能有 ±1mm 误差 |
| 记录表格 | 记录 (u,v) ↔ (x,y) 对应 | Excel 或纸质表格 |
| 小磁铁/胶带 | 固定靶标 | 避免靶标移动 |

### 标定步骤

#### 步骤 1：制作靶标

1. 打印黑白棋盘格（7×7 格子，每格 20mm）或圆点阵（3×3，直径 10mm）
2. 用卷尺测量实际尺寸（打印可能有误差）
3. 记录每个角点的物理间距

#### 步骤 2：标定中心点

1. 将靶标放在托盘中心（对准装置坐标 (0,0) 位置）
2. 用磁铁或胶带固定
3. 启动 MaixCAM 实时预览（通过 TCP 9001 端口或串口日志）
4. 读取靶标中心角点的像素坐标 (u,v)
5. 记录：像素 (u,v) ↔ 装置坐标 (0, 0)

#### 步骤 3：标定四角点

移动靶标到工作区四角，重复步骤 2：

| 位置 | 装置坐标 (mm) | 操作 |
|------|---------------|------|
| 左上角 | (-80, +80) | 放靶标，读像素 (u₁,v₁) |
| 右上角 | (+80, +80) | 放靶标，读像素 (u₂,v₂) |
| 左下角 | (-80, -80) | 放靶标，读像素 (u₃,v₃) |
| 右下角 | (+80, -80) | 放靶标，读像素 (u₄,v₄) |

⚠️ 注意：不要超出工作区边界（±82.5mm）

#### 步骤 4：标定中点（可选，增加鲁棒性）

| 位置 | 装置坐标 (mm) | 操作 |
|------|---------------|------|
| 上中 | (0, +80) | 放靶标，读像素 (u₅,v₅) |
| 下中 | (0, -80) | 放靶标，读像素 (u₆,v₆) |
| 左中 | (-80, 0) | 放靶标，读像素 (u₇,v₇) |
| 右中 | (+80, 0) | 放靶标，读像素 (u₈,v₈) |

最终得到 **9 对点**：(u₀,v₀)↔(0,0), (u₁,v₁)↔(-80,80), ..., (u₈,v₈)↔(80,0)

## 4️⃣ 计算仿射矩阵参数

### 方法 1：Python 脚本（推荐）

创建临时脚本 `calc_affine.py`：

```python
import numpy as np

# 填入标定记录的 9 对点（像素 → mm）
# 格式：[(u, v, x_mm, y_mm), ...]
points = [
    (320, 240,    0,    0),  # 中心
    (100, 100,  -80,  +80),  # 左上
    (540, 100,  +80,  +80),  # 右上
    (100, 380,  -80,  -80),  # 左下
    (540, 380,  +80,  -80),  # 右下
    (320, 100,    0,  +80),  # 上中
    (320, 380,    0,  -80),  # 下中
    (100, 240,  -80,    0),  # 左中
    (540, 240,  +80,    0),  # 右中
]

# 构造最小二乘矩阵
# x = a11*u + a12*v + tx
# y = a21*u + a22*v + ty
A = []
b_x = []
b_y = []
for u, v, x_mm, y_mm in points:
    A.append([u, v, 1])
    b_x.append(x_mm)
    b_y.append(y_mm)

A = np.array(A)
b_x = np.array(b_x)
b_y = np.array(b_y)

# 最小二乘求解
params_x = np.linalg.lstsq(A, b_x, rcond=None)[0]
params_y = np.linalg.lstsq(A, b_y, rcond=None)[0]

a11, a12, tx = params_x
a21, a22, ty = params_y

print(f"[CameraCalibration]")
print(f"a11 = {a11:.6f}")
print(f"a12 = {a12:.6f}")
print(f"tx = {tx:.2f}")
print(f"a21 = {a21:.6f}")
print(f"a22 = {a22:.6f}")
print(f"ty = {ty:.2f}")
```

运行：`python calc_affine.py`  
将输出的 6 个参数填入 `电控/calibration_config.ini`

### 方法 2：在线工具

使用在线矩阵计算器（如 Wolfram Alpha、MATLAB Online）求解线性方程组。

## 5️⃣ 验证标定结果

### 步骤 1：自检测试


预期输出：
```

标定配置已加载: camera_height=398.0mm, 物体高度 5 类, ...
```

### 步骤 2：九宫格反向验证

1. 用夹爪探针法：让夹爪依次走到 9 个已知点（如上面的 9 个标定点）
2. MaixCAM 检测夹爪位置，读取像素坐标 (u,v)
3. 用 `pixel_to_device.py` 反算装置坐标 (x,y)
4. 对比反算坐标与目标坐标，计算误差

### 验收标准

| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| RMS 误差 | ≤ 2mm | √(Σ(Δx² + Δy²)/N) |
| 单点最大误差 | ≤ 5mm | 9 个点中最大偏差 |
| 抓取成功率 | ≥ 95% | 50 次实物抓取，夹爪到达目标 ±5mm 内 |

### 步骤 3：记录验证结果

在 `电控/calibration_config.ini` 末尾添加：

```ini

rms_error = 1.8  # mm
max_error = 4.2  # mm
calibration_points = 9
calibration_date = 2026-09-17
```

## 6️⃣ 故障排查

### 问题 1：像素坐标读不到

**症状**：MaixCAM 没有输出检测框中心坐标

**排查**：
1. 检查 MaixCAM TCP 9001 端口是否开启
2. 检查网络连通性：`ping <MaixCAM IP>`
3. 检查 MaixCAM 是否正常推理（FPS > 0）
4. 用工具/monitor_gui.py 查看实时检测结果

### 问题 2：标定后抓取偏移很大（>10mm）

**可能原因**：
1. 相机高度测量错误（视差补偿失效）
2. 物体高度测量错误
3. 靶标摆放时移位（标定点记录错误）
4. 像素坐标与装置坐标对应关系弄反

**排查**：
1. 重新测量相机高度和物体高度
2. 用九宫格反向验证找出误差最大的点
3. 检查标定记录表：像素 (u,v) 是否对应正确的装置坐标 (x,y)

### 问题 3：边缘物体被拒识

**症状**：工作区边缘的物体返回 None

**排查**：
1. 检查 `WorkspaceLimits` 是否太小（应为 ±82.5mm）
2. 检查边缘物体的视差补偿是否过大（高度太高）
3. 用 pixel_to_device.py 单独测试边缘点坐标

## 7️⃣ 附录：备选方案（夹爪探针法）

### 适用场景
- 无法打印靶标
- 需要自动化标定（减少人工操作）

### 操作步骤

1. 定义 9 个目标点（装置坐标，单位 0.1mm）
2. 通过树莓派发送 ITEM_TASK 命令，让夹爪走到每个点
3. 夹爪到位后，MaixCAM 检测夹爪顶部（涂红色标记便于识别）
4. 读取像素坐标 (u,v)，记录对应关系
5. 按第 4 节计算仿射矩阵

### 注意事项
- 夹爪停在 (0,0) 会挡镜头 → 先标定四角和中点，最后标定中心
- 夹爪尺寸较大，像素定位精度低 → 建议夹持细棒作探针
- STM32 步进电机丢步会累积误差 → 每次移动后读取实际位置（若固件支持）
