## 1️⃣ 误差预算表

| 误差源 | 预估误差 | 占比 | 计算依据 | 缓解措施 |
|--------|---------|------|---------|---------|
| **相机分辨率** | ±0.26mm | 10% | MaixCAM 640×480，工作区 165mm<br>→ 165/640 ≈ 0.26mm/pixel | 提高分辨率或缩小工作区（硬件限制） |
| **标定操作误差** | ±1.5mm | 35% | 人工摆放靶标、读取像素坐标的累积误差<br>包括：靶标打印误差（±0.5mm）、摆放对齐（±0.8mm）、像素读取（±0.2mm） | 用激光打印、靶标夹具固定、多次标定取平均 |
| **视差残差** | ±1.0mm | 20% | 物体高度测量误差（±2mm）<br>相机高度测量误差（±5mm）<br>d=400mm, h=40mm → Δh=2mm 导致 Δx≈1mm | 精确测量物体高度（游标卡尺）<br>精确测量相机高度（激光测距仪） |
| **XY 丢步** | ±0.5mm | 10% | 步进电机 16 微步，单步 0.0103mm<br>累积 50 步 ≈ 0.5mm | 减速运动、增加限位开关复位频率 |
| **夹爪机械误差** | ±1.0mm | 15% | 夹爪宽度、对齐精度、磨损 | 定期校准夹爪、检查磨损 |
| **其他（振动/台面倾斜）** | ±0.5mm | 10% | 设备振动、台面不平、温度形变 | 设备固定、台面水平校准 |
| **总预算（RSS）** | **±2.2mm** | 100% | √(0.26² + 1.5² + 1² + 0.5² + 1² + 0.5²) ≈ 2.2mm | — |

### RSS（Root Sum Square）计算

```
总误差 = √(Σ 各项误差²)
       = √(0.26² + 1.5² + 1.0² + 0.5² + 1.0² + 0.5²)
       = √(0.07 + 2.25 + 1.0 + 0.25 + 1.0 + 0.25)
       = √4.82
       ≈ 2.2mm
```

### 结论

- **理论误差 ≤ 2.5mm**，符合赛事要求（螺母直径 ≥ 10mm，±5mm 容差可接受）
- **最大误差源：标定操作误差（35%）** → 改进标定流程可显著提升精度
- **视差残差（20%）**可通过精确测量相机高度和物体高度降低

## 2️⃣ 验证方案

### 方案 A：九宫格反向验证（推荐）

#### 目标
验证仿射变换的全局精度，覆盖整个工作区。

#### 步骤

1. **定义 9 个验证点**（装置坐标，单位 mm）

   | 点序号 | 装置坐标 (x,y) | 位置描述 |
   |--------|---------------|---------|
   | 1 | (0, 0) | 中心 |
   | 2 | (-60, +60) | 左上（距边界 22.5mm） |
   | 3 | (+60, +60) | 右上 |
   | 4 | (-60, -60) | 左下 |
   | 5 | (+60, -60) | 右下 |
   | 6 | (0, +60) | 上中 |
   | 7 | (0, -60) | 下中 |
   | 8 | (-60, 0) | 左中 |
   | 9 | (+60, 0) | 右中 |

   ⚠️ 避开边界（±82.5mm）以防 XY 轴到位误差

2. **让夹爪走到每个点**
   
   使用树莓派发送 ITEM_TASK 命令：
   ```python
   for i, (x_mm, y_mm) in enumerate(validation_points):
       x_mm10 = int(x_mm * 10)
       y_mm10 = int(y_mm * 10)
       send_item_task(target_seq=i, x=x_mm10, y=y_mm10, ...)
       wait_motion_done()
       # 读取 MaixCAM 检测的夹爪像素坐标 (u, v)
       pixel_coords[i] = read_gripper_center()
   ```

3. **反算装置坐标**
   
   ```python
   from electrical_control.rpi.pixel_to_device import PixelToDeviceConverter
   
   converter = PixelToDeviceConverter()
   errors = []
   
   for i, (u, v) in enumerate(pixel_coords):
       # 反算（假设夹爪 class_id=99，h=0）
       result = converter.pixel_to_device(u, v, class_id=99)
       if result is None:
           print(f"点 {i} 超出工作区（不应发生）")
           continue
       
       x_calc, y_calc = result  # 单位 0.1mm
       x_calc_mm = x_calc / 10.0
       y_calc_mm = y_calc / 10.0
       
       x_target, y_target = validation_points[i]
       
       dx = x_calc_mm - x_target
       dy = y_calc_mm - y_target
       error = np.sqrt(dx**2 + dy**2)
       errors.append(error)
       
       print(f"点 {i}: 目标({x_target},{y_target}) "
             f"反算({x_calc_mm:.2f},{y_calc_mm:.2f}) "
             f"误差 {error:.2f}mm")
   ```

4. **计算 RMS 误差**
   
   ```python
   rms_error = np.sqrt(np.mean(np.array(errors)**2))
   max_error = np.max(errors)
   
   print(f"\nRMS 误差: {rms_error:.2f}mm")
   print(f"最大误差: {max_error:.2f}mm")
   ```

#### 验收标准

| 指标 | 目标值 | 判定 |
|------|--------|------|
| RMS 误差 | ≤ 2.0mm | 通过：可用于比赛<br>2-3mm：可用但需优化<br>>3mm：需重新标定 |
| 最大误差 | ≤ 5.0mm | 通过：符合赛题容差<br>>5mm：该点需重点检查 |
| 通过点数 | ≥ 8/9 | 允许 1 个点误差偏大（可能是边界效应） |

### 方案 B：实物抓取验证

#### 目标
验证完整链路（视觉检测 → 坐标转换 → 运动控制 → 抓取）的端到端精度。

#### 步骤

1. **准备测试样本**
   - 5 类物体各 10 个，共 50 个
   - 随机摆放在托盘上（覆盖工作区）

2. **记录每个物体的真实位置**
   - 用卷尺测量物体中心到装置中心的距离
   - 记录 (x_real, y_real)

3. **运行完整抓取流程**
   ```python
   success_count = 0
   for i in range(50):
       # 视觉检测 → 坐标转换 → 发送 ITEM_TASK
       result = run_single_pick()
       
       if result == "SUCCESS":
           # 判断：夹爪是否到达目标 ±5mm 内
           if gripper_position_within_5mm(x_real[i], y_real[i]):
               success_count += 1
   
   success_rate = success_count / 50 * 100
   print(f"抓取成功率: {success_rate}%")
   ```

#### 验收标准

| 指标 | 目标值 | 判定 |
|------|--------|------|
| 抓取成功率 | ≥ 95% | 通过：可用于比赛<br>90-95%：可用但需优化<br><90%：需重新标定或检查硬件 |

### 方案 C：视差补偿验证

#### 目标
验证高度视差补偿是否正确。

#### 步骤

1. **准备不同高度的物体**
   - 低物体（h=20mm，如螺栓）
   - 高物体（h=40mm，如齿轮）

2. **固定物体在同一位置**
   - 用胶带固定在 (x=80mm, y=0)

3. **分别检测并抓取**
   ```python
   # 低物体（h=20mm）
   u1, v1 = detect_object(class_id=2)  # h=20mm
   x1, y1 = converter.pixel_to_device(u1, v1, class_id=2)
   
   # 高物体（h=40mm）
   u2, v2 = detect_object(class_id=4)  # h=40mm
   x2, y2 = converter.pixel_to_device(u2, v2, class_id=4)
   
   # 理论视差差异
   # scale_low = 400/(400-20) = 1.053
   # scale_high = 400/(400-40) = 1.111
   # Δscale = 1.111 - 1.053 = 0.058
   # Δx = 80 * 0.058 ≈ 4.6mm
   
   dx = abs(x2 - x1) / 10.0  # 转 mm
   print(f"视差差异: {dx:.2f}mm (理论 ≈4.6mm)")
   ```

4. **验收标准**
   - 视差差异应在理论值 ±30% 内
   - 高物体的坐标应大于低物体（视差补偿方向正确）

#!/usr/bin/env python3
"""相机标定快速验证脚本

用法：
    python validate_calibration.py --mode grid     # 九宫格验证

    python validate_calibration.py --mode parallax # 视差验证
"""

# 添加 src 到路径

    """九宫格反向验证"""
    print("=" * 60)

    validation_points = [
        (0, 0),       # 中心
        (-60, 60),    # 左上
        (60, 60),     # 右上
        (-60, -60),   # 左下
        (60, -60),    # 右下
        (0, 60),      # 上中
        (0, -60),     # 下中
        (-60, 0),     # 左中
        (60, 0),      # 右中
    ]
    
    print("\n⚠️  需要手动操作：")
    print("   1. 让夹爪依次走到 9 个验证点")
    print("   2. 记录 MaixCAM 检测的夹爪像素坐标")
    print("   3. 填入下面的 pixel_coords 列表")
    print()
    
    # 示例数据（需替换为实测值）
    pixel_coords = [
        # (u, v) 对应上面 9 个点
        # TODO: 填入实测像素坐标
    ]
    
    if not pixel_coords:
        print("⏸️  等待实测数据...")
        return None
    
    errors = []
    for i, (u, v) in enumerate(pixel_coords):
        result = converter.pixel_to_device(u, v, class_id=99)
        if result is None:
            print(f"点 {i}: 超出工作区（异常）")
            continue
        
        x_calc_mm = result[0] / 10.0
        y_calc_mm = result[1] / 10.0
        x_target, y_target = validation_points[i]
        
        dx = x_calc_mm - x_target
        dy = y_calc_mm - y_target
        error = np.sqrt(dx**2 + dy**2)
        errors.append(error)
        
        status = "✓" if error <= 5.0 else "✗"
        print(f"{status} 点{i}: 目标({x_target:6.1f},{y_target:6.1f}) "
              f"反算({x_calc_mm:6.2f},{y_calc_mm:6.2f}) "
              f"误差 {error:5.2f}mm")
    
    if errors:
        rms_error = np.sqrt(np.mean(np.array(errors)**2))
        max_error = np.max(errors)
        
        print("\n" + "=" * 60)
        print(f"RMS 误差: {rms_error:.2f}mm (目标 ≤2.0mm)")
        print(f"最大误差: {max_error:.2f}mm (目标 ≤5.0mm)")
        
        if rms_error <= 2.0 and max_error <= 5.0:
            print("✅ 通过：可用于比赛")
            return True
        elif rms_error <= 3.0:
            print("⚠️  可用但需优化")
            return True
        else:
            print("❌ 需重新标定")
            return False
    
    return None


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--mode", choices=["grid", "pick", "parallax"],
                        default="grid", help="验证模式")
    args = parser.parse_args()
    
    if args.mode == "grid":
        validate_grid()
    else:
        print(f"⏸️  {args.mode} 模式待实现")
