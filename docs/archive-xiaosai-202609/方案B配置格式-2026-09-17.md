# 方案B 配置格式与切换说明

> **日期**：2026-09-17

> **目的**：让用户通过修改 `sorting_config.ini` 在方案A/B 间切换，无需改代码

## 1. 配置格式

### 方案A（六固定盒）— 当前方案

```ini
# sorting_config.ini（方案A）
[DropPoints]
# box_id = x_mm, y_mm（单位：mm；程序自动换算为 0.1mm）
1 = 10.5, 20.3
2 = 30.0, 40.0
3 = 50.0, 60.0
4 = 70.0, 80.0
5 = 90.0, 100.0
6 = 110.0, 120.0

[BoxMap]
# (color_id, shape_id) = box_id
0, 2 = 1
0, 3 = 2
1, 2 = 3
1, 3 = 4
2, 2 = 5
2, 3 = 6
```

### 方案B（转盘选格）— 校赛目标

```ini
# sorting_config.ini（方案B）
[TurntableAngles]
# 固定落料点（所有货格用同一点，转盘对准货格）
# ⚠️ 坐标待现场确定（用户说"在角落，具体哪个角到时候告诉你"）
# 单位：mm；程序自动换算为 0.1mm
turntable_drop_point = 0, 0

# box_id = angle_degrees（0° = 货格1零位，顺时针）
1 = 0
2 = 60
3 = 120
4 = 180
5 = 240
6 = 300

[BoxMap]
# 对应表不变（视觉侧仍按 class_id → box_id）
0, 2 = 1
0, 3 = 2
1, 2 = 3
1, 3 = 4
2, 2 = 5
2, 3 = 6
```

---

## 2. 方案判定逻辑

程序自动识别方案：

| 条件 | 判定结果 |
|------|---------|
| 存在 `[TurntableAngles]` 节 | **方案B**（TurntableStrategy） |
| 不存在 `[TurntableAngles]`，只有 `[DropPoints]` | **方案A**（FixedBoxStrategy） |

**fail-closed 保护**：
- 方案A：`[DropPoints]` 缺货格 1-6 任一项 → 程序拒绝启动
- 方案B：`[TurntableAngles]` 缺货格或 `turntable_drop_point` 无效 → 拒绝启动

---

## 3. 切换步骤（用户操作）

### A → B（当前 → 校赛）

1. 用 `工具/control_panel.py` 打开 `sorting_config.ini`
2. **删除或注释掉** `[DropPoints]` 整个节
3. **启用** `[TurntableAngles]` 节（取消注释）
4. **填入现场实测的落料点坐标**（`turntable_drop_point = x_mm, y_mm`）
5. 保存并重启 `run_chain.py`

### B → A（校赛 → 当前）

1. 用 `工具/control_panel.py` 打开 `sorting_config.ini`
2. **删除或注释掉** `[TurntableAngles]` 整个节
3. **启用** `[DropPoints]` 节（取消注释）
4. 保存并重启 `run_chain.py`

## 4. control_panel.py 修改清单（仅说明，不改代码）

**当前面板只识别 4 个节**：
- `[DropPoints]`
- `[BoxMap]`
- `[Display]`
- `[Motion]`

**方案B 需新增**：
- `[TurntableAngles]` 节（含 `turntable_drop_point` + 6 个 `box_id = angle`）

**面板改动量**：
- 新增 1 个 Tab 页（"转盘角度"）
- 新增 7 个输入框（1 个坐标 + 6 个角度）
- 约 **80-120 行**（含布局 + 读写逻辑）

**不在本任务范围**（用户说"面板只写4个节，新节要进面板只写需改什么、多少行"）。

## 5. 示例完整配置文件

```ini
# sorting_config.ini（完整示例）

# ========== 方案A：六固定盒 ==========
# 若启用方案A，启用下面的 [DropPoints]，删除或注释 [TurntableAngles]
[DropPoints]
# box_id = x_mm, y_mm（单位：mm）
1 = 10.5, 20.3
2 = 30.0, 40.0
3 = 50.0, 60.0
4 = 70.0, 80.0
5 = 90.0, 100.0
6 = 110.0, 120.0

# ========== 方案B：转盘选格 ==========
# 若启用方案B，删除或注释 [DropPoints]，启用下面的 [TurntableAngles]
# [TurntableAngles]
# # 固定落料点（所有货格用同一点，转盘对准货格）
# turntable_drop_point = 0, 0
# # box_id = angle_degrees（0° = 货格1零位，顺时针）
# 1 = 0
# 2 = 60
# 3 = 120
# 4 = 180
# 5 = 240
# 6 = 300

# ========== 对应表（方案A/B 共用）==========
[BoxMap]
# (color_id, shape_id) = box_id
0, 2 = 1
0, 3 = 2
1, 2 = 3
1, 3 = 4
2, 2 = 5
2, 3 = 6

# ========== 显示配置 ==========
[Display]
screen_width = 1024
screen_height = 600

# ========== 运动配置 ==========
[Motion]
x_steps_per_mm = 80
y_steps_per_mm = 80
```
