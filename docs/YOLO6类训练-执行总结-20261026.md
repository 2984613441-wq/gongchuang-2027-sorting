## 三、关键阻塞

### 🔴 阻塞1：圆锥数据缺失

**现状**：
- 圆锥(class_id=4)当前**0个实例**
- 需要**150-200个标注实例**才能训练

**影响**：
- ❌ 无法开始6类模型训练
- ❌ 后续模型转换、部署全部阻塞

**解除条件**：
1. 机械组提供圆锥实物（5色）
2. 在白托盘上拍摄150-200张照片
3. 标注完成（class_id=4）
4. 整合到`_dataset_yolo_6c/`

**应对方案**：
- **Plan A**：紧急采集（推荐，2-3天）
- **Plan B**：降级为5类YOLO + 纯几何修正（圆锥/圆柱用尖锐度判定）
- **Plan C**：数据增强（如果实物只有1-2个）

### 🟡 风险2：域偏移

**现状**：
- 现有数据：木桌 + 粉色LED + 3/4侧视
- 实际环境：白托盘 + 顶视 + 扁平片

**影响**：
- ⚠️ 训练模型在现场准确率可能<80%

**应对**：
- 圆锥采集时**必须用白托盘**
- 其余5类补充白托盘数据（每类每色20-30张）
- 如果准确率不达标，现场快速fine-tune
