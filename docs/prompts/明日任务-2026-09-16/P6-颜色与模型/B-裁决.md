## 2. 要裁的第二件：**模型族与 `.mud`**

### 前提

- 3 个 `.onnx`（10.4MB / 36.6MB / 36.6MB），`main.py` 用 **`nn.YOLOv8`**
- **工作区 0 个 `.mud`**；但 `Downloads` 里有 `maixhub-model-convert` 包：
  **`model_8766.mud` + `model_8766.cvimodel`（存在！）**、`model_8622.*`、`model_8629.*`
- 🔴 **已实测（2026-09-15）：`model_8766.mud` 在 MaixCAM 上加载成功** ——
  `type=yolov8` / `input 448x448` / `labels num=7`
  → **与 `main.py:375` 的 `nn.YOLOv8` 匹配**。
  **`8622` / `8629` 的 `model_type=yolo11` → 不能用**（8629 来自 YOLO11n 训练线）

### 你要裁的

1. **MaixCAM 到底该加载什么产物？**（`.mud` + `.cvimodel`？还是 `.onnx` 直接上？）
   —— 依据 MaixPy 官方文档，**给链接**
2. **`nn.YOLOv8` 与 `yolo5s_*` 的 onnx 能不能配？**
   —— 对方会给 onnx 元数据，你**独立判断**
3. **8622 / 8629 该用哪个？8766 呢？**
4. **`model_path` 的正确值**是什么（含设备上的目标路径）
