# 给机械组：托盘上沿会不会挡住夹爪？（2026-09-17）

> 这份是给**机械组（人）**的任务单。**断电做，半小时能测完。**
> 背景：电控已经查清，这个问题的答案**完全押在两个数上**，量出来就能定案。

---

## 0. 一句话问题

**夹住货物之后，爪子能不能抬得足够高，让货物越过托盘的上沿？**

能 → 没问题，电控这边时序已经是对的，收工。
不能 → 下面有 3 个**不用重做零件**的最小改法。

---

## 1. 为什么会撞（先看懂这张图）

```
      ┌──── 夹爪 ────┐        ← 爪口夹在"货物上半部"，高度 ≈ 货物顶面
      │   货物        │
      │              │        ← 货物底面 = 托盘面高度
  ────┴──────────────┴────    ← 托盘上沿（比盘面高 ≥10mm，赛规要求）
      ░░░░ 托盘面 ░░░░
```

**关键**：夹爪是从上往下夹住货物的。所以
- **爪口**在货物**顶面**高度
- **货物底面**在托盘**盘面**高度

而赛规强制「托盘边缘高度不小于 10mm」（防货物滑落）。所以**只要夹着货平移，货物底面天生就比上沿低 10mm 以上**。

👉 **唯一的出路是：夹住之后，整套爪子连同货物还能再往上抬 ≥「上沿高出盘面的那几毫米」。**

---

## 2. 🔴 必须先回答的一件事（这一个字决定全部）

**Z 升降和夹爪开合，是同一个舵机还是两个？**

电控这边的文档**自己打架**（我们已登记为待澄清）：

| 来源 | 说法 |
|---|---|
| 电控固件注释（引自 `发给机械组.txt:29`） | **张开 = 下降**，**闭合 = 上升** |
| 另一份记录 | 张开 = 高位，**完全闭合 = 最低位** |

**这两条不可能同时成立。**

**为什么这么关键：**
- 如果 **闭合 = 上升** → 夹住货就自动抬起来了 → **基本没问题**
- 如果 **闭合 = 下降** → 夹住货的同时爪子**最低** → **必撞上沿，而且电控没法救**（想抬起来就得松开货）

## 4. 如果确实不够，3 个最小改法（**不用重做零件**）

按性价比排序：

| | 做法 | 耗时 | 合规性 |
|---|---|---|---|
| **①** ⭐ | **把托盘上沿磨/削到 12mm 左右** | 10 分钟 | ✅ **合规**（赛规只要求 ≥10mm） |
| ② | 在**出料那一侧**的上沿开一个豁口，让货从缺口出去 | 快 | ⚠️ **有被裁判判"边缘高度不足"的风险**，慎用 |
| ③ | 上沿**内侧加倒角/斜坡**，让货"爬"过去而不是"撞"上去 | 中等 | ✅ 合规 |

**① 是单点收益最大的一刀** —— 直接干掉十几毫米的抬升需求。

**❌ 我们已排除、别做的：**
- **把托盘整体降低** —— 抓取点跟着一起降低，**相对高度完全不变，白费**
- 换更长的爪子 —— 还是同一个单自由度联动，夹住的高度照样被钉死
- 改"先抬后走"的时序 —— **电控已经是对的**，问题不在那里
