# 任务：补齐"高度视差补偿"的测试 + 填对货物高度表

## 背景

相机装在**托盘中心正上方、光轴垂直向下**（θ=0°）。这消除了**倾斜视差**，但**没有**消除**透视视差**：

```
相机 ──── d ────┐
                │
      ┌─────────┴──────────┐  ← 托盘面（标定平面）
      │   ↑ h              │
      │  ▓▓▓ 货物顶面       │  ← 实际被抓的面
      └────────────────────┘

离光轴 x 处的物体顶面，在图像上被看成 x·d/(d−h)
→ 误差 = x·h/(d−h)
```

**这就是"用托盘平面标定、却去抓有高度的顶面"的代价。**
