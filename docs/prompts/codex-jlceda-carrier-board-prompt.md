```text

真实目标：把已确认的机构转成一套可审查的探索者 STM32F407ZGT6 载板方案，完成真实 GPIO/定时器分配和嘉立创 EDA 原理图工程；在机械尺寸和电气参数未齐全前，不得假装已经具备布局或投板条件。

已确认事实：
- 主控为正点原子探索者 STM32F407ZGT6 开发板，通过排母安装在自制载板上。
- X、Y、Z 各一台 17HS4401 两相四线步进电机，三轴同型号；X/Y 各预留一个 A4988 候选模块位和一个默认 DNP 的板外驱动控制接口，两种驱动方式互斥。
- Z 轴是机械手升降轴，同样使用 17HS4401；载板只提供 STEP_Z/DIR_Z/ENABLE_Z 和可选反馈，驱动器及动力完全板外，断电防坠由机械组负责。
- X/Y/Z 的驱动器具体型号由团队后续自定（可板外，X/Y 也可用板上 A4988 候选位）；当前驱动器选型不阻塞载板原理图，因为载板只画低能量控制信号，驱动器功率级和电机相线都在板外。唯一需在定驱动器后回填的是外部驱动器的控制电平（3.3V/5V、共阳/共阴极）和连接器针序，这可以后补，不影响先画主框架。
- 挡板有四个舵机，必须使用 BARRIER_PWM_1..4 四路独立 PWM；软件在同一阶段同步更新，但 PCB 不得并联 PWM。四路允许分别校准方向、归集角和避让角。
- 夹爪采用三指自定心结构，由 DS3120MG 数字舵机控制开合，使用 GRIP_PWM。
- 比赛只要求抓起物体并投入固定储物盒，不要求投放姿态。腕部旋转舵机不进入当前主链，但载板保留 WRIST_PWM 连接器和 MCU 资源，默认 DNP、固件禁用。
- 六个储物盒为固定部件，不得为其增加电机、驱动器、限位或控制接口。
- 原理图默认保留 X_HOME、X_END、Y_HOME、Y_END、Z_UP、Z_DOWN 六路通用限位输入；优先支持常闭机械开关，并保留调整为其他传感器输入的调理器件位。
- 急停使用至少两组常闭触点的蘑菇头：一组通过板外继电器/接触器切断所有危险执行器动力正极；一组形成 ESTOP_FB。公共地不断，逻辑保持供电，释放后不自动续跑。
- 舵机动力、DC/DC、急停主回路、Z 轴驱动器和补光功率级均在载板外。载板只承担低能量连接、调理、默认态、保护器件位和测试点。
- 用户稍后负责给出板框尺寸、排母间距、安装孔和连接器朝向；在此之前不得冻结 PCB 布局。

工作方法与顺序：

第一阶段，资料核对：
- 检查工作区和 git 状态，保留用户已有改动，不得回滚无关文件。
- 自行查找并核对正点原子探索者 STM32F407ZGT6 的官方原理图、尺寸图、扩展排针表和板载资源。公开资料不要反复向用户索要。
- 特别核对 TF 卡、SWD/ST-Link、板载 USB 转串口、晶振、外部存储、摄像头/网络等已占用引脚。记录资料 URL、文件版本、访问日期和证据强度；第三方引脚图只能作为交叉验证，不能覆盖官方资料。
- 查找工作区是否已有嘉立创 EDA 工程、EasyEDA JSON、KiCad、Gerber 或封装文件。没有就明确记录，不要声称已有 PCB。

第二阶段，资源与引脚分配：
- 生成 docs/design/stm32f407-pin-timer-allocation.md。
- 表格至少包含：功能、外设/定时器通道、STM32 GPIO、探索者排针位置、上电默认态、是否支持 5V、板载资源冲突、嘉立创 EDA 网名、选择依据。
- 必须覆盖三路 STEP、三路 DIR、三路 ENABLE、BARRIER_PWM_1..4、GRIP_PWM、WRIST_PWM、六路限位、ESTOP_FB、START_SIG、MANUAL_RESET_SIG、补光控制、正式通信、备用 UART、驱动 FAULT/READY 和必要测试点。
- 三路 STEP 优先采用可验证的硬件定时器资源。若决定用统一高频调度定时器加 GPIO，必须给出最大步频、最坏 ISR 负载、抖动和三轴协调方法，不能只写“软件实现”。
- 四路挡板 PWM 必须可独立校准并同步更新；夹爪和腕部通道也要有明确的定时器资源。不要把“名义 180 度”直接换算成未经实测的固定脉宽。
- 保留 TF 卡、SWD 和正式通信可用性。发现冲突时重新分配，不得通过禁用调试或 TF 卡来掩盖冲突，除非用户明确裁决。

第三阶段，同步设计基线：
- 把已经确认的 Z 轴步进电机、四路独立挡板 PWM、三指夹爪、腕部 DNP 预留和固定储物盒无电控接口同步到：
  docs/requirements/analysis.md
  docs/design/modular-pcb-design.md
  docs/design/pcb方案-17HS4401版.md
  docs/design/electrical-control-practical-hardware.md
  电控/资料/要求汇总.md
- 保留事实、推断、候选和未知的区分。Z 轴电机型号已确认 17HS4401（与 X/Y 相同）；挡板舵机型号/电流、限位实物、电池/DC-DC、保险、线径、连接器额定、A4988 实物针序、X/Y/Z 最终驱动器型号与电平仍未知，不得补写成事实。

第四阶段，嘉立创 EDA 原理图：
- 先判断用户使用的是嘉立创 EDA 标准版还是专业版，以及当前环境能否可靠生成/编辑该版本的原生工程。能从已安装软件或现有工程识别时自行识别；只有版本确实无法判断且会改变文件格式时，才向用户问这一个问题。
- 创建实际可打开的嘉立创 EDA 原理图工程，不要用 Markdown 冒充 EDA 工程。若原生格式无法可靠生成，立即说明工具边界，并交付逐页原理图实施表、完整网络表、连接器针脚表和封装核对表，等待用户在 EDA 中建立工程后继续；禁止伪造一个不可打开的项目文件。
- 原理图建议分为：TOP、MCU_CARRIER、LOGIC_POWER、DRV_X_A4988_CANDIDATE、DRV_Y_A4988_CANDIDATE、EXTERNAL_DRIVER_CTRL、SERVO_GRIPPER_LIGHT、SAFETY_AND_INPUTS、COMM_DEBUG_TEST、CONNECTOR_SCHEDULE。
- X/Y A4988 标注 CANDIDATE - DNP UNTIL VERIFIED；不得虚构标准 FAULT 脚。A4988 与对应板外驱动器必须存在明确二选一装配规则。
- J_DRV_Z_CTRL 只画低能量 STEP/DIR/ENABLE/反馈；Z 驱动动力、电机相线和防坠不进入载板。
- 四路挡板、夹爪、腕部只画 PWM/参考连接；舵机动力不经过载板。
- 每个会引起运动的信号必须有经审查的安全默认态。所有板外输入保留适配最终电平、去抖、滤波和保护的器件位，但没有证据时不写死数值。

第五阶段，验证与交付：
- 执行 EDA 工具能提供的 ERC，并输出逐项结果；如果工具无法自动 ERC，则生成逐网审查表并明确“未执行自动 ERC”。
- 检查三轴网络互不短接、六路 PWM 独立、六个储物盒零电控网络、逻辑电源与危险动力不误并、急停主回路不经过载板、TF/SWD/UART 无复用冲突。
- 对文本文件运行 git diff --check；如项目有现成检查脚本则运行。不要为了得到全绿而改动无关代码或删除用户文件。
- 最终汇报：创建/修改的文件、已确认事实、仍缺输入、GPIO/定时器表摘要、ERC/网络检查结果、当前允许达到的门槛 G1/G2/G3/G4。

硬性限制：
- 不采购、不投板、不生成被描述为“可生产”的 Gerber，不接线、不上电、不烧录、不驱动实物。
- 不把候选值当冻结值，不根据线色推断电机线序，不根据常见 A4988 模块图片推断针序。
- 不让树莓派直接产生步进脉冲；STM32 仍是唯一底层运动与安全控制器。
- 不因急停切断公共地；急停释放后不得自动恢复。
- 不询问用户能够从公开资料或工作区自行获得的信息。
- 若缺少板框、安装孔和连接器方向，只停止 PCB 布局冻结，不要停止原理图和 GPIO/定时器工作。

验收标准：
1. 有证据可追踪的探索者排针/资源核对记录。
2. 有完整、无冲突的 GPIO/定时器五列表。
3. 三路独立 STEP/DIR/ENABLE，四路独立同步挡板 PWM，一路夹爪 PWM，一路默认 DNP 腕部 PWM。
4. 有六路通用限位和 ESTOP_FB，且默认态安全。
5. 嘉立创 EDA 工程真实可打开，或明确说明工具限制并交付足以人工无歧义建图的实施包。
6. 未知参数没有被虚构；当前门槛结论诚实，不把原理图草图说成可投板 PCB。
```

## 限制

- 本模板只适用于当前探索者 STM32F407 载板，不适用于重新设计裸 MCU 主板。
- 本模板不替代机械组对 Z 轴防坠、板框、安装孔和执行器安装参数的确认。
- 本模板不包含器件采购授权和生产授权。
