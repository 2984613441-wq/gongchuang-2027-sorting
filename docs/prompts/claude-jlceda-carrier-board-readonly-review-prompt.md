# 给 Claude 的嘉立创 EDA 载板只读审核词

## 用途

用于在 Codex 完成或更新探索者 STM32F407ZGT6 载板的 GPIO/定时器分配、嘉立创 EDA 候选原理图及验证记录后，委托 Claude 做一次独立、只读的 L3 回归审核。

该审核只评价当前工作区的证据和产物，不授权修改文件、采购、投板、接线、上电、烧录、实机运动或任何外部写入。

审查事实基线：
- 主控是正点原子探索者 STM32F407ZGT6 开发板，通过排母安装到自制载板；其官方原理图、尺寸图、扩展排针、板载占用资源必须以可追溯证据核对。第三方引脚图只能交叉验证，不能覆盖官方资料。
- X、Y、Z 各一台 17HS4401 两相四线步进电机，Z 与 X/Y 同型号。当前载板只承担低能量控制信号。
- 三轴驱动器由团队后续选定。每轴板外控制接口必须独立提供 STEP、DIR、ENABLE、GND，并可选预留 FAULT/READY；驱动器功率级、电机相线、Z 轴断电防坠均在板外。
- 外部驱动器的控制电平（3.3V/5V）、输入极性（共阳/共阴）和最终连接器针序尚未知。可以预留适配器件位，但不得虚构最终电平、阻值、方向、针序或驱动器型号。
- X/Y 仅可候选预留 A4988 插座，必须标记 CANDIDATE - DNP UNTIL VERIFIED；A4988 与同轴板外驱动器二选一，不得共同驱动同一电机。若出现 A4988 插座，其实际针序、封装、方向、调流与散热空间必须以最终实物核对，不能根据常见图片冻结。
- 四个挡板使用 BARRIER_PWM_1..4 四路独立 PWM，软件可同步更新但 PCB 不得并联这些 PWM。夹爪采用 DS3120MG 和独立 GRIP_PWM；WRIST_PWM 仅预留，默认 DNP 且固件禁用。
- 预留 X_HOME、X_END、Y_HOME、Y_END、Z_UP、Z_DOWN 六路通用限位输入及 ESTOP_FB。优先支持常闭机械开关，但最终传感器形式未定；调理、去抖、滤波和保护可留器件位，未证实前不得写死数值。
- 急停至少两组常闭触点：一组由板外继电器/接触器切断所有危险执行器动力正极，另一组形成 ESTOP_FB。公共地不断开，逻辑保持供电，释放急停后不得自动续跑。急停主回路不经过载板。
- 舵机动力、DC/DC、急停主回路、三轴驱动器、补光功率级均在载板外；载板只承担低能量连接、调理、默认态、保护器件位和测试点。
- 板框、排母间距、安装孔、连接器朝向尚未提供时，只阻塞 PCB 布局冻结，不阻塞 GPIO/定时器分配与候选原理图。

请按下列顺序审核，并给出可复查的文件与行号定位。

一、输入证据与实施范围
1. 列出实际读取的文件、版本/提交或 git diff 范围、缺失文件和不可验证项。
2. 检查本次产物是否与现行任务认知、主方案、PCB 基线和 REVIEW-015 一致；若发现基线互相矛盾，先记录矛盾，不要自行裁决为已解决。
3. 检查实施者是否把“可画 G1 候选原理图”误称为“可冻结、可布局、可投板”或“可生产”。

二、探索者板载资源与 GPIO/定时器分配
1. 审查 docs/design/stm32f407-pin-timer-allocation.md（或等价产物）是否逐项覆盖：三路 STEP、三路 DIR、三路 ENABLE、BARRIER_PWM_1..4、GRIP_PWM、WRIST_PWM、六路限位、ESTOP_FB、START_SIG、MANUAL_RESET_SIG、补光控制、正式通信、备用 UART、FAULT/READY 与必要测试点。
2. 每项是否给出功能网络、STM32 GPIO、开发板排针位置、复用外设/定时器通道、上电默认态、5V 适配状态、板载资源冲突、EDA 网名与选择依据。
3. 三路 STEP 是否使用可验证的硬件定时器资源；若采用统一高频调度定时器加 GPIO，是否量化最大步频、最坏 ISR 负载、抖动风险及三轴协调方法。
4. 检查 TF、SWD/ST-Link、板载 USB 转串口、晶振、外部存储、摄像头/网络等已占用资源没有被无证据复用；检查定时器和引脚不存在隐蔽复用冲突。
5. 所有可能导致执行器动作的输出，在 MCU 未上电、复位、模块未装或外部模块单独供电时，是否给出安全且证据支持的默认态，或诚实标为待最终资料确认。

三、原理图、连接器和网络独立性
1. 检查嘉立创 EDA 工程是否为真实可打开的原生工程；若工具限制导致不能验证，审核实现包是否足以无歧义人工建图，并明确“未验证原生可打开性”。
2. 检查推荐分页或等价边界是否覆盖：TOP、MCU_CARRIER、LOGIC_POWER、DRV_X_A4988_CANDIDATE、DRV_Y_A4988_CANDIDATE、EXTERNAL_DRIVER_CTRL、SERVO_GRIPPER_LIGHT、SAFETY_AND_INPUTS、COMM_DEBUG_TEST、CONNECTOR_SCHEDULE。
3. 检查 STEP_X/Y/Z、DIR_X/Y/Z、ENABLE_X/Y/Z、四路 BARRIER_PWM、GRIP_PWM、WRIST_PWM、限位、ESTOP_FB、启动/复位、通信与测试网彼此独立，且没有同名网标误并网。
4. 检查 X/Y A4988 候选与板外驱动控制接口的装配互斥和默认 DNP 是否清楚；不得接受“两个接口都有但未写明二选一”的设计。
5. 检查 J_DRV_Z_CTRL 及其他板外驱动接口只包含低能量控制与明确的参考地，未把动力、电机相线、制动/防坠或功率保护画入载板。
6. 检查所有连接器有针脚表、方向、对端、参考地、DNP/待冻结状态和未知项；若最终针序未知，接口不得伪装成冻结版本。

四、安全、电源与输入保护边界
1. 急停是否始终保持“板外独立硬件切危险动力正极、公共地连续、逻辑保电、释放不自动恢复”，ESTOP_FB 是否只作为状态输入。
2. 是否错误将舵机动力、DC/DC、补光功率、急停主回路、外部驱动器功率或电机相线纳入载板功率路径。
3. 是否把电平转换、上拉/下拉、RC、ESD/TVS、串阻、反灌保护、隔离、去耦等作为待验证器件位，而不是在缺资料时写死不受证据支持的数值或方向。
4. 是否存在 5V 外部输入直接进入 3.3V MCU、信号脚反向供电、外部模块单独供电导致默认态不安全、不同参考地/回流路径不清等风险。
5. 是否错误切断公共地、错误并联 PWM、伪造 BARRIER_READY/FAULT/READY，或把固定储物盒加入电控网络。

五、验证证据与门禁裁决
1. 审查 ERC 结果或逐网审查表。若没有自动 ERC，必须明确“未执行自动 ERC”，并评价人工逐网审查是否覆盖关键网络；不得把未运行 ERC 说成通过 ERC。
2. 审查静态检查是否至少覆盖：三轴网络无短接、六路 PWM 独立、储物盒无电控网络、逻辑电源与危险动力未误并、急停主回路未经过载板、TF/SWD/UART 无冲突、连接器针脚/网名/方向可追溯。
3. 核对本次结论是否严格区分：
   - G1：候选原理图草图；
   - G2：原理图冻结；
   - G3：PCB 布局布线；
   - G4：生产文件/投板。
4. 对 G2、G3、G4 分别列出仍缺的证据与责任来源。没有探索者官方资料、最终驱动器电平/极性/针序、实物 A4988 资料（若启用）、器件定值、ERC、板框/封装 1:1、电流温升/制造规则、台架与急停独立审查时，不得放行相应门禁。

## 审核通过后的处理

Claude 的发现项先由负责实施的 Codex 对照工作区证据验证；确认有效的 P0/P1 再逐项修正并复审。任何 G2-G4 的升级仍需用户对相应具体动作授权。
