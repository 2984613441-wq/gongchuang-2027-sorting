## 改动 1：删掉 `_pending` 队列（一帧多目标排队导致坐标过期）

### 问题（已定位到行）
`next_if_permitted()` 现在是这样：
```python
def next_if_permitted(self):
    if not self._permitted:
        return None
    with self._lock:
        if not self._pending:
            batch = self._latest
            self._latest = None
            if batch is None:
                return None
            self._pending = self._expand(batch)   # ← 一帧 N 个目标 → 排 N 个
        return self._pending.pop(0)
```

**故障**：赛规 `docs/references/赛题原文-提取文本/省赛规则.txt:136-138` 要求
"**将货物随机放入托盘中…货物放置时的方向和位置随机**"，也就是**一帧会检测到多个目标**。
`_pending` 排出 N 个之后，抓完第 1 个时，第 2..N 个的坐标**仍是那一帧的**，
但此时工件已被机械臂碰走或移位 → **抓空**。

这是"抓空"的独立成因。**协议层的 request_id 握手解决不了它** ——
握手只保证"帧是新的"，保证不了"执行时工件还在"。

### 要改成
"**永远只用最新一帧，且一帧只取一个**"——删掉 `_pending` 队列。

### 约束
- 保持线程安全（仍在 `self._lock` 内）
- 保持 fail-closed（task_id 不匹配、解析失败照样整批丢弃）
- `next_if_permitted()` 的**签名与返回类型不变**（`ItemTaskContext | None`），
  `scheduler` 那边在用
