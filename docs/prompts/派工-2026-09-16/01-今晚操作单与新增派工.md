```python
def next_if_permitted(self):
    if not self._permitted:
        return None
    with self._lock:
        if not self._pending:
            batch = self._latest
            self._latest = None
            if batch is None:
                return None
            self._pending = self._expand(batch)   # ← 一帧 N 个目标 → 排 N 个

（这是"抓空"的独立成因。协议层的 request_id 握手解决不了它 ——
握手只保证"帧是新的"，保证不了"执行时工件还在"。）
