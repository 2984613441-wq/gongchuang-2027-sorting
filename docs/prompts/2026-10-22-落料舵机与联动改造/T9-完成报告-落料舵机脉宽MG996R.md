# 二、改动（3 个文件）

## 2.1 `App/Inc/ec_drop_servo.h`

| 宏 | 改前（占位） | **改后（MG996R 实测）** | 依据 |
|---|---|---|---|
| `EC_DROP_SERVO_MID_US` | 1500 | **1500** | 实测中位 |
| `EC_DROP_SERVO_OPEN_US` | 1500 | **845** | 1500 − 655 = −90° |
| `EC_DROP_SERVO_CLOSE_US` | 1500 | **2155** | 1500 + 655 = +90° |
| `EC_DROP_SERVO_MIN_US` | 500 | **700** | 收紧：避开机械端点，防堵转烧舵机 |
| `EC_DROP_SERVO_MAX_US` | 2500 | **2300** | 同上 |
| `EC_DROP_SERVO_SETTLE_MS` | 400 | 400（不变） | MG996R 90° ≈ 0.20~0.26s，400ms 留 1.5~2 倍余量 |

**文件头注释完整记录了**：
- 型号与实测依据（带文档路径行号）
- 脉宽换算公式（1500 ∓ 655）
- **方向未验证的警示 + 验证方法**（`DROP POS 845` / `DROP POS 2155` 各试一次看门往哪边摆）
- 若安装反向，**只需交换 OPEN/CLOSE 两行**

## 2.2 `App/Src/ec_diag.c`

`ERR DROP_RANGE` 的提示文案从**硬编码** `"DROP POS 500-2500"` 改为**引用常量**：

```c
(void)snprintf(output, sizeof(output),
               "ERR DROP_RANGE DROP POS %u-%u\r\n",
               (unsigned)EC_DROP_SERVO_MIN_US,
               (unsigned)EC_DROP_SERVO_MAX_US);
```

**⇒ 以后改范围时文案自动跟随，不会再出现"文案说 500-2500、实际 700-2300"的失同步。**

## 2.3 `tests/test_diag.c`（断言重写）

| 断言 | 内容 |
|---|---|
| 范围常量 | `MIN == 700U`、`MAX == 2300U`（**字面值断言**，防日后改常量时测试悄悄跟着变）|
| 合法值 | `DROP POS 1000` → `OK` 且 `fake_drop_us == 1000` |
| **下界越界** | `DROP POS 699` → `ERR DROP_RANGE` 且**输出值不变** |
| **上界越界** | `DROP POS 2301` → `ERR DROP_RANGE` 且**输出值不变** |
| 边界值 | `DROP POS 700` / `2300` 均通过 |
| **实测工作点** | `DROP POS 845` / `2155` 均能下发 |
| 动作别名 | `DROP MID/OPEN/CLOSE` → 1500 / 845 / 2155 |
| **占位值回归防线** | `TEST_ASSERT(OPEN != CLOSE)`、`TEST_ASSERT(MID != OPEN)`<br>⇒ **防止以后又被填成同一个占位值** |

# 四、⚠️ 仍未验证（**接线后必须做**）

| # | 项 | 怎么做 |
|---|---|---|
| 1 | **OPEN/CLOSE 的物理方向** | 接线后发 `DROP POS 845`，看门往哪边摆；再发 `DROP POS 2155` 看另一边。<br>**哪边让物块掉得下去 = OPEN**。若与当前假设相反，交换头文件两行即可（测试用宏，不用改） |
| 2 | **上电默认 MID(1500) 是否安全** | 1500 是两极限之间的中位。**若机械上中位会卡住物块或顶到东西**，应改为实测确认的"安全侧"（通常是 CLOSE） |
| 3 | **实际到位时间** | 看 `DROP` 动作后门是否在 400ms 内静止；若不足则调大 `SETTLE_MS` |
| 4 | **PWM 波形** | 示波器量 PE5，应为 50Hz、脉宽 845~2155µs |
