# 三、🔴 现状事实（已核对，**不要重复调查**）

## 3.1 引脚：PE5 / TIM9_CH1（唯一空闲的 PWM）

| 引脚 | 定时器通道 | 用途 | 能否用 |
|---|---|---|---|
| PB10 | TIM2_CH3 | 夹爪 PWM | ❌ |
| **PB11** | TIM2_CH4 | **气动电磁阀** | ❌ **别搞错，它不空闲** |
| PB0 / PB1 | TIM3_CH3/CH4 | barrier | ❌ |
| PB6 | TIM4_CH1 | Y 步进 | ❌ |
| PC6 | TIM8_CH1 | X 步进 | ❌ |
| **PE5** | **TIM9_CH1** | **🔴 预留，当前未用** | ✅ **用这个** |
| PF6 / PF7 | TIM10_CH1 / TIM11_CH1 | barrier | ❌ |

**证据**：
- `Core/Src/stm32f4xx_hal_msp.c:277` — `PE5 ------> TIM9_CH1`，`GPIO_AF3_TIM9`
- `Core/Src/main.c:561` — 注释原文：`/* ... 100kHz（预留PWM，当前未用）*/`

## 3.2 TIM9 现在是 10Hz，**必须改成 50Hz**

`Core/Src/main.c:560-577` 当前：
```c
htim9.Init.Prescaler = 839;     // 84MHz/840 = 100kHz
htim9.Init.Period    = 9999;    // 100kHz/10000 = 10Hz   ← 舵机要 50Hz！
```

**改成**（与 TIM2 夹爪完全同参数）：
```c
htim9.Init.Prescaler = 83;      // 84MHz/84 = 1MHz → 1µs 分辨率
htim9.Init.Period    = 19999;   // 1MHz/20000 = 50Hz（20ms 周期）
```

## 3.3 现有夹爪驱动的写法可以参考

- `App/Src/ec_axis_driver.c` — 夹爪脉宽下发逻辑（`__HAL_TIM_SET_COMPARE` + `HAL_TIM_PWM_Start`）
- `App/Src/ec_board_stm32.c:689-697` — **PB11（TIM2_CH4）的完整启停写法**，**照这个结构抄**

## 3.4 TIM2_CH3 与 CH4 共用计数器（重要教训）

`ec_board_stm32.c:586` 注释原文：
> 而 PB11 = TIM2_CH4 与 PB10 = TIM2_CH3 共用同一个计数器：`ec_servo_port_stop_z()`

**⇒ 同一 TIM 的两个通道，`HAL_TIM_PWM_Stop` 会**连带影响另一个通道**（见该文件 596 行附近的详细注释）。
**你的 TIM9 只有 CH1 一个通道在用，不存在这个问题**，但要知道这个坑存在（以后别人往 TIM9 加 CH2 时会踩）。

# 五、具体实现要求

## 5.1 `ec_drop_servo.h` 必须包含

```c
#ifndef EC_DROP_SERVO_H
#define EC_DROP_SERVO_H

#include <stdint.h>
#include <stdbool.h>

/* ===== 落料舵机（XY 最远端挡料板）=====
 * 硬件：PE5 / TIM9_CH1 / 50Hz
 * ⚠️ 型号未定（用户 2026-10-22 确认"暂时不知道"）
 *    ⇒ 下面三个脉宽值全部是【占位值】，型号确定后必须现场实测重填。
 *    ⇒ 上电默认输出 MID(1500µs)，禁止上电就动。
 */

#define EC_DROP_SERVO_MID_US      UINT16_C(1500)  /* 中位/上电安全位 */
#define EC_DROP_SERVO_OPEN_US     UINT16_C(1500)  /* TODO(型号): 放行脉宽，待实测 */
#define EC_DROP_SERVO_CLOSE_US    UINT16_C(1500)  /* TODO(型号): 挡住脉宽，待实测 */

#define EC_DROP_SERVO_MIN_US      UINT16_C(500)   /* 下界（含安全余量） */
#define EC_DROP_SERVO_MAX_US      UINT16_C(2500)  /* 上界 */
#define EC_DROP_SERVO_SETTLE_MS   UINT32_C(400)   /* 动作后等待到位（与夹爪同量级） */

/* 生命周期 */
bool ec_drop_servo_init(void);                 /* 配 PWM、上电默认 MID，不使能动作 */
bool ec_drop_servo_set_us(uint16_t pulse_us);  /* 任意脉宽，越界返回 false 不动 */
bool ec_drop_servo_open(void);                 /* = set_us(OPEN_US) */
bool ec_drop_servo_close(void);                /* = set_us(CLOSE_US) */
bool ec_drop_servo_mid(void);                  /* = set_us(MID_US) */
bool ec_drop_servo_is_ready(void);             /* init 成功且 timer 可用 */
uint16_t ec_drop_servo_current_us(void);       /* 当前已下发的脉宽 */
void ec_drop_servo_stop(void);                 /* 停止 PWM（输出 0），用于急停 */

#endif
```

**要求**：
1. **三个动作脉宽先都写 1500**，并带 `TODO(型号)` 标记 —— **不许猜方向！**
2. `ec_drop_servo_init()` **不许**调用 `open()/close()`，只输出 MID
3. 所有函数**必须能在主机测试里被 stub 掉**（不依赖 HAL 时也要能编译）

## 5.2 `ec_drop_servo.c` 实现要点

```
1. 内部保存 static uint16_t s_current_us = EC_DROP_SERVO_MID_US;
2. ec_drop_servo_set_us(us):
   - 校验 EC_DROP_SERVO_MIN_US <= us <= EC_DROP_SERVO_MAX_US
   - 越界 → return false，不动 PWM
   - 合法 → __HAL_TIM_SET_COMPARE(&htim9, TIM_CHANNEL_1, us)
            确保 HAL_TIM_PWM_Start(&htim9, TIM_CHANNEL_1) 已启动（只启一次）
            s_current_us = us; return true
3. ec_drop_servo_stop(): HAL_TIM_PWM_Stop + SET_COMPARE(0)
4. 所有 HAL 调用必须在 #if 保护下，让主机测试能编译（参考 ec_tof.c 的写法）
```

## 5.3 `ec_board_stm32.c` 需要新增

参考 `ec_board_stm32.c:689-697` 的 PB11 写法，新增：

```c
bool ec_board_drop_servo_set_us(uint16_t pulse_us);
void ec_board_drop_servo_stop(void);
```

## 5.4 `main.c` 的改动（**只两行 + 注释**）

```c
-  htim9.Init.Prescaler = 839;     /* ... 100kHz（预留PWM，当前未用）*/
-  htim9.Init.Period = 9999;
+  htim9.Init.Prescaler = 83;      /* 2026-10-22: TIM9 改为落料舵机 50Hz。84MHz/84=1MHz */
+  htim9.Init.Period = 19999;      /* 1MHz/20000 = 50Hz（20ms） */
```

**并在 `main()` 里 `MX_TIM9_Init()` 之后调用 `ec_drop_servo_init()`** —— 但要确认 `ec_drop_servo.c` 的 init 是否依赖 HAL 句柄 extern。
