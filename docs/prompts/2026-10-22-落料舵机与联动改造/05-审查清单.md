# 六、审查纪律

| 原则 | 说明 |
|---|---|
| **不代做** | 发现问题**只指出**，不直接改（改了就不是独立审查了） |
| **不轻信报告** | 报告说"7/7 通过"必须自己跑一遍 |
| **看 diff 不看描述** | 描述可以美化，diff 不会 |
| **一票否决项优先** | 安全相关先看，风格问题后看 |
| **明确说"没验证"** | 无法验证的项写清楚，不装懂 |
| **不许用"应该可以"** | 要么有证据，要么标 UNVERIFIED |
