## 4. 目标逻辑（浓缩版，完整在 `docs/design/目标逻辑-总设计-20261106.md`）

```
主相机：YOLO 判形状(6类) + HSV 框内判色(5色) → code(1..30)
   ↓ BATCH_TARGETS 7B/target（TCP 8765，id 字节 = code）
树莓派：时效护栏 → 首件稳定门 → 类别投票(默认关) → code 解析/拒识
   → 动态分格（同 code 复用；新 code 取最小空号 1→6）
   → 帧内排序（A/B/C 三套之一；难件不得排首位；可放弃圆柱/圆锥）
   → 取"当前最该抓的一件"（一帧一件）
   → 去落料点【前】挡板巡检（差分；有件→能判 code 就当正常件，否则夹爪停住）
   → 生成 ITEM_TASK 12B（落点 + 抓取点，角度 0xFF）→ UART 115200 → STM32
   → 转盘转到该格角度（与滑台并行；读回位置 ±20counts 判到位；失败锁死停链）
   → 15 步动作：PARK→PICK→Z取→夹爪闭→Z行→PICK→PLACE→Z放→开槽门→夹爪开→关槽门→Z回→PLACE→PARK→Z安全
   ↓ 落料后（可选）
副相机：落料位 ROI 判色 → MATCH/MISMATCH/UNKNOWN → 台账纠正（off/observe/correct）
```
