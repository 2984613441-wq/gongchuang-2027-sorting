## 1. 【P0】E-17 裁决：颜色和形状在哪一层合流？

### 事实

| 层 | 事实 | 证据 |
|---|---|---|
| 视觉 YOLO | `class_id` 是 **7 个形状类**给cube/cuboid/cylinder/hexagonal_prism/pentagonal_prism/square_pyramid/triangular_prism） | `workspace_label/classes.txt`、`视觉/models/labels_yolo5s_geom7c.txt` |

| 分组 | `BoxAssignment.mapping : (color_id, shape_id) -> box_id` | `视觉/src/sorting_vision/sort_plan.py:51-95` |
| 主链路 | `run_chain.py` 原注释写 **"`box_id = class_id`给class_id 已编码颜色×形状，用户拍板）"** | 该注释已删除，但 `VisionTarget(..., box_id=...)` 结构仍在 |

### 冲突

**一个 `class_id` 不可能同时承载颜色和形状。** YOLO 只出形状。

所以 `BATCH_TARGETS` / `VisionTarget` 里的 `box_id`，究竟是谁算的？

- 如果是 **MaixCAM 端**算的 → 那它必须同时有颜色和形状，可 MaixCAM 的颜色代码是 `color_quant.py`给在树莓派侧的 `视觉/src/sorting_vision/`）——**跑在哪台机器上？**
- 如果是 **树莓派端**算的 → 那 `VisionTarget.box_id` 就不该由上游填，而应在树莓派用 `BoxAssignment` 查表
- 如果两边都在算 → **两套逻辑会不一致**

### 你要裁决的

1. **把数据流画出来**给MaixCAM 出检测框 → … → `ITEM_TASK` 的 x/y），每步标 `文件:行号`。
2. 判定 `box_id` **应该**在哪一层产生，并说明为什么。
3. 判定 `color_quant.py` / `sort_plan.py` **实际部署在哪台机器上**给查部署脚本、
   `电控/deploy/`、`视觉/src/maixcam_deploy/`，不要靠推测）。
4. 指出当前实现与"应该"之间的差距，以及**最小修复路径**。

> ⚠️ 有一个已被作废的说法要小心：PDF `智能分拣装置方案与问题分析.pdf` §1 说

## 3. 【P0】接线安全性审查：`KeyError` 会不会崩掉整条链路

2026-09-15 有另一个节点把落点表接进了 `电控/deploy/run_chain.py`：

```python
# 真模式
drop_points = load_drop_points(args.config)
missing = [b for b in range(1, 7) if b not in drop_points]
if missing:
    raise SystemExit(...)                       # 启动时 fail-closed
...
source = build_socket_source(
    round_id=round_id, round_task_id=round_task_id,
    drop_point_for_box=drop_points.__getitem__,  # ← 未知 box_id 抛 KeyError
)
```

### 你要审查的

1. **`KeyError` 会在哪一层被抛出、被谁接住？**
   一路追到 `drop_point_for_box` 的调用点给在 `electrical_control` 包里），
   判断异常会不会：
   - 崩掉整个 `run_chain.py` 进程？
   - 让某个线程静默死掉给**最危险**：比赛时无提示地停止工作）？
   - 被吞掉后继续用错误的坐标发指令给**如果会，这是最严重的情况**）？
2. **比赛场景下哪种 fail 方式才对？**
   规则是"超过 15 秒没有动作本轮结束"——所以：
   - 崩溃给进程死）→ 比赛直接结束
   - 静默继续用错坐标 → 货物落错盒，违反"形状颜色一致的放同一个盒"
   - 停下来并报警 → **可能才是对的**
   请给出你的判断和理由。
3. **fail-closed 的时机对不对**？现在是在读串口**之前**就失败吗？
   给先开了串口再 `SystemExit` 会留下一个已打开的设备）

### 验收

- 逐条回答，附 `文件:行号`
- 如果发现"静默用错坐标"这类情况，**标为最高优先级**
