## 4. 环境事实（踩过的坑，别再踩）

| 坑 | 正确做法 |
|---|---|
| `python` 指向一个**没有 pip 的坏 venv** | 一律用 **`py -3`**（Python 3.14.5，已装 PyQt5） |
| MinGW `make` 在中文路径下报 `Illegal byte sequence` | 直接调 `gcc`，或先 `cd` 进目录用相对路径 |
| `unittest discover` 报 `Start directory is not importable` | `tests/` **没有 `__init__.py`**，`top_level_dir` 必须传 `tests/` 自己 |
| `电控/tests` 是 **pytest 风格**，但 **pytest 没装** | 要么 `py -3 -m pip install pytest`，要么改写为 unittest |
| `电控/deploy/` 与 `电控/deployment/` 只差 3 个字母 | **不要靠目录名判断死活**，见台账 §7.1 |
| 有几个空缓存目录删不掉（`.pytest_cache` 等） | 沙箱拒绝，需手动 `cmd /c rmdir`，见台账 §5 |
