## 3. 【P1】颜色阈值无法现场调 —— 但先纠正一个前提

### 🔴 先纠正：**MaixCAM 上根本没有颜色计算**

我实测读了 `视觉/src/maixcam_deploy/main.py` 全文给476 行）：

- 它**只做** YOLO 形状检测给`nn.YOLOv8`）→ 过滤 `ACTIVE_CLASS_IDS` → 经 8765 上报 → 画框 → 9001 旁路广播
- **全文没有任何 HSV / 颜色判定代码**给grep `HSV|hsv|color` 只命中画框用的 `image.COLOR_RED`）

**颜色判定的真身在**：`视觉/src/sorting_vision/color_quant.py:354-385` 的 `color_name()`。
它用的是 **HSL**给不是 HSV，但同一族），阈值**硬编码在源码里**：

```python
def color_name(rgb):
    h, s, l = rgb_to_hsl(*rgb)
    if s < 0.12:                       # ← 饱和度阈值
        if l < 0.15:   return "black"  # ← 明度阈值
        if l > 0.85:   return "white"
        return "gray"
    hue = h * 360
    if hue < 15 or hue >= 345: return "red"    # ← 红色跨 0 度
    if hue < 45:  return "orange"
    if hue < 70:  return "yellow"
    if hue < 165: return "green"
    if hue < 200: return "cyan"
    if hue < 255: return "blue"
    if hue < 285: return "purple"
    return "pink"
```

它自己的 docstring 就写着：
> *"This is a starter mapping to be calibrated against the real lighting and
> white-balance setup; the HSV thresholds should be frozen only after an on-site
> calibration pass."*

**所以"现场必须调"说的是这段代码的阈值，不是 MaixCAM 的网络参数。**

### 已经为你准备好的给**别重做**）

`工具/control_panel.py` 已经加了 **「5 颜色标定」** 区：

- 一个**本地试算器**：输入 RGB → 立刻显示判成什么颜色 + HSL 值 + 色块预览
- 阈值表给11 项：`s_achromatic` / `l_black` / `l_white` / 7 段色相分界 + `hue_red_start`）
- 写盘时落到配置文件的 **`[ColorThresholds]`** 节，逐字节保留其余注释
- `--selftest` 里有一组断言，**逐行对齐 `color_quant.py` 的输出**
  给`(205,25,25)`→red、`(25,175,60)`→green、纯蓝 h=240° 等）

### 你要做的给只剩"接线"这一步）

   给默认值必须等于现在硬编码的那组，行为不能变）。
2. **决定这台机器**：`color_quant.py` 跑在**树莓派**还是 **MaixCAM**？

   - 跑 MaixCAM → `sorting_vision` 这个包怎么部署过去？
   > ⚠️ 这个判断与 `04-架构与安全审查.md` 的 **E-17** 是同一件事，
   > **不要自己拍板**，把你的发现交叉给它。
