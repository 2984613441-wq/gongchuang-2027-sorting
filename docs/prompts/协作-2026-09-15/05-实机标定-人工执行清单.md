## 2. 【必做·第一步】重测 Z 轴 —— 🔴 **舵机与结构都变了，旧值作废**

### ⚠️ 2026-09-15 晚的硬件变更（用户口述）

| 项 | 旧 | **新** |
|---|---|---|
| 舵机型号 | DS3120MG | **LDX-335MG**（数字舵机） |
| 控制方式 | PWM | **PWM —— 不变**（所以控制逻辑不变） |
| 机械结构 | 旧形式 | **改了** —— 一个舵机驱动**两处**（升降 + 夹爪），"可以直接加上去" |

| 脉宽 | 1100 = 下降/张开，1900 = 上升/闭合 | **未定，要重测** |

## 4. 【必做】对应表 `(颜色, 形状) → 货格`

规则原文：**"形状、颜色以及信息完全一致的货物放到同一个储物盒"**。

含义：
- 红三棱柱和蓝三棱柱 → **必须不同盒**

用面板「3 对应表」区填：

| 颜色 | 形状 | → 货格 |
|---|---|---|
| | | |
| | | |
| | | |

**颜色词表**（11 个，下标即 `color_id`）：
`0=red 1=orange 2=yellow 3=green 4=cyan 5=blue 6=purple 7=pink 8=black 9=white 10=gray`

## 5. 【必做】HSV 阈值标定

**前置阻塞**：MaixCAM 现在**只接受 `conf_th` / `iou_th` 两个远程参数**，
HSV 阈值要改代码重启。现场标定前，需要先把 `UPDATE_PARAMS` 扩展好
（见 `02-视觉.md` §3）。

### 标定顺序

1. **先固定物理条件**：相机位置、镜头、分辨率、托盘位置、补光灯 —— 定下来就别再动
2. **固定曝光与白平衡**，然后**验证环境光变化下的稳定性**
3. 对每种颜色，取 **3 个以上**不同物料、不同位置，记录 HSV 分布
4. 阈值要满足：**同色物料全落在区间内**，**不同色物料不重叠**

| 颜色 | H 下限 | H 上限 | S 下限 | S 上限 | V 下限 | V 上限 |
|---|---|---|---|---|---|---|
| red | | | | | | |
| ... | | | | | | |

> 注意：红/橙在 HSV 里 H 会**跨界**（红色 H 在 0 和 180 两端），要特别处理。

| 件 | 识别耗时 | XY 搬运 | 转位/落料 | 显示确认 | 单件总时长 | 最长无动作间隔 |
|---|---|---|---|---|---|---|

**目标**：单件 8–10 秒（你们自己定的台架目标，**不是**赛规规定）。

## 9. 【必做】九点标定（图像 ↔ 机械）

PDF §6 要求。用于把视觉的像素坐标换成机械 mm。

1. 托盘上放 160×160mm 网格，取 **9 个点**（X、Y 各取 16 / 80 / 144 mm）
2. 每个点在图像里记下 `(u, v)` 像素坐标
3. 拟合平面映射 `λ[XT, YT, 1]ᵀ = H[u, v, 1]ᵀ`
4. **用没参与拟合的新点验证**误差

| 点 | X (mm) | Y (mm) | u (px) | v (px) |
|---|---|---|---|---|
| P1 | 16 | 16 | | |
| P2 | 80 | 16 | | |
| ... | | | | |

> ⚠️ 两个坑（PDF §6 明确点了）：
> 1. **先确认 YOLO 输出是原图坐标，还是缩放/补边后的坐标**
> 2. **物料顶面有高度**，不能假定托盘平面的映射对顶面也准 → 要按实际参考高度分层标定
