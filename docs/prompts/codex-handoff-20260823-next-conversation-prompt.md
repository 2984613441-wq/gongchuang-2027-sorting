## 三、唯一剩余：实机上机复核 P0

上机第一步（烧录新 HEX 后）：

```
MOTION ARM                      → 期待 OK MOTION ARMED 10S
MOVE X DIR0 STEPS 100 HZ 100    → 期待 OK MOTION STARTING
                                  → 最终 STEP_RESULT=DONE + STEP_REMAIN=0
```

- `DONE` = P0 坐实；`TIMEOUT` = P0 未生效（停，回报串口回显）。
