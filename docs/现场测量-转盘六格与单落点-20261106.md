## 1. 定义「落料口正下方」（两个测量共用同一个基准）

测量前先约定一个**物理基准**，后面两次测量都用它：

- 方法 A（推荐）：把 Z 轴降到较低位置，用夹爪/一根细杆作**垂线**，其正下方即落料口中心。
- 方法 B：在转盘上放一张纸，目视槽门中心，用笔画圈。

> 关键：**6 格测量**与**落点测量**必须用**同一个**基准，否则两者拼起来会偏。

## 2. 测 6 格位置值（转盘）

```bash
# 把工具拷到 Pi（只需一次）
scp 工具/measure_turntable_slots.py pi@172.20.10.8:/home/pi/
ssh pi@172.20.10.8 'python3 /home/pi/measure_turntable_slots.py --ping'      # 先确认在线
ssh pi@172.20.10.8 'python3 /home/pi/measure_turntable_slots.py --interactive \
    --drop-x <待测X> --drop-y <待测Y> --out /home/pi/tt_slots.ini'
```

交互流程：

1. 工具提示「把第 1 格转到落料口正下方」——用 `pi_turntable.py <pos>` 或直接用手/上位机把该格转到基准正下方（**目视对准**）
2. 回车 ⇒ 工具读回位置值并记录
3. 重复 1~6 格；`s` 跳过、`q` 中止
4. 结束后工具打印：

```
[TurntableAngles]
turntable_drop_point = <X>, <Y>
1 = 0.0   # pos=<p1>  delta=0
2 = <角度> # pos=<p2>  delta=<p2-p1>
...
```

**记录表**（也保存到 `docs/reports/标定记录-转盘-YYYYMMDD.md`）：

| 格 | 位置值(0~4095) | 相对第1格 delta | 角度(°) | 备注（目视偏差）|
|---|---|---|---|---|
| 1 | | 0 | 0 | 基准 |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |
| 6 | | | | |

> 判据：6 个角度**应当接近等分**（如 6 格 ⇒ 60°/格）。若某格偏差 > 10°，先检查机械分度/皮带打滑，不要硬填。
> 方向：`drop_strategy` 的口径是「0° = 货格1 零位，**顺时针为正**」；若实测方向相反，把角度改成 `360-θ` 或直接按实测（只要表内自洽即可）。

## 3. 测单一落点坐标（滑台）

前提：**已知当前滑台真值**（`--cur-x/--cur-y`）。若不确定，先走到一个已知点（如 HOME 内角）再开始，逐次累加。

```bash
scp 工具/measure_drop_point.py pi@172.20.10.8:/home/pi/
# 先看计划（不动）：
ssh pi@172.20.10.8 'python3 /home/pi/measure_drop_point.py --cur-x -40 --cur-y 80 \
    --tgt-x -38 --tgt-y 82 --allow-far-y'
# 确认无误再真走 2mm：
ssh pi@172.20.10.8 'python3 /home/pi/measure_drop_point.py --cur-x -40 --cur-y 80 \
    --tgt-x -38 --tgt-y 82 --allow-far-y --yes'
# 单轴微调更好用：
ssh pi@172.20.10.8 'python3 /home/pi/measure_drop_point.py --cur-x -40 --cur-y 80 \
    --jog-axis Y --jog-delta 1 --allow-far-y --yes'
```

流程：

1. 把一个件放在**落料口正下方**（或转盘目标格的中心）
2. 用 2mm 级点动逼近，直到 Z/槽门/夹爪的**垂线正对件中心**
3. 记下此刻真值 = **滑台记账坐标**（`[TurntableAngles] turntable_drop_point` 直接填这个值，**不再叠加 ToolOffset**）
4. 物理坐标校验（可选）：物理 = 记账 + `(120.5, 43.5)`（来自设备 `sorting_config.ini` 注释）

**记录表**：

| 项 | 值 | 备注 |
|---|---|---|
| 落点 X（mm） | | X ≤ +90.0 |
| 落点 Y（mm） | | Y ≤ +92.5（超了 `drop_strategy` 启动校验会拒绝）|
| 对应物理坐标 | (X+120.5, Y+43.5) | 便于机械核对 |
| 目视偏差 | | 件中心 vs 垂线 |
