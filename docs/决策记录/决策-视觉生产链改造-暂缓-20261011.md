## 决策理由

### 为什么不选方案A（改造生产链）

1. **形状特征有已知缺陷**（执行AI实测并固化为测试）：
   - 光滑正六边形误判为`cylinder`（圆度0.962，满足阈值）
   - 正八边形误判为`cylinder`
   - 只能区分3类（cube/cylinder/triangular_prism），其余返回`unknown`
   - **hexagonal_prism是7类词表里的真实类** → 自信的错答案比`unknown`更危险

2. **阈值全部未标定**：
   - 移植自归档区`stage1_contour_v3.py`的经验值
   - 归档检查是"主机侧截图"，非真机/实际光照验证
   - 需现场光线/白底/俯视固定机位重新核验

3. **改动风险高**：
   - 改已部署生产链 + 有契约测试守护（`test_stage1_color_v6_pose.py`）
   - 静默覆盖`class_id`会破坏"现场冻结映射"的约定
   - 需重新验证完整契约测试 → 2-3天额外成本

4. **时间成本高**：
   - 改造3天 + 实机验证2天 + 风险缓冲2天 = **7-8天**
   - 这8天投入数据集补采，可直接推进正确路径

### 为什么选方案B（数据集+YOLO）

1. **唯一能支撑省赛的正确路径**：
   - YOLO可学习8+类（含正四面体）
   - 可区分"俯视相同"的歧义组（需配合ToF深度）
   - 模型精度可通过数据质量控制

2. **时间窗口够用**：
   - 总窗口7周=49天
   - 关键路径：数据集7天 + YOLO重训12天 + ToF集成10天 + 测试5天 = 34天
   - 余量15天 ✅

3. **并行空间大**：
   - Week 1：数据集补采
   - Week 2-3：YOLO重训
   - Week 4：ToF集成（可与Week 2-3并行）
   - Week 5：端到端测试
   - Week 6-7：现场标定+缓冲

4. **可回退性**：
   - 形状特征代码已完成并测试通过，作为**降级预案**保留
   - 若YOLO重训失败（概率低），可紧急启用形状特征（已有适配器）
