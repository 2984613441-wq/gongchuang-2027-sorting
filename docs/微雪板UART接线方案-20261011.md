# 微雪转盘驱动板UART接线方案

**日期**：2026-10-11  
**方案**：UART直连树莓派GPIO0/GPIO1

---

## 一、接线方式

### 微雪 Bus Servo Adapter (A) 接线

| 微雪板端子 | 接到 | 树莓派引脚 | BCM号 | 说明 |
|-----------|------|-----------|-------|------|
| **UART TXD** | → | **Pin28** | GPIO1 | 微雪→树莓派 |
| **UART RXD** | ← | **Pin27** | GPIO0 | 树莓派→微雪 |
| **GND** | ─ | **Pin6或其他GND** | GND | 共地 |
| **VCC** | 不接 | - | - | 独立供电 |

### 微雪板供电

| 微雪板端子 | 接到 | 说明 |
|-----------|------|------|
| **DC 5.5x2.1** 或 **电源端子** | 14.8V电池+ | 9~12.6V范围 |
| **GND** | 总地 | 地 |

**⚠️ 注意**：
- 微雪板和舵机共用一个电源
- 14.8V在9~12.6V范围内，可以直接接
- 不要用降压模块的6V（不够）

### 舵机接线

| 微雪板舵机口⑤ | 接到 | 说明 |
|-------------|------|------|
| 舵机接口 | 转盘舵机 | feetech总线舵机 |

## 二、树莓派配置

### 1. 启用UART3（GPIO0/GPIO1）

编辑 `/boot/config.txt`，添加：
```bash
# 启用UART3在GPIO0/GPIO1
dtoverlay=uart3
```

**⚠️ 注意**：
- 不是 `uart0` 或 `uart5`，是 **`uart3`**
- GPIO0/GPIO1对应UART3

### 2. 重启树莓派
```bash
sudo reboot
```

### 3. 验证设备节点
```bash
ls -l /dev/ttyAMA*
# 应该看到 /dev/ttyAMA3
```

### 4. 修改配置文件

编辑 `~/sorting_config.ini` 的 `[Turntable]` 部分：
```ini
[Turntable]
port = /dev/ttyAMA3    # 改为UART3设备节点（原来是/dev/ttyUSB0）
baud = 1000000         # 波特率（保持不变）
servo_id = 1           # 舵机ID（保持不变）
center_us = 1500
us_per_90deg = 655
settle_s = 1.0
index_side = none
```

## 四、引脚占用总结

更新后的树莓派GPIO占用：

| BCM号 | 物理针脚 | 功能 | 接到 |
|------|---------|------|------|
| GPIO0 | Pin27 | UART3 TX | 微雪板RXD |
| GPIO1 | Pin28 | UART3 RX | 微雪板TXD |
| GPIO14 | Pin8 | UART0 TX | STM32 PA3 |
| GPIO15 | Pin10 | UART0 RX | STM32 PA2 |
| GPIO16 | Pin36 | 输入 | 启动按钮 |

**✅ 无冲突**

## 五、常见问题

### Q1: `/dev/ttyAMA3` 不存在？

**A**: 检查 `/boot/config.txt` 是否添加了 `dtoverlay=uart3` 并重启

### Q2: 权限拒绝？

**A**: 
```bash
sudo chmod 666 /dev/ttyAMA3
# 或加入用户组
sudo usermod -a -G dialout pi
```

### Q3: 通讯失败？

**A**: 
- 检查TXD/RXD是否交叉接对（微雪TXD → 树莓派RX）
- 检查波特率是否匹配（1000000）
- 检查GND是否共地
- 用万用表测微雪板供电是否正常

### Q4: 为什么不用GPIO14/GPIO15？

**A**: GPIO14/GPIO15已经给STM32用了，不能冲突

```
【转盘控制链路】

14.8V电池+
    ↓
微雪板 DC输入
    ↓

    ├─ TXD → 树莓派 GPIO1 (Pin28)
    ├─ RXD ← 树莓派 GPIO0 (Pin27)
    └─ GND ─ 树莓派 GND
    ↓
微雪板舵机口⑤
    ↓
转盘舵机

【数据流】
树莓派 run_chain.py
    ↓ /dev/ttyAMA3 @ 1M baud
微雪板 (feetech协议)
    ↓
转盘舵机 (ID=1)
    ↓ 845µs / 2155µs
A侧 / B侧
```
