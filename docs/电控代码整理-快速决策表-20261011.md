## 四、决策流程图

```
[Agent报告到达]
    ↓
[按置信度分组]
    ├─ ≥0.8 → 🟢 绿灯清单 → 直接归档
    ├─ 0.6~0.8 → 🟡 黄灯清单 → 人工确认
    └─ <0.6 → ⏸️ 搁置（不动）
    ↓
[检查红线]
    ├─ 在红线清单中？ → 🔴 阻断（不归档）
    └─ 不在 → ✅ 执行
    ↓
[执行归档]
    ├─ mkdir archive/电控死代码-20261011/{分类}/
    ├─ mv {文件} archive/
    └─ git commit
    ↓
[更新文档]
    └─ 在最终报告中记录
```
