#### 4.1 发送运动命令

使用固件诊断命令格式：`MOVE X DIR0 STEPS 1600 HZ 1000`

```bash
ssh pi@172.20.10.8

# 创建测试脚本
cat > test_xy.py << 'EOF'
#!/usr/bin/env python3
"""XY电机测试脚本"""

import serial
import time

PORT = '/dev/serial0'
BAUD = 115200

def send_command(ser, cmd):
    """发送ASCII命令"""
    print(f"发送: {cmd}")
    ser.write((cmd + '\n').encode())
    ser.flush()
    time.sleep(0.5)
    
    if ser.in_waiting > 0:
        resp = ser.read(ser.in_waiting).decode('utf-8', errors='ignore')
        print(f"收到: {resp.strip()}")
    else:
        print("无响应")

try:
    ser = serial.Serial(PORT, BAUD, timeout=1)
    print(f"已连接到 {PORT} @ {BAUD}\n")
    time.sleep(1)
    
    # X轴测试（小步长）
    print("=== X轴测试 ===")
    send_command(ser, "MOVE X DIR0 STEPS 800 HZ 500")
    time.sleep(3)
    
    send_command(ser, "MOVE X DIR1 STEPS 800 HZ 500")
    time.sleep(3)
    
    # Y轴测试（小步长）
    print("\n=== Y轴测试 ===")
    send_command(ser, "MOVE Y DIR0 STEPS 800 HZ 500")
    time.sleep(3)
    
    send_command(ser, "MOVE Y DIR1 STEPS 800 HZ 500")
    time.sleep(3)
    
    print("\n测试完成")
    
except Exception as e:
    print(f"错误: {e}")
finally:
    if 'ser' in locals():
        ser.close()
EOF

chmod +x test_xy.py

# 运行测试
python3 test_xy.py
```

## 三、故障排查

### 如果任务1失败（无`a5 5a`帧头）

检查清单：
1. STM32是否上电（指示灯亮）
2. STM32 GND与树莓派GND是否共地
3. PA2/PA3接线是否正确（TX→RX交叉）
4. 固件是否烧录成功（重新烧录）

### 如果任务2失败（气动夹爪不动）

检查清单：
1. PB11接线是否正确
2. 6V供电是否正常（万用表测量）
3. 气路是否连接（气源→电磁阀→气缸）
4. 电磁阀是否损坏

### 如果任务3失败（转盘不动）

检查清单：
1. `pi_pw.py`是否运行（`ps aux | grep pi_pw`）
2. `pigpiod`是否运行（`ps aux | grep pigpiod`）
3. GPIO18接线是否正确
4. 舵机供电是否正常

### 如果任务4失败（电机不动）

检查清单：
1. 任务1是否通过（通讯必须先通）
2. PD42S1供电是否正常（V+ 14.8V）
3. EN/DIR/STEP接线是否正确
4. 细分拨码是否=16
5. COM是否接3.3V
