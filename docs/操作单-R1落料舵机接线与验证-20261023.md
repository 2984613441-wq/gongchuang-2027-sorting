> 适用：回到实验室、机械臂停稳时操作。
> 前置：**断电操作**，接完再上电。
> 生成：2026-10-23

# 一、硬件清单

| 项 | 规格 | 说明 |
|---|---|---|
| 舵机 | **MG996R** | 就是原来挡板用的那款（用户 2026-10-22 确认）|
| 信号线 | 接 **PE5** | STM32 的 TIM9_CH1，50Hz PWM |
| 电源 | **5V（建议独立 5V/3A）** | ⚠️ 见下方"供电警告" |
| 地线 | **必须与 STM32 共地** | 不共地 = 信号无参考，舵机乱抖 |

## ⚠️ 供电警告（这是最容易烧板的地方）

MG996R 堵转电流可达 **2.5A @ 6V**。

| 做法 | 结果 |
|---|---|
| ❌ 从 STM32 板上的 5V 取电 | **极可能烧板载稳压器 / 导致 MCU 复位** |
| ✅ 独立 5V 电源 + **共地** | 正确 |

**判断标准**：如果接上后 STM32 频繁复位、串口掉线 → 就是供电不足，立刻断开改用独立电源。

# 二、接线（断电操作）

```
MG996R 线色（常见，务必先核对你的实物）
  棕 / 黑  → GND      ┐
  红       → +5V      │ 三者都必须接，缺一不可
  橙 / 黄  → PE5      ┘
```

**三条线的作用：**

| 线 | 接到 | 接错的后果 |
|---|---|---|
| 地（棕/黑）| 独立 5V 电源 GND **+ STM32 GND** | 不共地 = 信号无参考，舵机乱抖/不动 |
| 电（红）| 独立 5V 电源 +5V | 接到 12V 会**立刻烧毁** |
| 信号（橙/黄）| **PE5** | 接到别的脚 = 完全不动 |

**PE5 位置**：STM32F407 的 **PE5**（不是 PA5）。引脚数法参考 `docs/design/` 的引脚表。

# 三、上电后的验证顺序（**严格按序，每步确认再下一步**）

## 第 1 步：确认板子活着

```
PING
→ 期望：OK PONG
```
**不过 → 供电不足或接线短路，立刻断电检查。**

## 第 2 步：确认落料舵机初始化成功

```
DROP?
→ 期望：OK DROP ready=1 current_us=1500 open_us=845 close_us=2155
```

**三种可能的结果：**

| 结果 | 含义 | 处理 |
|---|---|---|
| `ready=1` | 初始化成功，PE5 正在输出 50Hz/1500µs | ✅ 继续 |
| `ready=0` | 初始化失败 | ⚠️ 见下方"ready=0 排查" |
| `ERR` / 无应答 | 固件不含 DROP 命令 | 固件没烧对，重新烧 |

### ready=0 排查

`ec_board_drop_servo_set_us()` 返回 false 只有三种原因：

1. `pulse_us == 0` —— 不会
2. `pulse_us > htim9.Init.Period(19999)` —— 不会
3. **`HAL_TIM_PWM_Start(&htim9, TIM_CHANNEL_1) != HAL_OK`** ← 最可能

**处理**：先别管它，`DROP` 命令会返回 `ERR DROP_NOT_READY`（fail-closed，不会误动）。
此时板子其他功能完全正常（因为 2026-10-22 已把 `Error_Handler()` 改成非致命）。
**记录下来告诉我，我查 TIM9 的 MSP 配置。**

## 第 3 步：确认方向（**关键 —— 这是唯一还没验证的**）

**先看舵机臂现在是哪个位置**（1500µs 中位 = 两个极限的中间）。

**然后小步试探：**

```
DROP POS 1000
→ 期望：OK DROP POS 1000
```

**看舵机往哪边摆，记下来。然后：**

```
DROP POS 2000
→ 期望：OK DROP POS 2000
```

**看另一边。**

### 判断规则

| 观察 | 含义 | 要做什么 |
|---|---|---|
| 门**打开**（物块能掉下去）| 那个方向 = OPEN | 若在 2000 侧，**交换头文件两行** |
| 门**挡住**（物块停住）| 那个方向 = CLOSE | 若在 1000 侧，**交换头文件两行** |
| 不动 | 信号线接错 / 供电不足 | 断电查线 |
| 抖动/嗡嗡响 | 脉宽超出机械行程 | **立刻 `DROP MID` 回中位**，断电 |
| 打死一边不出声 | 已到机械端点 | 危险，立即回中位 |

### 交换方法（若方向相反）

`App/Inc/ec_drop_servo.h`：
```c
#define EC_DROP_SERVO_OPEN_US     UINT16_C(845)    // ← 与下一行交换
#define EC_DROP_SERVO_CLOSE_US    UINT16_C(2155)
```
**只需交换这两个值，重新编译烧录。** 测试用的是宏名，不用改测试。

---

## 第 4 步：确认中位安全（防意外落料）

**故意让门停在 1500µs（上电默认），往门上方放一个物块。**

| 观察 | 结论 | 处理 |
|---|---|---|
| 物块**掉不下去** | 中位 = 挡住 ✅ 安全 | 保持 |
| 物块**掉了** | 中位 = 放行 ❌ 上电就可能误落料 | **把上电默认改成 CLOSE**（改 `ec_drop_servo_init()` 里的 `MID` 为 `CLOSE`）|

**⚠️ 这条很关键**：如果中位是放行的，每次上电都可能掉一个件下来。

---

## 第 5 步：确认到位时间（400ms 够不够）

```
DROP OPEN
→ 立即肉眼观察：门是否在 400ms 内静止？
```

| 观察 | 处理 |
|---|---|
| 400ms 内静止 | ✅ 保持 `SETTLE_MS = 400` |
| 还在动 | 加大到 500~600 |

MG996R 空载 90° 约 0.20~0.26s（@5~6V），400ms 有 1.5~2 倍余量，**理论上够**。

# 五、⚠️ 安全红线

| # | 红线 |
|---|---|
| 1 | **必须断电接线**，接完检查再上电 |
| 2 | **不能用 STM32 板载 5V 给 MG996R 供电** |
| 3 | **必须共地** |
| 4 | 试方向时**先放空门**（门上不要放物块），确认方向后再试落料 |
| 5 | 听到持续嗡嗡声**立刻 `DROP MID`**（持续堵转会烧舵机，不可逆）|
| 6 | 第一次上电**手放在电源开关上** |
