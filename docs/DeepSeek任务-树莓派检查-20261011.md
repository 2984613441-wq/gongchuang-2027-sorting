# DeepSeek任务 - 树莓派检查与标定准备

**优先级**：高  
**预计时间**：15-20分钟  
**任务分工**：DeepSeek负责树莓派侧检查和标定准备

---

## 一、SSH连接信息

```bash
ssh pi@172.20.10.8
# 免密登录（密钥认证）
```

**前提条件**：
- 本机已连接iPhone热点（172.20.10.x网段）
- 树莓派已开机并连接同一热点
- 手机热点频段为2.4GHz（"兼容性最大化"）

## 二、任务1：环境检查

### 1.1 基本信息
```bash
ssh pi@172.20.10.8 "hostname; whoami; pwd; uname -a"
```

**预期**：
- hostname: raspberrypi
- user: pi
- 工作目录: /home/pi

### 1.2 目录结构
```bash
ssh pi@172.20.10.8 "ls -la ~"
```

**寻找**：
- 工创赛相关目录
- 电控代码目录
- 视觉代码目录

### 1.3 串口设备
```bash
ssh pi@172.20.10.8 "ls -l /dev/serial0 /dev/ttyAMA* /dev/ttyUSB* 2>/dev/null"
```

**检查**：
- `/dev/serial0` → 应该指向STM32通讯口
- `/dev/ttyUSB*` → 微雪板（STS3215转盘舵机）

### 1.4 GPIO状态（可选）
```bash
ssh pi@172.20.10.8 "which gpio && gpio readall || echo 'gpio工具未安装'"
```

## 三、任务2：电控链路检查

### 2.1 查找Python代码
```bash
ssh pi@172.20.10.8 "find ~ -maxdepth 3 -name '*.py' -type f | head -20"
```

### 2.2 查找串口配置
```bash
ssh pi@172.20.10.8 "grep -r 'serial0\|ttyAMA\|115200' ~ --include='*.py' --include='*.ini' 2>/dev/null | head -20"
```

**关键信息**：
- 波特率：应为115200
- 串口设备：应为 `/dev/serial0`

### 2.3 查找配置文件
```bash
ssh pi@172.20.10.8 "find ~ -maxdepth 3 -name '*.ini' -o -name '*.conf' -o -name 'config.py' 2>/dev/null"
```

### 2.4 查看运行进程
```bash
ssh pi@172.20.10.8 "ps aux | grep -E 'python|sort|vision'"
```
