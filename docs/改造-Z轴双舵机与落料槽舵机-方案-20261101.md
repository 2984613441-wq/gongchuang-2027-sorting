> - **夹爪仍是原来的夹爪舵机**（与 Z 轴**不再联动**）

## 一、固件现状（代码事实，已核对）

| 功能 | 当前实现 | 证据 |
|---|---|---|
| Z 轴 | **与夹爪共用一个舵机**（LDX-335MG），PB10 / TIM2_CH3，机械上"升降+开合"联动、单自由度 | `App/Inc/ec_axis_driver.h:212-214` |
| 夹爪 | 同上（联动）；另有幻尔**总线舵机** HX-06L 的协议实现（115200 半双工） | `App/Inc/ec_bus_servo.h` |
| 落料门 | MG996R，**PE5 / TIM9_CH1 / 50 Hz**，中位 1500、±90° = 845 / 2155 µs | `App/Inc/ec_drop_servo.h` |
| 原挡板 4 路 | PB0/TIM3_CH3、PB1/TIM3_CH4、PF6/TIM10_CH1、PF7/TIM11_CH1（现仅自检 `ec_barrier_test` 用） | `App/Inc/ec_barrier_test.h`、`Core/Src/main.c:428` 起 |
| 气动夹爪 | PB11 / TIM2_CH4（50 Hz PWM） | `Core/Src/main.c:379` |

> 关键点：TIM2/TIM3/TIM9/TIM10/TIM11 都已按 **50 Hz、Period=19999、1 µs 分辨率** 配好，所以新增舵机**不需要新增定时器**，只是把某一路的脉宽按需输出。

## 五、验证顺序（接线后，不用整机跑）

```
① 上电：3 路舵机都应停在安全侧（Z 最高 / 夹爪张开 / 槽门关）
② GRIP 1500 → 看夹爪；GRIP 845/2155 → 看两个极限（别顶死）
```

## 六、风险

| 风险 | 说明 | 对策 |
|---|---|---|
| **电源** | 3 个 MG996R 同时动作，峰值可能 > 3 A | 舵机独立 5V/5A 供电，共地；软件上避免三路同时启动 |
| **联动解除后的机械干涉** | 原来 Z 与夹爪是**联动单自由度**，现在拆成两自由度，夹爪可能撞托盘 | 先手动量行程，再定安全位 |
| **原 12 步程序时序** | Z 从步进变舵机后，"到位"判据从步数变成**时间等待** | 每步后加 `SETTLE_MS`（MG996R 90° ≈ 0.2~0.26 s，取 400 ms） |
| **槽门方向** | 方向反了 = 件掉不下去或提前掉 | 用 `SLOT` 命令实测两个极限各拍一段视频确认 |

### 8.2 节拍口径澄清（重要更正）

**15 s 不是单件节拍预算**。用户 2026-11-01 明确：15 s 指的是
① 开机后 15 s 内不动；② 物料落到转盘后 15 s 内不显示物料。
⇒ 因此**不需要**为压节拍而压缩舵机 settle，仍按安全值（Z/槽门 400 ms、夹爪 600 ms）。
（记录：新 15 步程序的单件预估 ≈ 15~17 s，仅用于报告总时长，不是硬约束。）

### 8.4 赛场"测量件高/件宽 → 换算脉宽"的方法

因为物料尺寸未知，必须**一点现场标定 + 线性换算**，不要拍脑袋填数：

1. **测两个已知高度**：拿两件不同高的件（或垫块），用卡尺量高度 h1 / h2（mm）
2. 手动发 `ZPOS <us>` 找到"夹爪刚好接触件顶"的两个脉宽 p1 / p2
3. 线性拟合：`p(h) = p1 + (p2 - p1) * (h - h1) / (h2 - h1)`
4. 同理测件宽 w → 夹爪闭合脉宽 `grip_close_us(w)`（两件不同宽、正好夹住的两点）
5. 把 6 类件的实测 h / w 代进去，得到 6 组 `z_pick_us / z_place_us / grip_close_us`

测量表模板（现场填）：

| 类别 | 件高 h (mm) | z_pick_us | z_place_us | 件宽 w (mm) | grip_close_us | 备注 |
|---|---|---|---|---|---|---|
| cube | | | | | | |
| cuboid | | | | | | |
| cylinder | | | | | | |
| pentagonal_prism | | | | | | |
| cone | | | | | | |
| tetrahedron | | | | | | |

公共量（一次测完、全场通用）：`z_travel_us`（抬到不撞件的安全高）、`grip_open_us`（张开最大）、
`slot_open_us` / `slot_close_us`（槽门两极限，用 `SLOT` 命令实测方向）。
