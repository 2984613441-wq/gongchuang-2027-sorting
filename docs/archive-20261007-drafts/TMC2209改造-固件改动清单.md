## 2. 引脚分配

### 2.1 UART（TMC2209配置通道）

| 信号 | STM32引脚 | TMC2209引脚 | 说明 |
|---|---|---|---|
| UART3_TX | **PD8** | PDN_UART（单线双向） | TMC2209单线模式：TX/RX共用 |
| UART3_RX | **PD9** | 悬空 | TMC2209不用独立RX |
| （电阻） | PD8 → PD9 | — | 需要1kΩ电阻从PD8接到PD9（单线模式） |

### 2.2 堵转检测（StallGuard）

| 信号 | STM32引脚 | TMC2209引脚 | 上拉 | 说明 |
|---|---|---|---|---|
| DIAG_X | **PG6** | X轴TMC2209 DIAG（引脚5） | PULLDOWN | 堵转=高电平 |
| DIAG_Y | **PD5** | Y轴TMC2209 DIAG（引脚5） | PULLDOWN | 堵转=高电平 |

**为什么选PG6/PD5**：
- 原本是X/Y的HOME限位输入（`X_HOME`/`Y_END`）
- 你们已决定不装限位 → **引脚空闲** ✅
- 已配置为输入 + NOPULL → 只需改上拉模式

### 2.3 步进信号（不变）

| 信号 | A4988 | TMC2209 | STM32引脚 |
|---|---|---|---|
| STEP_X | 引脚4 | 引脚4 | PC6（TIM8_CH1） |
| DIR_X | 引脚7 | 引脚7 | PA7 |
| EN_X | 引脚1 | 引脚1 | PA5 |
| STEP_Y | 引脚4 | 引脚4 | PB6（TIM4_CH1） |
| DIR_Y | 引脚7 | 引脚7 | PC7 |
| EN_Y | 引脚1 | 引脚1 | PD7 |

## 3. TMC2209寄存器配置（UART写入）

### 3.1 初始化序列
```c
// App/Src/ec_tmc2209.c

void TMC2209_Init(UART_HandleTypeDef *huart, uint8_t addr) {
    // 1. 微步配置：1/16（与A4988保持一致）
    TMC2209_WriteReg(huart, addr, REG_CHOPCONF, 
        (0x3 << 24) |  // MRES=0011 → 1/16微步
        (0x1 << 15)    // intpol=1，256插值（更平滑）
    );
    
    // 2. 电流配置：RMS = 1.0A（17HS4401额定1.7A，留余量）
    //    IRUN = 31 × (I_rms / I_max) = 31 × (1.0 / 2.0) ≈ 16
    TMC2209_WriteReg(huart, addr, REG_IHOLD_IRUN,
        (16 << 8) |    // IRUN=16 → 1.0A运行电流
        (8 << 0) |     // IHOLD=8 → 0.5A保持电流
        (5 << 16)      // IHOLDDELAY=5
    );
    
    // 3. StallGuard配置
    TMC2209_WriteReg(huart, addr, REG_TCOOLTHRS, 0xFFFFF);  // 使能StallGuard
    TMC2209_WriteReg(huart, addr, REG_SGTHRS, 10);          // 阈值10（需标定）
    TMC2209_WriteReg(huart, addr, REG_COOLCONF,
        (1 << 24) |    // sg_stop=1，堵转时停止
        (0 << 16)      // semin=0
    );
}
```

### 3.2 地址分配
```
X轴TMC2209：MS1=0, MS2=0 → UART地址 = 0x00
Y轴TMC2209：MS1=1, MS2=0 → UART地址 = 0x01
```
（通过硬件跳线设置：MS1/MS2接GND或VCC）

## 4. StallGuard堵转处理

### 4.1 中断配置
```c
// main.c
void MX_GPIO_Init(void) {
    // PG6（X轴DIAG）
    GPIO_InitStruct.Pin = GPIO_PIN_6;
    GPIO_InitStruct.Mode = GPIO_MODE_IT_RISING;  // 上升沿中断
    GPIO_InitStruct.Pull = GPIO_PULLDOWN;
    HAL_GPIO_Init(GPIOG, &GPIO_InitStruct);
    
    // PD5（Y轴DIAG）
    GPIO_InitStruct.Pin = GPIO_PIN_5;
    GPIO_InitStruct.Mode = GPIO_MODE_IT_RISING;
    GPIO_InitStruct.Pull = GPIO_PULLDOWN;
    HAL_GPIO_Init(GPIOD, &GPIO_InitStruct);
    
    // 使能中断
    HAL_NVIC_SetPriority(EXTI9_5_IRQn, 2, 0);
    HAL_NVIC_EnableIRQ(EXTI9_5_IRQn);
}
```

## 6. 回退方案

**如果TMC2209不work**：
1. 关电 → 拔掉TMC2209 → 插回A4988
2. 烧录备份hex（`MDK-ARM/diankongv1.0/xxx.hex`）
3. 上电 → 立即恢复到改动前状态

**备份要求**：
- 改动前：编译当前固件 → 命名为 `before_tmc2209.hex` → 复制到安全位置
- 改动后：每次编译 → 命名为 `tmc2209_vN.hex`（N=版本号）
