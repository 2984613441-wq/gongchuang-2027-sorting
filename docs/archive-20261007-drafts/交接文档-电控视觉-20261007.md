## 一、视觉方案（已决策 ✅）

### 1.1 技术路线：路线C

**三层判别架构**：
```
输入：单帧图像（320×240）
  ↓
Layer 1: HSV颜色分类（6色，已验证6个月）
  ↓
Layer 2: 几何特征辅助（角点/圆度/Hu矩/对称性）
  → 置信度输出 feature_probs
  ↓
Layer 3: YOLOv8n形状分类（7类）
  → 置信度输出 yolo_probs
  ↓
融合: final_probs = 0.3 * feature_probs + 0.7 * yolo_probs
  ↓
Layer 4: ToF深度消歧义（三棱柱 vs 正四面体，圆锥高度）
  ↓
输出：(color_id, shape_id)
```

**关键改进点**（你的建议✅）：
1. **特征点辅助**："将一些东西提到算法层面来做，数据集压力就会小很多"
2. **ToF多角度标定**："物料高度要全方位标注，俯视角度不同，ToF标注是不同的"
3. **Roboflow标注**："AI辅助标注，减少工作量"

**固定落点坐标**：
```c
#define EC_DROP_POINT_X_MM10  (0)   // X=0mm（托盘中心）
#define EC_DROP_POINT_Y_MM10  (0)   // Y=0mm

// 每次drop，XY轴都去(0,0)，转盘转动到目标格子
```
