## 🔧 接线变化对比

### X轴电机接线（示例）

**校赛（A4988）**：
```
STM32 ──► A4988底座 ──► 17HS4401电机
  PC6 ───► STEP         4根相线（A+/A-/B+/B-）
  PA7 ───► DIR
  PA5 ───► EN
  3.3V ──► VDD
  GND ───► GND
  12V ───► VMOT

= 10根线
```

**省赛（PD42S1）**：
```
STM32 ──► PD42S1驱动器（9针接口）──内部──► 42闭环电机
  PC6 ───► PUL+（脉冲+）
  GND ───► PUL-（脉冲-）
  PA7 ───► DIR+（方向+）
  GND ───► DIR-（方向-）
  PA5 ───► EN+（使能+）
  GND ───► EN-（使能-）
  12V ───► VCC
  GND ───► GND
  （第9针：COM公共端，接3.3V/5V）

= 9根线（无需电机4根相线 ✅）
```

**关键变化**：
1. 差分信号（PUL+/PUL-、DIR+/DIR-、EN+/EN-）
2. 无需A4988底座（PD42S1自带驱动器）
3. 电机与驱动器已连接好（1根编码器线）
