## 详细分析：为什么这么选

### 🥇 必买：亚博 MP2491C（¥49）

#### 解决的问题
```
现状：所有设备共用12V锂电池
  ├─ STM32（5V）    ← 通过LDO降压
  ├─ 舵机（5-6V）   ← 直接接12V？会烧！
  ├─ 步进驱动（12V）← OK
  └─ 树莓派（5V）   ← 独立充电宝

问题：
1. 舵机MG996R/DS3120MG标称电压5-6V，接12V会：
   - 过压损坏（概率30%）
   - 或者能用但发烫+抖动+寿命减半
2. 转盘舵机+Z轴夹爪 = 2个舵机同时转 → 瞬时电流5A
   → 如果从STM32的5V输出取电 → 拉垮整个板子
```

#### MP2491C的优势
| 参数 | 值 | 对你们的意义 |
|---|---|---|
| 输入 | 6-24V | ✅ 接12V电池 |
| 输出 | **固定5V 5A** | ✅ 2个舵机同时动也不崩 |
| 自带显示 | 数码管 | ✅ 实时看输出电压，故障秒查 |
| 尺寸 | 小 | ✅ 装在底座不占空间 |
| 成本 | ¥49 | ✅ 比买2个独立LDO+散热片便宜 |

#### 接线方案
```
12V电池 ─┬─► MP2491C 输入（VIN）
         │      ↓
         │   固定5V输出（5A）
         │      ├─► 转盘舵机 VCC（GND共地）
         │      └─► Z轴舵机 VCC（GND共地）
         │
         ├─► A4988/TMC2209 VMOT（12V）
         └─► STM32板载LDO输入（12V）
```

#### 为什么不用LM2596？
- LM2596：老芯片，效率85%，发热大
- MP2491C：新芯片，效率**95%**，发热小，纹波低
- "优于LM2596"不是广告词，是真的

**结论**：✅ **必买，周一下单**

### ⏸️ 不买：正点原子 PD42S1（虽然很好，但不适合）

#### ✅ 它确实很强

| 优势 | 说明 |
|---|---|
| **真闭环** | 14位磁编码器，位置反馈，自动补偿丢步 |
| **精度高** | <0.08°（TMC2209开环是1.8°/步 = 1/16微步后0.1125°） |
| **FOC控制** | 运行更平顺，比TMC2209静音还静音 |
| **功能全** | 支持脉冲/CAN/485/Modbus，PID可调 |
| **大厂** | 正点原子，教程多，售后好 |

#### ❌ 但有4个问题

**1. 杀鸡用牛刀（性能过剩）**

```
你们需求：
- 定位精度：±5mm（赛规要求）
- 实际精度：±2mm（实测）
- 开环1/16微步：0.1125° × 80步/mm = 0.009mm/步 ← 已经富裕500倍

PD42S1提供：
- 定位精度：<0.08°（比你们需求高25倍）
- 适用场景：医疗设备、光学平台、精密测量 ← 不是分拣机
```

**你们的问题不是"精度不够"，而是"丢步了不知道"**
- TMC2209 StallGuard：能检测堵转 → 解决问题 ✅
- PD42S1闭环：自动补偿丢步 → 也解决问题 ✅
→ 但TMC2209便宜¥90 + 改动小 + 够用

**2. 改动量更大**

| 项目 | TMC2209 | PD42S1 |
|---|---|---|
| 硬件接口 | 兼容A4988（STEP/DIR/EN） | **需要额外接CAN/485（可选）或UART** |
| 固件改动 | 加USART3 + DIAG中断 | 加参数配置+PID调试 |
| 标定工作 | StallGuard阈值（1个参数） | PID三参数 + 磁编零点 + FOC参数 |
| 工期 | 3天 | **5-7天** |

**3. 成本高**

```
PD42S1 × 2              ¥153（¥76.5×2）
vs
TMC2209 StepStick × 2   ¥80

多花 ¥73 买的是：
- 定位精度从0.1°提升到0.08° ← 你们用不到
- FOC更静音 ← TMC2209已经够静音了
```

**4. CAN/485接口用不上（你们现在是UART）**

```
你们现在：
- 树莓派 ↔ STM32 = UART2（115200，协议冻结）
- 加PD42S1的CAN = 需要STM32开CAN接口 + 树莓派不参与 → 架构割裂

如果只用脉冲+方向：
- PD42S1退化成"贵版TMC2209"
- 闭环优势发挥不出来
```

#### 💡 什么时候该买PD42S1？

**省赛后，如果你们要做产品化**：
- 需要长期运行（每天8小时×6个月）
- 需要免维护（不能隔三差五回零校准）
- 需要噪音<40dB（医院/图书馆）
- 需要真正的位置反馈（PLC读取当前坐标）

→ 那时候换PD42S1 ✅

**但现在省赛**：
- 运行2小时/轮，只跑几天
- 每轮开始手动回零
- 场地噪音无所谓（裁判不扣分）

→ TMC2209够用 ✅

**结论**：⏸️ **省赛不买，以后产品化再买**

## 你纠结的"界限问题"解答

### Q1：为什么不买PD42S1？明明更好啊

**A**：分两种"好"
- **技术指标好**：PD42S1 > TMC2209 ✅
- **对你们项目好**：TMC2209 > PD42S1 ✅

**类比**：
```
你要从北京到上海（1300km）
- PD42S1 = 特斯拉Model S（性能强，但¥80万）
- TMC2209 = 高铁二等座（够快，¥553）

特斯拉确实更快（0-100km/h 2.1秒），但：
- 你只需要"到上海"（不是赛道竞速）
- 高铁4.5小时也到了（够用）
- 省下¥79万可以买很多其他东西

→ 选高铁 = 理性决策
```

### Q2：TMC2209会不会不够用？万一省赛要求高了呢？

**A**：看赛规原文
```
docs/references/赛题原文-提取文本/省赛规则.txt
（你们已核读过）

评分标准：
- 识别正确 +X分
- 放入正确盒子 +Y分
- 时间快 +Z分

没有"定位精度±0.1mm"这种要求 ← 工业级赛项才有
```

**即使出现极端情况**（抓取点随机到±0.5mm级）：
- TMC2209：1/16微步 = 0.0125mm/步 → 够
- 如果真不够 → 现场换PD42S1（3小时能换完，因为是脉冲+方向接口兼容）

### Q3：¥135会不会太省？是不是该买贵的保险？

**A**：看投入产出比（ROI）

| 方案 | 成本 | 解决问题 | ROI |
|---|---|---|---|
| 只买电源（¥49） | ¥49 | 舵机稳定供电 | 高（必须解决） |
| 电源+TMC2209（¥135） | ¥135 | 舵机+堵转检测 | **极高** ✅ |
| 电源+PD42S1（¥202） | ¥202 | 舵机+真闭环 | 中（性能过剩） |
| 全买最贵的（¥1000+） | ¥1000+ | 全方位升级 | 低（省赛用不到） |

**¥135 = 最佳性价比点**
