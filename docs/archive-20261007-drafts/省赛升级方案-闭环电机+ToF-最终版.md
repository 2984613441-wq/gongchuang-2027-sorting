### 方案A：正点原子 PD42S1 一体化闭环电机（推荐）

**为什么现在推荐它了**：
- ✅ **驱动+电机一体**：出厂已调好，**接线只需4根**（电源+脉冲+方向+使能）
- ✅ **真闭环**：14位磁编，<0.08°，自动补偿丢步
- ✅ **STM32兼容**：脉冲+方向接口，现有代码几乎不改
- ✅ **不需要A4988底座**：独立安装，不依赖拓展板

#### 型号选择

| 型号 | 区别 | 推荐度 | 单价 |
|---|---|---|---|
| **PD42S1-1684（光耦-TTL版）** | 驱动器+外壳+电机 分体，灵活布局 | ⭐⭐⭐⭐⭐ | ¥76.5 |

#### 接线（比A4988简单10倍）

**老方案（A4988）接线**：
```
STM32 ──────► A4988底座 ──────► 42电机
  PC6 ───────► STEP          A+/A-/B+/B-
  PA7 ───────► DIR           (4根相线)
  PA5 ───────► EN
  3.3V/5V ──► VDD
  GND ───────► GND
12V ─────────► VMOT
               └──► 驱动电机
```
= **10根线**（信号3 + 电源2 + 电机4 + 地1）

**新方案（PD42S1）接线**：
```
STM32 ──────► PD42S1驱动器 ──┐
  PC6 ───────► PUL+          │（驱动器与电机间
  GND ───────► PUL-          │  已内部连接，
  PA7 ───────► DIR+          │  只需1根编码器线）
  GND ───────► DIR-          │
  PA5 ───────► EN+           │
  GND ───────► EN-           │
12V ─────────► VCC           │
GND ─────────► GND           │
                             └──► 42电机（一体化）
```
= **8根线**（信号6 + 电源2），且**无需电机4根相线** ✅

## 🔧 固件改动清单

### 改动1：PD42S1脉冲接口（工作量：小）

**好消息**：PD42S1的脉冲+方向接口与A4988**完全兼容** ✅

**只需改3处**：

1. **接线引脚重映射**（如果引脚换了）
```c
// 原来
#define STEP_X_PIN  PC6
#define DIR_X_PIN   PA7
#define EN_X_PIN    PA5

// 现在（如果引脚不变就不用改）
// 保持不变 ✅
```

2. **使能信号极性**（PD42S1是高有效，A4988是低有效）
```c
// 原来（A4988低有效）
HAL_GPIO_WritePin(EN_X_GPIO_Port, EN_X_Pin, GPIO_PIN_RESET); // 使能

// 现在（PD42S1高有效）
HAL_GPIO_WritePin(EN_X_GPIO_Port, EN_X_Pin, GPIO_PIN_SET);   // 使能
```

3. **微步数确认**（PD42S1默认1600脉冲/圈 = 1/8微步）
```c
// 你们现在：80步/mm = 3200脉冲/圈 = 1/16微步
// PD42S1出厂：1600脉冲/圈 = 1/8微步

// 方案A：改PD42S1参数（通过上位机软件，5分钟搞定）
//   细分 = 1/16 → 3200脉冲/圈 ✅

// 方案B：改固件步数
//   #define STEPS_PER_MM  40  // 原来80，现在减半
```

**推荐方案A**：改PD42S1参数（一次设置，永久保存）

### 改动2：VL53L1X I2C接口（工作量：中）

## 🛡️ 风险与备选方案

### 风险1：PD42S1参数设置不会

**缓解**：
- 正点原子有详细视频教程（B站搜"正点原子 PD42S1"）
- 上位机软件傻瓜式（拖滑条改参数，点"保存"）
- 最坏情况：用默认1/8微步，改固件步数（20分钟搞定）

### 风险2：VL53L1X I2C冲突

**缓解**：
- STM32F407有3个I2C（I2C1/I2C2/I2C3）
- 查`.ioc`看哪个空闲，用哪个
- 最坏情况：用软件I2C（任意GPIO模拟，慢一点但能用）

### 风险3：ToF测不准

**缓解**：
- VL53L1X有3种模式（短距/中距/长距），都试一遍
- 如果还不准 → 不用深度，回到YOLOv26方案（软件深度估计）
- VL53L1X只花¥20，试错成本低

### 终极回退方案

**如果1周后还是有问题**：
- PD42S1拆掉 → 插回A4988（引脚兼容）
- VL53L1X不用 → 视觉走纯颜色+几何判据
- 损失：¥227材料费（但电机和ToF可以留着以后用）
