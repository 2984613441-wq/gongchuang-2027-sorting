## 3. 接线简化对比

### 3.1 现在（A4988开环）

```
每个A4988：
  STM32 ──► A4988底座 ──► 42电机
    STEP      STEP        A+/A-/B+/B-
    DIR       DIR         (4根相线)
    EN        EN
    3.3V      VDD
    GND       GND
    12V       VMOT

= 10根线/轴（信号3 + 电源2 + 电机4 + 地1）
× 2轴 = 20根线
```

### 3.2 升级后（PD42S1闭环）

```
每个PD42S1：
  STM32 ──► PD42S1驱动器 ──内部连接──► 42电机
    STEP      PUL+
    GND       PUL-
    DIR       DIR+
    GND       DIR-
    EN        EN+
    GND       EN-
    12V       VCC
    GND       GND

= 8根线/轴（信号6 + 电源2）
× 2轴 = 16根线

减少：20 - 16 = 4根线 ✅
且无需电机4根相线（驱动器与电机一体化）✅
```

## 5. 固件改动量（最小化）

### 5.1 PD42S1驱动（脉冲模式）

**改动1：使能极性**（1处）
```c
// 原来（A4988低有效）
HAL_GPIO_WritePin(EN_X_GPIO_Port, EN_X_Pin, GPIO_PIN_RESET); // 使能

// 现在（PD42S1高有效）
HAL_GPIO_WritePin(EN_X_GPIO_Port, EN_X_Pin, GPIO_PIN_SET);   // 使能
```

**改动2：微步确认**（可选，用PD42S1上位机改参数更简单）
```c
// 你们现在：80步/mm = 3200脉冲/圈 = 1/16微步
// PD42S1出厂：1600脉冲/圈 = 1/8微步

// 方案A（推荐）：用PD42S1板载按键/上位机改细分 = 1/16
//   → 固件不用动 ✅

// 方案B：改固件步数
//   #define STEPS_PER_MM  40  // 原来80，现在减半
```

**推荐方案A**：PD42S1板载按键5分钟搞定

**改动3：无**（其他代码完全不动）
