## 标准TMC2209接线（与A4988完全一样）

### 引脚定义（16针StepStick）

```
左侧8针（从上到下）：
1.  EN      ← STM32 PA5（使能，低有效）
2.  MS1     ← 接GND（UART地址选择）
3.  MS2     ← 接GND（UART地址选择）
4.  STEP    ← STM32 PC6（步进脉冲）
5.  DIR     ← STM32 PA7（方向）
6.  GND     ← 公共地
7.  VDD     ← 3.3V/5V（逻辑电平）
8.  VIO     ← 3.3V/5V（I/O电平）

右侧8针（从上到下）：
9.  VMOT    ← 12V（电机供电）
10. GND     ← 公共地
11. A1      ← 电机A相+
12. A2      ← 电机A相-
13. B1      ← 电机B相+
14. B2      ← 电机B相-
15. GND     ← 公共地
16. DIAG    ← STM32 PG6（堵转检测输出）⚡ 关键
```

**⚡ 额外接线（A4988没有的）**：
```
背面焊盘 PDN_UART ← STM32 PD8（UART3_TX，单线双向）
                   需要1kΩ电阻接到GND（上拉）
引脚16 DIAG      ← STM32 PG6（堵转信号输入）
```

## 验货清单（收货后立即检查）

**外观**：
- [ ] PCB完整无裂痕
- [ ] 芯片无磨字/重印痕迹
- [ ] 引脚无氧化/弯曲
- [ ] 有散热片（如果描述说有）

**万用表测试**（上电前）：
- [ ] VDD与GND间无短路（阻值>1MΩ）
- [ ] VMOT与GND间无短路
- [ ] A1/A2/B1/B2两两间阻值相等（约1-2Ω，电机线圈）

**通电测试**（接STM32前）：
- [ ] VDD接3.3V → 芯片微热（正常）
- [ ] VMOT接12V → 无烟无异味
- [ ] 用示波器看STEP引脚 → 输入3.3V方波 → 有响应

## 常见问题

### Q1：BigTreeTech和FYSETC哪个好？
**A**：功能一样，BigTreeTech市占率更高，固件案例更多。推荐BigTreeTech。

### Q2：V1.2和V1.3有什么区别？
**A**：V1.3改进了散热设计，其他一样。都可以买。

### Q3：需要买原装Trinamic的吗？（¥200+/个）
**A**：不需要。BigTreeTech/FYSETC用的就是原装芯片，只是做成了模块。

### Q4：一定要散热片吗？
**A**：12V、1A电流、连续运行 → **强烈建议有**（芯片会到60-70°C）

### Q5：可以直接替换A4988吗？
**A**：✅ 物理尺寸完全兼容，但**必须改固件**（见`docs/TMC2209改造-固件改动清单.md`）
