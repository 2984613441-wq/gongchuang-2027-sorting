```python
# 三层判别架构
def classify_object(image, bbox):
    # Layer 1: 颜色（HSV阈值，已验证）
    color_id = hsv_classify(image[bbox])
    
    # Layer 2: 几何特征（轻量，不需要深度学习）
    features = {
        'hu_moments': cv2.HuMoments(cv2.moments(contour)),  # 旋转不变
        'edge_count': count_edges_by_angle(contour),        # 边数统计
        'circularity': compute_circularity(contour),        # 圆度
        'symmetry': compute_symmetry(contour)               # 对称性
    }
    
    # 特征规则判别（减少数据集需求）
    feature_probs = compute_feature_probability(features)
    
    # Layer 3: YOLO模型
    yolo_probs = yolo_classify(image[bbox])
    
    # 融合（置信度加权）✅
    final_probs = 0.3 * feature_probs + 0.7 * yolo_probs
    shape_id = max(final_probs, key=final_probs.get)
    
    # Layer 4: ToF消歧义
    if shape_id in ['tri_prism', 'tetrahedron', 'cone']:
        height_mm = tof.get_distance()
        shape_id = disambiguate_by_height(shape_id, height_mm)
    
    return color_id, shape_id
```

### 2.4 路径规划优化（已决策 ✅）

**算法**：分块TSP（同格件集中处理）

```python
# 文件：电控/src/electrical_control/pick_strategy/planner.py

def optimized_pick_sequence(detections):
    """
    你的建议："同格件集中处理，减少转盘转动"✅
    
    三层优化：
    1. 按box_id分组（同格件集中处理）
    2. 组内按Y坐标分层（利用托盘开口方向）
    3. 层内按X坐标从左到右（减少换向）
    """
    groups = defaultdict(list)
    for det in detections:
        groups[det.box_id].append(det)
    
    sequence = []
    for box_id in sorted(groups.keys()):  # 1号盒优先
        items = groups[box_id]
        
        # 按Y分3层
        layers = [[], [], []]
        for item in items:
            if item.y_mm < -30:
                layers[0].append(item)
            elif item.y_mm < 30:
                layers[1].append(item)
            else:
                layers[2].append(item)
        
        # 每层从左到右
        for layer in layers:
            layer.sort(key=lambda d: d.x_mm)
            sequence.extend([d.target_seq for d in layer])
    
    return sequence
```

- 换向：14次 → 8次（-43%）
- 转盘：18次 → 9次（-50%）
- X总行程：3420mm → 2680mm（-22%）
- **节省时间**：4.2秒/轮 ✅

### 3.2 待决策：夹爪改动 ⏸️

**核心问题**（你说的）：
```
"一旦贴在一起，夹爪的运动路径会把中间的东西给弄走"✅
```

**场景重现**：
```
托盘上3件紧贴：
  [A正方体] [B圆柱] [C三棱柱]
     ↓        ↓        ↓
  间距=0mm  间距=0mm

现在要抓B圆柱：
  夹爪从上方下降 → 罩住B → 闭合 → 提升
  
问题：
  闭合时爪片横向移动 → 推到A和C → 推出托盘 ❌
```

**方案A：改夹爪为纵向收缩**（推荐）
```
现在夹爪：      改进夹爪：
 \  目标  /      |  目标  |
  \__  __/       |__  __|
     \/             ||
   横向闭合       纵向闭合
（推到旁边件）  （不推旁边件）✅

实现：
  - 用平行夹爪（气缸驱动 or 双舵机平行连杆）
  - 成本：¥60（已在采购清单）
  - 工期：3天（蒋负责机械设计）
```

**方案B：改双舵机**（备选，需L4审批）
```
现状：单舵机联动（升降+夹爪同一脉宽）
改进：双舵机独立（升降1个，夹爪1个）

好处：
  + 存在"低位+张开"状态
  + 尖顶件不弹飞
  + 贴紧件可以先张开再下降
  
代价：
  - L4红线（I/O映射变更）⚠️
  - 机械重新设计（3周工期）
  - 成本：+¥30（多1个舵机）
```

**决策时机**：
```
Week 4: 单舵机+方案A测试
  IF 尖顶件成功率≥80% AND 整场≥85% → 保持单舵机 ✅
  ELSE → 启动双舵机方案（L4审批）⚠️
```
