# 视觉方案：3D视频 → 深度模型训练 · 实施清单

> **目标**：不买ToF硬件，用视频重建3D模型 → 渲染深度真值 → 训练YOLOv26深度模型
> **适用场景**：省赛"6类件形状未知" + "俯视投影歧义"
> **工期估算**：5-7天（采集1天 + 重建2天 + 渲染1天 + 训练2天 + 验证1天）

---

## 阶段1：视频采集（1天）

### 1.1 设备准备
- [ ] 手机/相机（≥1080p，30fps）
- [ ] 三脚架或稳定器（**必须**，手持抖动=重建失败）
- [ ] 转台（可用现有转盘，手动每10°停一下拍照）
- [ ] 均匀光照（避免阴影，LED环形灯最佳）

### 1.2 拍摄规范（每类件）
```
① 固定相机，件放转台上
② 拍摄角度：俯视45° + 侧视0°（两个视角）
③ 每10°停顿拍一帧（360° = 36帧）
④ 每类件×2视角×36帧 = 72张/类
⑤ 6类件 = 432张原始图
```

### 1.3 文件组织
```
raw_videos/
  ├── 正方体-俯视45.mp4
  ├── 正方体-侧视0.mp4
  ├── 圆柱-俯视45.mp4
  ├── ...
  └── 正四面体-侧视0.mp4
```

## 阶段2：3D重建（2天，MATLAB）

### 2.1 MATLAB工具箱要求
- Computer Vision Toolbox
- Image Processing Toolbox

### 2.2 SFM重建脚本
```matlab
% 从视频提取关键帧
videoFile = 'raw_videos/正方体-俯视45.mp4';
v = VideoReader(videoFile);
frames = {};
while hasFrame(v)
    frames{end+1} = readFrame(v);
end

% Structure from Motion
images = imageDatastore('frames/*.png');
vSet = imageviewset;

% 特征检测+匹配（ORB/SIFT）
for i = 1:length(images.Files)
    I = readimage(images, i);
    points = detectSURFFeatures(rgb2gray(I));
    [features, validPoints] = extractFeatures(rgb2gray(I), points);
    vSet = addView(vSet, i, 'Points', validPoints, 'Features', features);
end

% 三角化 + Bundle Adjustment
[xyzPoints, reprojectionErrors] = triangulate(...);

% 导出点云
ptCloud = pointCloud(xyzPoints);
pcwrite(ptCloud, 'pointclouds/正方体.ply');
```

### 2.3 质量检查
- [ ] 重建点云 ≥5000点/件（太稀疏=失败）
- [ ] 重投影误差 <2像素
- [ ] 可视化验证（用`pcshow()`看是否完整）

## 阶段3：Mesh生成与渲染（1天）

### 3.1 点云→Mesh（MeshLab / Blender）
```python
# 用Open3D处理
import open3d as o3d

pcd = o3d.io.read_point_cloud("pointclouds/正方体.ply")
# Poisson表面重建
mesh, densities = o3d.geometry.TriangleMesh.create_from_point_cloud_poisson(pcd, depth=9)
o3d.io.write_triangle_mesh("meshes/正方体.obj", mesh)
```

### 3.2 批量渲染（Blender Python API）
```python
import bpy
import numpy as np

# 加载模型
bpy.ops.import_scene.obj(filepath="meshes/正方体.obj")
obj = bpy.context.selected_objects[0]

# 设置渲染
scene = bpy.context.scene
scene.render.resolution_x = 224  # MaixCAM输入尺寸
scene.render.resolution_y = 224

# 100个随机姿态
for i in range(100):
    # 随机旋转
    obj.rotation_euler = (
        np.random.uniform(0, 2*np.pi),
        np.random.uniform(0, 2*np.pi),
        np.random.uniform(0, 2*np.pi)
    )
    
    # 渲染RGB
    scene.render.filepath = f"renders/正方体_rgb_{i:03d}.png"
    bpy.ops.render.render(write_still=True)
    
    # 渲染深度（切换到Z-pass）
    scene.use_nodes = True
    tree = scene.node_tree
    links = tree.links
    render_layers = tree.nodes.new('CompositorNodeRLayers')
    output = tree.nodes.new('CompositorNodeOutputFile')
    output.base_path = f"renders/正方体_depth_{i:03d}"
    links.new(render_layers.outputs['Depth'], output.inputs[0])
    bpy.ops.render.render()
```

### 3.3 深度归一化
```python
# 你们件高10-30mm，ToF量程200mm
# 渲染的depth单位是Blender单位（通常=米）
depth_raw = np.load("renders/正方体_depth_000.npy")
depth_mm = depth_raw * 1000  # 米→毫米
depth_norm = np.clip(depth_mm, 0, 200) / 200.0  # 归一化到[0,1]
np.save("depth_normalized/正方体_000.npy", depth_norm)
```

## 阶段4：YOLOv26训练（2天）

### 4.1 数据集格式
```
depth_dataset/
  ├── images/
  │   ├── train/
  │   │   ├── 正方体_000.png  # RGB
  │   │   └── ...
  │   └── val/
  ├── depths/  # 深度真值
  │   ├── train/
  │   │   ├── 正方体_000.npy  # 或 .png（16bit灰度图）
  │   │   └── ...
  │   └── val/
  └── data.yaml
```

`data.yaml`：
```yaml
path: depth_dataset
train: images/train
val: images/val
depth_train: depths/train  # YOLOv26深度任务特有
depth_val: depths/val

nc: 6  # 分类数（如果同时做检测+深度）
names: ['正方体', '圆柱', '三棱柱', '圆锥', '正四面体', '长方体']
```

### 4.2 训练脚本
```python
from ultralytics import YOLO

# 方案A：纯深度估计（不检测）
model = YOLO('yolo26n.pt')
results = model.train(
    task='depth',
    data='depth_dataset/data.yaml',
    epochs=50,
    imgsz=224,
    batch=16,
    device=0  # GPU
)

# 方案B：检测+深度联合（更适合你们）
model = YOLO('yolo26n.pt')
results = model.train(
    task='detect',  # 主任务是检测
    data='depth_dataset/data.yaml',
    depth=True,  # 开启深度分支
    epochs=50,
    imgsz=224
)
```

### 4.3 验证指标
- [ ] 深度MAE（平均绝对误差）<5mm
- [ ] 能区分"圆锥30mm vs 正四面体10mm"（高度差20mm）
- [ ] FPS ≥5（MaixCAM上）

## 关键风险与Plan B

| 风险 | 概率 | 缓解 |
|---|---|---|
| **SFM重建失败**（纯色件无纹理） | 高 | Plan B：贴标签纸增加纹理特征 |
| **深度模型精度不够** | 中 | Plan B：改用ToF硬件（PMOD_TOF100，¥300） |
| **MaixHub不支持深度模型转换** | 中 | Plan B：只训练分类模型，深度用几何先验（圆锥高=底面直径） |
| **渲染数据与真实差距大** | 中 | 混合训练：50%渲染 + 50%真实拍摄 |
