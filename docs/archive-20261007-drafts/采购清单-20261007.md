## 📋 供电架构（最终方案）

```
12V 6Ah锂电池组（主电源）
  ├─► DC-DC 12V→5V 10A模块
  │      ├─► 树莓派（5V 3A）
  │      ├─► MG996R Z轴舵机（5V 2A）
  │      ├─► STM32（5V → 板载LDO → 3.3V，1A）
  │      └─► 白光补光灯（5V 0.6A，可选）
  │      合计：6.6A（余量3.4A）✅
  │
  ├─► STS3215转盘舵机（12V直接接，2A）✅
  └─► PD42S1 × 2（12V直接接，6A）
      合计：14A（电池额定放电20A，余量6A）✅
```

**为什么这样设计**（你的建议✅）：
- ✅ **12V电池组统一供电**（不会像校赛那样电压不稳）
- ✅ **大功率走12V直接接**（PD42S1 + STS3215）
- ✅ **小功率走5V稳压**（树莓派 + STM32 + 舵机）
- ✅ **续航2小时+**（6Ah / 14A × 0.8效率 = 2.05小时）
