**路线C：YOLO形状 + HSV颜色 + ToF深度**

```python
# 消歧义表
AMBIGUOUS_PAIRS = [
    (3, 4),  # 三棱柱 vs 正四面体（投影都是三角形）
    (5, 6),  # 五棱柱 vs 六棱柱（顶视差异小）
]

def fuse_shape(shape_id, height_mm):
    # 非歧义类直接返回
    if shape_id not in [s for pair in AMBIGUOUS_PAIRS for s in pair]:
        return shape_id
    
    # 歧义类：用高度判定
    if shape_id in (3, 4):  # 三棱柱 vs 正四面体
        if height_mm < 20:
            return 4  # 正四面体
        else:
            return 3  # 三棱柱
    
    return shape_id
```

## 二、抓取策略优化方案（Agent 2）

### 2.1 核心问题与方案

**单舵机联动的物理约束**：
- 脉宽↓ = 升降↑ + 张开↑（同步耦合）
- 脉宽↑ = 升降↓ + 闭合↑（同步耦合）
- **致命缺陷**：不存在"低位+张开"状态 → 尖顶件弹飞/贴紧件夹不进

**方案**：单舵机保留（配合补偿策略），双舵机作为回退方案

### 2.2 7类件脉宽优化表

| 类别 | 形状特征 | **预降脉宽（µs）** | 理由 |
|---|---|---|---|
| 正方体 | 平顶方 | **700**（650→700） | 当前650会挡件，放宽50µs |
| 三棱柱 | 平顶三角 | **750** | 保持 |
| 圆柱 | 平顶圆 | **800** | 保持 |
| **正四面体** | **尖顶三角** | **850** | ⚠️ 新增；比三棱柱多100µs，避免压尖 |
| 圆锥 | 尖顶圆 | **850** | 同正四面体 |
| 四棱锥 | 尖顶方 | **850** | 同上 |
| 球 | 球顶 | **800** | 与圆柱同 |

**通用5阶段序列**：

```
[0] 待机/移动：625µs（高位+最大张开）

[3] 夹取：1900µs（完全夹紧）
[4] 提升/搬运：1900µs（保持）
```

### 2.3 抓取点选择策略

**算法**：
```python
def compute_grasp_point(contour, shape_type, color_mask):
    # 1. 形心作为第一候选
    cx, cy = compute_centroid(contour)
    
    # 2. 尖顶件特殊处理：优先抓底部/侧面
    if shape_type in ['tetrahedron', 'cone', 'pyramid']:
        # 向形心方向偏移0.3倍高度（避开尖顶）
        bbox = cv2.boundingRect(contour)
        offset_y = int(bbox[3] * 0.3)
        cy = min(cy + offset_y, bottom_point[1])
    
    # 3. 紧贴件检测：向轮廓内部收缩4像素
    if is_touching_neighbors(contour, color_mask):
        cx, cy = shrink_to_interior(contour, cx, cy, pixels=4)
    
    return (x_device, y_device)
```

## 三、电控优化方案（Agent 3）

### 3.1 路径规划优化（分块贪心TSP）

**算法**：
```python
def optimized_pick_sequence(detections):
    """
    三层优化：
    1. 按box_id分组（同格件集中处理）
    2. 组内按Y坐标分层（利用托盘开口方向）
    3. 层内按X坐标从左到右（减少换向）
    """
    groups = defaultdict(list)
    for det in detections:
        groups[det.box_id].append(det)
    
    sequence = []
    for box_id in sorted(groups.keys()):
        items = groups[box_id]
        # 按Y分3层：下[-97.5,-30] 中[-30,+30] 上[+30,+92.5]
        layers = [[], [], []]
        for item in items:
            if item.y_mm < -30:
                layers[0].append(item)
            elif item.y_mm < 30:
                layers[1].append(item)
            else:
                layers[2].append(item)
        
        # 每层从左到右（X升序）
        for layer in layers:
            layer.sort(key=lambda d: d.x_mm)
            sequence.extend([d.target_seq for d in layer])
    
    return sequence
```

**24件优化效果**：
- 换向：14次 → 8次（-43%）
- 转盘：18次 → 9次（-50%）
- X总行程：3420mm → 2680mm（-22%）
- **节省时间**：约4.2秒/轮
