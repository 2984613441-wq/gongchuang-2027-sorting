## 一、PD42S1引脚定义（手册确认）

根据手册第11-15页，PD42S1接线端子：

| 端子标识 | 功能 | 说明 |
|---------|------|------|
| **V+** | 电源正 | 12~32VDC |
| **GND** | 电源负 | 地 |
| **COM** | 控制信号公共端 | 接3.3V或5V |
| **EN** | 使能信号 | **高有效**（与文档一致） |

| **Lim** | 限位输入 | 我们不用 |

## 二、关键发现

### 🔴 EN极性冲突

**手册说明**（第13页）：
- EN = **高电平**：使能（电机可转）
- EN = **低电平**：失能（电机断电）

**固件代码**（`ec_board_stm32.c:362-363, 724-727, 743-744`）：
```c
// 使能时
HAL_GPIO_WritePin(ENABLE_X_GPIO_Port, ENABLE_X_Pin, GPIO_PIN_RESET);  // 低电平

// 失能时
HAL_GPIO_WritePin(ENABLE_X_GPIO_Port, ENABLE_X_Pin, GPIO_PIN_SET);    // 高电平
```

**⚠️ 结论**：
- 手册：高有效
- 固件：低有效
- **完全相反！**

## 六、需要修改的地方

### 🔴 必须修改：EN极性反转

**两种方案**：

#### 方案A：改固件（推荐）
修改 `ec_board_stm32.c`，将EN的GPIO_PIN_RESET和GPIO_PIN_SET互换：

```c
// 使能时（改为高电平）
HAL_GPIO_WritePin(ENABLE_X_GPIO_Port, ENABLE_X_Pin, GPIO_PIN_SET);
HAL_GPIO_WritePin(ENABLE_Y_GPIO_Port, ENABLE_Y_Pin, GPIO_PIN_SET);

// 失能时（改为低电平）
HAL_GPIO_WritePin(ENABLE_X_GPIO_Port, ENABLE_X_Pin, GPIO_PIN_RESET);
HAL_GPIO_WritePin(ENABLE_Y_GPIO_Port, ENABLE_Y_Pin, GPIO_PIN_RESET);
```

#### 方案B：硬件反相（不推荐）
- 在EN和STM32之间加三极管反相
- 增加复杂度，不推荐

**建议**：采用方案A，改固件
