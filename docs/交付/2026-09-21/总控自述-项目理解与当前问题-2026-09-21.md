## 第一部分 · 我理解的项目（**请逐条核对**）

### 1. 物理链路
```
MaixCAM 相机 172.20.10.9（跑单文件视觉，纯 HSV 颜色法，**不用 YOLO**，MaixVision 点运行）
   └─ 主动 TCP 连 ─→ 树莓派 172.20.10.8:8765

### 2. 三个坐标系
| 坐标系 | 定义 |
|---|---|
| 像素系 | MaixCAM 320×320 取景 → 内部缩 224 检测（scale 0.7）→ ROI 内缩 3%（det 6px / 320 系 9px） |
| 装置系 | 毫米；原点 = **上电时机构位置**（"上电位置即 HOME"，不寻零）；**无限位开关、无编码器** |
| 滑台系 | = 装置系 + `[ToolOffset]`；**发给 STM32 的全部是滑台系** |

已定案数值（我按这个理解）：
```

### 3. 视觉 V6（现役）= `视觉/src/maixcam_deploy/stage1_color_v6_send.py`
**原理：HSV 阈值分六色，形状从来不测量，货格号由颜色查表。**
```
cyan→1(cube)  green→2(cube)  red→3(triangular_prism)
blue→4(triangular_prism)  black→5(cylinder)  orange→6(cylinder)
```
wire（**冻结**）：`target_count(1) + task_id(2,BE) + target[N]`，每 target **7 字节** =
`id_byte(=bin)/confidence(0-100)/X(2,BE)/Y(2,BE)/angle(0xFF)`，`struct.pack(">BBHHH"...` 实为 `">BBHHB"`（`stage1_color_v6_send.py:63`）。`TASK_ID` 强制 = 1。
⚠️ 交接文档里写的 `target_seq/class_id/image_id` 是**错的**（字段名与个数都不对，那样列是 8 字节）。

## 第三部分 · 当前问题（这才是要分发的东西）

### 问题陈述
**单目、纯 HSV 颜色法、形状不测量**的视觉，如何把「机器自身的黑色结构件」（夹爪 + X/Y 轴黑色方框）
与「真的黑色圆柱（bin=5）」区分开？

已知它们**颜色相同、亮度同档、形状不可用于区分、面积重叠**：
| 对象 | 短边@320 | 面积@320 | aspect | 备注 |
|---|---|---|---|---|
| 真件（cube cyan） | 94 | 8078.6 | 0.9565 | |
| 真件（cylinder orange） | 86 | 5440.8 | 1.0000 | |
| 真件（prism_tri red） | 73 | 3088.8 | 0.8793 | |
| **静止黑块**（停在视野左下） | 59 | 2258~2485 | 0.9535 | **比真件还"方正"** |
| **静止黑带**（右侧竖带） | 40 | 4599~6817 | 0.1321 | c3 也能挡 |
| M2 下限 | 62 | 2600 | — | |

**⇒ 挡住幻影的余量只有 3px / 4.6%，而幻影自身帧间抖动是 ±10%**【实测】⇒ 换个光照它就会通过 M2。

### 我按"移动前后差分"做的尝试，以及它为什么失败（**实测**）
设计：机构停在 A 位置抓一帧 → 移开 → 抓 B 帧 → `|A-B|>25` 的像素 = 机构扫掠区 → 存成遮罩，
黑候选必须完全落在遮罩外。外部审核方给的理由是"跨帧差分信号强度差 3 个数量级"
（件 bbox 内变化 36.9~67.3%，两块固定黑物内 0.00~0.06%）——**这个理由本身是对的**。

实测结果：
```
噪声地板（机构没动，相隔 0.2s）：变化像素 0.0000%        ← 场景极稳，阈值 25 远高于噪声
沿 +X/+Y 分 4 段走到落点③，每段抓一帧：
   s1 变化 39.32%   s2 46.69%   s3 45.41%   s4 41.12%
4 帧并集 = 92.9% 画面（95113/102400）  ⇒ 脚本按设计**拒绝**写入遮罩
相位相关：最佳整体平移 dx=+0.2 dy=-0.6 resp=0.058，平移后残留仍 39.4%
8×8 网格（数字 = 该格变化百分比）：
   s1  row0-3 中间五列 =  0  0  0  0  0     ← 件所在区域，没变
       row5-7 中间     = 50 45 57 26 92 …   ← 下半幅几乎全变
   s4  row1-2 中间     = 86 77 82 92 98     ← 走到远端时上半幅也变了
```

### 我从中得出的结论（**这条也请核对**）
- 相机**固定**（不是整体平移）；变的是**一个大结构在固定背景前扫过**。
- 视场 155mm，而行程 140+145mm **比视场还大** ⇒ 机构结构在大行程下会把**几乎整个视场**扫一遍
  ⇒ **"扫掠并集"必然接近 100%，静态遮罩这条路按原设计走不通**——不是参数没调好，是几何上的必然。
- 现有 c2（贴≥2 条边才丢）+ c7（M2）**只在机构"停着"时有效**（停着时黑块贴 2~3 条边被 c2 挡掉）；
  一旦机构动起来，结构会出现在画面**中部**（不贴边）⇒ c2 失效，只剩 c7 那 3px 余量。
