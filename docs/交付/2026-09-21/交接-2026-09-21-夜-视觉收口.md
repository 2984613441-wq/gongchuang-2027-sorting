## 2. 本轮做完的三项（全部带设备证据）

### ② 拒绝计数按颜色分开 【已落盘 + 设备验证】

- 新增 `_REJ_C = {gate: {color: n}}` + 统一入口 `_bump(gate, color)`；**全局键名不变**，老读法继续有效。
- 日志新增一段 `bycolor[...]`，只列非零项，正常帧 1~3 项。
- **顺带修掉一个"看不见的丢件"**：`c6_black_mutex`（black 与彩色候选互斥）的计数**从来没被自增过**——
  init 里有键、代码里无人写它 ⇒ "black 被 C 段悄悄丢掉"在日志里完全不可见。现已补上。
- ⚠️ 反面教训（我自己犯的）：我一开始写了个断言"裸 `_REJ[...] += 1` 只允许剩 c8"，
  结果测试当场告诉我 **c8 那行是普通赋值不是 AugAssign**（它存的是像素数不是次数）⇒ 裸自增实际是 0 处。
  这正是"先写断言再看真相"的价值，也是为什么不能靠记忆写判据。

### ③ AE/AWB 读取顺序 【已落盘】

```
:199  LOCK_AE_AWB = False          ← 默认关，今天行为零变化
:499  cam.set_awb(0)               ← 必须先切手动
:500  _wb2 = list(cam.set_wb_gain())  ← 这时才读得到有效值
:501  if _wb2 and any(_wb2): cam.set_wb_gain(_wb2)
```
依据：现场实测 `wb_gain=[0.0, 0.0, 0.0, 0.0]` —— **AWB 在 Auto 模式下 getter 不返回有效值**，
所以"读一次再写死"对白平衡根本不成立。
⚠️ 同时删掉了一处残留的 `if _wb: cam.set_wb_gain(_wb)` —— `[0,0,0,0]` 是非空列表（truthy），
留着会把刚读到的正确值覆盖成全 0。
可用的现场值：`exposure=9977`（另一次 13155）`gain=1024 iso=100 luma=50`。

### ⑤ 取证脚本不再抄 analyze() 【已落盘 + 设备验证】

**根因不是"忘了同步"，是"存在第二份真相"。** 旧 `forensic_v6_frame.py` 里抄了一份
`analyze_instrumented()`（约 145 行），已落后生产 4 次改动（c2 改判据 / c7 M2 / c8 M3 /
A′ 形心 / C 互斥 / center 字段）⇒ 它会产出"描述着不存在的闸"的现场报告，**比没有更坏**。

做法：生产 `analyze()` 新增可选 `trace=None` 参数（**默认 None ⇒ 线上行为逐字节不变、判定路径零开销**），
由它自己把中间量吐出来；取证脚本删掉副本，只负责呈现。

```
生产侧新增：analyze(..., trace=None) :247 与 _mark() :234
  各闸在 _bump 之后跟着一行 _mark(_tr, "<闸名>")，另无条件记 edge 贴边数
  闸的清单（AST 断言覆盖）：c1_area c2_border c3_aspect_extent c4_color_frac
                            c5_black_core c6_black_mutex c7_min_size
取证侧：def analyze_via_production() :118，删掉 analyze_instrumented
XCHECK 改为「按色重新打包后的闸计数」对「生产函数自己的 _REJ」逐闸复算
```

## 6. 纪律与坑（本轮新增/复述）

1. **任何"我改了 X"的声明必须落到行 + hash。** A′ 死代码就是这么被抓出来的。
2. **改完立刻 `py_compile`。** 本轮我真把生产文件写坏过一次（换行被写成字面量 `\n` ⇒ SyntaxError），
   当场编译才立即可见。
3. **不要重新推导，要取唯一真相。** ⑤ 与 ⑤b 是同一个病：抄一份 / 再算一遍 ⇒ 必然漂移。
4. **主机上没有 cv2 ⇒ 不要在主机上假装验证。** 设备上有真 cv2，且已有 3 张实拍可离线重放，
   比在主机的 OpenCV 5.0 上验强得多。`py -3 -m pip install opencv-python` 在这台机器上会解析到
   **5.0.0**（项目自述 pin 的 4.5.5.64 在 py3.14 上根本没有轮子），且会被 DSH 沙箱拒写 Temp ⇒ 别装。
5. **测试套件陷阱**（老账，仍有效）：`test_stage1_color_v6_pose.py` 里 test_30 是 expectedFailure、
   test_56 假绿、test_12 二分方向反了、test_17 用 red 画图却找 bin1。本机没 cv2 时它们**全部被 skip**，
   所以"绿"≠"验过"。
6. `ssh host "多行脚本"` 会被 PowerShell 啃引号并混入 CRLF/BOM（本轮又踩一次：`bash: line 1: ﻿cd: command not found`）
   ⇒ 用**单条无引号命令**。
7. MaixVision 只把**当前打开的那一个文件**推到 `/tmp/maixpy_run/` ⇒ 取证脚本按候选目录搜生产文件并打印路径+sha256。
