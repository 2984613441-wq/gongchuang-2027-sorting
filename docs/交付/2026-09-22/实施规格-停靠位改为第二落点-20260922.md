# 实施规格 · 停靠位改为第二落点（避让腿方案）— 2026-09-22

> **用户已确认**：夹爪停在第二落点 `(−95.0, +47.5)` 时，**MaixCAM 画面里看不到夹爪** ✓
> **为什么走这条路**：夹爪常驻负端角落会被相机判成"黑色件"（现场实测第 7 件）。
> HOME 迁移已独立审核判为弊大于利并**已回退**；本方案**不动上电原点**，只换停靠位。

## 一、设计（用户 2026-09-22 口头定稿）

```
上电原点 HOME = (−95.0, −97.5)  【不变】—— 负端硬限位，唯一绝对基准保住了
停靠/避让位 PARK = 第二落点 = (−95.0, +47.5)  【相机看不到夹爪，用户已确认】

① 起轮第一段：HOME → PARK
② 每件：PARK → PICK → PLACE → PARK
③ 全部件做完：PARK → HOME（回原点）
```

**附带好处**：落点 = 第二落点的那两件（2 号 / 5 号，`[DropPoints] 2 = -95.0, 47.5`）
⇒ 回程腿长度为 0 ⇒ **不增加任何时间**；其余件各多一小段（无合规风险，见下）。

**合规性（重要，已澄清）**：赛规 R-R04 判的是
「一键启动后 15 秒没有开始动作」与「落点后 15 秒屏幕无显示」，
**不是"单件必须 15 秒内完成"** ⇒ **机器在动时判据不成立** ⇒ 每件多几秒**无合规风险**，
只是总时长（决胜用）略增。
