## 三、🔴 必须补的 3 处（第 1 处是**红线级**，不改会顶死堵转）

```
【缺口1·红线】它自己拼 run_chain 命令起链 ⇒ **不走 p_go8.sh** ⇒ 不会做"起轮前把滑台
  从 HOME 送到 PARK(+145mm)"。而固件按"每件程序起点 = PARK"发增量 ⇒
  滑台在 HOME 时起链 ⇒ 第一段整体错 145mm ⇒ **顶死堵转**（= 项目 §四 禁令第 1 条）。
  证据：工具/pi_side/sh/p_go8.sh 中 "python3 /home/pi/pi_goto.py 0 145"（HOME→PARK）
       + 电控/firmware/stm32f407_m144z/App/Src/ec_motion_plan.c 的 leg1 起点 = PARK(-950,+475)
  修法：起链**一律** Popen("bash /home/pi/p_go8.sh", stdin=PIPE) 并写精确 "HOME\n"
       （p_go8.sh 已含：p_look2 粗筛 → HOME 门禁 → AVOIDANCE/HOME→PARK → 起链 → 提示收轮 back）
       ⇒ 同时天然满足"不许削弱 HOME 门禁"（门禁仍在 p_go8.sh 里，只是由 PIPE 喂 HOME）

【缺口2】派工 §2.2.1（用户已冻结）要求：**再按一下弹起 = 请求停止**（等价
  pkill -f "[r]un_chain.py"；**不动板子状态**、不发 STOP/HOME/RESET）。
  现实现只把"弹起"当 arming guard 解锁，**没有停止功能**，也没有"关掉停止"的开关。
  修法：释放沿（release edge）且 state==RUNNING 时执行 pkill；加一个开关
       STOP_ON_RELEASE（默认 True，理由：自锁按钮的第二次按下就是弹起 ⇒ 这是操作员唯一的
       受控停止手段；误碰代价 = 丢一轮，故保留开关可关）。

【缺口3】今晚新查出的硬约束没写进去：**板子同一次上电只允许跑一轮**。
  根因：板子轮内 success_count 只在【开机】或【FAULT_LOCK 下按物理 START】复位
       （电控/stm32_logic/src/ec_protocol_gateway.c:282 与 :506-508），
       而链每轮自称新轮次却不做握手 ⇒ 同一次上电跑第 2 轮，第 1 件的 DISPLAY_ACK 必被
       0x13(ACK_NOT_APPLICABLE) 拒 ⇒ 卡死。（证据见交接文件 §13.1/§13.5）
  修法：起链前拦截 —— 读板子 TICK_MS 得开机时刻（/home/pi/pi_status_once.py 的
       "AXIS ... TICK_MS=<ms>"），若 /home/pi/logs/round-R8-*.log 里有任一轮的最后写入时刻
       **晚于开机时刻** ⇒ 判定"本轮次已跑过" ⇒ **拒绝启动**并提示"推到底 + 断电上电"。
       允许用环境变量 ALLOW_SAME_BOOT=1 跳过（默认拦）。
```

## 四、接线（**用户做，你只写清规格**）

```
NO-A → 树莓派 GPIO23 = 物理针 16
NO-B → GND        = 物理针 14
🔴 NO 两脚【只接 GPIO 与 GND，绝不接电源】——厂商资料的"接线案例1/2（用按钮切电源）"
   本项目禁止：会把电源灌进 GPIO23 ⇒ 烧 GPIO / 烧树莓派
软件侧：GPIO23 输入 + 内部上拉（按下=读 0）
   已核实树莓派上 pigpio 可用且 pigpiod 在跑（/home/pi/pi_pw.py 用的就是它）⇒ 可用 pigpio 读；
   RPi.GPIO 也在（但别和 pigpio 抢同一批脚；GPIO17/18 已被转盘占用，不可用）
灯：接【独立电源】（先量额定电压），不要用 GPIO 直驱
```
用户 2026-09-22 确认买的是【**自锁**】按钮 ⇒ 语义：按下锁定=请求启动一轮；再按弹起=请求停止；
持续按住不得重复触发（边沿触发 + 去抖）。**arming guard 是必须的**：上电后必须先见到一次
"断开"才允许把"闭合"当启动请求（自锁开关会物理记住上次状态，而 R-R01 要求上电处于待机）。

## 五、部署到树莓派（**先请用户确认，再执行**）

```bash
# 1) 传文件（用 base64 走 stdin，别把内容塞进命令行——大文件会 WinError 206）
scp 工具/pi_side/pi_onkey.py        pi@172.20.10.8:/home/pi/pi_onkey.py
scp 工具/pi_side/pi-onkey.service   pi@172.20.10.8:/tmp/pi-onkey.service
# 2) 安装服务
ssh pi@172.20.10.8 "sudo cp /tmp/pi-onkey.service /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl enable --now pi-onkey.service"
# 3) 看日志
ssh pi@172.20.10.8 "journalctl -u pi-onkey -n 50 --no-pager"
```
⚠️ service 里 `User=` 建议 **pi**（不是 root）：p_go8.sh 要读 /dev/serial0（pi 已在 dialout 组），
   而 pkill 停链也只作用同一个用户的进程。
