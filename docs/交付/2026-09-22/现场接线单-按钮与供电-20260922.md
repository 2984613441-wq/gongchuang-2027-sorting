## 一、两个降压模块的分工（就按这个配）

| 模块 | 带什么 | 输出电压 | 理由 |
|---|---|---|---|
| **5A** | 树莓派 + MaixCAM（Type-C）+ HDMI 屏 | **5.1V**（≤5.25V） | 峰值 ~3~4.5A，5A 留余量 |
| **3.5A** | 转盘舵机（MG996R）+ 夹爪/Z 舵机（+ 屏可选挪这边） | **5.8~6.0V** | 舵机正常 ~1A、单只堵转 2.5A；不要超 6V |

```
12V 电池 ─[总开关 + 保险]─ 【12V 公共点】
    ├→ A4988① VMOT（12V 直给，不动）
    ├→ A4988② VMOT（不动）
    ├→ 3.5A 模块 IN+ / IN−  →  5.8~6.0V  → 舵机（+ 屏）
    └→ 5A   模块 IN+ / IN−  →  5.1V      → 树莓派 + MaixCAM
所有 GND 星型汇到【GND 公共点】：电池−、两个模块 OUT−、A4988 GND、STM32 GND、舵机 GND、屏 GND、Pi GND
```
**四条红线**
```
🔴 两个模块的**输出绝不并联**（会互相灌）
🔴 树莓派**不要同时**用 USB-C 和排针两处供电（Pi4 的排针 5V 与 USB-C VBUS 是连通的）
🔴 绝不把 5V 接到 3.3V（物理针 1 / 17）
🔴 舵机的电源/地线单独走，**不要经过树莓派或屏的支路**
```
**接线前先量**：两个模块**空载输出**分别调到 5.1V 和 5.8~6.0V，量准了再接负载 ✓

## 二、树莓派 5V 接哪几个针

```
5V  →  物理针 2（或 4）
GND →  物理针 6（或 34）
```
电容：**Pi 入口就近 1000µF 电解 + 0.1µF 陶瓷**；MaixCAM 的 Type-C 入口 100µF + 0.1µF

## 三、一键启动按钮（带灯自锁，4 线）

```
黑色两条 = NO 触点（无极性）：
   一根 → 物理针 36（GPIO16）
   另一根 → 物理针 34（GND）
🔴 触点两脚只接 GPIO 与 GND，**绝不接任何电源**（接电源=把 5V/12V 灌进 GPIO ⇒ 烧 GPIO/烧树莓派）

红色两条 = 灯（+ / −）：
   红(+) → 12V（总开关/保险之后）
   红(−) → GND 公共点
   ⚠️ 先确认灯的额定电压：不确定就**先用 5V 试**（12V 灯用 5V 只会偏暗，不会烧）；
      千万别直接拿 12V 怼未知灯（若是 5V 灯会烧）。稳妥做法：串 1kΩ + 5V 试，亮了再降阻/加压
   ⇒ 这样接 = "上电就亮"的电源指示灯（推荐）
      若要让灯显示"本轮在跑"，需要另加三极管/MOS 由 GPIO 驱动（可不做）
⚠️ 灯的线要与串口线/步进线/舵机线分开走
```
**为什么用 GPIO16 而不是文档里写的 GPIO23**：实测 `/boot/config.txt` 里有
`dtoverlay=gpio-ir,gpio_pin=23`（红外接收占用了 GPIO23）、`gpio-ir-tx,gpio_pin=22`（GPIO22 也被占）
⇒ 用 GPIO16 不用改系统配置、不用重启 ✓（软件里 `BUTTON_PIN` 由 23 改 16，一行）

## 四、MaixCAM（摄像头）

```
数据：MaixCAM ──WiFi──▶ 树莓派 172.20.10.8:8765（TCP）
```
