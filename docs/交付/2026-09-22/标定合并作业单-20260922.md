## §0 为什么合并、以及一条必须遵守的口径（别改回去）

```
链只需要【像素 → 滑台记账 PICK】。把它拆成 affine + ToolOffset 时，平移部分**不可辨识**：
    数据只能定出 (tx+ox, ty+oy)；任何 (tx+δ, ox−δ) 观测完全一样
⇒ 可辨识的只有共形 4 参：  Px = a·u + b·v + cx ,  Py = b·u − a·v + cy
⇒ 本次标定的目标 = 直接解这 4 个；ToolOffset 保持**机械真值**（不动它），
   写盘时令  tx = cx − ox , ty = cy − oy
   （与 pixel_to_device.py「device = affine(px)，PICK = device + ToolOffset」完全等价）

点数：≥3 才有残差；**本次用 5~6 点**（4 个未知数 ⇒ 5~6 点给 6~8 个自由度）
```

## §2 第 1 阶段：测点（我开车、你只做"对正 + 画圈"）

**布点**：在可用区内取 **5~6 个点**，覆盖四角 + 中心。可用区（推算值，本次会被实测修正）
= `x[−95, +18.4] × y[−97.5, +9.4]`（上界由相机视场定，下界由机械原点定）。
⚠️ 避开负方向两条死带：`x < −95`、`y < −97.5`（越过机械原点，夹爪到不了）。

**每个点的 7 步**（沿用 2026-09-21 已验证流程 `夹取点标定-精确法3点-20260921.md:33-43`）：

```
① 我把夹爪开到【精确滑台坐标 P】（STEP_RESULT=1；负位移带 --allow-neg）
② 你把件塞进爪片开口、对到正中
③ 你在托盘上对着件画圈（= P 的物理锚点）
④ 你把件取出
⑤ 我把夹爪移开（+120mm）
⑥ 你把件放回圈里
⑦ 我读像素 ⇒ 得到一对 (P, 像素)
```
🔴 **必须第 ⑤ 步移开夹爪再读**：件卡在爪片里读像素会偏 **(−27,−53)px**，且颜色会被阴影压暗导致
**类别误判**（同文档 `:26-28` 实测）。
🔴 **不许目视报残差**（老方法的 ±5mm 噪声就是这么来的，同文档 `:3-5`）。
🔴 **不要用 ToolOffset 去补残差**（§10.4 的教训）。
