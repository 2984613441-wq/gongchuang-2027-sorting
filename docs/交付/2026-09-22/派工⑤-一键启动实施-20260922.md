## 二、必须改的 5 处（前 4 处是 DSH 已评审过的返工点）

```
1) 🔴 起链改走 p_go8.sh：Popen(["bash","/home/pi/p_go8.sh"], stdin=PIPE, ...) 并写 "HOME\n"
   （原实现自己拼命令 ⇒ 不送 PARK ⇒ 红线）
2) 🔴 RUNNING 判据改用 **pgrep -f "[r]un_chain.py"**，不要用子进程 poll()
   （p_go8.sh 内部是 `nohup python3 deploy/run_chain.py … &` + `sleep 30` ⇒ 脚本会先退出，而链还在跑
    ⇒ 用 poll() 会误判"链已退出"并可能**起第二条链抢 /dev/serial0**）
   同时：起链前查"链已在跑"⇒ 拒绝启动
3) 🔴 缺"释放沿=停止"：RUNNING 下 release 沿 ⇒ 等价 `pkill -f "[r]un_chain.py"`，
   **不动板子状态**；停止后状态回 **STANDBY**（不是 FAULT）；加开关 STOP_ON_RELEASE（默认 True）
4) 🔴 缺"同一次上电只允许跑一轮"拦截：读板子 TICK_MS 得开机时刻
   （`python3 /home/pi/pi_status_once.py` 的 `TICK_MS=<ms>`），若 `/home/pi/logs/round-R8-*.log`
   里有任一轮的**最后写入时刻 > 开机时刻 + 5s** ⇒ 拒绝启动并提示"推到底 + 断电上电"；
   允许 ALLOW_SAME_BOOT=1 跳过。⚠️ 判据只认链自己的 `round-R8-*.log`；
   自己的日志请用 `onkey-*.log` 命名（避免与缺口3 的 glob 自撞）
5) 🔴 `BUTTON_PIN` 由 **23 改成 16**（GPIO23/22 被 `/boot/config.txt` 的 `dioverlay=gpio-ir` /
   `gpio-ir-tx` 占用；GPIO16 = 物理针 36 ✓ 实测空闲）
   ⇒ 接线（**用户 2026-09-22 已接好**）：NO 黑线一根→**物理针 36 = GPIO16**，另一根→**物理针 9 = GND**
     （排针上 8 个 GND 是同一网络，用哪个都行；**信号脚必须是 GPIO16**）；灯：红(+)→12V、红(−)→GND 公共点
```
