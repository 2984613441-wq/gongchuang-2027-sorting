#### 步骤 2：创建带自启逻辑的启动脚本

在 **本地** 创建文件 `C:\Users\29845\Desktop\工创赛\视觉\src\maixcam_deploy\main_autostart.py`：

```python
"""MaixCAM 自启动入口：网络就绪等待 + 互斥锁 + stage1_color_v6_send.py

设计约束：
  1. 网络未就绪时等待最多 30 秒（每 2 秒探测一次）
  2. 超时后仍启动（避免网络故障导致永久无视觉）
  3. 通过 /tmp/vision_lock 互斥，取证时不启动生产程序
  4. 启动失败写 /tmp/vision_error.log，便于排查
"""

import os
import sys
import time
import socket
import subprocess

GATEWAY_HOST = "172.20.10.8"
GATEWAY_PORT = 8765
NETWORK_WAIT_TIMEOUT = 30  # 秒
NETWORK_PROBE_INTERVAL = 2  # 秒
LOCK_FILE = "/tmp/vision_lock"
ERROR_LOG = "/tmp/vision_error.log"
PRODUCTION_SCRIPT = "/root/stage1_color_v6_send.py"


def log_error(msg: str):
    """记录错误到日志文件"""
    try:
        with open(ERROR_LOG, "a") as f:
            f.write(f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] {msg}\n")
    except Exception:
        pass


def check_network() -> bool:
    """检查网络是否就绪（能连上树莓派网关）"""
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.settimeout(1.0)
        s.connect((GATEWAY_HOST, GATEWAY_PORT))
        s.close()
        return True
    except Exception:
        return False


def wait_network():
    """等待网络就绪，超时后仍返回（避免永久卡死）"""
    print(f"[AUTOSTART] 等待网络就绪 ({GATEWAY_HOST}:{GATEWAY_PORT})...")
    start = time.time()
    attempt = 0
    
    while (time.time() - start) < NETWORK_WAIT_TIMEOUT:
        attempt += 1
        if check_network():
            elapsed = time.time() - start
            print(f"[AUTOSTART] 网络就绪（耗时 {elapsed:.1f}s，尝试 {attempt} 次）")
            return True
        time.sleep(NETWORK_PROBE_INTERVAL)
    
    elapsed = time.time() - start
    msg = f"[AUTOSTART] 网络超时（{elapsed:.1f}s，尝试 {attempt} 次），仍继续启动"
    print(msg)
    log_error(msg)
    return False


def check_mutex() -> bool:
    """检查互斥锁（取证脚本运行时不启动生产程序）"""
    if os.path.exists(LOCK_FILE):
        print(f"[AUTOSTART] 检测到互斥锁 {LOCK_FILE}，退出（取证模式）")
        return False
    return True


def main():
    print("[AUTOSTART] ========== MaixCAM 视觉自启动 ==========")
    print(f"[AUTOSTART] 时间：{time.strftime('%Y-%m-%d %H:%M:%S')}")
    
    # 互斥检查
    if not check_mutex():
        sys.exit(0)
    
    # 网络等待
    wait_network()
    
    # 检查生产脚本是否存在
    if not os.path.exists(PRODUCTION_SCRIPT):
        msg = f"[AUTOSTART] 生产脚本不存在：{PRODUCTION_SCRIPT}"
        print(msg)
        log_error(msg)
        sys.exit(1)
    
    # 启动生产程序
    print(f"[AUTOSTART] 启动生产程序：{PRODUCTION_SCRIPT}")
    try:
        # 使用 exec 替换当前进程（避免多一层进程）
        os.execv(sys.executable, [sys.executable, PRODUCTION_SCRIPT])
    except Exception as e:
        msg = f"[AUTOSTART] 启动失败：{e}"
        print(msg)
        log_error(msg)
        sys.exit(1)


if __name__ == "__main__":
    main()
```

## 三、网络未就绪重试策略

### 3.1 重试参数

| 参数 | 值 | 理由 |
|------|-----|------|
| **超时时间** | 30 秒 | 覆盖正常网络初始化（实测 5-10 秒） + 2× 余量 |
| **探测间隔** | 2 秒 | 避免频繁连接消耗资源，同时不过于稀疏 |
| **探测方式** | TCP connect 到 `172.20.10.8:8765` | 最直接的验证方式（ping 可能通但端口未监听） |
| **超时后行为** | **仍启动**（写日志） | 避免网络故障导致视觉永久挂掉 |

### 3.2 失败处理

**场景 1：网络永久不通**  
→ 30 秒后仍启动，但 `stage1_color_v6_send.py` 内部会持续重连（已有逻辑）

**场景 2：启动脚本本身失败**  
→ 写 `/tmp/vision_error.log`，用户可通过以下命令查看：
```bash
ssh root@172.20.10.9 "cat /tmp/vision_error.log"
```

```python
import os

            f.write(f"forensic {os.getpid()}\n")

    except Exception as e:
        print(f"[FORENSIC] 创建锁文件失败：{e}")
        sys.exit(1)
    
    try:

    finally:
```

## 七、最坏情况与风险

### 7.1 风险矩阵

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 自启脚本死循环 | 低 | 中 | 超时后仍启动 + 错误日志 |
| 网络永久不通 | 中 | 低 | 30 秒后仍启动，`stage1_color_v6_send.py` 内部会持续重连 |
| 取证时启动冲突 | 低 | 中 | 互斥锁 + 取证脚本优先 |
| `/root/main.py` 覆盖现有重要文件 | 低 | 高 | **步骤 1 强制备份** |
| MaixCAM 不支持 `/root/main.py` 自启 | 中 | 高 | 见 §1.2 查证命令，若不支持则改用 systemd/cron |

### 7.2 最坏情况

**场景**：MaixCAM 不支持 `/root/main.py` 自启机制

**后果**：自启脚本不会自动运行，仍需手动启动

**应对**：
1. 通过 §1.2 的查证命令确认真实自启机制（systemd / cron / rc.local）
2. 改用 systemd service 或 cron @reboot
3. 示例 systemd service（备选方案）：

```ini
# /etc/systemd/system/vision-autostart.service
[Unit]
Description=MaixCAM Vision Auto-start
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/usr/bin/python3 /root/main.py
Restart=on-failure
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

启用方式：
```bash
ssh root@172.20.10.9 "systemctl daemon-reload && systemctl enable vision-autostart.service && systemctl start vision-autostart.service"
```
