## 六、现场纪律 / 已经付过学费的坑

1. **上电即原点**：必须先把 X/Y 推到负向机械极限顶住，**再上电**；绝不能先上电再推。
   故障按 **RESET，不要断电**（断电会丢原点）。
2. **`STEP_RESULT=1` 只证明"脉冲发完了"，不证明"到位了"** —— 开环步进堵转/打滑时照样报成功。
3. **每次运动先公告**，公告当方程读：`起点 + Δ = 终点`，X 和 Y 都要核。
4. **先走横向余量大的那个轴**；最后一段从正 −Y 方向直套上去。
5. **件塞在爪片里时不要读视觉** —— 实测遮挡偏差可达 (−27,−53) px、还会把 class 判错。
   正解：对正 → 画圈做记号 → 取出件 → 夹爪让开 → 件放回圈里 → 再读。
6. **PowerShell → ssh 的双引号会被啃掉**：`printf "845\n"` 会写成 `845n`。用 `echo 845 > file` 这种无引号写法。
7. **`ps`/`pkill`/`timeout` 在 MaixCAM(busybox) 上没有**；Pi 上有 `pkill` 和 `timeout`。
8. **改脚本入口前先 grep 全部调用方**（曾因漏 grep 导致 11 个启动脚本全部拒启）。
