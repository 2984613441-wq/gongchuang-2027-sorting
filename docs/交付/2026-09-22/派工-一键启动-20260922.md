### 2.1 `pi_onkey.py` 状态机

```
STANDBY → ARMED → RUNNING → （本轮结束）→ STANDBY
              ↘ FAULT（任何一步不成立就进这里，且**绝不派件**）

· 上电即 STANDBY，**不派件**（R-R01：上电后处于待机）
· 按钮按下（边沿）→ ARMED → 起轮（见 2.3）→ RUNNING
· 任何异常（GPIO 初始化失败 / 起链失败 / 链异常退出）→ FAULT + 明确日志 + 不派件
```

### 2.2 按钮接线与电气（**这部分由用户做，你只需在文档/注释里写清楚**）

```
NO-A → GPIO23（物理针 16）
NO-B → GND  （物理针 14）
输入配置 = 内部上拉（INPUT + PULL_UP），按下 = 读到 0
🔴 **NO 脚只接 GPIO 与 GND，绝不接任何电源**（接电源会烧 GPIO）
🔴 指示灯接【独立电源】：先测灯的额定电压再上电，不要用 GPIO 直驱
🔴 GPIO17 = 转盘索引、GPIO18 = 转盘 PWM ⇒ **已被占用，不可用**
🔴 必须用【点动按钮】；若用自锁按钮，必须【边沿触发 + arming guard】——
   即"必须先见到松开一次（release）才允许 arm"，否则上电时若按钮已闭合会立刻误启动

### 2.2.1 🔴 **用户 2026-09-22 确认：买的是【自锁】按钮** ⇒ 以下为强制要求

```

  它会把电源直接灌进 GPIO23 ⇒ 烧 GPIO/烧树莓派。资料只用于认脚位。）

语义（自锁特有，必须按此实现）：
   按下锁定  = 请求启动（一轮）
   再按弹起  = 请求停止（等价于现场手法 `pkill -f "[r]un_chain.py"`：
