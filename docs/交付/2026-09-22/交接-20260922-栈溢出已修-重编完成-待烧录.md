## 3. 🔴 三处必须知道的更正（否则下一轮会误判）

### 3.1 「峰值链未必经过 `ec_app_start_motion`」——**错，它确实经过**

链接图原文（改前）是：
```
Max Depth = 1208
Call Chain = main ⇒ ec_app_poll ⇒ ec_app_poll_motion ⇒ ec_app_handle_transition
           ⇒ ec_app_start_motion ⇒ ec_axis_driver_start_pick_place ⇒ … ⇒ __aeabi_uldivmod
```
⇒ 改 `static` 是**直接削峰值链**。实测削减 **728 B**（1184 → 456），与逐层加算完全吻合。

```
Max Depth = 976   （改前也存在，976 < 1024，只差 48 B 就溢出）

           ⇒ ec_diag_process_line ⇒ ec_motion_test_start_steps ⇒ … ⇒ __aeabi_uldivmod
```
⇒ **若只做 `static` 而不加栈，余量只剩 4.7%，远达不到 25% 判据。两条必须都做。**
