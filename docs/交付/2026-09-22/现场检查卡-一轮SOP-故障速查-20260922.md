# 现场开工检查卡 · 一轮操作 SOP · 故障速查（2026-09-22 定版）

> 用法：**跑每一轮之前照①逐条打勾**；跑的时候照②；出问题查③。
> 全部条目都来自实测踩坑（今天一整天），不是纸上推演。

---

## ① 开工前检查（每轮都做，缺一不可）

| # | 检查项 | 判据 | 怎么查 |
|---|---|---|---|
| 1 | **电池电压（静置）** | **≥12.5V** | 万用表量 12V 电池端 |
| 2 | **电池电压（带载）** | **≥11.5V**、压降 ≤0.5V | 跑起来、电机在动时量 |
| 3 | **树莓派供电** | `throttled` **低两位 = 0**（0x0 或 0x50000 都算过） | `vcgencmd get_throttled` |
| 4 | **串口** | 连测 3 次全 **`PING -> OK PONG`** | `python3 /home/pi/pi_status_once.py` |
| 5 | **板子本轮未跑过** | `MOVES=0` **或** 刚断电上电过 | 同上（看 AXIS 行） |
| 6 | **相机在发数据** | sender 进程在跑 | 相机上 `ps \| grep stage1`（或看它屏幕有识别框） |
| 7 | **转盘通路** | `pi_pw` 有 **1 个**进程、`pw.txt = 1500` | `pgrep -f pi_pw.py`；`cat /home/pi/pw.txt` |
| 8 | **一键启动服务** | `is-active = active`、按钮**松开**状态 | `systemctl is-active pi-onkey`；服务日志看"按钮初始值 = 1" |
| 9 | **链没在跑** | 没有 `run_chain.py` 进程 | `pgrep -f run_chain.py` |
| 10 | **机构安全** | 手/物离开运动范围；急停（断电）在手边 | 目视 |

**三条硬红线（任一不过就不跑）**：#1 #2 #3。今天所有怪现象都出在这三条上。

## ② 一轮操作 SOP

```
1. 摆件：放进**可抓区中间**（避开靠外区域 —— 今天多次出现"算出 PICK=(-14.6,-103.0)mm 不在工作区"的拒识）
2. 检查滑台在 HOME 附近；确认转盘指向 A 侧（链开工自检会摆到 A 侧并打日志"已摆到 A 侧（货格 1）"）
3. 若板子本轮已跑过 ⇒ **板子断电 5 秒再上电**（板子同一次上电只允许跑一轮）
4. **按一下按钮** ⇒ 链自动起（p_go8.sh：HOME 门禁 → 送 PARK +145mm → 起链）
5. 盯屏幕：应显示**逐件累加表格**（序号/货物名称/图片/分拣成功总数量；最新行高亮；最多 6 行）
6. 跑完看日志收尾：应出现
     "空闲 15.0s 无新件（阈值 15.0s）⇒ 判本轮结束，干净收场，退出码 0。**不向 STM32 发任何停止/复位命令**"
7. 记录本轮：派发件数 / 成功计数（"本轮汇总: 派发 N 件, 成功计数 M"）
```

### 想中途停链
- **运行中再按一下按钮** ⇒ 停链（只杀树莓派的链，**不给板子发任何停止/复位命令**）
- 停完要再跑 ⇒ **板子必须断电上电**（同一次上电只允许一轮）

## ③ 故障速查（今天实测过，按症状查）

| 症状 | 最可能原因 | 处置 |
|---|---|---|
| `throttled` 有低两位（0x…1 / 0x…5） | 逻辑侧供电不足 | 换满电电池 / 逻辑侧用充电宝单独供电（实测有效 ✓） |
| 串口**乱码** | 欠压 ⇒ UART 电平不稳 | 先解决供电；再看共地 |
| 串口**完全无应答**（PING 空） | 板子没上电 / 串口线松 / 共地断 | 查板子电源灯、量板子 5V、查针 8/10 与共地 |
| X/Y **原地抖、走不到位** | 12V 电池电压低（11.3V ⇒ 步进失步）✗ | 换满电电池（充半小时不够 ⇒ 需约 1.5 小时） |
| 板子收到 ITEM_TASK 后**不回报** | 动作走不完（同上，动力不足/卡阻/驱动电流）| 查 12V 带载电压 → A4988 电流 → 机械卡阻 |
| 转盘**一直在动/乱转** | `pw.txt` 被写成非中位的角度（1500=A 侧、2155=B 侧，两者都合法）| 属正常翻转；若转到位还持续动 ⇒ 查该角度是否顶到机械端点 |
| 转盘**完全不动** | `pi_pw.py` 没在跑（它是链的必需搭档 ✗ 不能杀）| `sudo /etc/init.d/S98turntable start` |
| 夹爪**没抓取** | ①急停被拉低 ②舵机供电 ③机械连杆 ④时机/数值 | 用台架：`python3 /home/pi/pi_servo_bench.py`；注意 **ARM 是一次性授权**（每条命令前都要 ARM） |
| 屏幕**没显示四栏/表格** | ①图片缺失（fail-closed 不落屏）②渲染异常 | 看日志有无 `货物图片加载失败 image_id=…` |
| 屏幕**第一件前闪"识别到待分拣物体"** | 正常 ✓（只在第一件之前画一次） | 不用管 |

## ④ 两条"绝不能做"（今天踩过）

```
✗ 不要杀 /home/pi/pi_pw.py —— 它是**链的必需搭档**（链只写 pw.txt，真正输出 GPIO18 的是它）
  杀掉的表现：转盘一格不动、而且链**不报错**（最难查的一种）
✗ 不要在同一条串口上同时跑链和台架 —— 两者共用 USART2 ⇒ 会互相干扰（今天因此空跑一轮 ✗）
  纪律：要台架就停链；要跑轮就只按按钮
```
