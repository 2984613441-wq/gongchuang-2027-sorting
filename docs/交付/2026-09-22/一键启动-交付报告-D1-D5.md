### 决策 1：HOME 门禁绕过方案

**问题**：
[电控/deploy/run_chain.py:607-643](电控/deploy/run_chain.py#L607-L643) 的 `require_home_confirmation()` 要求 stdin 精确输入 `"HOME"`，非交互环境一律拒绝 `--start-round`。

**证据**：
```python
# 电控/deploy/run_chain.py:635
answer = input_fn("确认滑台已在 HOME 后输入 HOME（其他输入均退出）：")
# :641
```

`subprocess.Popen(..., stdin=subprocess.PIPE)`，写入精确的 `"HOME\n"`（参考 [工具/pi_side/sh/p_go8.sh:87](工具/pi_side/sh/p_go8.sh#L87) `echo HOME | nohup python3 ...`）。

### 决策 3：Arming Guard 实现

**需求**：
[docs/交付/2026-09-22/派工-剩余任务-20260922-晨.md:35](docs/交付/2026-09-22/派工-剩余任务-20260922-晨.md#L35)  
"自锁按钮必须【边沿触发 + arming guard（先见过松开一次）】"

**实现**：
1. `setup()` 时读取初始值，若 = 0（按下）→ `arming_guard_released = False`
2. `poll_button()` 检测到 `release` 事件 → `arming_guard_released = True`
3. `press` 事件只有在 `arming_guard_released == True` 时才触发起链

**分档**：事实  
**置信度**：5/5

---

### 决策 4：Fail-Closed 原则

**要求**：
[docs/交付/2026-09-22/派工-剩余任务-20260922-晨.md:37](docs/交付/2026-09-22/派工-剩余任务-20260922-晨.md#L37)  
"GPIO 初始化失败则禁止派件、停止服务时释放 GPIO（不发运动命令）"

**实现**：
- GPIO 初始化失败 → 直接进 `State.FAULT`，抛异常退出
- 起链失败 → `State.FAULT`（不重试、不掩盖）
- 链异常退出（退出码 ≠ 0）→ `State.FAULT`
- `State.FAULT` 时不处理按钮、不起链，只等停止

**分档**：事实  
**置信度**：5/5
