## 三、**v2 最终方案**（三件，按"最省事且够用"重排）

### 件① 相机开机自启（分三步，每步都能停）
```
第 0 步【必做·用户执行】先查证设备的自启机制（不查清就动手 = 赌）：
    ssh root@<相机IP> "ls -l /root/main.py 2>&1; head -5 /root/main.py 2>&1"
    ssh root@<相机IP> "ls /etc/init.d/ 2>/dev/null; cat /etc/rc.local 2>/dev/null; systemctl --version 2>/dev/null | head -1; ls /etc/systemd/system/ 2>/dev/null | head"
    断电上电后立刻： ssh root@<相机IP> "ps aux | grep -E 'python|maix' | grep -v grep"
第 1 步【首选·0 行代码】若 `/root/main.py` 是自启入口 ⇒ 直接指过去：
    ssh root@<相机IP> "cp -p /root/main.py /root/main.py.bak-$(date +%Y%m%d-%H%M%S) 2>/dev/null; ln -sfn /root/stage1_color_v6_send.py /root/main.py; ls -l /root/main.py"
    ⇒ 覆盖"断电重启"；**不覆盖崩溃**
第 2 步【需要自愈时】若设备有 systemd ⇒ 用它的 Restart（不写自定义循环）：
    /etc/systemd/system/vision-sender.service  →  ExecStart=/usr/bin/python3 /root/stage1_color_v6_send.py
                                                Restart=always / RestartSec=3
    ⇒ 覆盖"崩溃自愈"，且启动顺序/日志交给 init
第 3 步【兜底·无 systemd 且无 main.py 自启】才写 3 行监督循环（**无网络探测、无互斥**）：
    while :; do python3 /root/stage1_color_v6_send.py; sleep 2; done
```
