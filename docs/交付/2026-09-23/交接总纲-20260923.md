## 3. 现场 SOP（★ 照做即可）

### 3.1 每轮开跑四步（**顺序不能错**）
```
① 推到底：滑台推到 负X最里、负Y最里（= HOME(−95.0,−97.5)）
② 断电 5 秒
③ 上电（此刻它在 HOME ⇒ 原点正确）
④ 按一下开关（p_go8.sh 会先把它送到 PARK，再起链）
```
⚠️ 顺序颠倒 ⇒ 原点错 ⇒ 固件按 PARK 发的增量整体偏 **145mm** ⇒ 顶死堵转
⚠️ 省掉断电 ⇒ 板子带着上一件未结清任务 ⇒ 后面每件被 `NACK_SINGLE_TASK_ONLY` 拒

### 3.2 摆件纪律
```
· 每波 **2~3 件**（用户 2026-09-23 验证：比一次摆 6 件稳得多）
· 摆在托盘**中部**、件与件**间距 ≥5cm**、**离边 ≥3cm**
· 件太靠 −Y 最里侧 ⇒ 抓取点会被钳到边界(y=−97.5) ⇒ 只能夹外缘 ⇒ **易夹空** ✗
· 可抓窗口（物块坐标）：X ∈ [25.5, 210.5]、Y ∈ [−54.0, 136.0]
· 三棱柱不做特殊排序（用户裁决）；六类都要摆（赛题要求）
```

### 3.3 光照（今晚多项症状的共同根因）
```
相机 LOCK_AE_AWB = False（自动曝光/白平衡未锁）⇒ 光照一变六色 HSV 判定整体漂 ✗
⇒ 表现：同一件时好时坏 / 幻影忽多忽少 / 贴边件忽然认不出
现场做法（零代码、零风险）：**固定光照** —— 拉窗帘、开固定那盏灯，
  跑轮全程别开关灯、别让人站旁边挡光。相机那盏灯尤其不能碰。
根治＝锁 AE/AWB ⇒ 但**六色阈值必须全部重标**（约 30~60 分钟）⇒ 赛前不做。
```

### 3.4 两个常见故障的处置
| 现象 | 真因 | 处置 |
|---|---|---|
| 按开关后**什么都不动** | 板子没上电/无应答（链日志里 `PING -> (no reply)`、每件 `ITEM_TASK 超时 5.0s 无应答`） | 查板子电源灯+串口线 ⇒ 走 3.1 四步 |
| 每件都被拒、日志 `NACK_SINGLE_TASK_ONLY` | 板子有未结清任务（多因上一轮没断电就开新轮） | 走 3.1 四步（唯一处置） |
| 末尾多出一件"黑色圆柱" | **幻影**：夹爪/轴架被当成黑件（静止、同色） | 无需处理：真件已分完，只多跑一趟约 13 秒；评委问起就说明是视觉误判 |
| 相机"看不到东西" | 相机 VI 卡死（我取图时报 `mmf vi init failed`） | **给 MaixCAM 断电 10 秒再上电**（重启服务救不回来） |

### 4.4 测"一轮跑得对不对"（看日志 6 行）

| 要看的行 | 含义 | 合格标准 |
|---|---|---|

| `MOTION_DONE accepted` + `ITEM_RESULT accepted` | 板子完成 | 每件都有 |
| `边缘件钳位` | 该件中心超出范围、被钳到边界 | **出现越多越不稳**，应把件往中间摆 |
| `本轮汇总: 派发 N 件, 成功计数 M` | 收尾 | N==M 且与台上件数一致 |
