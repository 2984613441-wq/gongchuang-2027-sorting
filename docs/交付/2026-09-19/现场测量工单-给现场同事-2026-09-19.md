## ⚠️ 一、先读安全须知（很重要，涉及设备损坏）

1. **这台机器的 X、Y 轴没有限位开关**。也就是说：**推过头它不会自己停，也不会报警，只会硬顶住**，
   顶住会导致"丢步"，而丢步之后机器的坐标基准就永久失准了（要重新标定）。
   ⇒ **任何时候不要用力推滑台、不要推到听见电机/机构顶死的声音就继续推。**
2. **机器通电、程序在跑的时候，绝对不要拔插串口线、不要插着电脑去看串口。**
3. **机器出故障（不动了 / 失控 / 卡住）时：按板子上的 `RESET` 按钮，不要直接关电源。**
   关电源会丢位置信息。
4. **机器运动时，手不要伸进托盘区域。**
5. 如果完全不确定某件事能不能做，**停下来问，不要试**。

我（AI）看不到这台机器的样子，很多判断做不了，就是因为缺照片。**请拍下面 8 张，尽量拍清楚、光线够。**

| 编号 | 拍什么 | 怎么拍 |

## 📏 三、任务 B：用尺量 5 个数

**所有长度统一用毫米（mm）**，量不准就写"约 205"。

| 编号 | 量什么 | 怎么量 | 写 |
|---|---|---|---|
| B1 | **托盘 X 方向全长** | 从托盘最内角，沿**长边**量到另一端 | ______ mm |
| B2 | **托盘 Y 方向全长** | 从托盘最内角，沿**短边**量到托盘近端边 | ______ mm |
| B3 | **橙色圆柱直径** | 量这个物块的直径（最宽处） | ______ mm |
| B4 | **相机中心落点的 X 距离** | 从托盘最内角，沿长边，量到"**相机镜头正下方那个点**"（可以吊一根线/拿个重物垂下，对准镜头中心，看它落在托盘哪里） | ______ mm |
| B5 | **相机中心落点的 Y 距离** | 同上，但沿短边量 | ______ mm |

> **B4/B5 的做法**：拿一根线，一头挂在相机镜头正中央，另一头吊一个小螺母让它垂下，
> 看螺母尖落在托盘上的哪一点 —— **从那点到托盘最内角的距离**就是你要量的。

## 🧊 四、任务 C：摆两个点（我来读数据，你只管摆）

**做之前先确认：托盘上没有别的东西挡路。**

| 步骤 | 做什么 |
|---|---|
| C1 | 把橙色圆柱放到托盘上**靠近最内角**的位置，**要完整落在黄色识别框里，不要贴边** |
| C2 | 用尺量：**物块中心**到托盘最内角的 X 距离、Y 距离（见下方"中心怎么量"） |
| C3 | 填表并**拍照**，然后告诉对接人"第 1 点好了" |
| C4 | 把物块挪到托盘上**离最内角尽量远**的位置（同样不要贴边） |
| C5 | 再量一次 X / Y 距离，填表、拍照，说"第 2 点好了" |

**"物块中心"怎么量**：
> 先量物块**靠最内角那一侧的边缘**到最内角的距离，**再加上半个直径**（= B3 ÷ 2）。
> 例：B3 = 30mm，边缘量得 120mm → 中心 = 120 + 15 = **135mm**。

## 🔧 五、任务 D：确认烧录的固件版本

这一条**需要接电脑**，如果没条件就跳过，告诉对接人"做不了"。

| 编号 | 做什么 | 结果 |
|---|---|---|
| D1 | 看板子上**型号丝印**（STM32F407 那块的完整型号），拍照 | |
| D2 | 最近一次**烧录固件的时间**是什么时候？烧的是哪个工程/哪个文件夹里的？ | |
| D3 | 烧录用的软件是 Keil 吗？工程文件路径还记得吗？拍照 | |
| D4 | 板子上有没有 **ST-Link / DAP 调试器**插着？拍照 | |

> **为什么要这个**：代码里有一个已修复的缺陷（叫 `RX-DEAF-FIX`，见
> `电控/firmware/stm32f407_m144z/App/Src/ec_board_stm32.c:38-48`），
> **如果板子上烧的还是修复前的版本，机器可能"跑着跑着突然完全没反应，按 RESET 才恢复"。**
>
> ⚠️ **更正**：2026-09-19 晚出现的 4 次"板子无响应"，**已确认是人为断电造成的，不是这个缺陷**。
> 所以这一项**不是紧急任务**，只是"顺便确认一下"，没有条件可以直接跳过。
> 但请务必确认一件事：**做任何测试前，板子必须是通电状态**（电源指示灯亮）。
