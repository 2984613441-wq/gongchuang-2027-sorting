## 三、整链启动前必须知道的

### 启动命令（`start_vision_bridge.sh` 端口写错，别直接用）

```bash
cd /home/pi/电控/deploy
export PYTHONPATH=/home/pi/电控/src:$PYTHONPATH
python3 run_chain.py --port /dev/serial0 --frame-output none \
    --round-id live --round-task-id 1 --names-file names.json --image-dir /tmp/images
```

🔴 **`start_vision_bridge.sh` 里写的是 `--port /dev/ttyAMA0`，是错的** ——
实机是 `/dev/serial0`（`→ ttyS0`，GPIO14/15）。Pi 上 `/dev/serial1 → ttyAMA0` 是蓝牙串口。
不直接跑 `run_chain.py` 会 `ModuleNotFoundError: No module named 'electrical_control'`（缺 PYTHONPATH）。

### 启动前硬不变式

**把滑台推到负向最里角**（X 负到底、Y 负到底）**再上电，或推到后按 RESET**。
整链的计划是**增量**且**假设起点是 HOME (−95.0, −97.5)**（`ec_motion_plan.h:178-181`）。
违反会导致第一段 `PICK−HOME = (+140.0, +65.0)mm` 撞停 —— **2026-09-18 已实测发生一次**。

### 其他

- `[BoxMap]` 为空 → **只警告不拒启动**（`run_chain.py:1030-1034`），`box_id=6` 直接用 `[DropPoints] 6`
- `[DropPoints]` 六格全是 `(20.0, 20.0)`；落点在装置坐标里，`(0,0)` = 装置中心
- `[PickPoint]`（`x=0.0, y=-45.0`）**只是"标定未加载"时的兜底**（`run_chain.py:747`）；
  标定已加载 ⇒ **整链走视觉**，不会用这个固定点
- `[ObjectHeights]` 有 `6 = 0.0` ⇒ 高度门禁放行
- 15 秒失活窗口在固件 `ec_app.c:553`，**只在 `DISPLAY_ACK` 时关闭**；配置里的
  `[Timeout]` 节已删（改 ini 无效，台账 E-31）
