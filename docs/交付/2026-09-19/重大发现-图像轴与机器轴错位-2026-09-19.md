# 重大发现：图像坐标轴与机器轴错位约 90°（标定不收敛的真正根因）

日期：2026-09-19
状态：**已实测确认并修复**，误差 190mm → 0.24mm

---

## 一句话结论

`calibration_config.ini` 里 `a12 = a21 = 0.0`（交叉项被冻结为零），但**交叉项才是主导项**。
相机/图传相对机器轴的偏转角约 **85°**，所以正确矩阵是：

```
a11 =  0.047142      a12 = -0.483206      tx = 148.453
a21 = -0.483206      a22 = -0.047142      ty =  52.105
```

旧值 `a11 = 0.55`、`a22 = 0.552` **算在了完全错误的轴上**。

---

## 怎么发现的（关键实验，一步定死）

把物块**沿机器 +Y 方向平移 30mm**（尺量），前后各读一次像素：

```
移动前： box_id=6  px=134  py=103
移动后： box_id=6  px= 72  py= 96
Δ像素 = (-61.5, -6)
```

**物块在机器 Y 方向走了 30mm，像素却几乎纯水平挪了 62px（竖直只带了 6px）。**

一台"u 对应机器 X、v 对应机器 Y"的相机，Y 方向位移必须产生**竖直**像素位移。
实测是水平的 ⇒ **图像 u 轴大致对应机器 Y 轴，v 轴大致对应 X 轴**（相机装歪约 85°）。

### 为什么以前一直没发现

配置里 `a11 ≈ a22`（0.55 / 0.552），"方形像素自检"因此一直通过 ——
**但两个值错得一样，自检通过恰恰是共模错误的表现，不是证据。**

affine = (cal.getfloat('a11'), cal.getfloat('a12'), cal.getfloat('tx'),

## 顺带修掉的 bug：`工具/pi_read_object.py` 拒识分支漏了交叉项

```python
# 旧（错）
rwx = raw_value("a11") * px + raw_value("tx")
rwy = raw_value("a22") * py + raw_value("ty")

# 新
rwx = raw_value("a11")*px + raw_value("a12")*py + raw_value("tx")
rwy = raw_value("a21")*px + raw_value("a22")*py + raw_value("ty")
```

这个 bug 在**越界点**上表现最恶劣：越界恰恰是最需要看数的时候，
而它会把一个 0.2mm 的正确标定报成 46mm 误差（漏掉 `a12*96 = -46.4`）。
**已修，已重新部署验证。**

## X 列已验证（2026-09-19 补测，6 个参数全部有实测依据）

物块**沿机器 −X 方向平移 20mm**（真值 105.0 → 85.0，Y 不变）：

```
box_id=6   px=70  py=138   （25 帧稳定）
算出 (85.1, 11.8) mm      真值 (85.0, 12.5) mm
误差 (+0.1, -0.7) mm      |误差| = 0.7 mm
```

### 两根轴交叉验证 —— 85° 偏转在两个方向上都成立

| 实验 | 位移 | 实测 Δ像素 | 预测 Δ像素 |
|---|---|---|---|
| +Y 30mm | 纯 Y | (-61.5, -6) | 几乎纯**水平** |
| −X 20mm | 纯 X | (-2.5, **+42.0**) | (-4.0, **+41.0**) |

**一个走水平、一个走竖直** —— 这是图像轴与机器轴错位的签名。
两次预测误差均 ≈1.5px ≈ 0.7mm。

**结论：`a11`/`a21` 由正交旋转假设推出，现已被独立实验证实；**
仿射（而非单应）模型成立，相机倾斜可忽略。

### 精度声明

两个验证点残差分别为 (+0.46, +0.29) 与 (+0.1, -0.7) mm，平均 ≈ (+0.3, -0.2) mm。
**0.7mm 已在物理重复性噪声量级以内，不再继续收敛** —— 低于噪声底去拟合只会过拟合。

## 上机前必须知道的两件事

1. **物块必须落在可达区内**：X ∈ [-95, +90]、Y ∈ [-97.5, +92.5]。
   超出时转换器**正确地**返回 None（fail-closed 拒识），不是故障。
2. **抓取点 = 物块坐标 − 工具偏置 (−75, −25)**。
   例：物块 (85.0, 12.5) ⇒ 滑台目标 (10.0, -12.5)。
