# 上电调试速查（2026-08-26）

> 用途：电控首次上电台架的快速参考。集中记录成品驱动板接线、精简共地、串口调试、诊断命令和「串口没信息」的排查框架。

---

## 1. 成品驱动板接线（板子标识 STEPPER Driver，不是标准 A4988）

X/Y 各一块，引脚相同，只有 STEP/DIR/EN 接的 STM32 引脚不同。

| 驱动板引脚 | 接到 | X 轴 | Y 轴 |
|---|---|---|---|
| VIN | 12V 正极 | 同左 | 同左 |
| GND（VIN 旁） | 12V 负极 + 共地 | 同左 | 同左 |
| V | STM32 的 **5V** 排针 | 同左 | 同左 |
| G（V 旁） | STM32 GND | 同左 | 同左 |
| STEP | STM32 GPIO | **PC6** | **PB6** |
| DIR | STM32 GPIO | **PA7** | **PC7** |
| EN | STM32 GPIO | **PA5** | **PD7** |
| 1A/1B | 电机一相两根线 | — | — |
| 2A/2B | 电机另一相两根线 | — | — |
| MS1/MS2/MS3 拨码 | **全拨 ON** = 1/16 细分 | 同左 | 同左 |

> 逻辑电源是 **V=5V**（不是 3.3V），电机电源 **VIN=12V**。两套独立，别把 12V 接进 V。

## 2. 精简共地（不用端子，2 根桥接线）

地分三块，就近接，块之间用桥接线：

```
12V 负极 ──┬─ 驱动板 X GND(VIN旁)
           ├─ 驱动板 Y GND(VIN旁)
           ├─ 降压模块 IN-      （降压 OUT- 内部已通 → 舵机 GND 就近接 OUT-）
           └─①─ STM32 GND ──②── 树莓派 GND
```

- ① 逻辑地 ↔ 功率地，② 树莓派地 ↔ 逻辑地。
- 万用表通断档：STM32 GND 对 12V 负、驱动板 GND、降压 IN-/OUT-、树莓派 GND 都导通；对 12V 正极必须开路。

## 3. 串口调试（USART2 = PA2/PA3，主链路）

- 诊断命令和协议帧**同一个串口** USART2，靠首字节区分（0xA5 走协议，其他走诊断）。
- 调试阶段用 **USB-TTL（CP2102）** 接，树莓派先不接：

```
USB-TTL TX ── STM32 PA3（RX）
USB-TTL RX ── STM32 PA2（TX）
USB-TTL GND ── STM32 GND
```

- 串口工具：**115200 8N1**。

---

## 4. 诊断命令（上电调试用）

| 命令 | 作用 | 期待回显 |
|---|---|---|
| `PING` | 串口通断 | `OK PONG` |
| `INPUTS` | 读 9 路输入 | `ACTIVE=0000`（悬空=不触发） |
| `MOTION ARM` | 武装电机 10s | `OK MOTION ARMED 10S` |
| `MOVE X DIR0 STEPS 800 HZ 500` | X 走 800 步(10mm) | `OK MOTION STARTING` |
| `SERVO ARM` | 武装舵机 10s | `OK SERVO ARMED 10S` |
| `SERVO PB11 P1500` | Z 舵机中位 | `OK SERVO STARTING 2S` |
| `SERVO PB11 P1000` | Z 升=夹爪闭合 | 同上 |
| `SERVO PB11 P1900` | Z 降=夹爪张开 | 同上 |
| `STOP ALL` | 停所有 | `OK STOP ALL` |

- 参数范围：步数 1~1000000，频率 10~10000 Hz（先 200~500）。
- 先 `MOTION ARM` 再 `MOVE`，arm 窗口只有 10 秒。
- 只用带 `STEPS` 的 MOVE（不带会连续走不停，限位又悬空）。

## 5. 「串口没信息」排查框架

串口数据流 5 环节：

```
①固件跑起来 → ②USART2 初始化 → ③PA2 发信号 → ④USB-TTL 接线 → ⑤电脑工具
```

- ② 已确认完整（PA2/PA3 的 AF7 在 `HAL_UART_MspInit`，不在 `MX_GPIO_Init`）。
- **一刀切**：万用表量 PA2 ↔ GND：
  - ~3.3V → ①③ 正常，问题在 ④⑤（接线/工具）
  - 0V → ①③ 断（固件没烧进去 / 没复位 / 没上电）

定位三问：① 烧录显示 Programming Done 还是报错？② 烧录后复位/上电了吗，板子灯亮吗？③ PA2 电平 3.3V 还是 0V？

## 6. 引脚映射（权威来源 docs/design/m144z-m4-tested-pin-pcb-map.md）

- 9 路输入：X_HOME=PG7, X_END=PG6, Y_HOME=PG9, Y_END=PD5, Z_UP=PF11, Z_DOWN=PG14, ESTOP_FB=PG13, START=PA4, MANUAL_RESET=PF8（全部内部上拉，调试期悬空）。
- 串口：USART2_TX=PA2, USART2_RX=PA3（主链路）；备用 USART3_TX=PD8, RX=PD9。
- Z 舵机：PB11（复用 TIM2_CH4）。
