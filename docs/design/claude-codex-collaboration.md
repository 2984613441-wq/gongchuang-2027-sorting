# Claude–Codex 文档协作约定（电控实操）

> 状态：任务级草案；不构成实时多代理系统或长期治理规则。  
> 适用范围：方案 B 的实操电控、模块化 PCB、协议、代码入口、状态机伪代码与本轮审查记录。  
> 工作方式：在同一 VS Code 工作区通过受版本控制的 Markdown 文件异步交接；不建立实时模型通信。

## 1. 目的、边界与证据

让硬件、PCB、协议、状态机、代码测试入口与协作记录可并行推进，同时把跨模块接口、未决机械输入和验收责任留在可追溯文件中。Claude 与 Codex 都可以起草、复核和提出修订；本约定**不指定固定主笔**。

| 分类 | 内容 | 证据强度 |
|---|---|---|
| 已确认事实 | 校赛仅实施方案 B；STM32F407 是唯一的底层运动、安全及 15 秒边界控制端。 | 强：现行方案 B 与需求汇总 |
| 已确认事实 | `BARRIER_READY`、`MOTION_DONE`、`ITEM_RESULT`、`DISPLAY_ACK` 是不同事件；仅成功 `ITEM_RESULT` 更新累计成功数。 | 强：接口契约与验收清单 |
| 已确认事实 | 同轮不得自动跳件、重放运动、自动回零、重抓或人工复位后续跑。 | 强：现行方案 B |
| 推断 | 多个模块可在文件所有权隔离下并行起草。 | 中：本轮已有并行产出，仍待跨节点协作验证 |
| 未知 | 电机、舵机、夹爪、限位、显示和补光的具体机械/电气参数。 | 强：资料明确列为待外部输入 |

本轮只产生和审查文档。不得采购、上电、接线、烧录固件、执行实机运动、修改账号或权限、向外部服务发送数据，亦不得把未验证参数写成定值。

| 接口/不变量 | 提供方 | 消费方 | 不可违反的条件 |
|---|---|---|---|
| 单件高层任务 | 树莓派调度/接口契约 | STM32 | 树莓派不得下发逐轴脉冲或实时关节控制；STM32 独立执行。 |
| `BARRIER_READY` | STM32/硬件层 | 状态机、调度 | 仅在可验证挡板就绪后产生；仅发 PWM 不是就绪证据。 |
| `MOTION_DONE` 与 `ITEM_RESULT` | STM32 | 树莓派显示/统计 | 两事件分离；运动结束不等于成功；仅成功结果计数。 |
| `DISPLAY_ACK` | 显示/树莓派 | STM32 | 本件完整渲染后才有效；收到前不得接受下一件。 |
| 15 秒边界 | STM32 | 全模块 | 仅可观察执行器进展及首次有效 ACK 可更新时间基准；心跳、日志、重传、重识别和重复刷新不得续时。 |
| 安全与恢复 | 硬件、状态机 | 全模块 | 急停独立切危险执行器动力；禁止自动跳件、重放、回零、重抓及同轮复位续跑。 |

## 3. 贡献、复核与对账循环

1. **起草**：在拥有的文件中做最小变更，记录输入、假设、影响的不变量与待确认项。
2. **复核**：Claude 或 Codex 阅读变更与共享接口，按通过、需修改或待外部输入给出可定位意见。
3. **对账**：将分歧归入“接受 / 拒绝 / 待机械输入”；只回写已接受且未突破边界的内容。
4. **再审**：检查修改是否关闭原问题；若未能证明复核者与起草过程真正分离的独立阅读，必须标为“弱独立性”。

工作区没有实时代理通信：交接依赖 Markdown、版本历史和后续阅读者。任何“Claude 已审”或“Codex 已审”必须有实际审查记录、时间和定位；否则只能写“待 Claude 阅读”或“待 Codex 阅读”。


## 4. 决策、阻塞与完成条件

| 状态 | 含义 | 可写入范围 |
|---|---|---|
| 接受 | 来源充分、符合全部不变量且无需外部授权。 | 可写入所属模块，保留来源。 |
| 拒绝 | 与方案 B、赛规、接口契约或安全边界冲突。 | 只保留理由与替代建议。 |
| 待机械输入 | 依赖 ME/赛事方参数或确认。 | 仅抽象接口、参数卡和前置条件；不得猜定型号/数值。 |

待机械/视觉输入至少包括：X/Y 步进电机具体型号与电气参数、第三运动轴/夹爪的执行器类型与负载、舵机 PWM 范围、限位数量/类型/位置、重力轴断电防坠、挡板可验证就绪判据和补光安装空间。显示屏已确认为非触摸、仅显示，不再是待确认类型；仍需到货实测。A4988 当前仅为 X/Y 候选模块位，不代表已通过适配验证。

Claude 已在 `.claude/reviews/REVIEW-20260812-003-claude-independent-electrical-control.md` 留下独立审查证据。Codex 对该记录的核验与决议另存对账文件；不得改写 Claude 原始审查文件。

本模块完成条件：文件所有权和全部共享不变量可定位；Claude/Codex 均可起草或复核且无固定主笔；任务记录含目标、输入、输出、约束、风险、阻塞和责任；初始审查逐项覆盖现有验收清单，未实机验证的项目保持待验证。
