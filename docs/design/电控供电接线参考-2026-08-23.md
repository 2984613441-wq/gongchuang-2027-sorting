## 1. 电压链架构（12V 单母线）

电源（电池或 12V 适配器）只有**一对输出：12V+ 与 GND**。所谓"两路"，是外部把它分成两条支路：

```
电池 12V+
  └─[保险丝 2~3A]─┬───────────────► 支路① 动力：A4988 驱动 VMOT（12V 直给，不降压）
                  └───────────────► 支路② 逻辑：DCP3512 降压 ─► 5V ─► 舵机 + STM32 主控
```

- **支路①（动力，12V 直给）**：步进电机是电流驱动，A4988 内部斩波把绕组电流钳在设定值上。VMOT 只提供电流斩波的电压储备、决定高速时扭矩。12V 直给是正确做法，降压会掉高速扭矩。A4988 VMOT 范围 8~35V，12V 落在区间内。
- **支路②（逻辑）**：DCP3512 本身就是降压模块，把 12V → 5V 给舵机/主控，再由板载 LDO 出 3.3V 给 STM32。

> DCP 已确认四路输出：3.3V / 5V / 12V / 可调电压（2026-08-23）。

## 2. 供电拓扑图

```
电池 12V+ ──[保险丝 2~3A]──┐
                          ├──► 【12V+ 公共点】(WAGO 221-415 或 带母线端子排，1进4出)
                          │        ├─► DCP3512 VIN+
                          │        ├─► A4988① VMOT+（底座螺丝端子）
                          │        ├─► A4988② VMOT+（底座螺丝端子）
                          │        └─► 预留（备用）

电池 GND ──────────────────► 【GND 公共点】(WAGO 221，6~8 孔)
                                   ├─► DCP3512 GND
                                   ├─► A4988① GND（底座螺丝端子）
                                   ├─► A4988② GND（底座螺丝端子）
                                   ├─► STM32 GND
                                   └─► 舵机 GND（几路挡板+夹爪）

DCP3512 输出 5V  ──► 舵机 VCC + STM32 5V 入
DCP3512 输出 GND ──► 回到【GND 公共点】

STM32 排针 ──杜邦母对母──► A4988①底座 STEP/DIR/EN
STM32 排针 ──杜邦母对母──► A4988②底座 STEP/DIR/EN
```

## 3. 共地（GND）规则

- **所有 GND 必须接到一起**（星型拓扑：N 根线汇到同一个公共点，不是两两互接）。
- 没有公共地，STM32 发给驱动的 STEP/DIR 信号就没有回流路径，信号会乱。
- **降压模块只拉一根 GND**：非隔离型降压模块的输入地（12V-）和输出地（5V-/3.3V-）是同一个点，不用每个电压各拉一根。
- **电机不直接拉地**：电机是"哑的"，通过 4 根相线接 A4988，是**驱动**拉一根 GND 进公共点。
- **舵机是 3 根线**（5V 红 / 信号黄白 / GND 棕），只有 GND 那根汇到公共点。
- **树莓派**：若与 STM32 用 USB 通信，USB 线自带地线，**不用单独拉地**；只有裸 UART（TX/RX/GND）才需手动把树莓派 GND 接进公共点。

## 4. 端子怎么接（线是怎么"转化"的）

端子排/WAGO 只做一件事：**把几根剥了皮的铜线夹在同一个金属片上**。是星型（N 根线接一个点），不是"每根跟每根接"。

**方式 A：WAGO 221（首选，推荐新手）**
1. 线头剥皮 10mm；
2. 掰起橙色拨杆 → 插铜线 → 压下拨杆。
- 不用拧螺丝、不用冷压端子、可反复插拔。一个 5 孔 WAGO = 5 根线并到一个公共点。

**方式 B：螺丝端子（6P 端子排）**
1. 线头剥皮 5~7mm 露铜丝（多股线先套冷压端子/管型端子更牢）；
2. 插进孔，拧螺丝压住。

**确认夹没夹住**：扣下/拧紧后轻拽线，拽不出来即夹紧。

## 5. 杜邦线 vs 动力线（关键分界）

| 线 | 用什么 | 剥不剥线 |
|---|---|---|
| 信号线 STEP/DIR/EN、舵机 PWM（STM32↔A4988底座排针）| **杜邦线 母对母**，直接套排针 | 不剥 |
| 动力线 12V、GND、电机相线 | **0.2~0.5mm² 连接线**，剥 10mm 进 WAGO/螺丝端子 | 剥 |

- **杜邦线只插排针，永远不剥**。杜邦线 26~28 AWG（0.08~0.13mm²）太细：跑动力会发热；剥开夹 WAGO 221 会低于额定下限（0.14mm² 起），夹不住/虚接。
- 杜邦线 = 两头压好金属头的成品线，母头套排针即通，不用剥、不用拧、不用焊。拔时捏塑料壳，勿拽线身。
- 需夹很细信号地又不想换线时，改用 **WAGO 222（橙色）**，下限到 0.08mm²。

## 6. A4988 裸模块排针定义 + 底座对照

裸 A4988（紫色 StepStick）16 根公排针，分两侧：

```
      控制侧（逻辑，8 脚）             动力侧（功率，8 脚）
      ┌───────────────┐              ┌───────────────┐
      │ ENABLE 使能    │              │ VMOT  12V+    │ ← 动力电源
      │ MS1/MS2/MS3 细分│              │ GND   地      │ ← 动力地
      │ RESET / SLEEP  │              │ 2B / 2A       │
      │ STEP  信号     │              │ 1A / 1B  电机  │
      │ DIR   信号     │              │ VDD   3.3/5V  │ ← 逻辑电源
      │ GND   地       │              │ GND   地      │ ← 逻辑地
      └───────────────┘              └───────────────┘
```

- **控制侧**：STEP/DIR/EN + VDD(逻辑电源) + GND，来自主控板，mA 级。
- **动力侧**：VMOT(12V) + 4 根电机相线(1A/1B/2A/2B) + GND，A 级。

**推荐用 A4988 底座/扩展板**（几块钱），中间 16P 母座插 A4988，四周把公口"转好"：

```
      A4988 底座/扩展板
  ┌──────────────────────────────┐
  │ [螺丝端子] VMOT  GND          │ ← 动力 12V：剥线拧进去（不用杜邦）
  │ [螺丝端子] 1A 1B 2A 2B        │ ← 电机 4 相线：剥线拧进去
  │                              │
  │  [16P母座] ← A4988 插这里     │
  │                              │
  │ [排针] EN STEP DIR MS1-3 ...  │ ← 逻辑线：杜邦母对母插进去
  └──────────────────────────────┘
```

- **动力线（VMOT、电机相线）走螺丝端子**，剥线一拧，不碰杜邦母口。
- **逻辑线（STEP/DIR/EN）走杜邦母对母**，现成杜邦线插上。
- **逻辑地 + 动力地**必须连一起；底座通常已在板上并好，只需保证底座 GND 螺丝端子回到【GND 公共点】。

## 8. 决策记录与遗留项（2026-08-23 更新）

- **A4988 拖 17HS4401（1.7A/相）**：已定保留 A4988（不换驱动）。A4988 连续约 1A，
  故需限流设 ≤1A + 散热片，接受扭矩打折（分拣头轻载通常够）。
- **动力线规格**：杜邦线当动力线不可取；VMOT/电机相线/GND 动力回路建议 0.5mm² 以上，压端子进驱动螺丝端子/端子排，信号才走杜邦。
- **DCP 输出电压**：已确认四路 3.3V / 5V / 12V / 可调电压。
- **Z 轴（机械手升降）**：已确认为舵机（非步进电机），无板外 STEP/DIR 驱动；
  5V 舵机支路含 Z 升降 + 夹爪 + 4 挡板，注意 5V 支路电流裕量。

## 9. 上机实操流程（6 阶段）

> 代码已写完、P0 静态通过；实机复核是"写好 → 运行时已验证"的最后一步。
> 串口：USART3（PD8/PD9），115200 8N1，命令以 CRLF 结尾。
> 烧录：`diankongv1.0.hex`（SHA256 `1a565e56…a8d8196`）。

1. **备齐**：物料（A4988+底座×2、WAGO、杜邦母对母、0.5mm² 连接线、保险丝+座、12V 电源）；工具（ST-LINK、USB转TTL、万用表、剥线钳/螺丝刀）。
2. **断电接线**：12V+ → 保险丝 → 12V+ 公共点 → A4988①/② VMOT + DCP；所有 GND 星型汇一点；动力走连接线、信号走杜邦。上电前万用表查 12V+ 与 GND 不短路、VMOT 极性对、保险丝在位。顺带确认 DCP 那路"12V"是直通还是降压出。
3. **烧录**：ST-LINK 烧 HEX，确认校验通过。
4. **上电自检**：无冒烟/异常发热/保险丝断；板子正常复位、LED 正常，有问题立刻断电。
5. **串口验收（P0 复核）**：`MOTION ARM` → `OK MOTION ARMED 10S`；10 秒内 `MOVE X DIR0 STEPS 100 HZ 100` → `OK MOTION STARTING`；结果 `STEP_RESULT=DONE`+`STEP_REMAIN=0` = P0 坐实，`TIMEOUT` = P0 未生效（停，回报串口回显定位）。
6. **逐步扩**：X → Y → 舵机（Z 升降/夹爪）→ 4 挡板，每步验证过再下一步，别一上来全测。

安全红线：动力别走杜邦；长跑后摸线/驱动是否发烫；急停需物理切断动力（ESTOP_FB 只是辅助反馈，不替代硬件急停）。

## 10. 一句话总结

- **电压链**：12V 单母线；动力直给驱动 VMOT、逻辑经 DCP3512 降 5V —— 对。
- **共地**：所有 GND 星型汇到一个公共点，回电池负极；降压模块只拉一根地。
- **接线**：信号走杜邦母对母（不剥），动力走螺丝端子/WAGO（0.2~0.5mm² 连接线，剥 10mm）。
- **别碰**：别给动力线套杜邦母口；别把杜邦线剥开夹 WAGO；别让动力地走细线。
