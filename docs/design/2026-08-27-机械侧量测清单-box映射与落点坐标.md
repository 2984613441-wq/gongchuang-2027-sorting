# 机械侧量测清单：box_id 映射表 + 落点坐标（2026-08-27）

> **用途**：视觉/电控联调的最后两项硬前提数据。代码已齐、协议已冻结、测试全绿，
> **唯一卡住的就是这两张表的实测值**。机械手照本清单填完数 → 视觉/电控填进代码
> → 立刻能跑端到端分拣。

---

## 为什么需要这两项数据

**方案 A 已定**：`box_id` 是**固定物理盒编号（1..6）**，跨批次稳定，不再每批动态分配。

- **取料点固定** = 装置中心 `(0, 0)`，所有物块从这里抓。
- **落点由查表得出** = `box_id → 落点表` 直接查，不用相机坐标推算。

所以视觉侧需要知道「哪类物料放哪个盒」（映射表），电控侧需要知道「盒在哪」（落点坐标）。

---

## 输入 1：`(颜色, 形状) → box_id` 冻结映射表

定死「哪类物料放哪个物理盒」，**6 条记录**（赛题有 6 种物料 × 1 个盒 或其他组合）。

### 填表规则

```python
# 格式：(color_id, shape_id): box_id
映射表 = {
    (0, 2): 1,  # 红色圆柱 → 1 号盒
    (3, 0): 2,  # 绿色立方体 → 2 号盒
    # ... 共 6 条
}
```

### 编码对照

| **颜色** | color_id | **形状** | shape_id |
|---------|---------|---------|---------|
| 红 red | 0 | 立方体 cube | 0 |
| 橙 orange | 1 | 长方体 cuboid | 1 |
| 黄 yellow | 2 | 圆柱 cylinder | 2 |
| 绿 green | 3 | | |
| 青 cyan | 4 | | |
| 蓝 blue | 5 | | |
| 紫 purple | 6 | | |
| 粉 pink | 7 | | |
| 黑 black | 8 | | |
| 白 white | 9 | | |
| 灰 gray | 10 | | |

### 怎么定这张表

- **依据赛题规则**：赛题给的 6 种物料是哪 6 种（颜色 + 形状组合）。
- **依据机械布局**：6 个物理盒的位置顺序，哪个盒方便放哪类（比如重的放近的盒）。
- **拍板一次，全程不变**：这张表一旦定下来，整个比赛都用这个，不能每轮换。

### 填表模板（复制后填数）

```python

    (____, ____): 1,  # _______ → 1 号盒

    (____, ____): 3,  # _______ → 3 号盒
    (____, ____): 4,  # _______ → 4 号盒
    (____, ____): 5,  # _______ → 5 号盒
```

填完后给视觉手 → 写进 `sort_plan.py` 的 `BoxAssignment(box_assignment_data, box_count=6)`。

## 输入 2：`box_id → (X, Y)` 落点坐标表

测 **6 个物理盒的中心坐标**（STM32 把物块投到这里）。

### 坐标系约定（interface-contract V0.6 §5.2 已冻结）

| 项 | 约定 |
|---|---|
| **单位** | **0.1mm**（即 X=1200 代表 120.0mm；内部存 int16，传输时 2 bytes） |
| **原点** | 装置中心（取料点），也是机械零点 |
| **X 轴** | 向右为正，向左为负（单位：0.1mm） |
| **Y 轴** | 向前为正，向后为负（单位：0.1mm） |
| **范围** | ±145mm = `[-1450, 1450]` in 0.1mm 单位（±14.5cm，接口合同 §5 定死） |

### 测量步骤（用卡尺/直尺）

1. **找装置中心（取料点）** — 这是原点 `(0, 0)`，也是所有物块开始的地方。在台面上做个标记。
2. **量每个盒的中心到原点的距离**：
   - X 方向：卡尺/直尺量「盒中心到原点的水平距离」（mm），向右为正、向左为负。
   - Y 方向：卡尺/直尺量「盒中心到原点的前后距离」（mm），向前为正、向后为负。
3. **换算成 0.1mm 单位**：测量值（mm）× 10 = 坐标值。
   - 例：3 号盒中心在原点右 80mm、前 50mm → X = 80 × 10 = 800, Y = 50 × 10 = 500 → `(800, 500)`
   - 例：5 号盒中心在原点左 120mm、后 30mm → X = -120 × 10 = -1200, Y = -30 × 10 = -300 → `(-1200, -300)`

### 填表模板（复制后填数）

```python
# box_id: (x_0_1mm, y_0_1mm)
drop_table_data = [
    DropPoint(x_0_1mm=____, y_0_1mm=____),  # 1 号盒：实测 ____mm, ____mm → 填 × 10
    DropPoint(x_0_1mm=____, y_0_1mm=____),  # 2 号盒
    DropPoint(x_0_1mm=____, y_0_1mm=____),  # 3 号盒
    DropPoint(x_0_1mm=____, y_0_1mm=____),  # 4 号盒
    DropPoint(x_0_1mm=____, y_0_1mm=____),  # 5 号盒
    DropPoint(x_0_1mm=____, y_0_1mm=____),  # 6 号盒
]
```

或者 CSV 格式（Excel 打开填）：

```csv

1,___,___,___,___
2,___,___,___,___
3,___,___,___,___
4,___,___,___,___
5,___,___,___,___
6,___,___,___,___
```

填完后给电控手 → 写进 `drop_table.py` 的 `DropTable(drop_table_data)`。

## 校验清单（填完自查）

- [ ] 落点表的每组坐标在 `[-1450, 1450]` 范围内（±14.5cm）
- [ ] 落点表的坐标是 **0.1mm 单位**（实测 mm 值 × 10）
- [ ] 落点表的原点是装置中心（取料点），X 向右正、Y 向前正

## 常见错误（提前避坑）

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 落点坐标单位写成 mm（没 ×10） | STM32 运动距离缩 10 倍，物块投不到盒里 | 测量值（mm）**必须 × 10** |
| X/Y 符号反了（左右/前后搞混） | 物块投到对称位置的错盒子 | X 向右正、Y 向前正（看清图纸） |
| 映射表的 box_id 每轮换了 | 同一类物料这轮投 1 号盒、下轮投 3 号盒，乱套 | **映射表全程冻结不变** |
| 映射表的颜色/形状 ID 写错 | 视觉识别成「红色圆柱」，代码查表查不到，整批报错 | 对照上面编码表，仔细核对 |
