# 上机前待冻结项清单

日期：2026-08-25
用途：把主机侧无法自行裁决的参数列出来，避免上机时临时猜写。
状态：线格式（X/Y 有符号、角度 `0xFF`、8 字节载荷）、`image_id` 映射、MaixCAM↔树莓派波特率已于 2026-08-25 签字冻结；时序/超时/重传/心跳仍为候选，待台架实测；篮圈半径/角度约定/类别→篮子赋值仍未提供。

## 已经冻结

- 统一外层帧：帧头 `A5 5A`、版本 `01`、CRC-16/MODBUS、`task_id`/`frame_seq`/`data_len` 大端。
- 设备 ID：`0x01` MaixCAM、`0x02` 树莓派、`0x03` STM32。
- 命令字：L0 `0x01..0x06`、视觉链 `0x10..0x13`、调度链 `0x20..0x26`。
- `DISPLAY_ACK` 六字节载荷与显示内容 CRC32 输入/输出规则。
- `ITEM_TASK` 身份前缀 `target_seq + class_id + image_id`。
- `success_count` 规则。

## 上机前必须裁决

### 1. ITEM_TASK 完整线格式 ✅ 已签字冻结（2026-08-25）

| 字段 | 冻结值 | 说明 |
|---|---|---|
| X 坐标 | 有符号 16 位（补码），单位 `0.1 mm`，大端 | 原点=装置中心，越界（±135.0 mm 以外）拒绝 |
| Y 坐标 | 有符号 16 位（补码），单位 `0.1 mm`，大端 | 同上 |
| 抓取角度 | 1 字节，恒 `0xFF` | 夹爪不旋转；`0..180` 保留本轮不用 |
| 角度有效标志 | `0xFF` 哨兵，不另加标志字节 | — |
| 总载荷长度 | `3 + 2 + 2 + 1 = 8` 字节 | 冻结，不允许临时扩展 |
| 语义 | X/Y = 落点（篮子位置），抓取固定圆心 | STM32 不内建「类别→篮子」查表 |

### 2. image_id 分配 ✅ 已签字冻结（2026-08-25）

`image_id` 由树莓派在创建单件任务时确定，随 `ITEM_TASK` 显式传给 STM32。冻结项：

- `image_id == class_id`，1:1 映射；active 集 `{0,2,3,4,5,6}`（1=长方体本轮不出现）。
- 同类别多件时 `image_id` 稳定复用（同 `class_id` → 同 `image_id`）。
- 名称与图片映射只存树莓派 TF 卡，按 `image_id` 索引。
- `image_id` 与 `DISPLAY_ACK` 内容 CRC32 的五个字段顺序保持一致（图片 ID 为第 3 字段）。

### 3. 时序与重传

| 参数 | 建议候选 | 需要确认 |
|---|---|---|
| `BARRIER_READY` 超时 | 建议后续台架实测，不写死 | 挡板最坏动作时间 + 安全余量 |
| `DISPLAY_ACK` 超时 | 建议不超过 15 秒阶段预算剩余 | 屏幕到货后实测刷新耗时 |
| 每类最大重发次数 | 建议后续故障注入确定 | 明确数据扰动、任务异常、安全故障分级 |
| 心跳间隔 | 建议后续台架实测，不写死 | 与 STM32 监控一致 |
| 失联判定 | 连续心跳丢失次数 | 与 STM32 一致 |
| 15 秒阶段预算 | 分给整批识别、挡板、单件、显示 | 逐项台架计时 |

### 4. 串口与屏幕

- MaixCAM 与树莓派间波特率：✅ 已签字冻结 **115200 8N1**（统一全链路）；CP2102 方向仍待实测。
- 树莓派与 STM32 的探索者板载 USB 串口连接器和线材待确认，不得用 Type-C 替代未知接口。
- 顶部屏到货后的分辨率、供电、自动亮屏、全屏无裁切和正面/斜侧可读均待实测；本轮屏幕先不动。

### 5. 落点表物理量（树莓派侧，仍未提供）

`ITEM_TASK` 的 X/Y 语义是「落点（篮子位置）」，由树莓派按 `类别 → 篮子 → (X,Y)` 表计算。该表还缺三个物理量：

1. 篮圈半径 `R`（mm）；
2. 角度约定：1 号篮方向 + 顺/逆时针；
3. 类别 → 篮子赋值：剩余 6 形状绕圈顺序。

这三条不影响 STM32（STM32 只收 `(X,Y)` 不查表），只阻塞树莓派落点表。

## 上机动作授权清单

以下动作必须逐项取得用户授权后才能执行：

1. 连接 MaixCAM CP2102、树莓派 USB 串口、STM32 串口和共地线。
2. ST-Link 烧录 STM32 固件。
3. 上电、自检、回零、挡板/电机/舵机运动。
4. 顶部屏上电与 `DISPLAY_ACK` 闭环。
5. 急停、限位、补光等安全相关测试。

主机侧当前不产生任何串口、屏幕、电机或实机通过声明。
