# 采购清单（2026-08-22）

> 适用范围：智能分类垃圾桶电控系统——应急杜邦线接线方案（弃用问题载板后）。
> 系统电源架构：12V 直供 X/Y 步进驱动（Z 轴为舵机，5V 供电）；DCP3512 出 5V 供 STM32 + 舵机；树莓派 4B 独立 5V/3A 供电（调试用充电宝，比赛日换充电头）。所有 GND 汇到一点共地。

## 三、不要买 / 暂不买

| 物品 | 原因 |
|---|---|
| 载板 PCB 重新打样 | 赛前来不及，且针序未实测验证；赛后重做时再买 |
| 新 M144Z 核心板 | 现有核心板单烧正常，故障在载板不在核心板 |
| 面包板 | 夹持不可靠，端子排 + 杜邦线足够 |
| 18AWG 硅胶线 | 已实测杜邦线可承担电机电流，暂不买；若连续运转后线材发烫再补买 |

## 四、到货后接线顺序

1. 12V 电源 → 保险丝 → 6P 端子排（12V 母线）→ X/Y 驱动 VMOT + DCP3512 输入（动力线沿用杜邦线，已实测可行；长跑后摸一下是否发烫）。
2. DCP3512 可调通道设 5V（或 5.5~6V 给舵机）→ STM32 5V（JP_R-48）+ 舵机电源。
3. 全部 GND（12V 负、DCP3512 负、驱动、STM32、舵机、树莓派）汇入 12P 端子排一点。
4. 信号线按 [m144z-m4-tested-pin-pcb-map.md](./m144z-m4-tested-pin-pcb-map.md) 接。
5. 树莓派 4B：独立 5V/3A 供电，GND 一根线接公共地。

## 五、采购时需向卖家确认

- DCP3512 是「每路 3.5A」还是「5V 总 3.5A」；若是后者，舵机需另配一路 5V/3A UBEC。
- 杜邦线是否够 40cm（标准套装多为 20~30cm）。
- 端子排额定电流 ≥10A。
