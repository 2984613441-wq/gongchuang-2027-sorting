# 实机标定测试清单

> 日期：2026-08-26
> 用途：下午首次上电台架，标定 X/Y 步进（微步、速度）、夹爪/挡板舵机脉宽，并验证 steps/mm。
> 前提：这是**首次上电**，属于项目红线操作。务必有人在场、能在一秒内手动断电（急停/拔电源）。

---

## 0. 一句话现状

- 现有固件是**诊断版**（串口 ASCII 命令，见 [2026-08-20-motion-command-list-v1.md](2026-08-20-motion-command-list-v1.md)）。
- 串口能发命令、能读 `STEP_RESULT`（0=无/1=发完/2=超时/3=安全中止）和九路输入，但**开环**——看不到电机实际位移。
- 所以「失步」「走了多远」「steps/mm 对不对」都要靠**手工量**，这是本清单反复用到的核心手段。

## 2. A4988 接线要点

```
24V(+)  ──► VMOT          STEP ──► STM32 定时器 CH（X=htim8, Y=htim4）
24V(-)  ──► GND           DIR  ──► STM32 DIR 引脚
3.3V/5V ──► VDD           EN   ──► STM32 ENABLE 引脚（低有效）
逻辑 GND ──► GND（共地）  MS1/MS2/MS3 ──► 跳线帽（微步档，本清单要反复改）
电机 1A/1B/2A/2B ──► 17HS4401 两相四线（同名相接，接反会导致堵转/发热）
```

- **VMOT 和 VDD 必须共地**，否则 STEP 信号无参考、电机乱跳。
- STEP/DIR/EN 具体接到 STM32 哪个 GPIO，对着 `main.c` 的 `MX_GPIO_Init` / 载板定义查，别凭记忆接。
- 上电顺序：先 VDD 逻辑电 → 再 VMOT 24V（或同时），**断电反过来**。

## 2.5 九路输入接线（当前无开关：全部悬空）

- 九路输入（限位/急停/启动/复位）已改为 **STM32 内部上拉**（main.c `GPIO_PULLUP`）。
- 当前手头没有开关，**九路全部悬空**即可：内部上拉读高 = 未触发，系统正常跑标定，不锁死。
- **安全靠手动断电**：标定全程手放在电源开关/插头旁，出问题直接断电。
- 标定动作都是「走固定步数」，从短距离低速开始（先 `MOVE X DIR0 STEPS 400 HZ 500` 验证方向 = 5mm），别一上来就大距离高速。
- 开关到货后：常开开关一端接 GPIO、一端接 GND，插上即用，代码不用改。

## 3. 第一步：调 Vref 电流（万用表，务必先做）

A4988 出厂 Vref 不定，不调就上电可能电流过大烧电机/驱动，或过小无力矩。

- 公式：`I_limit = Vref / (8 × Rs)`，即 `Vref = I_limit × 8 × Rs`。
- 先看模块上 Rs 丝印：**R050 = 0.05Ω**（常见绿板），**R100 = 0.1Ω**（常见红板）。
- 17HS4401 额定 1.7A，A4988 建议跑 ≤ 1.2A 留散热余量：

| Rs | 目标电流 | 目标 Vref |
|---|---|---|
| R050 (0.05Ω) | 1.2A | **0.48V** |
| R100 (0.1Ω) | 1.2A | **0.96V** |

- 万用表直流电压档，红表笔点 Vref 电位器中间脚，黑表笔点 GND，用绝缘螺丝刀调电位器到目标值。
- **X/Y 两个模块各调一次。**

## 4. 测试流程 + 判定

> 串口 115200 8N1，交叉 TX/RX，共地，命令以 `\r\n` 结尾，每条等响应再发下一条。
> 用 VOFA+ 的**普通串口收发模式**（发文本、看文本）。**不要开 JustFloat / FireWater 绘图协议**——那是二进制帧，我们的固件是 ASCII 文本，二进制发过来会 `ERR BAD_COMMAND`，量大会触发 `ERR RX_OVERFLOW` 停止测试。
> 每次运动前先 `INPUTS` 确认 `ACTIVE=0000`（九路输入都正常），再 `MOTION ARM`。

### 4.1 定微步 + 验证 steps/mm（先做这个，是地基）

1. 把 MS1/MS2/MS3 三个跳线帽**全部短接** = 1/16 微步。
2. 发：`MOTION ARM` → `MOVE X DIR0 STEPS 3200 HZ 500`
   - 3200 步 = 1/16 微步下的 1 圈 = 20 齿 × 2mm = **40mm**。
3. **量同步轮/滑台实际位移**：
   - 正好 40mm → 微步 1/16 正确，`steps/mm=80` 正确，**锁定**。
   - 不是 40mm → 跳线接错，或 steps/mm 算错，回头查。
4. 观察 A4988 散热片温度（测温枪）：跑几十秒摸温度。**不烫 → 1/16 可留；烫手 → 降 1/8 或 1/4**（降档后 steps/mm 同步改成 40 或 20，耦合点已写进代码注释）。

### 4.2 标定速上限（找不失步的最高巡航速度）

从低到高试，每个速度量位移：

| 命令 | 理论位移 |
|---|---|
| `MOVE X DIR0 STEPS 800 HZ 500` | 800÷80 = 10mm |
| `MOVE X DIR0 STEPS 800 HZ 1000` | 10mm |
| `MOVE X DIR0 STEPS 800 HZ 2000` | 10mm |
| `MOVE X DIR0 STEPS 800 HZ 5000` | 10mm |
| `MOVE X DIR0 STEPS 800 HZ 10000` | 10mm |

- **失步表现**：实际位移 < 10mm、卡顿、异响、位置丢。
- 找到「不失步的最高 Hz」，取它的 **70~80%** 作为运行速度。
- 注意：现在固件是**定频起步**（没有加减速），起步瞬间最容易丢步。所以这里测出的「最高速度」偏保守——以后接了梯形曲线还能再往上提。
- 走一个来回（`DIR0` 走 800 步再 `DIR1` 走 800 步），看记号笔**回不回原点**——不回就是往返丢步。

### 4.3 标 Z 轴舵机脉宽（DS3120MG，PB11，升降联动夹爪）

> 单舵机机构：舵机下降 = 夹爪张开去抓，上升 = 夹爪闭合夹住。只标两个位置。

1. `SERVO ARM` → `SERVO PB11 P1900`（下降=张开占位）。
2. 依次试 `P1000 / P1100 / P1200 / P1300 / P1500 / P1700 / P1900`，观察夹爪张合程度。
3. 找到两个点：**下降张开能套住货物**、**上升闭合能夹住不夹碎**。记下两个脉宽，回填到 `ec_axis_driver.h` 的 `EC_AXIS_Z_DOWN_US`（张开）/ `EC_AXIS_Z_UP_US`（闭合）。

### 4.4 标挡板脉宽（MG996R × 4）

1. `BARRIER ARM` → `BARRIER 1 P1000`（单通道）。
2. 从 500 到 2500µs 扫，找「归集位」和「避让位」两个角度，记脉宽。
3. 四个通道各标一次（MG996R 一致性差，逐个来）。

## 5. 现在还测不了的（诚实说明）

- **加速度（梯形加减速）**：现有固件是定频 counted，梯形曲线还没接进 ISR。所以下午标不了加速度，只能标「定频速度上限」。
- 等梯形曲线接入后（纯逻辑已备好，只差 ISR 接线），再补「起步不丢步的最大加速度」标定。
