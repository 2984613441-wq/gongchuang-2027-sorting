# 方案 B 电控实操——硬件接口与选型门禁

> 状态：V0.3，**已确认 X/Y/Z 电机型号与夹爪执行器**，其余参数待机械组与台架验证后冻结。  
> 适用范围：校赛方案 B 的装机级硬件边界；不构成采购清单、接线图或安全回路定稿。  
> 依据：`docs/requirements/analysis.md`、`电控/资料/要求汇总.md`、`电控/资料/智能分拣装置电控总体方案B-完整技术版.md`。

## 1. 使用边界与信息状态

### 已确认事实

- 校赛仅实施方案 B：视觉端、树莓派、STM32 与执行器按既有架构分工；STM32 是唯一的底层运动与安全控制端。
- 整机只能使用**一套安装在装置内部的电源**；逻辑和动力必须分路，不能把分路误解为可增加第二套电源。
- 危险执行机构动力必须有独立硬件急停切断边界；逻辑端需保留供电，以便故障显示与记录。
- 电控须为 X、Y、机械手三条独立运动通道、四路挡板、夹爪、限位/原点、急停、驱动故障、补光和设备通信预留接口。
- **X/Y/Z 步进电机型号已确认：17HS4401**（NEMA17，1.8°步距角，1.7A/相，40N·cm 保持扭矩），详见第 5 节参数卡。
- **夹爪执行器类型已确认：数字舵机 DS3120MG**（金属齿轮，20kg·cm @ 6.0V），详见第 5 节参数卡。

### 当前未知，不能自行补为事实

第三运动轴（机械手 Z 轴）板外驱动器型号与断电防坠方案、四路挡板舵机型号、限位类型与数量、负载峰值、线束长度、连接器规格、保护器件参数及最终端子分配均未冻结。机械组负责提供剩余执行器和安装接口信息；相应器件供应商负责提供其额定条件、瞬态能力、接线和保护要求。未完成参数卡、计算和台架验证前，禁止下单或绘制正式接线图。

### 当前模块化实现决定

- 采用”探索者 STM32F407 开发板 + 自制载板/接口板 + 外购成熟功能模块”，详见 [模块化 PCB 设计](./modular-pcb-design.md)。
- 载板为 X/Y 各预留一个可插拔 A4988 **候选**模块位；是否装配必须经过与 17HS4401 的限流匹配、峰值工况、温升和急停台架验证。
- 第三运动通道仅提供通用 STEP/DIR 外接驱动接口；电源变换、舵机/夹爪动力、补光功率开关和急停动力切断使用外购成熟模块，载板不重复承担这些高风险功率功能。

## 2. 单一内部电源架构与分区

```text
单一内置电源
  → 总开关 → 防反接 → 总保护 → 配电节点
                                 ├─ 逻辑控制区：STM32、传感器、必要接口
                                 ├─ 计算/视觉/显示区：树莓派、视觉端、显示屏
                                 ├─ 补光区：补光负载及其逻辑控制接口
                                 └─ 危险执行器动力区：三轴驱动、四路挡板、夹爪
                                                    ↑
                               急停硬件回路切断本区动力；逻辑区不被切断
```

### 分区原则

| 分区 | 目的 | 必须遵守的原则 |
|---|---|---|
| 电源入口与配电区 | 形成唯一电源入口与可检查的分路 | 总开关、防反接和总保护位于入口侧；各负载组按核算结果独立保护。 |
| 逻辑控制区 | 保持控制、诊断、故障记录可用 | 与高干扰动力线分开走线；与其他分区保持按接口要求的可靠公共参考。 |
| 计算/视觉/显示区 | 保证识别、调度和显示稳定 | 不与未验证容量的运动或挡板动力共用转换/供电支路；显示屏只用于显示。 |
| 驱动与危险执行器动力区 | 向运动、挡板和夹爪供能 | 分支保护、线束固定与散热条件须由负载实测核实；不得把长期动力连接建立在临时试验线材上。 |
| 补光区 | 让补光可控且不干扰视觉 | 补光从独立负载支路取能，控制信号只作控制，不直接供给负载能量。 |

### 总入口、反接与保护原则

1. 总开关只负责整机可控上电/断电；其额定能力、安装方式与锁定方式待参数冻结后确定。
2. 防反接位于总入口，保护对象覆盖后续配电与负载；具体实现及其损耗、温升条件由参数计算和供应商资料确认。
3. 总保护覆盖入口及主干风险；每个高能量或故障影响可扩散的支路另设与其负载相匹配的保护。
4. 保护器件不是容量补偿：负载计算、转换能力、线束承载、散热和短路处置必须分别验证。

## 3. 逻辑与危险动力、急停边界

急停为**独立硬件动力切断回路**，其切断对象是三轴运动、四路挡板、夹爪及经风险评估确认的其他危险执行器动力支路。急停状态同时反馈给 STM32；STM32 随即停止脉冲、关闭相关使能、锁定故障并向上层报告，但软件动作不能替代硬件切断。

- 逻辑控制、视觉、树莓派和显示屏保持供电，用于展示故障、保存必要日志和阻止旧任务继续执行。
- 急停解除不应自动重新接通危险动力、不恢复旧任务、不自动回零或继续分拣；本轮结束后须人工复位，并重新自检、回零和生成新任务号。
- 对可能受重力影响的机构，安全性不得依赖软件或持续通电维持。机械组须给出断电安全措施；电控仅在其被验证后接入正式急停边界。
- 限位异常、驱动故障、运动超时或关键失联同样进入安全锁定；是否扩大到切断全部危险动力支路，应由正式安全回路评审和台架故障注入确定。

下表是**功能分配**，不是最终引脚表，也不隐含任一控制电平、接口标准或端子型号。

|---|---:|---|---|---|
| X 轴运动 | 1 路 | STM32 | 独立运动命令、使能、故障关联、动力接口 | 传动方式、行程、负载、安装尺寸 |
| Y 轴运动 | 1 路 | STM32 | 同上，不与 X 轴共用独立控制通道 | 同上 |

| 挡板 | 4 路 PWM | STM32 | 四路独立位置控制；可同阶段动作；到位判据另设 | 舵机型号、工作电压、PWM 范围、到位反馈方案 |
| 夹爪 | 1 组 | STM32 | DS3120MG 数字舵机：PWM 开合控制；动力由外接舵机供电模块提供 | 夹持行程、断电自然状态、是否需要旋转 |
| 限位/原点 | 按机械布置预留 | STM32 | 回零、行程保护、输入故障识别 | 数量、常态、位置、电气接口 |
| 急停反馈 | 1 组 | STM32 | 急停状态独立反馈，便于锁定与上报 | 触点与回路方案 |
| 驱动故障 | 每个驱动通道预留 | STM32 | 故障输入、故障源识别与锁定 | 故障输出形式、诊断条件 |
| 补光 | 1 组可控负载 | STM32 | 只输出控制信号；补光经独立负载支路供能 | 灯具参数、控制模块条件、安装空间 |
| 视觉—树莓派通信 | 1 条正式链路 | 视觉端/树莓派 | 与既有接口契约一致的通信、供电与接地 | 最终线束与连接方式 |
| 树莓派—STM32 通信 | 1 条正式链路 | 树莓派/STM32 | 与既有接口契约一致的通信、供电与接地 | 最终线束与连接方式 |
| 方案 A 通信 | 1 条基础预留 | 视觉端/STM32 | 仅为赛后评估保留，不进入校赛控制路径 | 是否启用的后续决策 |

`BARRIER_READY` 必须来自经验证的挡板就绪判据，不能只依据“已发出 PWM 命令”。`MOTION_DONE`、`ITEM_RESULT` 与 `DISPLAY_ACK` 是不同事件，端子分配不得改变其既有控制语义。

## 6. 选型门禁：从参数到采购与正式接线

任何候选器件或接线都必须按顺序通过下列关口。前一关未通过，后一关不授权开始。

1. **参数完整性门**：参数卡完整，机械组与供应商分别对其负责字段签认或给出可追溯资料；未知项形成阻塞清单。
2. **计算门**：基于全系统同时工况完成电源能力、各支路负载、保护协调、转换能力、线束承载、压降、发热、空间与固定条件计算；四路挡板按可同时动作工况核算。
3. **台架验证门**：在拟定拓扑下验证上电、峰值工况、急停、反接保护、短路/故障处置、通信与补光干扰、掉电恢复和温升。失败项必须回到参数或计算门，不以临时绕线放行。
4. **采购与正式接线门**：仅对通过前三关且版本冻结的条目下单；正式接线图必须引用已通过的参数卡、计算和测试记录。变更任一负载、线束路径或保护边界时，重新评估受影响关口。

危险动力急停详细回路另设独立审查门：在任何实机上电前，必须检查单点故障、触点粘连/线圈失效后的状态、额定能力、复位防自启，以及与重力轴断电防坠的协调。该审查不能由软件状态机审查替代，结论须单独归档。

## 7. 装机接线检查清单

### 上电前

- [ ] 电源入口唯一，未接入第二套供电源；总开关、防反接、总保护和各支路标识可见。
- [ ] 逻辑、通信与动力线束已分开走线、固定，活动区域不存在磨损、夹线或拉扯风险。
- [ ] 所有危险动力支路均在急停硬件切断边界内；急停反馈已接入 STM32。
- [ ] X、Y、机械手、四路挡板、夹爪、限位/原点、驱动故障、补光和通信端子均与功能表一致，并有唯一标识。
- [ ] 公共参考、屏蔽/接地及连接方向符合已确认接口资料；未使用临时线材作为长期动力连接。
- [ ] 所有已装负载都有版本匹配的参数卡、计算记录和台架通过记录。

### 首次上电与故障验证

- [ ] 无正式任务时上电，确认执行器不发生非指令动作，逻辑端可报告急停/限位/驱动故障状态。
- [ ] 逐一验证急停切断危险动力，同时逻辑端保持故障显示与记录；解除后不自动恢复旧任务。
- [ ] 逐一验证限位/原点、驱动故障和通信异常均能被 STM32 识别并进入锁定策略。
- [ ] 验证四路挡板的实际就绪条件再产生 `BARRIER_READY`；未就绪时三轴与机械手不启动。
- [ ] 在最大计划同时工况下验证供电稳定、无异常复位、无不可接受发热或通信/视觉干扰。
- [ ] 验证补光控制不从控制端直接供能，且不破坏视觉稳定性。

### 装机后复核

- [ ] 安装、线束、散热和维护空间未使整机超出赛规外形限制。
- [ ] 调试接口在装机后可访问，但比赛运行中不连接外部运动控制来源。
- [ ] 完整单件闭环中，急停与故障不会使系统自动跳件、重放运动、自动回零、重抓或继续旧任务。
- [ ] 完成检查记录并关联当前硬件、接线图和软件版本；未经变更评审不替换负载或改动动力边界。

## 8. 交付与冻结条件

本文件达到“可采购/可出正式图纸”状态的最低条件是：所有参数卡完成、计算可复算、台架验证通过且故障项关闭、急停边界经演示确认、接线图与实物标签一致。此前文件只提供接口和验证框架，不授权具体器件、数值或接线细节。
