# HDMI 屏到货验证指南（2026-08-29）

> 依据：`电控/7寸10寸 1024x600分辨率显示屏客户资料/说明文档/树莓派7" 10"11.6"13.3"系列显示屏使用说明书.pdf`
> 状态：屏幕已到货，**待上电验证**。本指南供团队上电时使用；上电/接线为 L4 授权操作，执行前需用户明确批准。
> 本屏为**非触摸 HDMI 屏**（R-D05），仅显示不参与控制。

## 1. 屏规格（说明书提取，待实物铭牌核对）

| 项 | 值 |
|---|---|
| 型号系列 | 树莓派 7"/10" 系列 HDMI 显示屏 |
| 分辨率 | **1024 × 600**（本项目，config.txt 用 `hdmi_cvt 1024 600`） |
| 接口 | HDMI（树莓派 4B 用 micro-HDMI 转接线）|
| 供电 | USB 口供电（CTouch 口兼具供电+触摸，本项目仅用供电）；供电不足时用 **5V/2A** 独立电源接 POWER 口 |
| 触摸 | 本屏支持但项目**不使用**（R-D05：仅显示） |
| 免驱 | 是（树莓派 Raspbian 改 config.txt 即可） |

## 2. 接线（树莓派 4B + 本屏）

1. micro-HDMI 转接线：树莓派 4B 的 **HDMI0** 端口（靠近电源口的第一个 HDMI 口；说明书强调 HDMI1 只有 HDMI0 有设备时才激活）→ 屏的 HDMI 口。
2. USB 供电线：树莓派任一 USB 口 → 屏的 **CTouch** 口（兼具供电）。
3. 树莓派供电：需 **足 5V/3A** 适配器 + 优质 USB 线（供电不足会导致屏幕闪屏/无法显示）。
4. 备用：若显示闪烁/无法显示，用 **5V/2A** 充电器独立给屏供电（接 POWER 口）。

## 3. config.txt 配置（1024×600，树莓派烧录后）

在 TF 卡 `boot/config.txt` 文件**末尾**追加（保存并安全弹出）：

```ini
max_usb_current=1
hdmi_force_hotplug=1
config_hdmi_boost=7
hdmi_group=2
hdmi_mode=1
hdmi_mode=87
hdmi_drive=1
display_rotate=0
hdmi_cvt 1024 600 60 6 0 0 0
```

> 备选：直接烧录随屏资料附带的镜像 `2021-10-18-raspbian-buster-full.7z`（预装驱动，见资料目录"系统镜像"），可跳过手动配置。

## 5. 常见问题速查（说明书 FAQ 提炼）

| 现象 | 原因 | 处理 |
|---|---|---|
| 无法显示 | config.txt 未改/格式错；micro-HDMI 没插紧；没插 HDMI0 | 核对配置；重新插紧；换 HDMI0 口 |
| 闪烁/抖动 | 供电不足（树莓派 USB 按需分配） | 独立 5V/2A 给屏供电；树莓派换 5V/3A |
| 显示正常但电脑端不显示 | 独立显卡 HDMI 被占用/分辨率兼容问题 | 与树莓派无关，本项目用树莓派 |
| 系统启动状态判断 | PWR 常亮、ACT 先快闪后慢闪 | 系统启动成功 |
