## 1. 与方案 A（六个固定盒）的对比

| 维度 | 方案 A：六盒 + XY 搬到位 | **方案 B：固定落料位 + 转盘** |
|---|---|---|
| **落料点** | **6 个**（每个盒一个坐标） | **1 个固定点** |
| **XY 要求** | 要精确跑到 6 个不同落点 | **只需跑到 1 个固定点** ← 精度要求更低 |
| **选格机构** | XY（复用现有 X/Y） | **第 3 个舵机 + 转盘** |
| **放料方式** | 夹爪下降 → 松开 | 夹爪松开 → **退出** → **底板开合**落料 |
| **额外执行器** | 无 | **转盘舵机** + **底板执行器** + 舵机驱动板 |
| **额外机械** | 无 | 转盘、六格、径向隔板、底板铰链 |
| **故障点** | X/Y 丢步（不可检测） | 转盘错格（**可用反馈检测**）+ 底板卡 |
| **相机** | 正俯视（现方案） | **斜视** |

### ✅ 为什么方案 B 可能更省事（我猜的动机，请确认）

落料点固定 → **XY 不再需要跑到 6 个不同坐标**，只需要：
- 精确到**托盘内的物品坐标**（这个精度要求本来就躲不掉）
- 然后走到**同一个固定点**（这个点可以反复标定到很准）

→ **XY 的绝对精度要求下降**，累积误差对落料的影响变小。

### 🔴 方案 B 的代价

1. **多一个舵机 + 一套转盘机构**（机械复杂度、装配、供电）
2. **底板开合需要额外执行器**（PDF §5 明确列为校核项）
3. **转盘零位是硬要求** —— PDF §5 原文：
   > "设置零位和可靠的位置依据，**不能只用电机通电时间选格**"
4. **空间**：装置包络 ≤350×350×450mm，转盘要放进这个范围

## 2. 关键机械校核（**直接来自 PDF §5，不要漏**）

PDF 给了落料口的几何约束：

```
r = sqrt[(Xd - Xc)² + (Yd - Yc)²]
Ri + a + c ≤ r ≤ Ro - a - c
```

- `C(Xc, Yc)` = 转盘轴心
- `P(Xd, Yd)` = 固定落料口中心
- `Ri / Ro` = 可用内外半径
- `a` = 物料水平包络圆半径
- `c` = 定位与下落偏移余量

**并且 PDF 提醒**：该式**只校核内外壁，还要单独校核两侧隔板**。

### 四个校核项（PDF 原文，逐条要过）

| 校核项 | 要求 |
|---|---|
| **物料离盘高度** | 固定落料位减少了逐盒放置的变化，但 **XY 本身不产生抬升**。若夹爪闭合已有托举作用，验证**底面净空**；否则**补充必要抬升** |
| **底板动作空间** | 向下翻开的底板**不能碰货格隔板或已存物料**。**先停转盘再开底板**，确认关到位后才允许转盘运动 |
| **货格定位** | **设置零位和可靠的位置依据，不能只用电机通电时间选格**。六格等分名义角间隔 **60°**，偏角与方向**实测** |
| **连续装料** | 分别测试货格内**已有 1、2、3 件**时再落料；检查卡口、跨格、外露，以及**转盘加减速导致物料移动** |

## 3. 坐标系与标定（PDF §6）

| 参数 | 定义 |
|---|---|
| 图像坐标 `(u, v)` | 左上角原点，像素 |
| 托盘坐标 `(XT, YT, ZT)` | 托盘**一个角**为原点，mm |
| 机械坐标 + 工具偏移 | 机械原点由回零确定；补偿滑块参考点到夹持中心的偏移 |
| **抓取点 / 落料点 / 退出点** | **抓取点每件更新**；**落料点 (Xd,Yd) 和退出点 (Xs,Ys) 分别标定** |
| **转盘角度** | `θk = θ0 + s × (k − 1) × 60°`，k = 1..6，s = 实测正反方向 |

> ⚠️ **抓取点每件更新、落料点固定** —— 这**正好是赛题要的语义**
> （货物位置随机 → 抓取点变；盒子固定 → 落点固定）。
>
> 🔴 **而固件现状是反的**：`ec_motion_plan.h:51-54` 把**抓取点写死成 (0,0)**，
> 把落料点做成参数。**这个修正（P2）对方案 A 和方案 B 都是必需的** ——
> 所以 **不需要等"选 A 还是选 B" 才能动 P2**。

## 4. 🎯 斜视相机的影响（这是方案 B 最大的技术变量）

用户要求**相机斜一点角度放**。这会改变几件事：

| 影响 | 说明 |
|---|---|
| **平面映射不再是一个简单单应** | 斜视下，**有高度的物体**在图像上的位移与俯视不同。PDF §6 已经点了"物料顶面有高度，不能直接假定托盘平面映射对顶面也准确" —— **斜视会把这条放大** |
| **遮挡** | 斜视时，**高物体挡住矮物体**的概率上升。赛题是"随机摆放"，遮挡必然发生 |
| **好处** | 斜视能看到**侧面**，**正好对应你们的"问题六：三棱锥与三棱柱投影一样"** —— 俯视分不开的，斜视可能能分开 |
| **标定工作量** | 九点标定仍然要做，但**要按多个高度层分开做**（或测高换算） |

> **建议**：**先做一个小实验**再决定倾角 ——
> 拿你们已知会混淆的物料（三棱锥 vs 三棱柱），
> **在真实倾角下拍 20 张**，看模型能不能分开。**分不开就是白改机构。**

| **1** | 舵机型号 | ✅ **MG996R**（普通模拟 PWM 舵机 → **无位置反馈**） |

### 🎯 MG996R 的规格（对照本方案需求）

| 项 | MG996R | 本方案需要 | 判定 |
|---|---|---|---|
| 行程 | **180°**（脉宽 500–2500µs 全行程） | 六格最远需 **±180°** | ⚠️ **刚好够，零余量** |
| 速度 | 0.17 s/60° @4.8V，0.14 s/60° @6V | 转 180° 约 0.42–0.51 s | ✅ 够快 |
| 扭矩 | 9.4–11 kg·cm | 转盘 + 物料 | ⚠️ 取决于转盘摩擦，**要实测** |
| 反馈 | ❌ **无** | — | 只能靠等时间 |

### ⭐ 关键发现 1：**固件已经在用 MG996R，而且是全行程**

项目里**已经有 4 个 MG996R**（挡板），而且：

```c
/* App/Inc/ec_barrier_test.h:7-8 */
#define EC_BARRIER_PULSE_MIN_US UINT16_C(500)
#define EC_BARRIER_PULSE_MAX_US UINT16_C(2500)
```

**500–2500µs 就是 MG996R 的满 180° 行程** —— 所以**固件已经会输出满行程脉宽**，
驱动转盘舵机不需要新的底层能力。

### ⭐⭐ 关键发现 2：**方案 B 取消挡板，正好腾出 4 个 PWM 通道**

现有 6 路伺服 PWM **全部占用**（`docs/design/stm32f407-pin-timer-allocation.md`）：

| 用途 | 定时器/通道 | 引脚 | 状态 |
|---|---|---|---|
| BARRIER_PWM_1 | TIM3_CH3 | PB0 | 已用（挡板） |
| BARRIER_PWM_2 | TIM3_CH4 | PB1 | 已用（挡板） |
| BARRIER_PWM_3 | TIM10_CH1 | PF6 | 已用（挡板） |
| BARRIER_PWM_4 | TIM11_CH1 | PF7 | 已用（挡板） |
| GRIP_PWM | TIM2_CH3 | PB10 | 已用（夹爪） |
| ~~WRIST_PWM~~ | TIM2_CH4 | PB11 | **原为"DNP 预留"，现已改作 Z 升降舵机**<br>（`ec_board_stm32.c:484` 注释：*"the former WRIST_PWM channel"*） |

→ **当前没有任何空闲伺服 PWM 通道。**

**但**：用户那份 PDF §1 明确写着方案 B 要「**取消额外挡板**与复检环节」。

**所以**：方案 B 不用挡板 → **4 个 `BARRIER_PWM` 通道全部空出**
→ 转盘舵机 + 底板舵机 **各占一个，还剩 2 个**。

**这解决了方案 B 最大的一个硬件顾虑**（"多两个执行器没地方接"）。

> ⚠️ 前提：**确认方案 B 真的不需要挡板**。若还需要，就得另找通道或加 PWM 扩展板。

### ⭐ 关键发现 3：**开机自动归位，不需要每次手动**

MG996R 是**模拟舵机**：内部电位器闭环 → **给固定脉宽 = 固定绝对角度**。

所以只要 STM32 上电后**主动输出"1 号格"对应的脉宽**，转盘**自己就会转到 1 号格**。

**这意味着**：

| 用户原计划 | 实际可以做成 |
|---|---|
| **每次开机前手动把转盘归位** | ✅ **装配时对齐一次**，之后**每次开机舵机自动回 1 号格** |

**装配时要做的**：把转盘的 **1 号格** 与舵机的 **"1 号格脉宽"角度** 对齐一次，锁紧。

> ⚠️ 但**三个前提**（任一不成立就退化成"必须手动归位"）：
> 1. 舵机输出轴与转盘**刚性连接、不打滑**
> 2. 转盘不会被外力**反向带动**（人手拨、卡料顶）
> 3. 舵机内部电位器**不漂移**（廉价 MG996R 会）
>
> **而且因为没有反馈，`1` 不成立你也发现不了** —— 见 §9 的建议。

### ⚠️ 供电警告（MG996R 的经典坑）

- MG996R **堵转电流可达 2.5 A**（@6V），**不能从 STM32 的 5V/3.3V 稳压器取电**
- 项目已有 **4 个 MG996R 挡板**，供电应该已经按它们算过 ——
  **但再加 1~2 个要重新核算总电流**，并确认**电源与舵机共地**
- **供电不足的典型表现是舵机乱跳/抖动/不响应** —— 不要误判成"代码 bug"

| — | 谁驱动舵机 | ✅ 见下方 §8 的链路：**树莓派算格号 → STM32 → 舵机** |

## 8. 驱动链路（按用户描述）

```
MaixCAM ──(视觉坐标)──→ 树莓派（中枢：决定去哪个格）
                            │
                            └──(目标格号)──→ STM32（主控芯片）
                                                │
                                                ├─→ 转盘舵机（PWM 脉宽 = 格号）
                                                ├─→ XY 步进（去抓取点 / 去固定落料点）
                                                └─→ 夹爪 + 底板舵机
```

**时序（用户明确要求）**：

```
① 树莓派等摄像头返回值 → 算出目标格号
② 树莓派把格号发给 STM32
③ STM32 发脉宽给转盘舵机 → 转盘转到该格
④ 【等转动完成】
⑤ 夹爪落到固定落料点 → 放料
```

> 关键：**④ "等转动完成" 才允许 ⑤ 放料** —— 不能边转边放（PDF §5：
> "**先停转盘再开底板**，确认关到位后才允许转盘运动"）。

## 9. 🔴 我必须提出的两个技术风险

### 风险 1：**六格 360°，普通 180° 舵机刚好够、但没有余量**

六格均布 → 相邻间隔 **60°**；从 1 号格走到 4 号格是 **180°**。

**好在圆是对称的**，以 **1 号格为归位点**，**±180° 就能覆盖全部 6 格**：

| 格 | 正向角度 | 反向角度 |
|---|---|---|
| 1 | 0°（归位） | 0° |
| 2 | +60° | — |
| 3 | +120° | — |
| 4 | +180° | −180° |
| 5 | — | −120° |
| 6 | — | −60° |

**最大需求 = ±180°**，正好是标准舵机的标称行程。

**⚠️ 必须确认三件事**：

1. **舵机实际行程是不是真 180°？** 很多标称 180° 的舵机实际只有 **170° 左右**
   → 那就**够不到最远的格**
2. **舵机输出轴与转盘是 1:1 直连，还是有减速/增速？**
   若不是 1:1，角度换算全变（`θk` 公式要带传动比）
3. **舵机行程若不足，两个出路**：
   - 换 **270° 舵机**（有余量，推荐）
   - 或**减小格数**（但赛题要求六个盒，不能减）
   - 或**加 2:1 减速**（舵机 90° → 转盘 180°，但那样舵机只需 ±90°，反而更宽松）

> **建议**：**直接用 270° 舵机**。180° 是"刚好够、且要押在标称值准确"上，
> 一旦实测 170° 就卡死。270° 留 90° 余量，成本几乎一样。

### 风险 2：**普通 PWM 舵机不回报"转完了"，只能等固定时间**

你说"等它舵机接收到指令转动完了过后，然后夹爪再放下去" ——
但**普通 PWM 舵机没有反馈信号**，STM32 **无法知道它转完了**。

**能做到的**：STM32 发完脉宽后**等一个固定时间**（要标定：转 60° 需要多久 + 安全余量）。

**✅ 一个好消息**：**误差不累积**。舵机是**绝对角度器件** —— 给不同脉宽就是不同绝对角度，
不像"连续旋转舵机"那样靠计时累积。**所以第 3 格永远在第 3 格的角度**。

**⚠️ 但有三个前提**：

1. **手动归位要准**（和 XY 原点方案 A 一样，靠人）
2. **舵机输出轴与转盘不能打滑**（打滑一次，之后就全错）
3. **上电瞬间舵机会不会自己动？** 很多舵机上电会跳到某个默认位置 ——
   **如果它跳到 0° 而你的转盘在别处，就等于"开机自动复位"**，这其实是好事；
   **但如果它保持在上次位置，你的"手动归位"就有意义**。**要实测确认。**

### 建议

- **落料口留足容差** —— PDF 公式里的 **`c`（定位与下落偏移余量）** 就是留给这个的。
  手动归位偏 5°，落料口就可能压到隔板 → **卡料 → 货没进盒 → 零分**
- **考虑加一个极简零位检测**（光电对管或微动开关，几块钱）：
  你已经放弃 XY 限位（可接受，因为有软件可达域兜底），
  但**转盘是离散选格 —— 错一格 = 分错盒 = 零分**，比 XY 的连续偏移更致命。
  **这是本方案里唯一我强烈建议不要省的东西。**
- 若不加：**每次开机归位后，目视确认落料口对准 1 号格**，并把这条写进开机流程
