# 智能分拣装置 PCB 方案（17HS4401 版）

> 文档状态：V0.1，方案评审稿；不是已冻结原理图、PCB、采购清单或正式接线图。  
> 适用范围：校赛方案 B，探索者 STM32F407ZGT6 载板/接口板。  
> 更新时间：2026-08-12。  
> 依据：`docs/design/modular-pcb-design.md`、`docs/design/electrical-control-practical-hardware.md`、`电控/资料/要求汇总.md`。

## 1. 任务分析与目标

### 1.1 真实问题

需要先把已确认的执行器型号落实到 PCB 的接口和模块边界，形成可评审、可进入 KiCad 原理图草图的方案；同时避免因 A4988、电源、端子、线宽和未确认机械参数过早冻结而返工或制造安全风险。

### 1.2 目标状态

本方案目标是形成一块“载板/接口板”，而不是重复制作一块大而全的控制主板：

- 探索者 STM32F407ZGT6 作为可拆卸主控，负责唯一的底层运动与安全控制。
- X、Y、Z 三轴各接一台已确认型号的 `17HS4401` 两相步进电机（Z 轴板外驱动）。
- X、Y 各预留一个可插拔 A4988 候选模块位；在适配验证前不得视为最终驱动。
- 夹爪使用已确认的 `DS3120MG` 数字舵机，只提供 PWM 控制和外部动力边界。
- 第三运动通道仅提供通用 `STEP/DIR/ENABLE` 及可选反馈接口，不在本 PCB 集成具体功率驱动器。
- 四路挡板、限位/原点、急停反馈、驱动反馈、补光控制和通信保留清晰接口。

### 1.3 验收方式

方案通过评审的最低条件：网络命名和接口边界完整；已确认型号与旧记录一致；未知项显式列出；急停主回路不经过 PCB；A4988 仍标记为候选；能够据此建立 KiCad 层级原理图草图和参数冻结清单。

## 3. 总体拓扑

```text
单一内置电源
  └─ 外部总开关/防反接/总保护/分路保护
      ├─ 外接逻辑电源模块 ──> PCB 逻辑入口 ──> 探索者 STM32F407
      ├─ 急停硬件切断后的危险动力
      │   ├─ X/Y A4988 候选模块动力输入（验证通过后）
      │   ├─ 外接 Z 轴驱动器及其动力
      │   └─ 外接挡板/DS3120MG 舵机供电模块
      └─ 外接补光负载开关与灯具

探索者 STM32F407
  └─ PCB 载板/接口板
      ├─ X/Y A4988 候选模块插座与电机端口
      ├─ X/Y 备用控制接口及 Z 轴通用 STEP/DIR/ENABLE 外接端口
      ├─ 四路挡板 PWM 与 DS3120MG PWM 接口
      ├─ 限位/原点、急停反馈、驱动反馈、启动/复位
      ├─ 补光控制、通信预留和调试测试点
      └─ 低能量保护、默认安全态和网络标识
```

PCB 不承担总电源入口、高能量 DC/DC、舵机功率分配、补光功率开关、急停接触器/继电器或 Z 轴具体驱动器。

急停主回路仅切断危险动力正极，公共参考地保持连续；否则会造成逻辑参考漂移、反馈失真或以断地代替安全切断。Z 轴的断电防坠方案未经机械组和台架验证前，急停动力回路不得冻结。

## 4. 功能与接口定义

以下为建议的 KiCad 网络/功能名，不是最终 MCU 物理引脚、控制电平或连接器针序。

| 接口/位号建议 | 功能信号 | 设计边界 |
|---|---|---|
| `J_MCU_A..n` | `GND_LOGIC`、经核对的逻辑电源、X/Y/Z 的 `STEP/DIR/ENABLE`、四路 `PWM_BARRIER`、`GRIP_PWM`、`LIGHT_EN`、限位/原点、`ESTOP_FB`、驱动反馈、启动/复位、通信预留 | 先核对探索者原理图和实物排针，再完成 GPIO 映射。 |
| `U_DRV_X_SOCKET` | X 轴 `STEP_X/DIR_X/ENABLE_X`、逻辑参考、候选 `VMOT_X`、动力地、电机四线、`MS1..3`、`RESET`、`SLEEP` | A4988 模块针序和封装以实物为准；故障脚不得虚构。 |
| `U_DRV_Y_SOCKET` | 与 X 轴同构但使用独立网络 | 不得与 X 轴共用电机、动力或控制网络。 |
| `J_X_MOTOR` / `J_Y_MOTOR` | `COIL_A1/A2/COIL_B1/B2` | 线序必须通过实测确认，不以线色推断。 |
| `J_DRV_X_CTRL` / `J_DRV_Y_CTRL` | 对应轴的 `STEP`、`DIR`、`ENABLE`、`GND_LOGIC`，可选 `DRV_FAULT_IN`、`DRV_READY_IN` | **方案 A 预留，默认 DNP。** 仅在对应 A4988 模块保持未装、危险动力未供或已禁止时，连接板外驱动器；板外驱动器的动力输入、电机输出和保护均在载板外。不得让 A4988 与板外驱动器同时连接或共同驱动同一电机。 |
| `J_DRV3_CTRL` | `GND_LOGIC`、`STEP_3`、`DIR_3`、`ENABLE_3`、可选 `DRV3_FAULT_IN`、`DRV3_READY_IN` | 只提供通用控制/反馈，Z 轴动力和防坠在板外。 |
| `J_BARRIER_CTRL_1..4` | 每路 `PWM_BARRIER_n` 与逻辑参考 | 舵机动力由外接急停边界内供电模块提供；不经 PCB 功率路径。 |
| `J_GRIPPER_CTRL` | `GRIP_PWM`、逻辑参考，可选反馈 | 对应 `DS3120MG`；动力由外接舵机电源提供，旋转默认不启用。 |
| `J_LIMIT_HOME` | 各轴限位/原点输入 | 输入类型、数量、滤波和电平待机械组确认。 |
| `J_ESTOP_FB` | `ESTOP_FB`、`GND_LOGIC`、可选反馈回路参考电源 | 只读急停辅助触点/模块反馈，绝不替代急停主回路；反馈参考电源是否装配、隔离方式和常开/常闭形式待安全回路确认。 |
| `J_BARRIER_READY_IN` / `J_AUX_IN_n` | 经验证的挡板到位/就绪反馈输入，可选 `GND_SENSOR`、`V_SENSOR` | 为 `BARRIER_READY` 预留输入路径；最终可采用独立传感器或经验证的时序判据。仅发出 PWM 不得产生 `BARRIER_READY`；未确认前不进入比赛主链。 |
| `J_LIGHT_CTRL` | `LIGHT_EN`、可选 `LIGHT_FB` | 只输出控制信号，灯具功率和开关模块在板外。 |
| `J_LOGIC_PWR_IN` | `V_LOGIC_IN`、`GND_LOGIC` | 来自外接逻辑电源模块，参数冻结后确定保护和连接器。 |
| `TP_*` | 逻辑电源、地、STEP/DIR/ENABLE/PWM、关键输入及候选动力网络 | 逻辑网络可用普通示波器测试点；候选动力网络不得采用可随意触及的普通探针焊盘，只能在额定、装配状态和触及防护经审查后使用专用测量连接方式。 |

## 5. 关键器件与适配策略

### 5.1 17HS4401 与 A4988 候选

`17HS4401` 额定 1.7A/相，A4988 模块在该电流附近存在持续散热和限流能力风险。因此本方案只冻结“模块位和接口形态”，不冻结 A4988 为最终驱动。

必须完成以下台架门禁：

1. 取得电机和候选模块供应商资料，核对相电阻、相电感、模块针序、散热方式和限流关系。
2. 在实际运动负载下测量两相同时导通的峰值/持续电流，验证限流可重复设定。
3. 进行最坏计划工况的连续运行和温升测试，记录驱动器是否过热关断、掉步或引发通信干扰。
4. 完成急停断动力、释放后不自动恢复以及断电后机构安全状态测试。
5. 任一门禁失败时，对应模块位保持 DNP，改用板外适配的更高能力驱动器；不得用临时加大电流或临时散热替代重新选型。

本版采用方案 A：`J_DRV_X_CTRL` 与 `J_DRV_Y_CTRL` 是默认不装配的候选控制接口。A4988 验证通过时接口保持 DNP；若任一轴 A4988 验证失败，必须保持该模块未装、其危险动力不供或使能被禁止，再根据最终板外驱动器资料装配/接线对应接口。接口仅提供低能量控制和可选反馈，不能假定 A4988 插座、板外驱动器电平、反馈定义或电机端子可直接兼容。

### 5.2 DS3120MG 夹爪

PCB 仅提供 `GRIP_PWM` 和逻辑参考。DS3120MG 的精确供电范围、PWM 脉宽/频率、堵转电流和机械断电自然状态仍需供应商资料及台架确认。夹爪电源必须位于急停危险动力边界内，夹紧动作设置软件超时并进入故障锁定，不把 PWM 已发出当作夹持成功。

## 7. PCB 布局与布线原则

1. 主控区居中或靠维护侧；USB 串口、SWD 和测试点保持可访问。载板不重复集成 MCU、晶振、下载器或板载 USB 串口。
2. X/Y A4988 候选模块相邻但完全独立，保留插拔、散热、调流和测量空间；动力/电机端子靠板边，控制侧朝主控区。
3. 低能量输入区靠板边，限位、启动、复位、急停反馈和通信与电机相线分开；长线输入的 RC/ESD 位靠连接器布置。
4. `STEP/DIR/PWM/UART` 远离电机相线、舵机动力和补光开关回路；必要交叉采用近似正交，并保持连续参考回流路径。
5. 候选驱动动力回路采用局部短回路思路；铜宽、铜厚、过孔、端子和温升必须依据冻结后的电流与制造能力计算，不使用默认经验值。
6. 逻辑地、动力地、传感参考和屏蔽连接的汇接点在整机接地方案中冻结；不通过细信号线承载动力回流。
7. 丝印必须标出功能、方向、危险动力与逻辑电源区别、候选/DNP 状态、一脚标记和维护注意事项。

## 9. 最小验收清单

- [ ] X/Y 均使用独立 `STEP/DIR/ENABLE`、独立动力和独立电机网络，无跨轴复制错误。
- [ ] `17HS4401` 的 1.7A/相风险在 A4988 页面醒目标注，A4988 未被写成最终驱动。
- [ ] `J_DRV_X_CTRL`、`J_DRV_Y_CTRL` 标注为默认 DNP，且明确 A4988 与板外驱动器二选一，绝不共同驱动同一电机。
- [ ] `DS3120MG` 仅进入 PWM 控制接口，舵机功率路径和急停边界在板外。
- [ ] `J_ESTOP_FB` 的信号、逻辑地和可选反馈参考电源与 PCB 基线一致；反馈参考不替代急停主回路。
- [ ] `BARRIER_READY` 的硬件输入路径使用 `J_BARRIER_READY_IN`/`J_AUX_IN_n` 预留，并明确最终判据；仅发送 PWM 不得放行运动。
- [ ] Z 轴没有被猜写成具体驱动器、动力输入、电机输出或防坠方案。
- [ ] 急停主回路不经过载板，`ESTOP_FB` 只作状态输入；释放急停不自动重接动力或恢复旧任务。
- [ ] 急停仅切危险动力正极，不切公共参考地；Z 轴防坠方案未经验证时，急停动力回路不冻结。
- [ ] 逻辑电源、A4988 动力、舵机动力和补光负载电源没有因同名标签误并网。
- [ ] 高能量网络没有装配为可随意触及的普通测试点；其测量方式、额定条件和触及防护已单独审查。
- [ ] 所有具体 GPIO、排针、针序、端子额定值、线宽和保护数值均有资料或计算依据。
- [ ] 完成无负载上电、单轴空载、单轴负载、X/Y 组合、夹爪堵转、急停、限位、掉压和通信干扰测试计划。

## 10. 下一步工作包

1. 机械组：提交 17HS4401 数据手册/实物线序、X/Y/Z 传动与负载、Z 轴驱动器选型与断电防坠、挡板舵机和限位参数。
2. 电控组：核对探索者排针与 STM32 复用功能，建立“功能网络—排针—GPIO/外设”三列表；不直接猜引脚。
3. 电控组：取得候选 A4988 实物尺寸和针序，建立 1:1 模块封装与 DNP 标识。
4. 集成组：依据单一电源和急停边界完成供电、线束、故障注入和台架测试记录。
5. 评审后：仅在候选项通过门禁后，将本方案转换为 KiCad 原理图输入；任何型号或接口变化都要更新版本和受影响清单。
