**创建时间**：2026-10-26  
**目标**：采集150-200个圆锥标注实例，用于YOLO 6类模型训练

## 一、采集环境要求

### 1.1 硬件设备
- **相机**：MaixCAM Pro（与现场部署一致）
- **托盘**：白色托盘（与现场一致，**这是最重要的**）
- **光源**：自然光 + LED补光灯
- **圆锥实物**：5种颜色各1个（白/红/蓝/绿/黄）

### 1.2 拍摄角度
- **主要角度**：正上方俯视（90°垂直）
- **辅助角度**（可选）：45°斜视（帮助区分圆柱/圆锥）

## 二、采集方案

### 2.1 基础场景（每色30-40张）

**单件场景**（每色15-20张）：
- 不同位置：托盘中心、边缘、角落
- 不同旋转：0°/45°/90°/135°（底面朝向）
- 不同光照：
  - 开灯/关灯
  - 有阴影/无阴影
  - 反光/不反光

**多件场景**（每色15-20张）：
- 相邻件：圆锥 + 圆锥
- 混合件：圆锥 + 圆柱（**重点！易混淆**）
- 混合件：圆锥 + 其他形状

### 2.2 困难场景（每色10张）

- **机械臂遮挡**：夹爪部分遮挡圆锥
- **边缘切割**：圆锥部分超出托盘边界
- **极端光照**：
  - 强烈反光（尖顶高光）
  - 深色阴影（侧壁暗）
- **底面特写**：圆形底面边缘清晰可见

### 2.3 对比场景（20张）

**圆锥 vs 圆柱**（最易混淆，重点采集）：
- 俯视对比：圆锥尖顶 vs 圆柱平顶
- 侧视对比：圆锥斜壁 vs 圆柱直壁
- 相邻摆放：两者挨在一起

## 四、标注指南

### 4.1 标注工具

推荐使用 **labelImg** 或 **Label Studio**：
```bash
# 安装labelImg
pip install labelImg

# 启动
labelImg 视觉/datasets/cone_collection_20261026/ \
         视觉/datasets/cone_collection_20261026/classes.txt
```

### 4.2 标注要点

**框选范围**：
- ✅ 包含整个圆锥（底面圆 + 尖顶）
- ✅ 底面边缘尽量清晰
- ❌ 不要框太紧（预留1-2像素边距）
- ❌ 不要包含阴影

**class_id**：
- 必须标注为 **4**（cone）
- 不要与圆柱(2)混淆

**质量检查**：
- 每标注20张，抽查一遍
- 用脚本画框验证

### 4.3 标注质量检查脚本

```python
# 在 视觉/tools/ 下创建
python 视觉/tools/visualize_labels.py \
    --images 视觉/datasets/cone_collection_20261026/images \
    --labels 视觉/datasets/cone_collection_20261026/labels \
    --output 视觉/datasets/cone_collection_20261026/visualized
```

## 七、常见问题

### Q1：圆锥实物没有，怎么办？
A：可以用以下替代：
- 纸质圆锥（彩纸卷成）
- 3D打印圆锥（STL文件在 `机械/models/` 下）
- 临时采购（淘宝几何体教具，搜"圆锥教具"）

### Q2：圆锥和圆柱俯视很像，如何标注？
A：看尖顶：
- 圆锥：中心有明显尖点
- 圆柱：中心平坦

如果实在难以区分，采集时加拍侧视照片。

### Q3：采集环境和训练环境不一致怎么办？
A：**必须在白托盘上拍**！这是任务要求，用木桌拍的数据无法解决域偏移问题。

### Q4：标注太慢怎么办？
A：
- 用预标注模型（先用5类模型预测，再手工修正）
- 批量标注工具（Label Studio支持）
- 数据增强（1张图→4张变种）

## 九、紧急预案

### 如果圆锥数据采集失败（时间不够、实物缺失）

**备选方案A**：几何特征辅助
- 保持5类YOLO模型
- 对圆柱/圆锥用几何特征判定（顶部尖锐度检测）
- 参考代码：`视觉/src/sorting_vision/shape_geometry.py`

**备选方案B**：简化任务
- 与赛方确认：圆锥是否可用圆柱代替计分
- 如果可以，跳过圆锥采集

**备选方案C**：现场快速训练
- 带笔记本到现场
- 现场采集100张圆锥照片
- 用GPU快速训练（30分钟）
- 立即部署
