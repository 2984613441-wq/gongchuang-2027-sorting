## ⚠️ 使用说明（必读）

### 优先级
1. **引脚以本文为准** - 交接总纲§5的引脚真相已整合到本文
2. **断电接线** - 所有接线必须在断电状态下进行
3. **分步验证** - 接一组线，验证一组功能，不要一次性全接
4. **万用表必备** - 上电前检查12V+与GND不短路

### 安全红线
- ❌ **动力线不走杜邦线** - 12V/GND/电机相线必须用0.5mm²以上连接线
- ❌ **不要单独给气动阀从STM32取电** - 气动阀需独立5V电源或MOS管驱动
- ❌ **所有GND必须接到公共点** - 星型拓扑，不是两两互接
- ❌ **保险丝必须在最前端** - 电池正极出来第一个就是保险丝

## 🔌 供电拓扑（核心架构）

```
电池 12V+ ──[保险丝 3A]──┬─► 【12V公共点】(WAGO 221-415 或端子排)
                          │     ├─► DCP3512 VIN+ (12V→5V)
                          │     ├─► PD42S1电机①驱动器 VIN+ (12V直供)
                          │     ├─► PD42S1电机②驱动器 VIN+ (12V直供)
                          │     └─► 预留扩展

电池 GND ──────────────────┬─► 【GND公共点】(WAGO 221大号 或 6P端子排)
                          │     ├─► DCP3512 GND
                          │     ├─► PD42S1驱动器① GND
                          │     ├─► PD42S1驱动器② GND
                          │     ├─► STM32 GND (多点)
                          │     ├─► 树莓派 GND (如果用UART连接)
                          │     ├─► 气动阀 GND
                          │     ├─► STS3215舵机 GND
                          │     └─► 微雪板 GND

DCP3512 输出 5V  ──► ├─► STM32 5V供电
                     ├─► 树莓派 5V供电（或独立适配器）
                     ├─► 气动阀 VCC（通过MOS管/继电器）
                     └─► STS3215舵机 VCC

DCP3512 输出 GND ──► 回到【GND公共点】
```

**关键点**：
- ✅ 所有GND星型汇聚到一个公共点
- ✅ 12V直供给电机驱动器（不降压）
- ✅ 5V支路供逻辑设备（STM32/树莓派/舵机/气动阀）
- ⚠️ 气动阀不要直接从STM32 GPIO取电（电流可能超标）

### 3. 转盘舵机（STS3215，串口控制）

| STM32引脚 | 信号 | 连接目标 | 说明 |
|-----------|------|----------|------|
| **PD8** | TX | STS3215 RX | USART3_TX（备用串口）|
| **PD9** | RX | STS3215 TX | USART3_RX |
| GND | GND | STS3215 GND | 共地 |
| - | VCC | 5V支路 | DCP3512输出5V |

**⚠️ 重要**：
- STS3215是**串口舵机**，不是PWM舵机
- 波特率：1000000（1Mbps，STS系列标准）
- 协议：Feetech STS协议（类似Dynamixel）
- USART3在`.ioc`中已配置为PD8/PD9，但代码中被迁移到PB10（死代码链）
- **需恢复USART3到PD8/PD9**，清理PB10的USART3代码

**或者使用树莓派GPIO控制**：
- 如果STM32 USART3冲突，可以用树莓派GPIO串口（TX/RX）直接控制STS3215
- 树莓派GPIO14(TX)/GPIO15(RX) → STS3215

### 阶段1：供电主干（最重要，先搭好）

**⚠️ 这一步错了后面全废，慢慢来**

#### 1.1 搭建12V公共点
```
电池12V+ ──► [保险丝3A] ──► WAGO 221-415 (5孔)
                               ├─ 孔1：电池12V+进线
                               ├─ 孔2：去DCP3512 VIN+
                               ├─ 孔3：去PD42S1驱动器① 12V
                               ├─ 孔4：去PD42S1驱动器② 12V
                               └─ 孔5：预留
```

**操作**：
1. 电池12V+剥线10mm → 保险丝座一端
2. 保险丝座另一端剥线10mm → WAGO 221-415 孔1（掰起橙色杆→插线→压下）
3. 准备4根红色连接线（各30cm）剥两头
4. 分别插入孔2/3/4/5

**验证**：
- [ ] 轻拽每根线，拽不出来
- [ ] 万用表测量孔2/3/4的线头，对GND电压=0V（因为还没上电）

---

#### 1.2 搭建GND公共点
```
电池GND ──► WAGO 221-415 (5孔) 或 6P螺丝端子排
              ├─ 去DCP3512 GND
              ├─ 去PD42S1驱动器① GND
              ├─ 去PD42S1驱动器② GND
              ├─ 去STM32 GND
              └─ 去树莓派 GND（如需）
```

**操作**：
1. 电池GND剥线10mm → WAGO 221大号孔1
2. 准备6根黑色连接线（各30-50cm）剥两头
3. 分别插入其他孔

**验证**：
- [ ] 轻拽每根线，拽不出来
- [ ] 万用表测量：12V+公共点 对 GND公共点 = 0V（断路，未上电）

---

#### 1.3 连接DCP3512降压模块
```
DCP3512 输入：
  VIN+ ──► 从12V公共点引出的红线
  GND  ──► 从GND公共点引出的黑线

DCP3512 输出：
  5V+  ──► 准备3根红线（去STM32/舵机/气动阀）
  GND  ──► 回到GND公共点
```

**操作**：
1. 从12V公共点拉一根红线 → DCP3512 VIN+螺丝端子
2. 从GND公共点拉一根黑线 → DCP3512 GND螺丝端子
3. DCP输出5V端子 → 准备分支（暂不接负载）

**⚠️ 第一次上电测试**：
1. 电池接上（保险丝已装好）
2. 万用表测量DCP输出：5V端子对GND = **4.8-5.2V**
3. **如果不是5V，立即断电检查**
4. 确认5V正常后断电，继续接线

### 阶段3：编码器电机（X/Y轴，精确定位）

#### 3.1 PD42S1驱动器供电（两台）

**X轴驱动器①**：
```
12V公共点 ──► 驱动器① VIN+ (螺丝端子)
GND公共点 ──► 驱动器① GND  (螺丝端子)
```

**Y轴驱动器②**：
```
12V公共点 ──► 驱动器② VIN+ (螺丝端子)
GND公共点 ──► 驱动器② GND  (螺丝端子)
```

**操作**：
1. 从12V公共点拉两根红线 → 两台驱动器VIN+
2. 从GND公共点拉两根黑线 → 两台驱动器GND
3. 拧紧螺丝端子

**验证**：
- [ ] 上电，驱动器LED亮（如果有）
- [ ] 驱动器无异常发热

---

#### 3.2 X轴控制信号（STM32 → PD42S1驱动器①）

| STM32 | 杜邦线颜色 | 驱动器① |
|-------|-----------|---------|
| PC6 | 白色 | STEP+ |
| PA7 | 绿色 | DIR+ |
| PA5 | 黄色 | ENA+ |
| GND | 黑色 | STEP-/DIR-/ENA- (公共信号地) |

**操作**：
1. 杜邦线母头套STM32引脚
2. 另一头接驱动器对应端子（查驱动器说明书确认引脚定义）

### 阶段4：气动夹爪（新增）

#### 4.1 气动阀供电（独立5V）

**⚠️ 不要从STM32 GPIO直接取电**

**方案A：MOS管控制（推荐）**
```
STM32 PB11 ──► MOS管 Gate (信号控制)
DCP 5V     ──► MOS管 Drain
MOS管 Source ──► 气动阀 VCC
气动阀 GND   ──► GND公共点
气动阀 信号  ──► STM32 PB11 (PWM)
```

**方案B：继电器控制**
```
STM32 PB11 ──► 继电器线圈 (通过三极管驱动)
DCP 5V     ──► 继电器常开端
继电器输出 ──► 气动阀 VCC
气动阀 GND ──► GND公共点
```

**方案C：如果气动阀电流<100mA，可直接连**
```
STM32 PB11 ──► 气动阀信号线
DCP 5V     ──► 气动阀 VCC
GND        ──► 气动阀 GND
```

**⚠️ 先万用表测气动阀工作电流，再决定方案**

## 🚨 常见问题与故障排查

### Q1：上电后STM32不启动
- 检查5V供电是否正常（万用表测）
- 检查GND是否连接
- 检查是否短路（12V+对GND应该>1MΩ）
- 尝试单独用USB供电STM32排除电源问题

---

### Q2：电机不转
- 检查ENABLE信号是否低电平（使能）
- 检查STEP脉冲是否输出（示波器/LED指示）
- 检查驱动器供电12V是否正常
- 检查电机相线是否接触良好
- 检查驱动器限流设置

---

### Q3：电机方向反
- 交换DIR信号（软件取反）
- 或交换电机A+/A-或B+/B-

---

### Q4：气动阀不动作
- 检查PB11 PWM输出（示波器测50Hz）
- 检查气动阀供电5V是否正常
- 检查气源压力是否足够
- 检查气管是否漏气

---

### Q5：串口通信乱码
- 检查波特率（115200）
- 检查GND是否共地
- 检查TX/RX是否接反
- 检查电平（STM32是3.3V，树莓派GPIO也是3.3V，兼容）

---

### Q6：HDMI屏无显示
- 检查Micro-HDMI线是否插HDMI0口
- 检查屏幕供电
- 检查分辨率设置（`/boot/config.txt`）
- 尝试`sudo raspi-config`重新配置

---

### Q7：保险丝烧断
- ⚠️ **立即断电！**
- 万用表测12V+对GND是否短路
- 检查接线是否有裸露铜线碰到一起
- 检查驱动器/电机是否短路
- 排除故障后换新保险丝
