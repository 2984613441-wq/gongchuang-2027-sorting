# 气动夹爪测试指南

**日期**: 2026-10-11  
**测试对象**: 气动电磁阀 + 气动夹爪  
**控制引脚**: STM32 PB11 (TIM2_CH4)  
**PWM频率**: 50Hz（周期20ms）

---

## 📋 测试前准备

### 硬件连接

#### 方案A：直接连接（如果气动阀电流<100mA）
```
STM32 PB11 ──► 气动阀信号线（黄/白）
STM32 GND  ──► 气动阀GND（黑/棕）
5V电源     ──► 气动阀VCC（红）
```

#### 方案B：MOS管驱动（推荐，安全）
```
STM32 PB11 ──► MOS管Gate（信号控制）
5V电源     ──► MOS管Drain
MOS管Source ──► 气动阀VCC
气动阀GND   ──► GND公共点
```

#### 气动管路
```
气泵 ──► 气动阀输入
气动阀输出1 ──► 夹爪气缸正向（张开）
气动阀输出2 ──► 夹爪气缸反向（闭合）
```

## 🧪 测试步骤

### 测试1：硬件连接验证（断电）

- [ ] 气动阀信号线连接PB11
- [ ] 气动阀GND连接STM32 GND
- [ ] 气动阀VCC连接5V电源（独立或通过MOS管）
- [ ] 气动管路连接正确
- [ ] **万用表检查**：5V对GND = 5V ± 0.2V
- [ ] **万用表检查**：PB11对GND = 0V（断电状态）

---

### 测试2：PWM信号验证（上电，不接气动阀）

**目的**：确认PB11输出PWM信号

**操作**：
1. 烧录固件（包含气动夹爪代码）
2. 上电
3. 用示波器或逻辑分析仪测量PB11引脚

**验收标准**：
- [ ] 频率 = 50Hz ± 1%（周期20ms）
- [ ] 初始脉宽 = 1500us（中位）
- [ ] 幅值 = 3.3V（STM32 GPIO高电平）

**如果没有示波器**：
- 用LED+电阻（330Ω）连接PB11→GND，LED应该亮（PWM占空比>0）
- 或直接接气动阀，听阀体声音

---

### 测试3：气动阀响应测试（不接气缸）

**目的**：确认气动阀能切换

**操作**：
1. 接好气动阀电源+信号线
2. **不接气管**（先测阀体）
3. 通过串口发送命令：
   ```bash
   # 在树莓派上运行
   python3 工具/test_pneumatic_gripper.py
   
   # 选择"1. 基本测试"
   # 依次设置 1000us / 2000us / 1500us
   ```

**验收标准**：
- [ ] 改变脉宽时，能听到气动阀切换声音（咔嗒声）
- [ ] 1000us和2000us声音不同
- [ ] 气动阀LED指示灯变化（如果有）

**如果没有响应**：
- 检查PWM信号是否到达（万用表DC档测PB11，应该有0.5-3V电压）
- 检查气动阀供电5V是否正常
- 检查气动阀信号线极性（某些阀体信号是负逻辑）

---

### 测试4：气动夹爪动作测试（接气缸）

**目的**：确认夹爪能张开/闭合

**操作**：
1. 接好气动管路
2. 确认气泵有压力（手感能感受到气流）
3. 运行测试脚本：
   ```bash
   python3 工具/test_pneumatic_gripper.py
   
   # 选择"1. 基本测试"
   ```

**验收标准**：
- [ ] 1000us → 夹爪张开
- [ ] 2000us → 夹爪闭合
- [ ] 动作连贯，无卡顿
- [ ] 能夹住测试物体（如笔、小方块）

**如果方向反了**：
- 交换气动阀输出1和输出2的气管
- 或在代码中交换 `PULSE_OPEN` 和 `PULSE_CLOSE` 的值

---

### 测试7：实际夹取测试

**目的**：模拟真实分拣

**测试件**：
- 轻质件（泡沫块）
- 标准件（小方块）
- 重件（金属块，如果夹爪承重允许）
- 不规则件（三棱柱、圆柱）

**操作**：
1. 手动放置测试件到夹取位置
2. 发送闭合命令
3. 提升（如果有Z轴）
4. 移动到目标位置
5. 发送张开命令

**验收标准**：
- [ ] 能稳定夹住所有测试件
- [ ] 夹持力适中（不夹伤、不掉落）
- [ ] 张开后件能自由落下
- [ ] 尖顶件不会被弹飞

**如果夹不住**：
- 增大闭合脉宽（增加夹持力）
- 检查气压是否足够
- 检查夹爪开口是否对准件中心

## ⚠️ 常见问题

### Q1: 气动阀不响应
**现象**：改变脉宽无反应，无声音  
**排查**：
1. 示波器测PB11是否有PWM（50Hz）
2. 万用表测气动阀VCC是否为5V
3. 检查信号线是否接触良好
4. 尝试用3.3V直接接信号线（绕过PWM）测试阀体

---

### Q2: 夹爪方向反了
**现象**：1000us闭合，2000us张开  
**解决**：交换气动阀输出1和2的气管

---

### Q3: 夹持力不够
**现象**：件会掉落  
**解决**：
1. 增大闭合脉宽（如2000→2100us）
2. 检查气源压力是否足够
3. 检查气管是否漏气
4. 考虑更换大缸径气缸

---

### Q4: 张开速度太慢
**现象**：气动阀切换后1-2秒才完全张开  
**原因**：气路阻力大、气泵流量不足  
**解决**：
1. 缩短气管长度
2. 增大气管内径
3. 提高气源压力
4. 更换大流量气泵

---

### Q5: 电磁阀发热
**现象**：连续工作后阀体烫手  
**原因**：线圈持续通电、电压过高  
**解决**：
1. 确认工作电压（5V还是12V）
2. 考虑使用PWM占空比控制（保持力<全力）
3. 增加散热片
