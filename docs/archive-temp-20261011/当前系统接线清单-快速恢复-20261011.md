## ⚡ 供电线（最重要，红黑两色）

### 主电源链
```
电池12V+正极 ──► [保险丝3A] ──► 12V公共点（WAGO或端子排）
                                 ├─► DCP3512降压模块 VIN+
                                 └─► （预留A4988驱动器，如还在用）

电池GND负极 ────────────────────► GND公共点（WAGO或端子排）
                                 ├─► DCP3512降压模块 GND
                                 ├─► STM32主控 GND（多处）
                                 ├─► 树莓派 GND
                                 └─► 舵机 GND
```

### 5V支路（DCP3512输出）
```
DCP3512 5V输出 ──► ├─► STM32主控 5V输入
                   ├─► 舵机（DS3120MG）VCC（红线）
                   └─► （如有其他5V设备）

DCP3512 GND ────► 回到GND公共点
```

**⚠️ 关键**：所有GND必须连接到同一个公共点（星型拓扑）

## 🤖 A4988步进驱动器接线

### X轴驱动器

**信号线（来自STM32）**：
- STEP ← PC6
- DIR ← PA7
- EN ← PA5
- GND ← STM32 GND

**电机线（去步进电机）**：
- 1A ← 电机A+
- 1B ← 电机A-
- 2A ← 电机B+
- 2B ← 电机B-

**供电**：
- VMOT ← 12V公共点（动力）
- GND ← GND公共点

### Y轴驱动器
同X轴，信号线换成 PB6/PC7/PD7

**⚠️ 注意**：
- 电机相线如果方向反，交换1A/1B或2A/2B
- 不要交换供电极性

## 🌲 树莓派连接

### 树莓派↔STM32（主链路）

**方式1**（USB，推荐）:
```
树莓派USB口 ──USB线──► STM32探索者板载USB转串口
```

**方式2**（GPIO）:
```
树莓派GPIO14(TX) ──杜邦线──► STM32 PA3(RX)
树莓派GPIO15(RX) ──杜邦线──► STM32 PA2(TX)
树莓派GND       ──杜邦线──► STM32 GND
```

### 树莓派↔MaixCAM Pro

```
树莓派USB口 ──USB线──► MaixCAM Pro USB-C口
```

### 树莓派↔HDMI屏

```
树莓派Micro-HDMI ──Micro-HDMI转HDMI线──► 显示屏HDMI输入
```
**注意**：用HDMI0口（靠近Type-C电源口）

### 树莓派供电

```
独立5V/3A适配器 ──► 树莓派Type-C电源口
```
或者从DCP3512 5V输出引线（如果电流够）

## 📞 应急方案

### 如果不记得某根线的作用
1. **拍照对比**：看其他类似线缆的走向
2. **万用表测通断**：确认是信号线还是电源线
3. **颜色规律**：
   - 红色 = VCC（5V或12V）
   - 黑色 = GND
   - 白/黄/绿 = 信号线

### 如果接错了会怎样？
- **信号线接反**（TX↔RX）：通信不通，但不损坏
- **电源极性接反**：⚠️ **立即断电**，可能烧毁设备
- **GND未接**：系统不稳定，通信乱码
