# 树莓派4B通过电池供电 - 物理引脚接线指南

**日期**: 2026-10-11  
**目标**: 从DCP3512 5V输出给树莓派供电，不用独立适配器  
**树莓派型号**: 树莓派4B 2GB

---

## ⚡ 供电方案选择

### 方案A：GPIO引脚供电（推荐，可靠）

**优点**:
- 绕过树莓派的保护电路，直接供电
- 可以反向供电（电脑通过树莓派USB供电其他设备）
- 接线简单

**缺点**:
- 无过流保护（需外部保险丝）
- 需要确保5V电压稳定

## 🔌 接线方式

### 推荐接线（使用物理引脚2和6）

```
DCP3512 5V输出 ──► 树莓派物理引脚2 (5V)
DCP3512 GND    ──► 树莓派物理引脚6 (GND)
```

**物理位置**：
- **引脚2 (5V)**：第1排第2个，红色标识（左上角第二个针）
- **引脚6 (GND)**：第3排第2个，黑色标识

**或者使用引脚4**：
```
DCP3512 5V输出 ──► 树莓派物理引脚4 (5V)
DCP3512 GND    ──► 树莓派物理引脚6 (GND)
```

**⚠️ 注意**：引脚2和引脚4都是5V，内部连在一起，用哪个都行

## 🛠️ 实际操作步骤

### 步骤1：准备线材

**需要**：
- 杜邦线 母对母 2根（或母对公，取决于DCP3512端子）
- 推荐线缆：0.5mm²（承载2-3A电流）

**颜色建议**：
- 红色 → 5V
- 黑色 → GND

---

### 步骤2：断电状态下接线

**⚠️ 必须断电！电池先拔掉**

**连接DCP3512侧**：
```
DCP3512输出端子（螺丝或接线柱）
  ├─ 5V输出 (VO+) ──► 红色杜邦线
  └─ GND输出 (VO-) ──► 黑色杜邦线
```

**连接树莓派侧**：
```
红色杜邦线 ──► 树莓派GPIO排针 物理引脚2 (5V)
黑色杜邦线 ──► 树莓派GPIO排针 物理引脚6 (GND)
```

---

### 步骤3：上电前检查

**万用表验证**（电池还未接）：
1. 测量DCP3512输出：
   - 5V端子 对 GND端子 = 应该0V（未上电）

**接好电池后，上电前最后检查**：
- [ ] 红线接5V（引脚2或4）
- [ ] 黑线接GND（引脚6或其他GND）
- [ ] 没有线接错到3.3V引脚（引脚1或17）
- [ ] 没有短路

---

### 步骤4：上电验证

**接上电池**，观察：
1. 树莓派红色电源LED亮（PWR灯，常亮）
2. 绿色活动LED闪烁（ACT灯，读写SD卡时闪）
3. 等待30-60秒，树莓派启动完成

**万用表测量**（上电后）：
- 树莓派引脚2 对 引脚6 = 5.0V ± 0.2V
- 树莓派引脚1 对 引脚6 = 3.3V ± 0.1V（板载LDO正常）

## ⚠️ 安全注意事项

### 1. 电流能力检查

**树莓派4B功耗**：
- 空载（无外设）：~600mA
- 典型负载（USB设备、HDMI）：~1.2A
- 峰值（4个USB全负载）：~3A

**DCP3512输出能力**：
- 规格：最大3A（确认您的型号）
- 建议：树莓派负载 < 2A（留余量给STM32/舵机）

**如果DCP3512负载过重**：
- 输出电压会下降（<4.8V）
- 树莓派会显示"低电压警告"（闪电符号）
- 解决：减少USB设备，或用独立适配器

---

### 2. 保护措施（强烈推荐）

**添加保险丝**（串联在5V线上）：
```
DCP3512 5V ──► [保险丝 2A] ──► 树莓派引脚2
```

**或添加肖特基二极管**（防反接）：
```
DCP3512 5V ──► [二极管|►─] ──► 树莓派引脚2
                正向      （压降0.3V）
```

---

### 3. 禁止事项

❌ **不要接到3.3V引脚**（引脚1或17）
- 5V接到3.3V会烧毁树莓派

❌ **不要接反极性**
- 红线（5V）接到GND会短路

❌ **不要热插拔**
- 先断电，再接线/拔线

❌ **不要从Type-C和GPIO同时供电**
- 可能导致反向电流或冲突

## 🔍 故障排查

### 问题1：树莓派不启动（PWR灯不亮）

**检查**：
- [ ] DCP3512输出是否有5V（万用表测）
- [ ] 树莓派引脚2是否有5V（万用表测）
- [ ] GND是否接好
- [ ] SD卡是否插好（ACT灯需要SD卡才闪）

---

### 问题2：树莓派启动后频繁重启

**原因**：电压不稳定或电流不足

**检查**：
- [ ] DCP3512输出电压是否<4.8V（万用表测）
- [ ] 拔掉USB设备，只保留必要外设
- [ ] 检查其他负载（STM32/舵机）是否耗电过大

---

### 问题3：屏幕右上角显示闪电符号

**含义**：欠压警告（<4.63V）

**解决**：
- 减少USB设备
- 检查DCP3512输出能力
- 考虑用独立5V/3A适配器

---

### 问题4：树莓派能启动，但USB设备不工作

**原因**：电流不足，USB口限流

**解决**：
- 用有源USB Hub（独立供电）
- 或减少USB设备数量

## 📊 电流分配参考

假设DCP3512最大输出3A：

| 设备 | 典型电流 | 峰值电流 |
|------|---------|---------|
| STM32主控 | 100mA | 200mA |
| 夹爪舵机（空载） | 100mA | 800mA（堵转） |
| 树莓派4B | 600mA | 1.2A |
| MaixCAM（USB供电） | 300mA | 500mA |
| HDMI屏（如从树莓派USB取电） | 300mA | 500mA |
| **总计** | **1.4A** | **3.2A** ⚠️ |

**⚠️ 峰值超标**！建议：
- 舵机和屏幕用独立电源
- 或升级到5A降压模块

## 🎯 推荐配置（平衡方案）

### 配置A：树莓派独立供电（最稳定）
```
电池12V ─┬─► DCP3512 ──► STM32 + 舵机
         └─► 树莓派独立5V/3A适配器
```

### 配置B：共用DCP3512（省线缆）
```
电池12V ──► DCP3512 (5V/5A大功率型号) ──┬─► STM32
                                        ├─► 舵机（有源时）
                                        └─► 树莓派
```

### 配置C：分级供电（当前可行）
```
电池12V ──► DCP3512 (3A) ──┬─► STM32 + 树莓派（轻负载）
                           └─► 舵机空载时共用
                               舵机堵转时可能欠压 ⚠️
```

## 📷 实物接线照片参考点

**树莓派GPIO排针位置**：
- 位于电路板边缘
- 靠近40针彩带排线插座
- SD卡槽对侧

**引脚2位置**：
- 最左上角往右数第2个针
- 通常有红色或黄色标识（如果电路板有印）

**引脚6位置**：
- 引脚2下方，隔1个针
- 第3排第2个

**识别技巧**：
- 找到方形针（引脚1，3.3V）
- 它右边就是引脚2（5V）
- 往下数3个针就是引脚6（GND）
