## 🎯 如果AI需要诊断信息，运行这些命令

**在树莓派终端依次运行，把输出发给AI**:

```bash
# 1. 检查WiFi硬件状态
echo "=== WiFi网卡状态 ==="
ifconfig wlan0
echo ""

# 2. 扫描可用热点
echo "=== 扫描周围WiFi ==="
sudo iwlist wlan0 scan | grep -E "ESSID|Quality|Frequency" | head -20
echo ""

# 3. 检查欠压（供电问题）
echo "=== 欠压检测 ==="
vcgencmd get_throttled
echo ""

# 4. 检查WiFi是否被禁用
echo "=== WiFi禁用状态 ==="
rfkill list
echo ""

# 5. 查看WiFi配置文件
echo "=== WiFi配置 ==="
sudo cat /etc/wpa_supplicant/wpa_supplicant.conf
echo ""

# 6. 查看连接状态
echo "=== 当前连接状态 ==="
iwconfig wlan0
echo ""

# 7. 查看系统日志（最近错误）
echo "=== 系统日志 ==="
sudo journalctl -u wpa_supplicant -n 30 --no-pager
```

**复制所有输出，发给AI说**："这是诊断命令的输出结果，请帮我分析问题"

## 🔧 常见AI建议的快速执行

### 如果AI说"重启WiFi模块"
```bash
sudo ifconfig wlan0 down
sleep 2
sudo ifconfig wlan0 up
sudo systemctl restart dhcpcd
```

### 如果AI说"重新配置WiFi"
```bash
sudo raspi-config
# 然后选择: 1 System Options → S1 Wireless LAN
# 输入SSID和密码
```

### 如果AI说"检查供电"
```bash
# 查看当前电压
vcgencmd measure_volts

# 查看是否欠压
vcgencmd get_throttled
# 如果返回不是 throttled=0x0，说明有问题
```

### 如果AI说"重置网络配置"
```bash
# 备份旧配置
sudo cp /etc/wpa_supplicant/wpa_supplicant.conf /etc/wpa_supplicant/wpa_supplicant.conf.bak

# 编辑配置
sudo nano /etc/wpa_supplicant/wpa_supplicant.conf

# 添加/修改为：
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1
country=CN

network={
    ssid="您的热点名称"
    psk="您的热点密码"
    key_mgmt=WPA-PSK
    scan_ssid=1
}

# 保存: Ctrl+O, 回车, Ctrl+X
# 重启网络
sudo systemctl restart dhcpcd
```
