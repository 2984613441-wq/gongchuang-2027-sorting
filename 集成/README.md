# 系统集成

> 负责跨子系统接口验证、端到端测试、部署配置。

## 职责

- 多子系统联调（按方案 B 验收标准逐项验证）
- 端到端测试（完整分拣流程）
- 故障注入测试（三个恢复闸口 + 安全故障）
- 连续稳定性测试（≥100 次循环）
- 部署脚本与环境配置
- 树莓派恢复镜像制作

## 测试顺序（方案 B 第 19 节）

1. 单设备通电和基础功能
2. 两两通信测试
3. 空载单轴运动、回零、限位、急停
4. 单件闭环（识别→抓取→投放→显示确认）
5. 多件随机分拣 + 抓取前目标复核
6. 故障注入（三个恢复闸口）
7. 安全测试（急停、重力轴防坠、人工复位）
8. 15 秒边界测试
9. 峰值负载、掉压、干扰
10. 连续稳定性 + 发布包冻结

## 目录约定

- `tests/` — 集成测试用例与自动化脚本
- `deployment/` — 部署脚本、环境配置、启动脚本、镜像制作说明
