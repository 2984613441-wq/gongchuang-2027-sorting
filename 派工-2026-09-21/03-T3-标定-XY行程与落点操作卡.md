## 1. 背景（非常重要，先读懂再写）

**2026-09-21 凌晨出过一次事故**：

* 用"发步数 + 数脉冲"的方法去推 X/Y 行程，累计发出 Y 共 **24920 步 ÷ 80 步/mm = 311.5 mm**，
  而 **Y 丝杆只有 29 cm** ⇒ 算术上不可能。
* 原因：**开环步进**。滑台早就顶死了，电机继续空转丢步，而
  **`STEP_RESULT=1` 只证明"脉冲发完了"，不证明"滑台到位了"**。
* 更糟：顶死堵转导致**电流拉高 → 供电跌落 → STM32 欠压重启**（实测 `MOVES=0`、`TICK_MS` 归零）。

**⇒ 结论：不能再靠"发命令 + 数脉冲"测行程。必须实测。**

## 2. 🔴 行程口径 —— **已由用户 2026-09-21 实测定案，不要再猜**

**⇒ 两个数不是一回事：**

| | 值 | 含义 |
|---|---|---|
| **滑台机械行程** | **X = 29 cm、Y = 29 cm** | **不装夹爪**时的理论行程 |
| **装夹爪后可用行程** | **X = 18.0 cm、Y = 18.5 cm** | 夹爪会撞到东西 ⇒ **链真正能用的** |

**换算到滑台坐标**（运动原点 = HOME = 滑台 `(−95.0, −97.5)`）：

```
机械行程 29cm     ⇒ 滑台理论能到  X = −95.0 + 290 = +195.0、Y = −97.5 + 290 = +192.5
夹爪安全线 18/18.5 ⇒ 滑台只能到    X = −95.0 + 180 = +85.0
                                   Y = −97.5 + 185 = +87.5
```

🔴 **固件现在放行到 `X = +90.0`、`Y = +92.5`**（`App/Inc/ec_motion_plan.h:126-127`）
⇒ **比夹爪安全线还远 5 mm ⇒ 会超程顶死 ⇒ 丢步 ⇒ 坐标基准漂移。**
（历史事故见上一节：顶死 → 堵转 → 欠压重启 → 坐标基准全废。）
⇒ **这条要收紧，不是放宽。**

**⇒ 落点允许范围（滑台坐标）**：`x ∈ [−95.0, +85.0]`、`y ∈ [−97.5, +87.5]`
**⇒ 当前落点 `(14.5, 19.0)`**：距 HOME 只有 **10.95 / 11.65 cm**，**远在安全区内**。
