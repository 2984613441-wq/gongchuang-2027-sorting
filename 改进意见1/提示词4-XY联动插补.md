## 核心需求
将X→Y串行运动改为XY同时斜线运动：
- 使用Bresenham直线插补算法
- 整数运算，无浮点误差
- 支持任意角度直线
- 限位保护升级（XY同时监控）

## 技术方案：Bresenham插补

### 算法原理
```c
// Bresenham算法决定每步哪个轴动
if (error > -dy && x != target_x) {
    x += sx;  // X轴动
    error -= dy;
}
if (error < dx && y != target_y) {
    y += sy;  // Y轴动
    error += dx;
}
```
