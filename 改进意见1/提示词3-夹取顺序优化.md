## 📋 给新对话的完整提示词

```
你好，我有一个智能分拣项目，需要实现【夹取顺序智能优化】功能。

## 背景
- 项目：智能分拣装置（校赛比赛项目）
- 架构：MaixCAM（视觉）→ 树莓派（调度决策）→ STM32（执行）
- 问题：当前按检测顺序抓取，效率低，可能触发15秒无动作判罚

## 核心需求
设计智能调度算法，在准确性和时间之间找平衡：
- 根据置信度、位置、历史成功率动态排序
- 15秒内最大化完成数量和准确性
- **关键约束**：不允许自动跳件（赛规红线）

## 技术方案：时间分段风险策略

将15秒分为三个阶段：

```
阶段1（0-7s）：快速收割期
  → 高置信度 + 近距离
  → 目标：完成3-4件

阶段2（7-12s）：稳定填充期
  → TSP路径优化
  → 只选Safe物块

阶段3（12-15s）：保守收尾期
  → confidence>0.9 且 time<1.5s
  → 预留3s安全边界
```

## 实施步骤

### 模块1：风险分级系统（2h）
创建`电控/src/electrical_control/scheduler/risk_classifier.py`：
- RiskLevel枚举（SAFE/MEDIUM/RISKY）
- ObjectRisk数据类
- RiskClassifier类：
  - classify()方法（根据置信度+成功率分级）
  - update_success_rate()方法（贝叶斯更新）
  - _calc_distance()方法（计算欧氏距离）

### 模块2：三阶段调度器（4h）
创建`电控/src/electrical_control/scheduler/phased_scheduler.py`：
- PhasedScheduler类
- start_round()：初始化物块列表
- get_next_target()：根据阶段选择目标
- _phase1_select()：高置信度+近距离
- _phase2_select()：TSP路径优化
- _phase3_select()：超高置信度+快速
- mark_completed()：标记完成+更新成功率
- should_abort()：判断是否提前终止

### 模块3：集成到主流程（2h）
修改`电控/src/electrical_control/integration/control_flow.py`：
- 初始化PhasedScheduler
- on_batch_received()：启动调度
- _dispatch_next_target()：调度下一个
- on_item_result()：更新调度器

### 模块4：TSP优化（可选，3h）
创建`电控/src/electrical_control/scheduler/tsp_solver.py`：
- greedy_tsp()函数（贪心最近邻）
- 集成到阶段2
```
