## 三、第二轮：对抗性交叉复核（模板，按需贴给另一个 AI）

六个 AI 都回来后，如果某条结论**风险高且我无法在本机复现**，就用下面模板把它交给**另一个 AI** 挑错。

**选人规则**：不要让原作者复核自己；优先「让 Claude 复核 Codex 的补丁」「让 Codex 复核 ChatGPT 的几何算法」。

```
你是 **对抗性复核员**。你的唯一任务是**推翻**下面这份结论，不是复述它。

【待复核结论】
<把 A 的 ①②③ 段整段贴进来>

【复核要求】
1. 逐条判定：**成立 / 有条件成立 / 不成立**，并给理由。
2. **必须主动构造至少 3 个反例或反场景**：
   - 一个「参数取边界值」的场景；
   - 一个「测量存在误差」的场景（例如 ±5% 或 ±2mm）；
   - 一个「按它的做法执行后，系统在另一种输入下坏掉」的场景。
3. 找出**被隐藏的假设**：这份结论默认了什么却没写出来？（例如"默认抓取点在矩形内"、"默认舵机线性"）
4. 找出**不可复现的部分**：哪些数字没有出处、无法被独立重算。
5. 如果结论其实是对的，就明确写「**未找到反例**」——**不要为了显得有用而制造问题**。

【输出格式】
=== 复核回执 ===
复核对象: <AI 名> 的 <任务号>
各自判定: 成立 n 条 / 有条件 n 条 / 不成立 n 条
反例数: n
隐藏假设: n 条
不可复现项: n 条
最终判定: 可采纳 / 有条件采纳 / 不可采纳
=== 正文 ===

【硬红线】禁止 git；禁止实机动作；只读；不编造数值。
```
