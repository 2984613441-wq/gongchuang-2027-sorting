## 1. 采集照片的代码

### 路径

```
视觉/src/maixcam_deploy/capture.py      ← 就是这个
```

### 它做什么

在 **MaixCAM 上**运行，每 `INTERVAL_S` 秒把当前原始帧存成 JPEG，**同时用当前 YOLO 模型跑一遍检测，把结果直接写成 YOLO 格式的 draft 标签**（同名 `.txt`）。

> 这样标注时**只需要改错框/改错类，不用从零画框** —— 这是采集效率的关键设计。

### 输出格式（一一对应）

```
img_00001.jpg   原始帧，干净图，不叠任何文字/框
img_00001.txt   YOLO 标签，每行 "class_id cx cy w h"，全部归一化到 0~1
```

### 可调环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `CAPTURE_DIR` | `/root/capture` | 输出根目录 |
| `INTERVAL_S` | `1.0` | 采集间隔（秒） |
| `CONF_TH` | `0.30` | 预标注置信度阈值，**故意偏宽松**（宁可多框、人工删） |
| `IOU_TH` | `0.45` | NMS 阈值 |
| `MODEL_PATH` | `/root/my_models/model_8629.mud` | 预标注用的模型 |

### 跑法（在 MaixCAM 上）

```bash
CAPTURE_DIR=/root/capture_session01 INTERVAL_S=1.0 python3 capture.py
```

### 采集完划分数据集

```bash
python3 视觉/training/shuffle_capture.py    # 把 session 打散成 train/val
```

## 3. 标定全过程

视觉这边一共**三类标定**，互相独立，不要混。

### 标定①：像素 → 毫米（相机仿射标定）

**目的**：把图像里的像素坐标换算成机器坐标（mm），供机械臂抓取。

**原理**（`工具/calib_photo.py` 开头的说明写得很清楚）：

```
尺子       → 给【比例】：每像素多少毫米
夹爪       → 给【原点】：机器坐标 (0,0) 落在哪个像素
尺子方向   → 给【机器 +X 轴在画面上朝哪】
机器 +Y = 把 +X 在画面上逆时针转 90°（相机从上往下看，不镜像，右手定则成立）

于是 6 个仿射参数全部确定：
    x_mm = a11*u + a12*v + tx
    y_mm = a21*u + a22*v + ty
```

#### 方式 A（推荐）：一张照片 + 点 3 下鼠标

**前置要求**（不满足会算错）：

1. **尺子要平行于机器 X 轴**摆（尺子 0 点在哪无所谓，只用到刻度差）
2. **尺子和夹爪必须在同一张照片里**，且都在相机视野内
3. **相机不能歪着装**（倾斜 < 几度；程序假设垂直向下看）
4. 照片最好直接用 MaixCAM 拍（320×320）；用别的相机也行，程序会按目标分辨率折算，但**视野必须一致**

**操作**：

```bash
# 1. 让夹爪停在机器坐标 (0,0)，旁边平行 X 轴摆一把尺子，拍一张
# 2. 跑（Windows 用 py -3）
py -3 工具/calib_photo.py 照片.jpg

# 若验证发现 Y 方向反了：
py -3 工具/calib_photo.py 照片.jpg --flip-y

# 只跑数学自检，不点图：
py -3 工具/calib_photo.py --selftest
```

**输出**：打印可直接粘进 `电控/calibration_config.ini` 的 **6 行参数**，并在照片上**画出算出来的原点与坐标轴**供肉眼确认。

#### 方式 B：三点法（MaixCAM 自动找色块）

**采集**（在 MaixCAM 的 MaixVision 里跑）：

```bash
python3 视觉/src/maixcam_deploy/calib_grid.py
```

它做两件事：
1. 在预览画面上画**带坐标标签的网格**，可人工读出任何东西的像素坐标
2. 自动找出画面里**最大的纯色块**，画十字准星并打印中心像素

**步骤**：

1. 在**夹爪上贴一小块纯色胶带**（绿/红/蓝，保证能从托盘背景干净分离）
2. 确认准星稳稳跟住胶带
3. 用 `MOVE` 把夹爪依次停到 3 个位置，每停一次读一次控制台打印的 `CALIB` 行：

```bash
MOVE X DIR0 STEPS 4800 HZ 1000     # X +60mm（60mm × 80步/mm = 4800）
MOVE Y ...                          # Y +60mm
```

建议三点：**(0,0) → (+60,0) → (0,+60)**

4. 把三行抄成 `u v x y` 格式，喂给电脑上的工具：

```bash
py -3 工具/calib_affine.py
```

**相关工具**：

| 工具 | 作用 |
|---|---|
| `工具/calib_affine.py` | 用 3+ 组 (u,v)→(x,y) 拟合仿射 |
| `工具/fit_affine_conformal.py` | 带一致性/置信区间的拟合 |
| `工具/calib_joint.py` | 联合标定 |
| `工具/pi_set_affine.py` | 把仿射参数推给树莓派 |

#### 结果落到哪

写进 **`电控/calibration_config.ini`** 的 `[CameraCalibration]` 段（6 个仿射参数 + 视场尺寸 + 相机高度）。

> ⚠️ **仓库里的 `电控/calibration_config.ini` 副本已过期，真值在树莓派上**。改之前先 `scp` 下来或直接在树莓派上改。

#### 还有一层：视差补偿

因为相机在上方、物体有高度，`pixel_to_device.py` 里还做了**视差换算**：

```
scale     = camera_height / (camera_height - object_height)
x_bottom  = nadir_x + (x_top - nadir_x) / scale
```

物体高度按 `box_id` 从 `[ObjectHeights]` 里取；最后再加 `[ToolOffset]`（工具偏置）。

### 标定②：颜色 HSV

**目的**：确定 6 种颜色（红/橙/黄/绿/青/蓝）+ 黑色的 HSV 阈值窗口，供颜色分类使用。

> ⚠️ **重要更正**：`视觉/docs/标定执行计划-20261011.md` 里写"把阈值手动复制到 `color_quant.py:122-157`"——**这个说法已过期**。`color_quant.py` 里现在**没有** `COLOR_RANGES`。
> 真正生效的 HSV 阈值在 **MaixCAM 端**的：
> ```
> 视觉/src/maixcam_deploy/stage1_color_v6_send.py  的 COLOR_RANGES  （约 226-238 行）
> ```
> 还有 `MIN_COLOR_FRACTION`（约 181 行，默认 0.60 = 目标色占比门槛）。

**当前生产阈值**（`COLOR_RANGES`，H 用 OpenCV 的 0~179 口径）：

| 颜色 | H 范围 | S | V |
|---|---|---|---|
| 红（双段） | `(0,95,35)-(2,255,255)` + `(173,95,35)-(179,255,255)` | 95~255 | 35~255 |
| 橙 | `(3,95,45)-(23,255,255)` | 95~255 | 45~255 |
| 黄 | `(24,95,45)-(35,255,255)` | 95~255 | 45~255 |
| 绿 | `(36,95,35)-(84,255,255)` | 95~255 | 35~255 |
| 青 | `(85,95,35)-(104,255,255)` | 95~255 | 35~255 |
| 蓝 | `(105,95,30)-(137,255,255)` | 95~255 | 30~255 |
| 黑 | `(0,0,0)-(179,150,50)` | 0~150 | 0~50 |

**颜色 → 物料映射**（`COLOR_TO_MATERIAL`）：青→cube1、绿→cube2、红→triangular_prism3、蓝→triangular_prism4、黑→cylinder5、橙→cylinder6。

#### 标定流程

```bash
# 1. 装补光灯（环形 5V 白光灯围在相机周围）—— 必须与实际比赛光照一致
# 2. 交互式采样 6 种颜色
cd 视觉/tools
python3 color_calibration.py --camera 0 --output samples.json
#    交互：放红色物体 → 按空格采样 → 放橙色 → 继续...每种至少 20 张

# 3. 自动计算边界
python3 color_boundary_analysis.py --input samples.json --output boundaries.py

# 4. 把算出来的阈值写进 stage1_color_v6_send.py 的 COLOR_RANGES

# 5. 验证
pytest 视觉/tests/test_color_quant.py -v     # 纯逻辑
# 再加真实物料实测，目标 ≥95% 正确率
```

**验收标准**（来自标定计划）：6 色各采样 ≥20 张、HSV 边界无重叠（或重叠 <5%）、真实物料 ≥95% 正确率。

**报告模板**：`视觉/docs/颜色标定报告模板.md`
