## 🎯 核心逻辑流程

```
┌─────────────────────────────────────────────────────────────┐
│                     视觉识别主链路                              │
└─────────────────────────────────────────────────────────────┘

1️⃣ 图像输入
   ├─ 相机采集（MaixCAM俯视）
   ├─ 640×480分辨率
   └─ 转盘中央物料

2️⃣ YOLO形状检测（NPU推理）
   ├─ 模型：yolo5s_geom7c.onnx
   ├─ 7类形状：cube/cuboid/cylinder/hexagonal_prism/
   │           pentagonal_prism/square_pyramid/triangular_prism
   ├─ 置信度阈值：0.50（constants.CONFIDENCE_THRESHOLD）
   └─ 输出：bbox + class_id + confidence

3️⃣ ToF深度融合（NEW！解决俯视歧义）
   ├─ 触发条件：shape in [cylinder, triangular_prism, cube]
   ├─ ToF读取：物体高度（mm）
   ├─ 计算高宽比：height_mm / (bbox_width_px × px_to_mm)
   ├─ 应用判据：
   │   • 圆柱 vs 球：H/W > 1.2 → cylinder, < 0.8 → sphere
   │   • 三棱柱 vs 正四面体：H/W > 0.8 → prism, < 0.6 → tetrahedron
   │   • 正方体 vs 四棱锥：0.9 < H/W < 1.1 → cube, < 0.6 → pyramid
   └─ 输出：精确形状（8类）

4️⃣ MMCQ主色提取
   ├─ 裁剪bbox区域
   ├─ HSV色彩空间
   ├─ 6色窗口：红/橙/黄/绿/青/蓝
   ├─ 特殊判定：
   │   • 低饱和度（s < 0.12）→ 黑/白/灰
   │   • 低亮度（l < 0.15）→ 黑
   │   • 高亮度（l > 0.85）→ 白
   └─ 输出：color_name（英文）

5️⃣ 显示名称映射（NEW！）
   ├─ 形状中文：cube → "正方体"
   ├─ 颜色中文：red → "红"
   └─ 输出："红正方体"（用于显示）

6️⃣ 分箱决策
   ├─ 查表：COLOR_TO_MATERIAL[(color, shape)]
   ├─ 输出：(material_name, bin_id)
   └─ 下发：ITEM_TASK消息给电控

7️⃣ Fail-Closed安全机制
   ├─ 置信度 < 0.50 → 拒绝输出
   ├─ 主色 = "unknown" → 拒绝输出
   ├─ ToF置信度 < 0.7 → 返回YOLO预测
   └─ 映射表找不到 → 报错

┌─────────────────────────────────────────────────────────────┐
│                     降级预案（ToF失败时）                        │
└─────────────────────────────────────────────────────────────┘

形状特征分类（shape_features.py）
   ├─ 轮廓提取
   ├─ 面积/周长比
   ├─ 凸包差异
   └─ 输出：shape分类（精度低于ToF）
```

## 🎨 颜色识别逻辑

### HSV 6色窗口（color_quant.py:122-157）

```python
# 主色判定（按H色相）
红色：  (0-15°)  或 (345-360°)
橙色：  15-45°
黄色：  45-70°
绿色：  70-165°
青色：  165-200°
蓝色：  200-255°

黑色：  l < 0.15 (低亮度)
白色：  l > 0.85 (高亮度)
```

## 🔺 形状识别逻辑

### YOLO 7类（校赛已验证）

```
0: cube              正方体
1: cuboid            长方体
2: cylinder          圆柱 ⚠️ 歧义（vs 球）
3: hexagonal_prism   六棱柱
4: pentagonal_prism  五棱柱
5: square_pyramid    四棱锥 ⚠️ 歧义（vs 正方体）
6: triangular_prism  三棱柱 ⚠️ 歧义（vs 正四面体）

❌ 缺失：regular_tetrahedron 正四面体（需补采）
```

### ToF深度融合判据（depth_fusion.py:15-20）

**三组俯视歧义解决方案**：

```python
# 组1：圆柱 vs 球
if height_ratio >= 1.2:  # 高宽比 > 1.2
    return "cylinder"    # 圆柱（高）
elif height_ratio <= 0.8:
    return "sphere"      # 球（矮）
else:
    return yolo_shape    # 歧义范围，信任YOLO

# 组2：三棱柱 vs 正四面体
if height_ratio >= 0.8:
    return "triangular_prism"
elif height_ratio <= 0.6:
    return "regular_tetrahedron"
else:
    return yolo_shape

# 组3：正方体 vs 四棱锥
if 0.9 <= height_ratio <= 1.1:  # ±10%容差
    return "cube"                # 正方体（高≈宽）
elif height_ratio <= 0.6:
    return "square_pyramid"      # 四棱锥（矮）
else:
    return yolo_shape
```

**阈值来源**：
- 初始值基于标准几何（cube高=宽，pyramid高=0.5-0.7×底边）
- ⚠️ 需要现场标定（ToF实测后调整）

## 🛡️ Fail-Closed安全机制

### 三道防线

**防线1：YOLO置信度**
```python
if confidence < constants.CONFIDENCE_THRESHOLD:  # 0.50
    return None  # 拒绝输出
```

**防线2：颜色识别**
```python
if color == "unknown":
    return None  # 无法确定颜色，拒绝
```

**防线3：ToF置信度**
```python
if depth_reading.confidence < 0.7:
    return yolo_shape  # 降级到YOLO，不强制深度
```

**防线4：映射表**
```python
if (color, shape) not in COLOR_TO_MATERIAL:
    raise ValueError  # 未知组合，停机
```

## 🎓 关键设计决策

### 决策1：ToF深度融合 vs 形状特征

**选择**：ToF深度融合为主路线  
**理由**：
- 物理测量直接可靠（高度是真实值）
- 判据简单（高宽比，易标定）
- 校赛未验证形状特征精度

**保险**：形状特征作为降级预案保留

### 决策2：统一置信度阈值0.50

**原因**：`config.py`和`vision_loop_template.py`不一致  
**方案**：全局使用`constants.CONFIDENCE_THRESHOLD = 0.50`  
**依据**：校赛经验（5/5成功）

### 决策3：暂缓改造生产链

**原因**：时间成本8天，投入YOLO重训更划算  
**记录**：`docs/决策记录/决策-视觉生产链改造-暂缓-20261011.md`
