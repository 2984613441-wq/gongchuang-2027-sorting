### 1. 协议改动（高4位+低4位）✅

**文件**：`视觉/src/sorting_vision/encoding.py`

**核心功能**：
```python
# 编码：将颜色+形状打包成单字节
image_id = encode_color_shape("red", "cube")  # 返回 0
image_id = encode_color_shape("blue", "cylinder")  # 返回 82

# ... 现场填写24件映射
```

**新建文件**：`电控/host/vision_decoder.py`

```python
from sorting_vision import decode_color_shape
import configparser

config = configparser.ConfigParser()
config.read('vision_config.ini')

def get_bin_from_image_id(image_id: int) -> int:
    """从编码的image_id查询盒号"""
    color, shape = decode_color_shape(image_id)
    key = f"{color}_{shape}"
    return config.getint('bin_mapping', key)
```
