## 🔌 硬件连接指南

### VL53L1X（I2C）连接

```
VL53L1X模块 → 树莓派GPIO
━━━━━━━━━━━━━━━━━━━━━━━━
VCC (3.3V)  → Pin 1  (3.3V Power)
GND         → Pin 6  (Ground)
SDA         → Pin 3  (GPIO2/SDA)
SCL         → Pin 5  (GPIO3/SCL)
```

**连接后验证**：
```bash
# 启用I2C（如未启用）
sudo raspi-config
# Interface Options → I2C → Yes

# 重启
sudo reboot

# 检测I2C设备
i2cdetect -y 1
# 应该看到 0x29 地址
```

### TF-Luna（UART）连接

```
TF-Luna模块 → 树莓派GPIO
━━━━━━━━━━━━━━━━━━━━━━━
VCC (5V)    → Pin 2  (5V Power)
GND         → Pin 6  (Ground)
TX          → Pin 10 (GPIO15/RXD)
RX          → Pin 8  (GPIO14/TXD)
```

**连接后验证**：
```bash
# 启用UART（如未启用）
sudo raspi-config
# Interface Options → Serial Port →
#   "login shell over serial?" → No
#   "serial port hardware?" → Yes

# 重启
sudo reboot

# 检查设备
ls -l /dev/ttyAMA0
# 应该存在
```

### 2. 快速验证脚本

创建 `/home/pi/test_tof_quick.py`：

```python
#!/usr/bin/env python3
"""快速验证ToF模块是否工作"""
import time

# VL53L1X版本
try:
    import board
    import adafruit_vl53l1x
    i2c = board.I2C()
    sensor = adafruit_vl53l1x.VL53L1X(i2c)
    sensor.start_ranging()
    
    print("VL53L1X初始化成功！")
    for i in range(10):
        if sensor.data_ready:
            dist = sensor.distance
            if dist:
                print(f"样本{i+1}: {dist*10:.1f}mm")
        time.sleep(0.2)
    
    sensor.stop_ranging()
    print("✓ VL53L1X工作正常")
except Exception as e:
    print(f"VL53L1X失败: {e}")

#             dist_cm = data[2] + (data[3] << 8)
#             print(f"样本{i+1}: {dist_cm*10:.1f}mm")
#     time.sleep(0.2)
# ser.close()
```

**运行验证**：

**预期输出**：
