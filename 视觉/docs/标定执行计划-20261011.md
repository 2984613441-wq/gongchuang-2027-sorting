## 📋 标定清单

### 1️⃣ ToF深度标定（本周末，2-3小时）⚠️ 优先级最高

**为什么先做**：
- ToF硬件已到货，可以立即开始
- 不依赖实验室环境（在宿舍/家里即可）
- 验证形状识别核心能力

**准备材料**：
```
硬件：
✓ ToF传感器（VL53L1X或TF-Luna）
✓ 树莓派
✓ 杜邦线×4根
⏸️ 测试物体：圆柱/球/正方体/四棱锥/三棱柱（任意3个即可开始）

工具：
✓ 卡尺（测量真实尺寸）
✓ test_tof_integration.py（已准备）
✓ ToF集成实测指南.md（详细操作手册）
```

**执行步骤**（按`ToF实测准备清单-20261011.md`）：

```bash
# 1. 连接ToF硬件（15分钟）
# VL53L1X（I2C）：VCC→Pin1, GND→Pin6, SDA→Pin3, SCL→Pin5

# 2. 验证ToF工作（5分钟）
python3 test_tof_quick.py
# 预期输出：10个稳定读数

# 3. 基础读数测试（30分钟）
cd ~/工创赛/视觉/tests
python3 test_tof_integration.py --sensor vl53l1x --mode reading --samples 20
# 检查：标准差<5mm

# 4. 消歧测试（1小时）
python3 test_tof_integration.py --sensor vl53l1x --mode disambiguation
# 测试6个物体（按提示放置）
# 目标：正确率≥83%（5/6）

# 5. 阈值标定（如需要，1小时）
# 只有消歧测试失败时才做

# 6. 填写报告（30分钟）
# 生成：ToF集成实测报告-YYYYMMDD.md
```

**验收标准**：
- ✅ 基础读数标准差<5mm
- ✅ 消歧测试正确率≥83%
- ✅ 填写完成实测报告

**如果没有标准测试物体**：
- 用生活中的物品也可以（只要能区分高矮）
- 例如：易拉罐(圆柱) vs 乒乓球(球)
- 例如：骰子(正方体) vs 金字塔糖果(锥)

### 2️⃣ 颜色HSV标定（Week 3，0.5天）⚠️ 需到实验室

**为什么Week 3才做**：
- 需要到实验室（实际光照环境）
- 依赖补光灯安装（Week 2采购）
- 需要6种颜色的实物（省赛物料）

**准备材料**：
```
硬件：
⏸️ MaixCAM相机
⏸️ 补光灯（5V白光LED，Week 2采购）
⏸️ 6色物料（红/橙/黄/绿/青/蓝实物）

工具：
✓ color_calibration.py（交互式采样）
✓ color_boundary_analysis.py（自动计算边界）
✓ 颜色标定报告模板.md
```

**执行步骤**（按`颜色标定报告模板.md`）：

```bash
# 1. 安装补光灯（30分钟）
# 环形灯安装在相机周围

# 2. 采样6种颜色（20分钟）
cd ~/工创赛/视觉/tools
python3 color_calibration.py --camera 0 --output samples.json
# 交互式：放置红色物体 → 按空格采样 → 放置橙色...

# 3. 分析边界（5分钟）
python3 color_boundary_analysis.py --input samples.json --output boundaries.py
# 自动计算HSV边界

# 4. 更新color_quant.py（10分钟）
# 手动复制boundaries.py的阈值到color_quant.py:122-157

# 5. 验证测试（10分钟）
pytest tests/test_color_quant.py -v
# 真实物料测试：≥95%正确率

# 6. 填写报告（15分钟）
# 记录原始数据+边界值
```

**验收标准**：
- ✅ 6色各采样≥20张
- ✅ HSV边界无重叠（或重叠<5%）
- ✅ 真实物料测试≥95%正确率

**应急方案**：
1. Week 5再标定（省赛前1周）
2. 使用当前占位值（风险：颜色误判）

1. 用生活物品替代（易拉罐、乒乓球、骰子等）
2. 只测试高度差异，不要求标准尺寸
3. 标定相对阈值（相对高矮即可）
