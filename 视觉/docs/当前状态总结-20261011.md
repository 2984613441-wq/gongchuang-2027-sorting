## 💡 核心架构（7步识别流程）

```
1️⃣ 图像输入（MaixCAM）
     ↓
2️⃣ YOLO形状检测（7类 → 待升级8类）
     ↓
3️⃣ ToF深度融合 ⭐ NEW（解决俯视歧义）
     ├─ 圆柱 vs 球
     ├─ 三棱柱 vs 正四面体
     └─ 正方体 vs 四棱锥
     ↓
4️⃣ MMCQ主色提取（HSV色彩空间）
     ↓
5️⃣ 显示名称映射 ⭐ NEW（中文显示）
     ↓
6️⃣ 颜色/形状编码 ⭐ NEW（高4位+低4位）
     ↓
7️⃣ 分箱决策（树莓派查.ini配置）
```

**降级链路**：
```
ToF失败 → YOLO纯视觉
YOLO低置信 → 形状特征分类
特征低置信 → Fail-closed拒绝
```
