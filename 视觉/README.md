# 视觉子系统

> 负责 MaixCAM Pro 上的 YOLO 模型部署与结构化视觉输出。

## 职责

- YOLO 模型训练/微调（如有需要）
- 模型部署到 MaixCAM Pro
- 图像采集与预处理
- 目标检测与分类（颜色、形状、文字、二维码）
- 结构化输出（类别 ID、置信度、机械坐标、可选抓取角度）
- 单件复核（每件抓取前重新运行 YOLO）
- 可选诊断二次核验（默认关闭，不进入校赛主链）

## 明确不承担

- 不向树莓派传输原始视频用于二次 YOLO
- 不直接控制执行器
- 不负责机械坐标变换的物理标定（标定参数由机械安装决定，视觉只使用标定结果）

## 输出到电控的接口

必须输出的结构化数据（通过方案 B 的 MaixCAM→树莓派链路）：

| 字段 | 格式 | 说明 |
|------|------|------|
| 任务号 | uint16 | 每轮递增 |
| 目标数量 | uint8 | 整批识别结果数 |
| 类别 ID | uint8 | 预定义的货物类别 |
| 置信度 | uint8 (0-100) | |
| X 坐标 | uint16 (0.1mm) | 机械坐标系 |
| Y 坐标 | uint16 (0.1mm) | 机械坐标系 |
| 抓取角度 | uint8 (0-180) | 0xFF=无效 |
| 角度有效标志 | 1 bit | |

详见 [接口契约](../docs/design/interface-contract.md)。

## 目录约定

- `src/` — 推理/预处理脚本（MaixCAM 端 Python）
- `models/` — YOLO 权重文件（.kmodel / .onnx）
- `datasets/` — 训练/测试数据集（如有）
