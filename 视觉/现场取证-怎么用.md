## 4. 拍完要回答的 3 个问题（答案从 stdout 里读，**别靠猜**）

**① 三角面朝上时掩膜是整条边暗、中间过曝、还是碎成块？**

| 现象 | stdout 里的特征 | 对应判据 |
|---|---|---|
| 中间过曝 | `c4_color_frac > 0`（环形/中空掩膜）+ `bright_px(V>=150)` 占比高 | `:254-255` |
| 整条边暗 | `contours=1`、`extent` 略低于理论值、`morphed_px < raw_px` | `:241-242` |
| 碎成块 | `contours` 偏大、多数轮廓 `REJECT :235-236 area`、`extent < 0.35` | `:235-236` |
| 整块消失 | 该色 `morphed_mask_px = 0`，看 `mask_H` 与 H 直方图落在哪个窗口 | `:184-192` |
| 被画面/黄框丢 | `clip=roi` 或 `clip=frame` | `:239-240`（**V1b/T1 领地，本轮不改**）|

**② 该姿态下 extent 实测值是多少？**
stdout 每行 `extent=`，直接抄。对照理论值（等边三角形 40mm 件随朝向）：

```
extent ∈ [0.4641, 0.5000]   aspect ∈ [0.8660, 1.0000]
正方形 extent = 1.0000      圆盘 extent = 0.7854
```

⇒ 实测若**明显低于 0.4641**，就是掩膜缺块（三角形对缺块的容差只有正方形的 ≈1/2.2）。

**③ 红件/橙件各面的 H 分布**（供决定是否动 `:184-192`）
读 stdout 的 `H_histogram`（36 桶 × 5，ROI 内 `S>=95 & V>=35`）与每色 `mask_H(min/med/max)`。
红窗口 `:185` = H∈[0,2]∪[173,179]；橙窗口 `:186` = H∈[3,23]。

⇒ 若红件有面落进 `H[3-4]`（橙窗口）→ 该面会被判成**橙圆柱 bin6**（投错盒）。
若红件某个面整块不出现 → 看它是不是 V/S 掉出窗口（属 `:184-192` 参数问题，**本轮只记录不修改**）。
