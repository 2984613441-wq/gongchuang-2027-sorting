## 二、🔴 由裁决推出的两条重要结论

### 结论 1：`model_8766.mud` 是**唯一正确**的模型

三个 `.mud` 的 `model_type` **不一样**（本节点已逐个解出内容）：

| `.mud` | `model_type` | 配 `main.py:375` 的 `nn.YOLOv8`？ |
|---|---|---|
| **`model_8766.mud`** | **`yolov8`** | ✅ **匹配 —— 用这个** |
| `model_8622.mud` | `yolo11` | ❌ 不能用 |
| `model_8629.mud` | `yolo11` | ❌ 不能用 |

三个都在 `C:\Users\29845\Downloads\maixhub-model-convert-maixcam-*.zip`。

**`.mud` 是 300 字节的 INI 描述符**（不是模型本体，本体是 2.99 MB 的 `.cvimodel`）：

```ini
[basic]
type = cvimodel
model = model_8766.cvimodel
[extra]
model_type = yolov8          ← 决定 main.py 该用nn.YOLOv8 还是别的
type = detector
input_type = rgb
labels = cube, cuboid, cylinder, hexagonal_prism, pentagonal_prism, square_pyramid, triangular_prism
mean = 0, 0, 0
scale = 0.00392156862745098, 0.00392156862745098, 0.00392156862745098
```

**所以 `main.py:28` 的 `MODEL_PATH = "/root/my_models/model_8766.mud"` 本来就是对的。**

> ⚠️ **⚠️ 但 8629 的来源已查明是另一条训练线**：
> `D:\AAAdesktop1\shijue\ultralytics-8.3.163\runs\block_detector\block_yolo11n_e100\weights\model_8629.{mud,cvimodel}`
> → **8629 是 YOLO11n 训出来的**，与工作区的 `yolo5s_geom7c` **不是同一个模型**。

| 项 | 值 |
|---|---|

**真正的弱类**（报告自己点出来的）：

| 弱类 | 问题 | 建议 |
|---|---|---|
| `cuboid` | 最弱（mAP50 0.778，召回 0.65），**样本最少（94 框）** | 补采样本 |
| `square_pyramid` | **召回最低 0.545** → 大量漏检，易与其它棱锥/棱柱混淆 | 补采 + 降阈值 |
| `triangular_prism` | **精度最低 0.655** → 误检偏多 | 补采 |

> 💡 **旁证**：`视觉/src/maixcam_deploy/main.py:44` 的
> `ACTIVE_CLASS_IDS = frozenset({0, 2, 3, 4, 5, 6})` **排除了 class 1 = `cuboid`**
> —— 与训练报告"cuboid 最弱"**互相印证**，不是随手写的。

⚠️ **但要注意**：排除 cuboid 后 **active 只有 6 类**，而赛题要求 **≥6 种**。
现场若抽到长方体 → **拒识或误判 → 分错盒 = 零分**。
