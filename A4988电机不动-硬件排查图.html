A4988 电机完全不动 —— 硬件排查决策图

STM32F407 + A4988（脉冲/方向）｜现象：固件报「命令已启动 / 剩余步数=0 / 结果=完成」，电机物理完全不动、无异响无堵转声｜2026-09-18

症状指纹（先读这一句）

无声 + 计数完成 = 两个最可能的方向：① 线圈从头到尾没有电流（EN 未使能 / VMOT 缺失 / Vref=0 / 不共地 / 保护锁死 / 线圈断）；② STEP 沿根本没到驱动（线缆断、接错、或 MCU 引脚没输出）。第一步用三个测量分流，不猜。

已核对（当前工作树源码）：MOVE 路径为 set_direction → enable_axis(拉低 EN) → 500Hz PWM 启动（ec_axis_driver.c:228；EC_AXIS_MOVE_FREQUENCY_HZ=500）；「剩余步数」由定时器溢出中断逐次递减（ec_board_stm32.c:485）——定时器跑满计数 ≠ STEP 引脚有输出。

三问分流（第 0 步，约 3 分钟）

症状：固件报「完成 / 剩余步数=0」、电机完全不动、无声
↓
Q1　上电使能后，手动盘电机轴 —— 有没有保持力矩？
（有力矩=电流通路 OK，问题在 STEP 通路；无力矩=电流通路没建立）
↓ 分流
无保持力矩 →「线圈无电流」族（按序查，10 秒/项）
  • ① EN 电平（X=PA5 / Y=PD7）：运动时 ≤0.8V
  • ② VMOT：8–35V，运动不掉压（先查动力电源/保险/急停）
  • ③ VREF 电位器：>0V（≈0.8V@1A，Rs=0.1Ω）
  • ④ 共地：MCU GND ↔ 驱动 GND <0.3V
  • ⑤ nSLEEP / nRESET：≥2V
  • ⑥ 保护：VMOT 电流≈0 / 芯片温度 / 断电重上电复测
  • ⑦ 线圈：1A-1B / 2A-2B 阻值 1–10Ω、两相对称
  • ⑧ 换一块已知好模块对比
对应清单：T0-1～4、T1-7/8/9、T2-10/12
有保持力矩 →「STEP 通路」族
Q2　示波器测 MCU STEP 脚（X=PC6/TIM8_CH1，Y=PB6/TIM4_CH1）
命令期间应有 500Hz 方波串（高≈1ms），数量=80×mm（10mm→800 个）
├─ 无脉冲 → 固件层：定时器在跑但引脚没输出（GPIO AF / TIM8 MOE / 台上固件版本不同）→ 交固件侧
└─ 有脉冲 →
Q3　测驱动板 STEP 脚
├─ 无脉冲 → 断线 / 虚焊 / 接错脚 / 排针接触不良（T1-5）
└─ 有脉冲 → 量脉宽：高、低各 ≥1µs（当前树 500Hz/50% 高≈1ms，此原因概率极低）
脉宽正常仍不动 → 相线接错 / 线圈断路（T2-10）+ 盘轴确认机械未卡死

梯队排查清单（按「可能性 ÷ 验证成本」排序，先做 T0）

#成因① 机理（一句）② 判定（万用表 / 示波器）③ 预期读数
T01EN 未生效（极性低有效 / 悬空 / 线缆断） EN 为高或悬空时 A4988 输出级全关断、线圈零电流；固件只按自身状态机报完成。 运动命令期间，分别量 MCU 的 EN 脚与驱动板 EN 脚（参考各自 GND）。 两处均 ≤0.8V；MCU 低而板高 → 线断/虚焊/接错/共地；两处都高 → 固件未使能（台上版本/命令路由）。
T02VMOT 缺失或 <8V 功率级无供电（或低于 8V 超规格）→ 全桥不斩波、线圈零电流。常见翻车：主控板由 USB/调试器供电正常，VMOT 独立电源没开/保险断/急停回路断开。 量驱动板 VMOT 对 GND；顺带查动力电源开关、保险、急停、端子压接。 8–35V（典型 12/24V），运动期间不掉压；0V=没供上，5V=超规格。
T03限流电位器归零（Vref≈0） Vref=0 → 峰值电流=0，驱动器"在运行"但线圈无电流，电机无力矩无声（新模块常出厂归零/过低）。 驱动上电，量 VREF 脚（电位器中心抽头）对 GND。 I=Vref/(8·Rs)；Rs=0.1Ω 时 1A↔0.8V；17HS4401 按 1.7A → ≈1.36V（Rs 以模块实际为准）；≈0V → 命中。
T04MCU 与驱动器不共地 两套地参考不一致 → STEP/EN 电平相对驱动逻辑阈值乱飘，信号无效甚至不定态。 万用表直流档量 MCU GND 与驱动 GND；测信号一律以驱动板 GND 为参考。 <0.3V；>1V 即异常。
T15STEP 未到达驱动板（断线/虚焊/接错/排针） 定时器在 MCU 内跑满、固件报完成，但 STEP 沿断在物理链路，驱动收不到 → 不动（此时保持力矩应正常）。 示波器先测 MCU STEP 脚（PC6/PB6），再测驱动板 STEP 脚；必要时量线缆通断。 MCU 脚：500Hz 方波串（高≈1ms），数量=80×mm；驱动板脚同形；板脚平线 → 线缆问题；MCU 脚无脉冲 → 固件层。
T16STEP 脉宽过窄 / 频率超限 A4988 要求 STEP 高、低各 ≥1µs：脉宽过窄沿被忽略（完全不动），频率过高丢步/失步（通常有声）。 示波器量 STEP 高/低脉宽与频率；DIR 变化到 STEP 沿 ≥200ns。 高≥1µs、低≥1µs。当前树固件 500Hz/50%（高≈1ms）远大于下限，此原因概率极低；仅当台上版本不同/改过频率时重点复查。
T17nSLEEP / nRESET 被拉低或悬空 nSLEEP 低 → 全桥休眠零输出；nRESET 低 → 逻辑复位不工作。模块一般默认上拉，裸片/个别模块需自查。 万用表量 nSLEEP、nRESET 对 GND。 ≥2V；≈0V → 命中。
T18动力电源带载跌落（功率不足/线阻过大） 空载量着够，一斩波就被拉垮到 <8V（欠压），驱动反复关断 → 不动或抖动。 万用表/示波器挂 VMOT，发运动命令同时观察。 运动期间始终 ≥8V；塌陷 → 电源功率不足/线太细/端子接触电阻大/大电解电容缺失。
T19过流 / 过热保护锁死（OCP/TSD） 相线短路/错接触发内部 OCP，或持续大电流过热触发 TSD，输出级关断 → 无力矩无声（多数模块无 FAULT 灯，只能靠测量）。 摸芯片温度；串电流表量 VMOT 电流；断电重上电后复测同一命令。 正常斩波：芯片温热、VMOT 电流数百 mA~A 级；锁死：电流≈0。重上电恢复但一运动又锁 → 先查电机短路（相间/对壳）。
T210相线接错 / 线圈断路 两相交叉错接或某一线圈断路 → 合成磁场失效/力矩极弱：双断完全不动、单断微抖或不动。 断电拔线，电阻档分别量 1A-1B、2A-2B，再量相间、对机壳。 同相 1–10Ω 且两相对称（差<10%）；相间/对壳 OL；断路 → OL（∞）。
T211微步跳线 MS1/MS2/MS3 只改变步距与电流形状，不改变"是否转动"——几乎不可能是完全不动的原因（作排除项）。 量 MS1-3 电平对照真值表；你们固定 1/16（三脚全高）。 与目标细分一致即可；即便不一致只会位移量错误，不会完全不动。
T212驱动器 / 模块损坏 输出级烧毁或模块故障，无斩波无电流。 前 11 项全过后，换一块已知好模块（同供电/同信号）对比。 好板命令时有斩波电流/电机转动；坏板没有。换板前先核对接线与限流，避免再烧。
排除项（看着像、不会导致「完全不动」）：STEP 与 DIR 接反（仍会动，只是方向/动作怪异）；串口/波特率（固件都回完成了，链路正常）；机械卡死（有电流时会堵转啸叫，本现象无声，但盘轴确认最稳）；微步细分（见 T2-11）。
